## ⚠ 왜 브라우저 패널에서 재면 안 되나

작업대를 클로드의 브라우저 **패널**에서 몰아 보면, 패널이 숨겨져 있을 때
(`document.hidden`) 브라우저가 그 화면을 스로틀링한다. 그때 잰 값은 전부
거짓이다 — 한 면 넘기는 데 12초가 걸리고 본줄이 60초씩 멈춘 것처럼 보였다.
같은 일을 **보이는 창**에서 재니 전권 30면 2.0초 · 60면 2.0초였다.

성능·타이밍이 걸린 판단은 반드시 이 스크립트(실제 창)로 다시 잰다.

## ⚠ 책을 건드린다

점검은 진짜 책 폴더를 고친다(넣고·바꾸고·되돌린다). 스크립트는 끝에서
이력을 되감지만, **납품 중인 책에는 돌리지 말 것**.
