**금지 (2026-08-26 지시, 해제 전까지 전 교재 적용)**

- **더스티 모브코럴** `#DB9488` 계열 — 붉은 주황(색상환 25~35)을 중간 밝기로 낮춘 색
- **세이지 그린** `#81B98C` 계열 — 녹색(색상환 145~160)을 중간 밝기로 낮춘 색

사용자 말: *"이거 두개가 너무 칙칙하고 예쁘지도 않아. 이런 색깔은 내가 먼저 쓰라고
하기 전까지 쓰지 마."*

**Why:** 채도를 낮춰 "뮤트 톤"을 만들 때 **밝기까지 같이 내리면** 이 두 색상환은
탁한 흙빛(모브·세이지)으로 빠진다. 사용자가 원하는 뮤트 파스텔은 **채도만 낮추고
밝기는 올린** 색이다. 같은 색상환이라도 L 0.80 이상으로 올리면 애프리콧·민트가 되어
문제없다 — 색상환이 아니라 **밝기가 원인**이다.

**How to apply:** 뮤트 파스텔을 만들 때 OKLCH 로 **L 0.80~0.86 / C 0.09~0.10** 을 쓴다
(L 0.70 이하로 내리면서 채도만 깎지 말 것). 흰 글자를 얹을 진한 색은 L 0.50 / C 0.12~0.135
로 따로 잡되, **따뜻한 색상(20~110)은 어두워지면 갈색·올리브로 빠지므로** 진한 색만
색상을 조금 돌려(예: 주색 48 → 진한색 32) 흙색이 아니라 테라코타로 만든다.
색상환 60~110(노랑)은 진한 색이 올리브가 되어 답이 없으니 주색으로 쓰지 않는 편이 낫다.

**검증 방법:** 최종 조판 전에 주색+진한색 조합을 스와치로 뽑아 눈으로 볼 것.
확정된 하우스 색감은 [[project_middle_regular_gachisaegim]] 의 팔레트 절 참고
(완성본 실측: 유채색 C 0.06~0.10 / L 0.68~0.85).
