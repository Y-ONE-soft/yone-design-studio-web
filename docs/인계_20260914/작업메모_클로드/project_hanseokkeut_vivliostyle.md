**한서끝 = 한영고 서술형 끝**(한단끝·한문끝과 같은 한끝 계열 특강 교재), 문제형.
책 폴더 `조판/교재/특강교재/한서끝/26-2-중간/한영1/` (README.md 먼저). 계열 `core/render_vivlio/series/hankkeut/`.

**확정 원고(2026-09-13)** = 드라이브 `콘텐츠 관리/내신대비/2026년/고1/한영고1/3. 26-2-중간/한서끝`
의 `한서끝 문제지.docx` + `한서끝 정답및풀이_학생용.docx` (로컬 `원고/` 사본). 9/8 초안(세트 [1~2]·
Part 1/2)과 **형식이 완전히 달랐다** — 40 단독 문항 `[서답형 N] 발문 〈출처〉`, 6유형
(요약13·어법5·내용 질문5·일치8·배열4·낱말5), 파트 표지 없음. 초안 파서는 버리고 새로 썼다.
정답및풀이도 받았으니 **PART 02 정답 및 풀이**(빠른 정답 표 + 문항별 풀이 2단)로 붙였다. 56p.

**사용자 지면 규칙**: 한 면 위·아래 두 칸, 칸에 안 들어가면 위 칸 차례=아래 칸 삭제 / 아래 칸
차례=비우고 다음 면 통째. 1면·끝 면 간지 1P, 파트 간지 2P.

**Why:** 원고보다 레이아웃을 먼저 잡았다가 확정 원고로 갈아탔다 — 렌더·배치·간지는 그대로 살고
data.py 와 블록 몇 개만 새로 들었다(구조가 분리돼 있어 가능).

**How to apply:**
- 구조 판정: `[라벨]` 목록 상자는 항목 언어로 보기/조건 가름(라벨 이름 X), 지문 뒤 `k.` 줄 = 배열 조각,
  `↓` 뒤 = 요약문. 게이트 = 원고 머리 구성 줄 vs 구조 판정, 요약문 글자 칸 vs 답란 첫 글자, 정답지
  유형·출처·정답 교차 — **망가뜨린 입력으로 fail 확인함**.
- 함정: 단어(구) 칩을 공백 없이 붙이면 줄바꿈 기회가 없어 판면을 뚫는다 · 영작 답 줄 도입부 칸은
  `width:1%;nowrap` · 풀이 속 ○/✕ 가 줄 머리에 오면 G-글리프 결함 → 도형(`mk-o/mk-x`).
- 정답 파트 면 수는 어림이라 패리티 루프가 한 번 더 굽는다(정상).
- 2026-09-14: 내지 54p(무선 기본, multiple 2) · 간지 문구 "한영고내신/필수서술형/완벽대비끝" 확정 · 왼쪽 꼬리 "2026 한영고1 한서끝".
- 표지는 일러스트로 `디자인/표지/한서끝/한영1_한서끝_표지.ai·pdf` — **대지 2개(겉표지+안쪽면) 둘 다** 세네카 3mm, PDF 2쪽,
  RGB→CMYK 변환 저장. 원래 한문끝(수정).ai 작업 상태는 같은 폴더 `…_작업중백업_20260914.ai`.
  ⚠ 처음에 안쪽면 대지를 빼먹어 지적받음 — 표지 대지가 여럿이면 전부 처리. JSX 는 UTF-8 BOM 필요, 파일명 비교는 NFD 라 실패.
- 미결: TTJamak 없음(마루부리), 표지 바탕 질감 51dpi(고해상도 원본 or 한단끝 5615px 이미지 재색 — 사용자 결정 대기), 안쪽면 목업 3개 133dpi(링크 끊김).
- 한영2(서답형 형식 다름)는 아직.
