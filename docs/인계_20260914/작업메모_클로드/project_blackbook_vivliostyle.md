**블랙북01 = 배재고1 26-2-중간 프리미엄북**(교과서 공통영어2 능률 1·2과). 사용자가 "비블로
스타일"(=Vivliostyle)로 지시 → **InDesign 아님**. 스크립트 = `Y.ONE STUDIO/조판/교재/프리미엄북/
블랙북/26-2-중간/automation/` (**README.md 먼저**). A4+도련3 = 216×303mm, **129쪽 / 빌드 16초**(측정+조판 2패스).

순서 = 1과 연관어휘 → 1과 문제 → 2과 연관어휘 → 2과 문제 → 1과 해설 → 2과 해설.
디자인은 **수정된 인디자인 원본**(`[원본]배재1_블랙북_Part_내지.indd` = 출력물 `블랙북_1_v2_9.pdf`)
에서 실측 이식. 간지·MEMO·뒤표지는 그 PDF의 실제 쪽을 build.py 가 끼워 넣는다.

- 파이프라인: `gen_data.py`(docx6 → data.json + 인식 게이트) → `render.py`(→ build/index.html) →
  `build.py`(서체·assets 배치 + CLI + 간지 삽입 + TrimBox) → `verify.py`(원고↔PDF 1,250항목 전수 대조).
- 머리말·해설 = **원고대로**(1차엔 능률(민)·해석 제외로 냈다가 사용자 지시로 되돌림):
  `SUBJECT='공통영어2 능률(오)'`, 해설은 정답→**해석**→해설 전부. 129쪽.
- 문항 번호는 원고 그대로 1~65 / 66~130(해설과 1:1).
- **한 면 2문항 가변 배치**: build.py 가 문항만 한 면 1개씩 조판해 natural height 실측
  (heights.json) → render.py 가 짝지어 위 문항 슬롯을 줄인다(둘 다 짧으면 반반 122.5mm).
- **빈칸**: 원고의 `     (A)     `(3칸+ 공백)은 밑줄 빈칸(.blk), 공백-라벨-공백을 **이어 붙여** 밑줄이
  끊기지 않게. 밑줄 전부 0.5pt/offset 0.5mm.
- **대화문**(`A:`/`American Sam:`/이름:) = 옅은 바탕(--dlg). 판정은 **덩어리 단위**(화자 줄 2개 이상이면
  그 줄 전부) — 줄마다 스타일 달라지는 사고·제목 오인 방지.
- **해설**: 7pt, 정답→해석→해설, 라벨 단락 내어쓰기(.lead)로 `해석 |`·`해설 |` 시작점 일치.
  **펼침면(4단) 단위로 흐름** — 왼→오 이어짐 허용, 펼침면 넘김 금지. 높이 실측(heights_ans.json)해
  용량으로 미리 나눔(반복 조판은 발산: 10→8→7).
- **빈 면 = MEMO 면**(원본 마스터 모눈), 뒤 간지 1장, **마지막 면은 항상 짝수(왼쪽)**. 116쪽.
- verify.py 게이트 = 누락·순서·판면넘침 + **빈칸 유실·머리제목 괘선겹침·레이아웃 낭비**
  (사용자 지적: "이런 걸 검수에서 잡아내야 해" — 육안 결함도 게이트로).

**통합웹 베타2(engines/blackbook_v2)와의 대조 — W59에서 6종 수정**
같은 원고를 웹 파서에 돌리면 인식 수(65/65·5/5·65/65)와 과 단위 순서는 **동일**.
차이는 전부 블록 구조였고, Vivliostyle 파이프라인 기준으로 웹을 고쳤다(회귀 0, 골든 5건 갱신):
①`< 보 기 >` 공백 마커 미인식 ②`(a) 한글` 보기 항목이 상자에서 이탈(한글 비율 판정)
③`↓`를 build_ir 이 버려 요약문이 지문에 뭉침(Sym 보존+다음 단락 Sum) ④`[채점 기준]`→조건
⑤플랜 순서(답란이 선지보다 먼저 찍힘)→보기→선지→답란→채점 ⑥**해설 `[해석]` 조용히 유실**
(_parse_answer_lines 어느 분기에도 안 걸림) → translation 필드.
회귀 테스트 `tests/test_blackbook_v2_w59_structure.py`. 남는 차이는 InDesign 경로 한계 —
대화문 바탕·공백형 빈칸 밑줄·가변 2문항·해설 펼침면 흐름·해석 전용 스타일(템플릿에 없음).

**2권(블랙북02, 2026-09-03) — 두 번째 책이 알려준 것**
원고가 교과서(과)가 아니라 **모의고사 지문 번호**(18~22 / 23·24·29~31). 책 폴더는
`블랙북/26-2-중간-02`(config+원고+assets+overrides.css), 116쪽. 계열 코드는 갈래를 늘리고
책마다 다른 것은 config 로 뺐다:
- `manuscript.labels`(묶음 이름)·`vocab_title`(어휘 제목 줄 유무), 지문 마커는 **꺾쇠 안 숫자**면
  마커로 보고 라벨은 원고 말 그대로(`<18번>`·`<1과 본문1>` 둘 다).
- **선지가 표**로 온다(6행×3~4열) → `read_paras` 가 `body` 를 순서대로 훑어 표를 표로 읽고
  한 행을 선지 한 줄(`① weary ― betrays`)로. `iter(w:p)` 로 훑으면 칸이 낱낱 줄로 흩어진다.
- **전각 공백(U+3000) 빈칸**·**⇓ 화살표** — 반각/↓만 보면 요약문이 지문에 뭉치고 줄이 판면을 넘는다.
- 표제어/뜻 경계는 두 칸 띄움 **또는 첫 한글**(`apply지원하다`).
- ①로 **시작하는 지문**(어법) — 선지 판정은 원문자 **간격**으로(짧으면 한 줄 선지, 길면 지문).
  이 수정으로 **1권 70번의 지문 둘째 단락이 선지로 조판되던 결함**도 드러나 고쳤다(1권 재조판 7차).
- 아트워크는 `assets.jobs[].src` 로 조각마다 다른 완성본에서 — VOL.2 브랜드/푸터는
  26-1-기말 2권 완성본에서 잘랐다(브랜드가 0.73mm 넓어 `--brand-w` 변수화).
- 긴 머리 제목은 **책 폴더 `overrides.css`** 로만 처리(문제 머리 12pt + 기입칸 오른쪽).
- **꺾쇠 라벨 한 줄이 블록을 연다** — `< 보 기 1 >`·`< 보 기 2 >`·`< 요 약 문 >`·`< conversation >`.
  라벨은 원고 말 그대로 상자에 인쇄하고, 요약이면 크림 상자·나머지는 보기 상자.
  대화문 바탕은 그 상자 **안에** 든다(사용자: "<conversation>도 아래랑 같이 묶여야").
  라벨을 못 알아보면 보기·요약문이 지문 상자 안 맨글로 남는다.
- 선지의 공백은 **빈칸이 아니라 사이 간격** — 밑줄 넣지 말고(`blank=False`),
  한 줄 선지(`① (a) ② (b) …`)는 `cgap` 7mm 로 벌린다. 검수도 같은 규칙으로 세야
  "빈칸 유실" 오탐이 안 난다.
- 밑줄은 반각 `_` 만이 아니다 — **전각 밑줄 ＿(U+FF3F)**. 반각만 보면 `답 : ＿＿＿` 이
  답란으로 안 잡혀 **보기 상자 안으로 끌려 들어간다**. 줄 맨 앞 공백은 **들여쓰기**라
  빈칸이 아니다(전각 두 칸 들여쓴 줄의 첫 낱말 앞에 밑줄이 그어졌다). 파서·렌더·검수
  세 곳을 같은 규칙으로 맞출 것.
- 새 게이트: **선택형 발문인데 선지 없음**(표 파싱 실패 시 선지 5줄 증발 방지).
  검수 게이트 오탐 둘도 고침 — 화자 줄은 **대문자 시작**만, 항목 번호 탐색은 **판면 안**만
  (머리말 "…11월…"의 11이 항목 번호로 잡혀 없는 펼침면 넘김을 신고했다).

**Vivliostyle 함정(여기서 실제로 겪음)**
- **결과 PDF를 미리보기로 열어 둔 채 재빌드하면 대부분의 면이 흰 종이로 보인다** — 파일 교체로
  뷰어 캐시가 깨진 것(조판 정상). PyMuPDF·poppler·CoreGraphics 3중 렌더로 확인했고, 검수용은
  이름을 바꾼 사본(`…(N차).pdf`)으로 전달할 것.
- **출력 PDF의 서체 이름은 `Type3 (n 0 R)`** — 검수·측정 코드에서 서체명(`PyeongChang`)으로 찾으면
  아무것도 못 찾고 **조용히 통과**한다. 크기·위치로 판정할 것.
- `@page` 배경은 **층마다 position/size 명시** — 안 하면 뒤 층이 앞 층 크기를 물려받아 방패 뒤에
  회색 띠 조각이 찍힌다.
- 얇은 괘선을 gradient **색 정지점**으로 그리면 72dpi 래스터화로 사라짐 → 단색 그라디언트를
  **선 두께만 한 상자**로(`no-repeat 0 20.25mm / 216mm 0.353mm`).
- 마진 박스 `@bottom-center` 는 무시됨. 쪽번호는 `@bottom-*-corner`(여백 밖 넘침 OK),
  고정 문구("| BLACK BOOK VOL.1")는 완성본에서 잘라낸 배경 이미지로.
- 아트워크 추출은 글자 bbox 만 믿으면 아래가 잘린다 → 넉넉히 자르고 자동 트림(gen_assets.py).
  회색 띠 위 그림은 바탕색 언믹스로 투명화(잔여 alpha<10 은 0으로 눌러야 트림이 먹는다).
- `.vunit:first-of-type` 은 앞의 `.sechdr`(같은 div) 때문에 안 맞음 → `.vunit + .vunit`.
