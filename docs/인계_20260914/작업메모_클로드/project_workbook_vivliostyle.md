`core/render_vivlio/series/workbook/` 신설(2026-09-01). 입력은 **기존 렌더 플랜
`wb-flows-v1`** 이라 원고 파서를 InDesign 경로와 공유한다 — 파서 무변경.

**네 계열이 코드 한 벌**: 본가(workbook_v2)·부교재(supp)·교과서(textbook)·선택결합
(select). 교과서·select 는 코드 수정 0으로 통과. 수능만만10강 76p/5.6s, 본가 전체(C)
252p/14.7s (InDesign 은 298p 템플릿에 부기 후 176p 삭제, 437초).

**③④(범위·스텝)가 죽는 지점** = `config.select {passages:[2,4], steps:[…], renumber}`.
지우는 게 아니라 **안 만든다** → 삭제·번호정렬·빈면제거 후처리 계열이 불필요.
지문 묶음 판정은 구조로: 라벨이 스텝 안에서 **한 번만** 나오면 지문, 두 번 이상이면
구역 이름(`본문`), 라벨 없어도 묶음 수가 지문 수와 같으면 순서대로.

**빈칸 어휘·어법의 실물 방법**: 해설지 원고를 넣고 정답 부분 서체를 **'색 없음'**
으로 → 앞 글자 하나만 힌트로 남고 가린 글자는 PDF 텍스트로도 안 뽑힌다.
빈칸 폭은 단어 폭이 아니라 **손으로 답 쓰는 자리**라 더 넓다 — 실측 8pt 기준
`4.9mm + 2.04mm × 가린글자수`(=`1.74em + 0.72em × n`, 상한 15칸). 가린 글자는
HTML 에 **넣지 않는다**(넣으면 정답이 복사된다).

**장평은 이 디자인에 없다.** PDF 명령에 `Tz`(장평)가 한 곳도 없고 전부 `Tc`(자간)
— 본문 -0.04em · 하단 지문 상자 -0.025em · 실전 2단 -0.038~-0.074em(양끝정렬).
2026-07 파일럿의 "86% 장평"은 **옛 디자인** 이야기다. CSS 자간 -0.028em 으로
맞췄다(글자 진행폭 0.9286 vs 실물 0.9278). 장평/자간 판별은 **선 단위 폭이 아니라
글자 하나 진행폭**으로, 확정은 콘텐츠 스트림의 Tz/Tc 로.

**서체는 파일명이 한글일 수 있다** — `12롯데마트드림Bold.ttf`,
`Cafe24Supermagic-Bold-v1.0.otf` 는 설치돼 있는데 `ls | grep LotteMart` 로는 안
잡힌다. **서체 안쪽 이름(fontTools name 테이블)으로 찾을 것.** 설치 서체
3,559개 중 TTMamablock 만 없다.

**디자인은 2026-07 파일럿과 다르다** — 크림 패널+좌측 세로바+진행 표시+우측 사이드 탭
(밴드·리본·플로럴 아님). 최신 완성본(`워크북수능만만10강_내지_v2_4.pdf`) 실측 이식.
아이콘은 전부 인라인 SVG(래스터 0). 고정 지면 |dy| 중앙 0.3~2.1mm.

함정:
- `.sec { break-before: page }` 필수 — 없으면 앞 섹션 끝난 면 한복판에서 시작해
  **지문 하나가 통째로 사라진다**. 반대로 `.pg` 마다 걸면 섹션마다 빈 면이 샌다.
- 고정 칸에 가두면(overflow hidden) 넘친 내용이 조용히 잘린다. 실물도 안 자르고
  다음 면으로 잇는다(어법 선택 '본문' 20문장 = 두 면).
- `word-break: keep-all` 없으면 한글 낱말이 줄 끝에서 쪼개진다.
- TTMamablockB 서브셋은 **cmap 이 없다**(Identity-H). 같은 계보 Light 의 글리프
  순서가 정확히 같아 cmap 을 옮겨 복원했다. 상용 서체 3종은 **내부 검증 한정**.
- Yeongdo(지문번호)는 12pt 인데 글자 상자가 16mm 라 흐름에서 8mm 내려앉는다 →
  `position: relative` 로 글리프만 띄우고 본문 시작은 `--body-gap` 으로.

게이트: 내용 보존(원고↔PDF 낱말 대조)·넘침(칸 끝 흰 0.4mm 표식, **표식이 사라진
것도 넘침**)·**빈 지면**(머리말만 있는 면 — 기존 빈면 게이트가 못 잡아 섹션마다
하나씩 샜다)·정답 누출·낱말목록·서체 폴백.

⚠ **텍스트 추출만으로 결함을 단정하지 말 것.** 완성본 165건 중 17건에서 빈칸 면이
낱말 목록으로 인쇄된 것을 찾았는데, 처음엔 "정답이 텍스트에 보인다"만 보고 원고
오류로 단정했다. 실물은 정답을 **색 없음**으로 넣으므로 텍스트에 답이 보이는 것은
정상이다. 지면을 **눈으로 렌더해 확인**한 뒤에야 판정이 섰다(그 17건은 정답이
본문 검정 #231f20 으로 그대로 찍혀 있다). 자세한 것은
`docs/vivliostyle_워크북_전환계획.md` · `…_작업로그.md`.
