PyMuPDF `get_drawings()` 채움값은 그걸 거칠게 RGB 로 바꾼 것(`#ECD4C2`)이라 실제 보이는 색(`#F1E0CD`)과 다르다 — 벡터 값을 색으로 쓰지 말 것. 이제 **그린 모양**에서 바탕·제목 색을 읽고 표지의 CMYK 연산과 가장 가까운 것끼리 짝지어(5권 거리 4~12 vs 다음 29~129) 인쇄 고정표에 넣는다 → 간지가 표지와 **같은 잉크**. 한 색 표지는 평평하게(지어낸 그러데이션 금지).
