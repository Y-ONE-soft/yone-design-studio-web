**강한 지적.** "디자인 요소로 글리프 사용 금지야. 너무 촌스럽고 너무 짜쳐.
ppt 수준의 디자인에서 벗어나야 해."

머리 기호·불릿·라벨 앞 표식으로 **문자 글리프**(`■ ● ▶ ✓ ❖ · ◆ ★ ①` 등)를 쓰지
않는다. 원고에 그런 글자가 있어도 **떼고**, 그 자리에는 도형(SVG/CSS 박스)·색면·
괘선·배지·번호 같은 **조판 요소**를 놓는다.

**Why:** 글리프 표식은 워드 문서의 흔적이다. 원고를 그대로 옮긴 티가 나고,
시중 출판 교재와 나란히 놓으면 바로 자비출판처럼 보인다. "원고 그대로 넣을 거면
왜 돈 주고 조판을 맡기나"가 같은 맥락의 지적이다.

**How to apply:**
- 불릿 → 작은 사각/원형 **색면**, 또는 들여쓰기 + 색 괘선, 또는 번호 배지
- 강조 표식 → 라벨 배지(탭·필), 좌측 컬러 바, 바탕 색면
- 모르겠으면 **우리가 작업한 내지들을 레퍼런스로 삼는다**(우솔서점·같이새김·
  블랙북·상일보카·광문보카). 그래도 모르면 웹검색으로 시중 교재를 본다.
  **멋대로 판단해서 넣으면 워드 수준을 벗어나지 못한다.**
