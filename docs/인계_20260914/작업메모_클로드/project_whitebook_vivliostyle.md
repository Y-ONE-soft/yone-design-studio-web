**화이트북 02 = 배재고1 26-2-중간 실전문제 전용 권.** 1권과 달리 A~E 단어 워크북이
없다 — 원고는 Day 01~20 × 20문항 = **400문항**(워드마스터 고등 COMPLETE Day 21~30),
`문제/정답` docx 40개. 산출 **122면**(앞 간지 1 + 문제 100 + 정답 20 + 뒤 간지 1),
A4+도련 3mm, 조판 12초.

- 책 폴더 `Y.ONE STUDIO/조판/교재/프리미엄북/화이트북/26-2-중간/` (**README.md 먼저**)
- 계열 신설 `core/render_vivlio/series/whitebook/` + `themes/whitebook.css`
- 디자인 원본 = 1권 인디자인 완성본 `배재1_화이트북01_내지_v2_2.pdf` 의 **23~27면
  (EXERCISE)·40면(정답)** 실측. `참고/` 에 원고·완성본 사본을 둬 언제든 A/B 가능.

**앞뒤 간지는 1권 완성본 아트워크 면을 끼운다**(판 번호가 없는 면이라 2권에 그대로).
간지를 **흐름 안에 실제 한 면**(`.divider`+마커)으로 두어야 쪽번호·좌우가 완성본과
맞는다(본문은 2면=왼쪽 면 시작). ⚠ 1권 완성본은 **도련 없이 뽑혀 있어**(A4 210×297)
그대로 끼우면 그 면만 작아지고 TrimBox 가 3mm 안쪽을 재단선으로 잡아 간지가 잘린다
→ `bleed.insert_page` 가 판형 한가운데 놓도록 고쳤다(크기 같으면 옛 경로 = 블랙북 무변).
**1차 납품 때 간지를 빼먹어 사용자가 지적했다** — 완성본 첫 면·마지막 면을 먼저 볼 것.

**사용자가 정한 것(2026-08-31)**: 정답은 **뒤에 몰아서**(Day 마다 새 면) · 머리 탭은
`DAY NN / EXERCISE`, 꼬리말 `DAY NN` · **사분면 고정 4문항 그대로**(짧은 문항 뒤가
비는 것이 설계다 — 자연 흐름으로 바꾸지 말 것).

**회귀 기준선**: 1권 실전문제 원고를 같은 엔진으로 조판해 완성본과 대조 → 기준선·
좌우 끝 **±0.2mm**(23·24·27면은 ±0.15). 대조 스크립트는 글자 내용으로 짝짓는다
(좌표 인덱스로 짝지으면 표지·러닝요소 때문에 한 줄씩 밀려 못 쓴다).

## 여기서 새로 배운 것

**인디자인 장평(95%)을 CSS 로 옮기는 길은 자간뿐이다.** 크기를 줄이면 세로가
달라지고, `transform:scaleX` 는 줄바꿈에 반영이 안 되고, 서체를 눌러 다시 굽는 건
Noto CJK 6.5만 자라 비싸다. 그래서 **서식마다 다른 자간** + **한글은 `word-spacing`
까지**(공백 0.22em 이 자간을 그대로 먹으면 20% 깎인다 → 한글 선지 오차 1.35mm→0.3mm).
**자간 값은 글꼴 표가 아니라 조판 결과로 정한다** — `letter-spacing:0` 으로 한 번 굽고
완성본과 같은 글줄의 폭을 최소제곱으로 푼다(글꼴 advance 로 계산하면 원문자 하나에
0.5em 이 어긋나 값이 통째로 틀렸다).

**한글에서 넘어온 docx 는 모든 런에 `<w:u w:val="none"/>` 을 붙인다.** 태그 유무로
밑줄을 판정하면 **문서 전체가 밑줄**이 된다. 블랙북 파서(`series/blackbook/data.py`
의 `_runs`)도 같은 코드였다 — `_on()` 으로 고치고 블랙북 data.json 바이트 동일 확인.

**줄 상자를 키우는 인라인 3종**: ①크기가 다른 인라인(8.63pt 빈칸 표기 하나가 지문
셋째 줄만 0.57mm 벌렸다) → `line-height:0` ②`display:inline-block` 문항 번호(11pt)가
발문 둘째 줄을 1.0mm 밀었다 → `position:absolute` 로 흐름 밖 ③기준선 보정은
`vertical-align` 말고 `position:relative`(vertical-align 은 줄 상자를 키운다).

**사분면**은 `column-count:2; column-fill:auto` + `.q{height:122.5mm}`. 판면 높이를
칸 두 개보다 **조금 크게**(246mm) 잡을 것 — 딱 245 면 반올림으로 둘째 칸이 밀린다.
**머리 장식 오프셋은 판면 기준으로 잡으면 저절로 미러링된다**(안팎 여백 차 3mm 를
장식이 그대로 물려받는다) → Day 가 좌우 어느 면에서 시작해도 맞는다.

**같은 발문이 400번 되풀이되는 교재에서 공용 검수는 못 쓴다.** `check_sequence` 는
전권을 한 줄로 이어 놓고 찾아 위치가 튄다(거짓 '순서 어긋남' 3,692건),
`check_gaps` 는 발문 앞부분을 열쇠로 써서 엉뚱한 면을 본다(거짓 '빈칸 유실' 6건).
→ 면 범위를 **Day 로 좁히고**, 순서 대신 **"문항 N = (N-1)//4 번째 면"** 계약을 본다.
**PDF 글자 추출 순서는 조판 흐름이 아니다**(사분면은 흐름 ①②③④, 추출은 좌표순
①③②④) — 면 안 순서 검사는 애초에 성립하지 않는다.

그 밖에: `verify.frame` 좌표는 **미디어(도련 포함)** 기준 · `end_on_left` 에 아트워크가
없으면 예전엔 조용히 아무것도 안 했다(빈 면으로 맞추도록 `bleed.py` 수정) ·
서체 없는 글자(`AcademyEngravedStd`)는 완성본에서 뜨되 **권 번호는 같이 뜨면 안 된다**
(2권에 VOL.1 이 나간다) → 앞부분만 뜨고 `VOL.N` 은 빌드 때 Elice 로 그려 붙인다.

**인쇄 원고(CMYK)**: `…_인쇄.pdf` 122p · TrimBox 사방 3mm · DeviceRGB 0개.
색은 **1권 완성본이 이미 CMYK 라 값을 직접 읽어 못 박았다**(팔레트 13색). 본문 먹은
K100 단색. ⚠ 색이 **세 갈래**로 샌다 — ①`rg` 연산자(기존) ②**머리 띠·괘선은 CSS
그러데이션이라 셰이딩 패턴**(`neutralize_patterns` 신설) ③**로고는 그림**이라 1×1 CMYK
+ SMask 로 바꾼다(`pin_flat_images` 신설). ②③ 없으면 띠·로고만 다른 색(#2dacc0)으로
나간다. 단색 판정 때 **투명한 자리 RGB 는 쓰레기**라 SMask 로 불투명 화소만 볼 것.
기존 print 사용 책(광문보카·예비고1특강)은 0건 매칭 = 회귀 없음(비파괴 확인).
