**이의1보카 = 이의고1 26-2-중간** 자체 편집 단어장(공통영어2 능률(민) 1과 · 수능특강Light 12~15강 · 26년9월 고1 학평). **✅ 2026-09-10 검수 주석 2건 반영 · 199p + CMYK.** 낱말 526(교과서 67 · 부교재 256 · 모의고사 203), 구간 33.

**계열 `vocacard` 두 번째 책 — 코드 없이 config 한 장으로 조판됐다**([[project_yiui2_voca_vivliostyle]] 가 첫 책). 책 폴더 = `조판/교재/단어장/이의1보카/26-2-중간/`(config.json + 원고 + assets/up3d.png). 정본은 **워드**(이 책은 엑셀에도 작업 메모가 없지만 관행 유지).

**⚠ 구간 이름 체계가 책마다 다르다 — 접두어를 코드에 박으면 안 된다.** 이의고2 는 `교과서 - 본문 1`, 이의고1 은 `교과서 공통영어2 능률(민) 1과 본문 1` / **`수능특강 Light 영어 12강 Exercise 01`(‘부교재’ 라는 말이 아예 없다)** / `2026년 9월 고1 모의고사 21번`. 기본 규칙만 믿었다가 **부교재 256낱말이 통째로 앞 구간(본문 4)에 흡수**됐다(272낱말 구간이 생겨 발각). → `options.parts_match` 로 [파트, 정규식] 을 책이 선언하고 **괄호 안이 소제목**이 된다(`(본문\s*\d+)` → "본문 1").

**면 나눔 값도 책 손잡이로 뺐다** — `page_fill_mm`(이어지는 면) · `page_first_fill_mm`(PART 시작면, 큰 헤더 30mm 때문에 자리가 13mm 좁다) · `rough_pad_mm`(어림 측정 보정). 이의고1 = 171/160/2.0. **이의고2 는 검수를 마친 189p 판을 지키려고 173/173/0 으로 고정**했다 — 기본값을 그대로 받으면 193p 가 되어 판이 달라진다. 납품·검수가 끝난 책은 값을 config 에 못 박을 것.

**카드 높이 계측의 한계**: 면의 **마지막 카드**는 다음 카드 머리가 없어 잉크 끝까지만 재므로 줄 상자만큼(약 3mm) **작게** 잡힌다. 그 값을 믿고 묶으면 실제로는 넘쳐 한 장이 밀린다. 대책 두 겹 — ①어림값으로 표시해 두고 다음 패스에서 그 카드가 면 중간으로 가면 정확한 값으로 교체 ②끝까지 어림인 카드는 `rough_pad_mm` 만큼만 넉넉히(정확값엔 안 더하므로 전체가 안 부푼다). FILL 을 전역으로 낮추는 것은 **역효과**였다(169 로 낮추니 이의고2 가 189→197p 로 늘고 밀림은 그대로).

**예문 표제어 강조는 이 책에서 100%(526/526)** — 이의고2 검수 지적 이후 보강한 규칙(불규칙·라틴복수·소유격·구 중간삽입·하이픈)에 더해, 이 책 원고에서 새로 나온 두 갈래를 추가했다: **자리표시자**(`compare A with B` → 예문의 A 자리에 6낱말짜리 목적어가 들어간다 → 자리표시자 **앞의 실질 낱말까지만** 짚는다) · **철자 변화**(have→having · bury→buried · body→bodies). 겹치는 매칭은 **짧은 쪽**을 남긴다(`the French Revolution` 의 `the` 가 앞의 다른 `The` 에 걸려 "The turn of the French Revolution" 을 통째로 물었다).

**2026-09-10 검수 주석 2건 — 둘 다 표제어가 라벨 열을 넘친 것**(각인북스 윤지수): `unemployment` 가 `unemploymen`/`t` 로 쪼개짐 · `anaerobic respiration` 이 품사 배지에 딱 붙음. 원인은 축소 단계를 **글자 수**로 고른 것(`len>=13 → 8.4pt`, `len>=18 → 7pt`) — m·w 가 많은 낱말은 같은 글자 수라도 훨씬 넓다(unemployment 12자인데 10pt 로 26.0mm > 열 25.25mm).

**처방: 폰트 메트릭으로 실제 폭을 재서 고른다**(`fontTools` 로 `NotoSansCJKkr-Bold.otf` 의 advance 합 + **자간 −0.02em 보정** — 이 보정을 빼면 3% 과대). 단계 10/8.4/7/**6(신설 `.xxlong`)** 중 폭이 `lab_w − 2.25mm`(배지와 띄울 자리) 안에 드는 가장 큰 것. 폰트를 못 읽으면 예전 글자 수 규칙으로 폴백. 결과: 두 책 모두 **표제어 줄바꿈 0 · 열 넘침 0**, 쪽수 불변(199/189).

**같은 결함이 이의고2 에도 6개 있었다**(cultural movement·be concerned with 등) — 검수자가 못 봤을 뿐. 함께 고쳤고 189p 는 그대로였다. **검수 지적은 그 책만의 문제가 아닐 수 있다 — 같은 계열 다른 책도 같이 훑을 것.**
