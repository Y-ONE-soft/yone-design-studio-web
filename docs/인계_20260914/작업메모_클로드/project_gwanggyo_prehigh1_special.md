- 내지: `조판/교재/특강교재/예비고1특강/26-여름` — **`HANDOFF.md` 먼저**, 그다음 README

**색 3계층의 정확한 뜻**(여기서 두 번 틀렸다): 주색·보조색은 **둘 다 부마다** 다르고,
공통색만 전권 공통 중립 톤(아이보리·베이지·크림·그레이)이다. 파트 무관하게 쓰이는
채도 있는 색을 "보조색"이라 부르면 안 된다 — 그건 공통색 자리다.
보조색 = 주색과 톤은 맞되 **색상이 다른 짝**, 넓은 면용 밝은 판 + 강조용 짙은 판 둘.
확정값: 어휘 머스터드`#c08618`↔웜아이보리`#f2e7d3`/`#9a6a2a`,
구문어법 버건디`#96323f`↔뮤트블루`#d2dfe8`/`#3f6480`,
독해 올리브`#6f7e2c`↔뮤트핑크`#f0d6d9`/`#a86271`.

**헤더는 내비게이션 텍스트를 늘어놓는 자리가 아니다.** 좌우 세트: 왼쪽=바깥 끝 각진
주색 면(WEEK/PART+번호)+단원 표기, 오른쪽=도형 없이 책 이름+로고(한 줄 안에서
`vertical-align:middle`, 표시 서체로 — 본문체면 워드처럼 보인다).
**간지는 2면 세트**(왼쪽 색면 제목 + 오른쪽 그 부의 차례), 왼쪽 면에서 연다.

## 글자만 세는 게이트의 사각지대 둘 (전수 대조가 통과한 결함)

**① 서식** — 어법 문제는 '밑줄 친 부분을 고치라'라서 밑줄이 곧 문제이고, 빈칸
추론의 빈칸도 밑줄이다. 이게 **두 번** 통째로 사라졌고 **두 번 다 전수 대조가
통과**했다(글자는 안 틀리니까). ⓐ`라벨|본문` 을 나누던 코드가 본문을
`esc(plain(...))` 로 내보냄 → 조각을 `|` 에서 갈라 뒤쪽은 `inl()` 로.
ⓑ테마의 `u { text-decoration: none }` 한 줄 → **끄지 말 것**. 원고는 밑줄을 5곳에
쓰지만(기입선190·POINT60·문제30·해설영문30·지문빈칸11) `<u>` 로 오는 건 71곳뿐,
기입 칸은 엔진이 괘선으로 그리므로 끌 이유가 없었다.
두께는 `--rule-u` 한 곳. **⚠ 렌더러가 선 두께를 1/8px 격자로 내림 스냅**해서
`.5pt` 는 0.47pt 로 나간다 — 격자가 0.47/0.56 이라 0.50 정확히는 불가, 0.5 이상
첫 값이 `.6pt`(0.56pt). "너무 얇다"가 나왔던 값이 0.47 이다.
→ `G-밑줄`. **⚠ 이 게이트를 HTML 의 `<u>` 로 셌다가 ⓑ를 통과시켰다 — `<u>` 는
71개 멀쩡히 있는데 CSS 가 지우고 있었다. 재는 곳은 언제나 최종 산출물(PDF)이다.**

## 겹침은 게이트가 없으면 아무도 못 잡는다

필기 모눈처럼 **판면에 못박는 요소**는 위 내용이 길어지면 본문 위에 겹쳐 찍히는데,
빌드는 성공하고 넘침·전수대조 게이트도 통과한다(글자는 다 들어가 있으니까).
`G-모눈` 신설 — 모눈 선 색으로 모눈을 찾아 위 본문 바닥과의 여유를 재고 4mm 미만이면
결함. **게이트를 짜다 같은 실수를 두 번**: ①측정창을 모눈 기준으로 자르면 겹쳐
내려간 글자를 스스로 못 본다(기준은 판면) ②라벨이 본문 줄에 붙으면 한 덩어리라
**줄(line) 단위로** 재야 한다. 라벨도 부마다 띄어쓰기가 다르다(`필기노트`/`필기 노트`).

원고의 **끊긴 지문**(문단 나눔 실수)은 지문 상자가 문장 한가운데서 쪼개져 인쇄된다 →
`소문자로 시작하는 지문 단락 = 앞의 이어짐` 구조 판정(`_join_passages`).

## 표지 — 글자색을 바꾸면 조판이 깨진다

표지는 워드마크 폭을 **실측해 수렴시키는** 조판이다. 그 잉크 판정이 절대 문턱값
(`RGB 합 < 200`)이었어서, 글자를 밤색(합 98) → **네이비 `#1E2B4D`**(합 150)로
바꾸자 세리프 얇은 획이 머스터드 바탕(합 406)과 섞여 문턱을 넘고 **둘째 줄이
통째로 안 잡혔다** → 워드마크가 뒤표지까지 넘어갔는데 **빌드는 성공으로 끝난다.**
`_ink()` 가 바탕·잉크를 페이지에서 읽어 중간을 문턱으로 잡도록 고쳤다.
**색을 바꾼 뒤에는 반드시 렌더해서 눈으로 본다.**

`books.png` 는 **벡터 원본**(같은 로고), `paper.png` 는 파이널엣지 내장 타일의
