**이의2보카 = 이의여고2 26-2-중간, 자체 편집 단어장**(YBM박 1과 + 수능특강Light 8~11강 + 26년9월 학평). 원고가 상일보카(Day+4섹션+워크북)와 근본적으로 다르다 — **단일 xlsx 표 121행, 행 하나 = 카드 하나**, '구간' 열로 교과서/부교재/모의고사 3파트만 나뉜다. Day도 Part2 워크북도 없음. **✅ 2026-09-09 검수 주석 6건 반영 · 예문 강조 542/542 · 189p + CMYK.**

**엔진 = 신설 계열 `vocacard`**(`~/dev/yone-design-web/core/render_vivlio/series/vocacard/`), `vocabook`(상일·배재보카)을 건드리지 않고 격리 신설 — [[project_sangil_voca_vivliostyle]]에서 계획한 3계층 분리의 첫 실제 적용 사례. **저수준은 vocabook 재사용**(word_block 서식 함수 esc/esc_gap/ex_en/ex_kr/syn, 헤더 4면 체계 running/day_head/cover_placeholder — import, 복붙 아님), **CSS만 별도 파일**(`themes/vocacard.css` = vocabook.css 전체 복사+말미에 카드 테두리 상자·영영풀이 이탤릭 추가) — build_css()가 파일 텍스트 치환이라 계열마다 스타일시트가 한 벌 필요해서, 공유하면 상일보카 색이 흔들리기 때문. **2패스**(처음엔 1패스로 갔다가 되돌림): 시작면에 큰 마름모(인플로우)와 작은 탭(마진 박스)이 **겹쳐 보인다**는 지적 → 상일보카처럼 1패스로 시작면을 찾아 `@page :nth(N){background:none; @top-left{content:none}}`. vocabook 의 ②밴드(짝면 큰 밴드)는 안 씀. 이어지는 면은 `running()` 이 알아서 이어 준다.

책 폴더 = `조판/교재/단어장/이의2보카/26-2-중간/`(config.json + 원고만, 코드 없음). `bin/viv "<폴더>" data|build[--sample]|verify` 로 실행.

**팔레트**: 원고에 없어 사용자가 준 표지 시안(`디자인/표지/송아영T/시안A_INFLATE/A_g2_vocab_front.pdf`, 그래픽=INFLATE 3D 벌룬 "UP")에서 PyMuPDF로 실측 — 배지 벡터값 초록 `#19A86B`, 제목 텍스트 먹 `#14161a`(get_text dict의 span.color, 픽셀샘플링보다 정확), 배경 분홍 `#FDD9E5`. **3파트가 상일보카처럼 색상환을 안 씀** — 표지가 단일 브랜드색(초록)이라 3파트는 같은 초록에서 명도만 달리 갈랐다(colorsys HLS 시프트), 분홍은 강조색(`--c-hl`, 예문 강조어)으로만. 브랜드 텍스트 = 표지 그대로 "EEGOEEGO".

**함정**: ①`bin/viv build`는 기존 data.json을 그대로 읽는다(`data_mod.load`) — 파서 수정 후 **`data` 스텝을 다시 안 돌리면 반영 안 됨**, 두 번 겪음. ②원고 "주의 / 혼동" 열 값이 이미 "주의. ~"/"혼동. ~"로 시작 — 행 라벨을 별도로 얹으면 "주의  주의. ~" 중복 표시(첫줄 접두어로 라벨 결정 후 그 접두어를 줄에서 제거해 해결). ③`cover_placeholder()`(vocabook 상속)가 `class="cover s-head"` 하드코딩 — 이 계열엔 s-head가 없어 :root 첫 섹션(s-text) 기본값에 우연히 얹혀 있었다(우연히 맞았지만 명시적으로 override 함). **검수 = 카드 테두리 벡터 rect bbox 대조**(get_drawings, 폭 95~112mm 필터)로 121장 전수 확인 — 페이지 텍스트 y좌표만으로는 러닝 요소(측면라벨·꼬리말)가 본문 y범위 밖(202~213mm)에 정상 위치해도 false positive가 뜬다(vocabook 검수 관행과 다름, 주의).

**2차 피드백 반영(2026-09-04)**: ①시작면 태그 겹침→2패스 ②구간 소제목을 카드꼴(연한색 바탕+주색 기둥+`N words`) ③**낱말 테두리 상자 제거**(머리 괘선만으로 가름 — 상자를 두르면 답답하다) ④**구간마다 새 면**(`.gsec{break-before:page}`) ⑤3파트 색을 명도차→**색상환**으로(교과서 초록 #14a667·부교재 파랑 #2570b6·모의고사 로즈 #c22e5f — 표지의 초록·분홍 두 축에 파랑을 더함, 짙은 그린은 탁하다는 지적) ⑥간지 앞뒤.

31쪽은 PART3 이 왼쪽에서 시작하느라 생긴 **MEMO 면**(백지 아님 — vocabook 테마의 `@page :blank` 가 괘선+"M E M O" 를 깐다). 빈 면 검사에서 "MEMO" 4글자 때문에 백지로 오판하기 쉬움.

**측면 라벨은 파트마다 계단**(`options.idx_step_mm: 22` → 교과서 28.5 · 부교재 50.5 · 모의고사 72.5mm). vocabook Renderer 가 이미 `--idx-step` 을 받으므로 `running(..., step)` 에 파트 순번×칸만 넘기면 된다(상일보카는 Day 마다 8mm, 여기는 파트가 셋뿐이라 22mm 로 크게).

**인쇄 원고 = `bin/viv <책> print`**(공용 `prepress.py`, Ghostscript + JapanColor2001Coated). config `print.gray_map` 에 **화면색→K 비율 표**를 적어 먹·회색을 DeviceGray 로 먼저 바꾼 뒤 나머지만 ICC 변환한다 — 안 그러면 본문 먹이 4도 리치블랙이 되어 5~7pt 글자가 뭉갠다. 이 책 표: `#14161a`/`#000000`=K100 · `#5c6470`=K61(해석·설명) · `#9aa2ac`=K37(행 라벨) · `#b9bfc7`=K25 · `#e4e8ec`=K9 · `#eef1f4`=K6 · 흰색=0. 검수는 **DeviceRGB 연산자 0개**·짙은 먹이 CMYK 가 아니라 DeviceGray 인지·이미지 dpi(UP 3D 754dpi, 다운샘플 없음)·MediaBox=BleedBox 154×216 & TrimBox 148×210. 표는 실제 PDF 의 `rg` 연산자를 세어 정한다(색이 바뀌면 표도 갱신할 것).

**두 가지가 따라 바뀌어야 했다.** ①**유반의어에 분류 태그**(`유. [유의어] downturn`, `[문맥상 대조]`, `[직접 반의어]`, 새 종류 `구조.` 428줄)가 생겼는데 vocabook 의 `syn()` 은 **바깥 대괄호를 묶음 표시로 보고 벗긴다** — 원고 '범위 및 표기' 시트가 [문맥상 유사어]는 따로 센다고 명시한 **의미 있는 분류**라, 벗기면 태그와 낱말이 뒤섞인다. `syn_line()`(vocacard 전용, 대괄호 유지 + `.tg` 로 색만 뒤로) 신설. ②유반의어가 1~2줄→**중앙 6줄**이 되며 카드가 40→**51mm**(최대 77) — `page_cap=4` 로는 4장 묶음이 면(가용 170mm)을 넘쳐 마지막 1장이 밀리며 **한 장짜리 면이 101개** 생겼다(258p). `options.page_cap: 3` 으로 낮춰 **199p**(3장 면 163 · 하단 여백 중앙 33.8→20.3mm). page_cap 은 이때 config 손잡이로 뺐다.

**면 나눔은 낱말 수가 아니라 실측 높이로**(3패스). 1패스로 한 번 조판해 **낱말 카드 높이를 재고**(카드 머리의 네 자리 번호 y 간격 — 예문 속 연도와 구분하려면 판면 왼쪽 끝 x<30mm 조건 필수), 2패스에서 그 높이로 면을 다시 나누고, 3패스에서 PART 시작면 pages.css. **카드 높이는 놓이는 면과 무관한 값**이라 되먹임이 없어 수렴을 걱정하지 않아도 된다(vocaunit 의 고정점 반복과 다른 점). 알고리즘 `_pack`: 그리디로 최소 면수 k 를 구하고 그 k 를 유지하는 가장 낮은 한 면 높이를 이분법으로 찾아 담는다 + 마지막 면이 1장이면 앞 면(3장 이상)에서 한 장 넘김.

**⚠ 용량은 잉크가 아니라 상자로 재라.** 구간 소제목을 글자 잉크 기준 8.9mm 로 잡았다가 실제 상자 10.2mm 와의 차 때문에 **0.2mm 초과로 카드가 밀려** 한 장짜리 면이 생겼다. 정확한 셈: 판면 179 - 소제목 상자 10.2 = 카드 자리 168.8mm, 재어 둔 높이에는 **카드 뒤 여백 5.4mm 가 이미 포함**(다음 카드 머리까지 재므로)이고 면의 마지막 카드는 그걸 안 쓰므로 판정은 `Σ높이 ≤ 168.8+5.4 = 174.2` → 여유 1.2 두고 `FILL_MM=173`. 결과: 낱말 수 기준(199p·한 장 면 15개·밀림 3면) → 높이 기준(199p·**한 장 면 0·밀림 0**·면당 3장 150면/2장 46면).

**정본은 워드(.docx)다 — 엑셀이 아니다.** 같은 수정 원고가 xlsx·docx 두 벌인데, **엑셀 유의어 칸에는 작업 메모가 섞여 있다**(`유. 3개 확보 불가 — 사유: political·social 등 다른 영역은 …`, 71낱말). 모르고 엑셀로 조판해 **65면에 그 메모가 인쇄됐다**. 워드본은 학생이 볼 것만 담긴 정본. 두 원고를 필드별로 대조해 확인했고(그 외 내용은 동일), config `manuscript.files.words` 를 docx 로 돌렸다. 199p→**189p**.

**표기 차이**: 분류 태그를 **엑셀은 대괄호**(`[유의어]`), **워드는 얇은 공백 U+2009**(`유. ⟨thin⟩유의어⟨thin⟩ downturn`)로 감싼다 — python-docx 의 `p.text` 로 읽으면 대괄호가 없어 처음엔 태그가 사라진 줄 알았다. `syn_line()` 이 둘 다 받아 `.tg` 로 낸다.

**docx 파서**(`parse_docx`, 엑셀 파서와 같은 모양을 돌려준다): 구간 줄 = `classify()` 가 알아보는 줄, 낱말 머리 = `^\d{4}\s+…`, 라벨 줄(예문/연관어휘 / 유반의어/파생어/주의 / 혼동/영영풀이)이 뒤따르는 줄들의 이름표. 머리 분해는 품사 마커(`n.` `v.` `a.` `ad.` …) 우선, 없으면 **첫 한글**에서 가르되 **한글 앞 물결표는 뜻 쪽**(`short for` + `~의 줄임말인` — 안 그러면 `short for ~` 가 된다).

**예문 속 표제어 강조** — 이 원고는 상일보카와 달리 예문에 `[낱말]` 표시를 **안 달아 준다.** 그래서 표제어와 굴절형을 렌더러가 직접 찾아(`mark_head`) 대괄호를 끼우고 기존 `ex_en()` 이 `<em>` 으로 만들게 했다. 세 갈래로 본다: 어간(abandoned→abandon+ed, realities→realit(y)+ies — **어간 4자 이상일 때만**, 짧으면 엉뚱한 낱말이 걸린다) · 접미사(aim→aims, fix→fixed, ban→banned 자음겹침 — 짧은 표제어용, 오탐 없음) · be(`be about to`→`was about to`). **536/542(99%)**, 오탐 0. 남는 6개는 불규칙(overcome→overcame·freeze→frozen·crisis→crises)이거나 예문에 표제어가 아예 없는 낱말. 색은 **파트 주색**(`.r-ex em { color: var(--main) }`) — 공통 강조색(`--c-hl` 로즈)을 쓰면 모의고사 파트 주색과 겹쳐 구분이 사라진다.

⚠ 이때 `s.replace()` 로 호출부를 갈아끼웠는데 **패턴이 안 맞아 조용히 실패**했다(함수만 들어가고 `mark_head` 는 불리지 않아 강조가 0개). 문자열 치환은 `assert old in s` 를 붙이거나 Edit 도구를 쓸 것.
