원고·파서(`data.py`, docx)
- 문항 = `N.` 로 시작하고 번호가 직전 +1. 지문 = 발문·선지·보기·답란·채점기준이 아닌 단락. 요약문 = `↓`(2권은 `⇓`도) 다음 단락. 답란 = 밑줄 있고 밑줄 뺀 글자 20자 이하. 해설 = 번호 단독 줄 뒤 `[정답]/[해석]/[해설]`. 연관어휘 = `<N과 본문M>` → 제목 → 지문 → `〈연관 어휘〉`.
- 2권에서 추가된 갈래: 선지가 **표**(행 하나 = 선지 한 줄), 전각 공백 빈칸, 전각 밑줄 ＿, 꺾쇠 라벨 한 줄(`< 보 기 1 >`·`< conversation >`)이 블록을 연다, 표제어/뜻 경계 = 두 칸 띄움 또는 첫 한글. config `manuscript.labels`·`vocab_title`.
- 인식 게이트: 과별 문항 수 == 해설 수, 번호 연속, 본문마다 지문·어휘 ≥ 1, 정답 비지 않음, 선택형 발문인데 선지 없음.

지면·배치
- **측정 패스(3패스)**: 문항 높이 측정 → 해설 높이 측정 → 본 조판 → 마감. `MEASURED=("problems","answers")`, 미리보기 `render_opts={"nomeasure": True}`.
- 한 면 2문항 **가변 배치**(실측 높이로 짝, 합이 판면 넘으면 1문항). 해설은 **펼침면(4단) 단위** — 왼→오 이어짐 허용, 펼침면 넘김 금지(반복 조판은 발산 10→8→7 이라 미리 나눔).
- 순서: 1과 연관어휘 → 1과 문제 → 2과 연관어휘 → 2과 문제 → 1과 해설 → 2과 해설.
- 간지·MEMO·뒤표지 = InDesign 완성본 아트워크 면을 끼움(`finish.art_pdf`). 마지막 면은 항상 왼쪽(짝수), 뒤 간지 1장. 고정 문구·브랜드는 `assets.py` 로 완성본에서 잘라 냄(`assets.jobs[]`).
- 인쇄: `PRINT_GRAY`(ink 1.0 / gray 0.8 / box 0.55 / band 0.5)를 팔레트 hex 에 매핑.

계열 고유 검수(`verify`): 조판 순서 대조(연관어휘→문제→해설) · 대화문 바탕 이탈(화자 줄 2개 이상일 때만) · 해설 펼침면 넘김(항목 번호 **14pt 크기로** 판정 — PDF 서체 이름이 `Type3` 라 이름으로 찾으면 조용히 통과).

함정·이력
- 한글에서 온 docx 는 모든 런에 `<w:u w:val="none"/>` — 태그 유무로 밑줄 판정하면 전부 밑줄(`_on()` 으로 수정).
- `--sample` 이 파일 이름만 바꾸고 전권을 조판해 작업대가 멎었음 → `_sample` 이 실제로 줄임.
- `@page` 배경 층마다 position/size 명시, 얇은 괘선은 선 두께 상자로, `@bottom-center` 무시.
- 결과 PDF 를 미리보기로 열어 둔 채 재빌드하면 흰 면으로 보임(조판 정상).

새 책 추가: config + 원고 + `assets/` + (필요 시) `overrides.css`. 2권 때 원고 갈래가 늘어 **계열 코드(파서) 수정이 필요했다**. 같은 형식이면 config 로 가능하나, 새 원고 형식이면 data.py 확장.

## 14. 계열 공통 — 새 책을 붙일 때 판단 순서

1. 원고 형식·디자인 계보가 기존 계열과 같은가 → 같으면 책 폴더에 `config.json`(+원고·assets)만. 실증: vocacard(이의1), final(학교별 Vol), pocketbook(학교별), workbook(select).
2. 원고 형식이 조금 다르다 → 그 계열 `data.py` 를 **구조 판정**으로 넓힌다(형식 화이트리스트 금지). 선례: blackbook 2권, vocacard `parts_match`.
3. 디자인 계보나 원고 형식이 근본적으로 다르다 → 새 계열 폴더 + `themes/<이름>.css` + `series/__init__.py` 에 `register` 한 줄. 선례: vocaunit(vocabook 과 분리), vocacard(vocabook 저수준 import + CSS 사본).
4. 손댄 뒤 같은 계열의 기존 책을 다시 조판해 쪽수·게이트가 그대로인지 확인한다(검수 끝난 책은 면 나눔 값을 config 에 고정).
