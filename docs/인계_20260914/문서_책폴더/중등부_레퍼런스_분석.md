## 3. 섹션 헤더 패턴 (글 스케치)

### 3-1. 백발 — "리본 배지 + 컬러 블롭" 방식

```
┌ 페이지 상단 0~28mm ────────────────────────────────────────┐
│ ◜◝ 파스텔 원형 블롭 2~3겹이 상단을 넘어 잘려 나감(섹션색)      │
│  ✎라인아이콘   ╭──────────────────────╮                    │
│  (기차/칠판/    │ [교과서] 속  핵심 **어휘** │────── 보라 괘선 ──○│
│   책상/회전목마)╰──────────────────────╯   (끝에 작은 원)   │
└───────────────────────────────────────────────────────────┘
   ↓ 8mm
  ( STEP 1 )  ←── 알약(pill) 라벨, 흰 글자·짙은 청록 배경
  ▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬ 연회색 롱 바(전폭)가 알약 뒤로 흐름
```

- **리본 배지**: 흰 라운드 사각(radius ≈ 6mm) + **1pt 보라 외곽선** + 왼쪽에 작은 `교과서` 태그, 오른쪽 끝에서 보라 괘선이 판면 우측 끝까지 뻗고 **작은 빈 원(◦)으로 종결**된다. 이 "선 끝의 작은 원"이 백발의 시그니처.
- **배지 텍스트 2톤**: 앞말은 검정 고딕(`핵심`), 뒷말은 **섹션 컬러 굵은 고딕**(`어휘`/`대화`/`문법`/`Reading`).
- **섹션색은 배경 블롭에만**, 배지 외곽선·괘선은 **항상 보라 #9C4B99** 로 고정 → 전권 통일감 확보.
- 발문 라벨 `A B C D`: **섹션 컬러 굵은 산세리프 1글자**(무배지) + 4mm 띄고 한글 발문 10.5pt Bold.
- 소단원 번호: **작은 사각 컬러 칩 안에 흰 숫자** (`1` `2`).
- 학습 가이드 라벨 4종은 **탭(tab)형**: `Study▮Point`, `Plus▮Point`, `Quick▮Check` — 어두운 왼쪽 칩 + 밝은 오른쪽 칩 2색 붙임 + 아래 전폭 얇은 괘선. `Check Up` 만 ✔ 아이콘 + 알약 + 옅은 배경 바.
- 실전 페이지의 영역 라벨(`어 휘`, `대 화`)은 **좌우로 뻗은 라운드 브래킷 괘선 가운데 컬러 알약**.
- 난이도/유형 태그: `서술형`(주황 알약) `신유형`(초록 알약) `고난도`(보라 알약) — 문제번호 **바로 위**에 얹는다.

### 3-2. 내콘 — "로고마크 + 꺾인 괘선" 방식

```
┌ 페이지 상단 0~24mm ────────────────────────────────────────┐
│  ◆◆   교과서 어휘 학습                                       │
│  ◆◆   **W**ORDS ──────────────────────────╮  (우측 끝 45° 꺾임)│
│ (회전사각 2개 겹침, 섹션색 2톤)  ↑ 첫 글자만 크게       ↘        │
└───────────────────────────────────────────────────────────┘
   ◆ Words   ──────────────────────────────  ← 마름모 + 굵은 워드 + 가는 컬러 괘선
```

- **로고마크**: 45° 회전 정사각형 2개를 겹친 마크. 섹션마다 색만 바꾼다(오렌지/핑크/그린/블루).
- **워드마크**: `WORDS` `GRAMMAR` `READING` `Dialogues` — **첫 글자만 2배 크게** 한 로고타입. 위에 아주 작은 한글 캡션(`교과서 어휘 학습`).
- **괘선 꺾임**: 헤더 우측 괘선이 판면 끝에서 45°로 꺾여 내려온다. 연습문제 페이지에서는 반대로 위로 꺾인다. 이것이 내콘 시그니처.
- 문제 페이지 헤더는 **로고를 단색 칠한 축소판**(`Words 연습 문제 1`)으로 격하시켜 "학습본문 vs 문제"를 헤더 단계에서 구분한다.
- **우상단 `▶정답 및 해설 p.002`** 가 y=19mm에 고정 배치(문제 페이지에만).
- 대항목 번호: **컬러 숫자 38pt + 사선(/)** + 검정 한글 제목 13.8pt.
- 발문 라벨 `A B C D`: **DINPro-Bold 14pt 섹션 컬러**, 무배지.
- 소섹션 라벨: `Listen & Talk A` = **핑크 알약(라운드 4mm) 흰 글자**.
- 퀵테스트: `QUICK TEST ①` = 좌측 그린 알약 + 우측으로 이어지는 **얇은 회색 라운드 브래킷이 블록 전체를 감싼다**(위·우·아래 3변만, 좌변 열림).
- 유형 태그: `★빈출유형`(빨간 물결밑줄) `✎서술형`(보라 물결밑줄) — 문제번호 **위**에 얹음.

### 4-4. 지문 직독직해

두 권 모두 **1단 전폭 + 문장당 3~5개 레이어**를 쓴다. 이것이 중등 내신 교재의 최대 특징이다.

**백발 (레이어 4층)**
```
        ┌→ 형 종류, 유형                     ← ① 문장 위쪽: 어휘 라벨(작은 컬러 손글씨)
❶ A new school year / started!              ← ② 영어 본문 11.5pt + 슬래시 끊어읽기
      학년                                   ← ③ 단어 아래: 뜻 (7.4pt 손글씨체)
   새 학년이 / 시작되었다                      ← ④ 직독직해 한글 (8pt, 슬래시 동일 위치)
```
- 문장번호 = **검정 원 안 흰 숫자 ❶~⓬**
- 화자 소구분(`Bora`, `Kangmin`) = 굵은 검정 11pt, 위에 6mm 빈 줄
- 핵심 문법 문장은 **노랑 형광 `#FFE67A`** 로 해당 구만 칠함
- 밑줄 종류 3가지: 실선(어휘), **점선/괄호 브래킷**(문법 범위), `⌐‾‾⌐` 꺾쇠(수식 관계)

**내콘 (레이어 3층 + 사이드 패널)**
```
        병렬구조
        ┌────────┐
02  You can make new friends and be a good friend to others, too.
     can    make friends:                        대 다른 사람들
     +동사원형 친구를 사귀다
```
- 문장번호 = **컬러 숫자 2자리 `01` `02`**(배지 없음), 시험 빈출 문장 앞에 **★**
- 문법 포인트는 본문에 두지 않고 **우측 패널(#EDF4FB, 폭 45mm)** 에 `1 감각동사 + 형용사` 식으로 번호 매칭 + **작은 표까지 넣음**
- 핵심 문장 전체를 **노랑 `#FFEDA4`** 로 칠함
- 한글 해석 없음 (해석은 별도 "연습 문제" 페이지)

### 4-5. 빈칸 문제

| | 백발 | 내콘 |
|---|---|---|
| 어휘 답란 | 화살표 `→` + **33.0mm 고정 밑줄** (STEP 1 영↔한) | **40.0mm** (A/B 단어) / **70.0mm** (C 표현, 전폭 1단) |
| 대화·본문 빈칸 | **18.0mm 고정 밑줄** 인라인 | **20.0mm 고정 밑줄** 인라인 |
| 배치 | 영어/한글 좌 + 답란 우, **답란 시작 x 고정** | 동일 |
| 정렬 | 대화 빈칸 페이지는 **양끝정렬 사용**(문장 폭이 넓어 자간 폭주 안 남) | 본문 빈칸 페이지 **양끝정렬 사용**(단폭 125mm 확보) |
| 대응 한글 | 우측 별도 컬럼(백발: 라운드 박스 / 내콘: 연블루 패널)에 **문항번호까지 반복 표기** | 〃 |
| 문항 간 간격 | 약 3.5mm | 약 20pt(=7mm) — 내콘이 훨씬 여유 |

> **관용구**: 빈칸은 **언제나 고정 길이 인라인 룰**이며, 밑줄 개수 = 답 단어 개수다. 언더스코어 문자나 공백 늘리기로 만들지 않는다.

## 5. 빈칸(밑줄) 처리 — 실측

| 항목 | 백발 | 내콘 |
|---|---|---|
| **선 두께** | **0.35pt** (지배적, 204/262건) | **0.30pt** (지배적, 167건) |
| **길이 세트** | **18.0mm**(인라인 빈칸) / **33.0mm**(답란) — 이 2종이 전체의 97% | **20.0mm**(인라인) / **40.0mm**(단어 답란) / **70.0mm**(표현 답란) / 10.0mm(짧은 답란) |
| **베이스라인 하단 오프셋** | 영문 11.5pt 본문 기준 **+1.6~2.0pt** / 한글 8pt 기준 +0.7~1.1pt | 영문 10pt 기준 **+1.0~1.1pt** |
| 색 | 검정 (본문색과 동일) | 검정/#231F20 |
| 강조 밑줄(문법) | 0.5pt / 0.54pt, 길이 2~13mm (단어 단위) | 0.28pt (얇게) + 1.42pt(굵게) 2겹 = **답란 강조** |
| 괘선(섹션 구분) | 0.7pt·1.0pt·2.0pt | 0.75pt·1.42pt |

**정리:**
- **밑줄 두께는 0.3~0.35pt.** 본문 글자 획보다 확실히 가늘다. (시안의 "본문과 같은 굵기" 문제 원인)
- **길이는 2~3종만 쓴다.** 백발 = {18, 33}, 내콘 = {20, 40, 70}. 가변 길이를 쓰지 않는다.
- **오프셋은 1~2pt.** 밑줄이 글자에 거의 붙는다.

## 7. `_비평_시안AB.md` 실패 요인 — 반복 금지 10줄

1. **학습 페이지와 문제 페이지를 한 면에 섞었다.** 시중 교재는 어휘학습 / 확인문제 / 실전문제를 **면 단위로 분리**한다.
2. **위계가 2단계뿐**(알약 라벨 + 본문). 시중은 표지→헤더→섹션→발문→본문 **5단계**.
3. **챕터 컬러가 헤더에서 1회만 등장**하고 본문 어디에도 반복되지 않아 챕터 정체성이 사라졌다.
4. **콘텐츠가 컨테이너 없이 공중에 떠 있다.** 시중은 모든 블록이 박스/배경/괘선 안에 담긴다.
5. **양끝정렬 + 긴 빈칸 조합으로 자간이 폭주**(`B o r a`, `What ____ you ____`)했다. 좁은 단 양끝정렬 금지.
6. **빈칸을 가변 길이로 만들었다.** 고정 길이 인라인 룰(18/20/33/40mm)로 해야 한다.
7. **본문 영어·한글 해석·문법 설명이 전부 같은 회색 톤**이라 무엇이 중요한지 알 수 없다.
8. **형광 하이라이트가 없다.** "오늘 외울 표현"을 지면에서 즉시 찾는 장치가 부재한 것이 가장 결정적.
9. **문제 번호가 그냥 `01.` 검정.** 시중은 컬러 + Bold + 크게(백발 17pt / 내콘 13pt)로 한 단계 올린다.
10. **Apple SD Gothic Neo + Helvetica Neue** 조합. 시스템 UI 폰트라 인쇄물에서 "워드 출력물"로 읽힌다. (+ 시안B는 반대로 미니멀에 치우쳐 중2용 온기를 잃었다.)

| 내콘 문법 학습 | 15.8% | 3.6% | 2.0% |
| 내콘 Reading 학습 | 24.6% | 4.3% | 1.9% |
| 내콘 실전 문제 | 33.1% | **3.0%** | 0.1% |
| *(참고)* 포켓북 | 12~32% | 2.1~4.5% | 0~2.3% |
| *(참고)* 시안B 표지 | 14.4% | 7.7% | **6.9%** |

**관찰:**
- **유채색은 지면의 1~8%.** 학습 페이지 3~8%, **문제 페이지 1~3%** 로 절반 이하로 떨어뜨린다.
- **비백색(연한 틴트 포함)은 10~33%.** 즉 **틴트 면적은 크게, 진한 색 면적은 작게** 가 밝음의 공식이다. 내콘 실전문제 페이지가 33% 비백색인데 유채색은 3%뿐 — 전부 연라벤더 문제박스.
- **진한 색면(고채도 대면적)은 0.1~2%** 로 억제된다. 5% 넘어가는 곳은 오직 **간지/표지**뿐.
- → **유치해지는 지점은 "진한 색면 5% 초과"**. 시안B 표지 6.9%는 오히려 색면은 충분했고 문제는 배치였다.

### 8-2. 여백

- 두 권 모두 **하단을 비운다.** 백발 실력굳히기 페이지(p.44)는 좌단 하단 40% 가까이 비어 있고, 내콘 실전 페이지도 문항 사이를 20pt(7mm)씩 벌린다. **면을 꽉 채우지 않는 것**이 밝음의 최대 요인.
- 행간을 크게 잡는다: **139~174%.** (포켓북은 130~150%로 더 빡빡하다.)
- 문항 간 간격 = 본문 행간의 **1.5~2배**.
- 사이드 패널(폭 45~59mm)을 두어 본문 단폭을 **125~127mm** 로 제한 → 한 줄이 길지 않다.

### 8-3. 아이콘·일러스트 사용량

| | 백발 | 내콘 |
|---|---|---|
| 래스터 이미지 | **0장** (전 페이지 벡터) | **0장** |
| 페이지당 벡터 패스 | 45~180 | 157~260 |
| 일러스트 위치 | **헤더 좌상단 1개** (기차/칠판/책상/회전목마 라인 아이콘) + 간지 | **헤더 로고마크 1개**뿐 |
| 본문 내 일러스트 | **없음** | **없음** |
| 본문 내 아이콘 | ✔(Check Up), 🎯(Test Point), ▶(정답안내) 등 **기능성 아이콘 1~3개/면** | ▶(정답안내), ✎(서술형), ★(빈출) **1~3개/면** |

**→ 결정적 관찰: 두 권 모두 본문에 일러스트를 쓰지 않는다.** 일러스트는 **간지와 헤더 배지 안에만** 산다. "중등부다움"은 일러스트 개수가 아니라 **헤더 그래픽의 밀도 + 컬러 틴트 박스의 반복**에서 나온다.
→ 시안A가 "표지 일러스트만 있고 본문은 0"이라 비판받았는데, 정확한 처방은 "본문에 일러스트를 넣어라"가 아니라 **"헤더를 매 페이지 반복하고 본문에 틴트 박스를 깔아라"** 이다.

### 8-4. 유치함을 막는 억제 장치 (관찰됨)

1. **본문 먹을 순흑으로 쓰지 않는다.** 내콘 `#231F20`, 백발 `#000000`+보조 `#727171`.
2. **둥근 모서리 반경을 작게.** 알약은 완전 라운드지만, 박스는 r ≈ 1.5~3mm 로 억제.
3. **손글씨체를 딱 한 자리에만.** 백발 `Yeongdeok-Sea` / 내콘 `GangwonEduSaeeum` — 둘 다 **직독직해 문법 라벨 전용**. 제목·발문에는 절대 안 쓴다.
4. **파스텔 배경 블롭은 페이지 밖으로 잘라낸다**(백발). 온전한 도형은 아동스럽고, 잘린 도형은 편집디자인이 된다.
5. **영문 로고타입에 세리프/스크립트를 쓰지 않는다.** DIN·Century Gothic·Inter·Roboto 같은 기하학 산세리프만.
6. **이모지·캐릭터 없음.** 아이콘은 전부 단색 라인 또는 단색 면.
7. **간지에서만 색을 100% 쓴다.** 실측:
   - 내콘 간지 = 전면 **`#00AC75` 그린 단색 86%** + 흰 숫자/제목 6%. (톤온톤 라운드 사각 2개만 얹음)
   - 백발 간지 = **크림 `#FEEFC6` 79% + 골든옐로 `#FBC80E` 20% + 보라 `#914897` 7%** + 진남색 제목 `#323371`.
   - 즉 **간지도 "진한 색 1가지 + 나머지는 그 색의 연한 톤"** 구조다. 3색 이상 강하게 쓰지 않는다.
