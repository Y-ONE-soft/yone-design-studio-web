# 화이트북 02 (배재고1 26-2-중간) — 내지 조판

**코드는 이 폴더에 없다.** 통합웹 리포의 Vivliostyle 엔진이 조판한다.
여기 있는 것은 `config.json` + `원고/` + `assets/`(1권 완성본에서 뽑은 아트워크)
+ `참고/`(대조용 1권 완성본·원고) 뿐이다.

- 계열 스타일시트: `core/render_vivlio/themes/whitebook.css`
- 설계·함정: `docs/vivliostyle_엔진.md`

## 이 권의 성격

**실전문제(어휘 연습) 전용 권**이다. 1권처럼 A~E 단어 워크북이 붙지 않는다.
원고는 Day 01~20, 하루 20문항 = **400문항**(워드마스터 고등 COMPLETE Day 21~30).

면 구성 = **앞 간지(1면)** → Day 01~20 문제(2~101면) → Day 01~20 정답(102~121면)
→ **뒤 간지(122면)**. 정답은 뒤에 몰아서, Day 마다 새 면(사용자 확정).
Day 하나 = **20문항 = 정확히 5면**(한 면 4문항 사분면 고정). 정답은 Day 당 1면.
**122면 · A4+도련 3mm · TrimBox 전면.**

앞뒤 간지는 1권 완성본의 아트워크 면을 그대로 끼운다(`config.finish`) — 판 번호가
안 들어간 면이라 2권에 그대로 쓸 수 있다. 간지가 흐름 안에 실제 한 면으로 들어가
있어서 **쪽번호와 좌우(짝/홀)가 완성본과 같다**(본문은 2면 = 왼쪽 면에서 시작).
파리티가 어긋나면 MEMO 면(완성본 33면)으로 채운다.

⚠ 1권 완성본은 **도련 없이(A4 210×297) 뽑혀 있다.** 그대로 끼우면 그 면만 작아지고
TrimBox 가 재단선을 3mm 안쪽으로 잡아 간지가 잘린다 → 백엔드가 판형(216×303)
한가운데 놓는다(`bleed.insert_page`). 간지 도안은 가장자리에 색이 닿지 않아 이걸로 충분하다.

## 디자인은 1권 실전문제 실측 이식

1권 완성본(`참고/배재1_화이트북01_내지_v2_2.pdf`)의 **23~27면(EXERCISE)·40면(정답)**
을 자로 재서 옮겼다. 같은 원고(1권 Day 21~23 실전문제)를 이 엔진으로 조판해
완성본과 대조한 결과 **기준선·좌우 끝이 ±0.2mm**(면 세 곳은 ±0.1mm) 안에 든다.

- 사분면 한 칸 122.5mm · 단 82.05mm · 단 사이 3.65mm
- 문항 번호 Neolli Bd 11pt 청록 / 발문 Elice 9pt / 선지 Minion 9.21pt
- 한글은 로마자보다 한 호 작다(8.77pt) — 인디자인 합성 서체를 그대로 옮긴 것
- 짧은 문항 뒤에 칸이 비는 것은 **설계**다(사용자 확정) — 자연 흐름으로 바꾸지 말 것

⚠ 완성본은 **장평 95%** 로 짜여 있다. CSS 에는 장평이 없어 서식마다 자간
(+한글은 낱말 간격)으로 흉내 냈다. 글자 폭이 제각각인 로마자는 ±0.2mm,
한글은 ±0.35mm 까지 어긋난다 — 줄이 아주 가끔 한 낱말 일찍/늦게 꺾인다.

## 검수 (`verify`)

공용 게이트(판면 넘침·TrimBox·도련·준빈면) + 계열 게이트:

- Day 20개 · 각 5면 (사분면 계약)
- **원고 4,013항목이 제 Day, 제 면에 있는가** — 이 교재는 같은 발문이 400번
  되풀이돼서 전권을 한 줄로 이어 놓고 찾는 공용 순서 검사는 거짓 경보만 낸다.
  그래서 면 범위를 Day 로 좁히고, 순서 대신 **문항 N = (N-1)//4 번째 면**을 본다.
- 빈칸 유실(Day 단위 개수 대조) · 사분면 넘침(측정 높이 vs 122.5mm)

경고로 남는 것: 청록 위 연두(DAY)·흰 바탕 위 청록(문항 번호) 대비가 3:1 미만.
**1권 디자인 그대로**라 고치지 않았다.

⚠ 이 판형에서 색이 **세 갈래**로 들어간다는 것을 알고 있어야 한다.

줄이고 알파(SMask)만 남긴다. ②③ 을 빼먹으면 띠와 로고만 다른 색으로 나간다
