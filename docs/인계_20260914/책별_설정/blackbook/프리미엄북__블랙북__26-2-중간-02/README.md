# 블랙북 02 (배재고1 26-2-중간) — 내지 조판

**코드는 이 폴더에 없다.** 통합웹 리포의 Vivliostyle 엔진(`blackbook` 계열)이 조판한다.
여기 있는 것은 `config.json` + `원고/` + `assets/` + `overrides.css` 뿐이다.

```bash
cd ~/dev/yone-design-web
bin/viv "…/프리미엄북/블랙북/26-2-중간-02" data      # 원고 docx 6종 → data.json
bin/viv "…/프리미엄북/블랙북/26-2-중간-02" build     # 높이 측정 → 조판 → 마감
bin/viv "…/프리미엄북/블랙북/26-2-중간-02" verify    # 원고 ↔ PDF 전수 대조 게이트
bin/viv "…/프리미엄북/블랙북/26-2-중간-02" theme     # 아트워크 재추출(디자인 변경 시)
```

## 1권과 무엇이 다른가

원고가 **교과서(과)** 가 아니라 **모의고사 지문 번호**다. 계열 코드는 그대로 두고
config 로 갈랐다.

| 것 | 1권 | 2권 |
|---|---|---|
| 묶음 | `1과`·`2과` | `18 ~ 22번`·`23·24·29 ~ 31번` (`manuscript.labels`) |
| 지문 마커 | `<1과 본문1>` | `<18번>` — 꺾쇠 안 숫자면 마커, 라벨은 원고 말 그대로 |
| 어휘 제목 줄 | 있음 | 없음 (`manuscript.vocab_title: false`) |
| 머리말 | 공통영어2 능률(오) | 고1 2023년 11월 학력평가 (`book.subject`) |
| 선지 | 단락 `① …` | **표**(6행×3~4열) — 한 행이 선지 한 줄 |
| 빈칸 | 반각 공백 | **전각 공백(U+3000)** |
| 화살표 | `↓` | `⇓` |
| 브랜드 | BLACK BOOK VOL.1 | VOL.2 — 아트워크는 26-1-기말 2권 완성본에서 잘랐다 |

## 조판 순서 (사용자 지시)

연관어휘 18~22 → 문제 18~22 → 연관어휘 23~31 → 문제 23~31 → 해설 18~22 → 해설 23~31.

| 구간 | 쪽 |
|---|---|
| 앞 간지 | 1 |
| 연관어휘 18~22번 (지문 하나 = 한 면) | 2–6 |
| 문제 01~60 (한 면 2문항 가변) | 8–37 |
| 연관어휘 23·24·29~31번 | 38–43 |
| 문제 61~140 | 44–83 |
| 정답 및 해설 간지 | 84 |
| 해설 1~60 · 61~140 (2단, 정답+해석+해설) | 86–98 · 100–115 |
| 뒤 간지 | 116 |

빈 면은 MEMO 면(원본 마스터 모눈)으로 채우고, 마지막 면은 언제나 왼쪽(짝수).

## overrides.css — 이 책만의 예외

머리 제목이 1권보다 훨씬 길다("고1 2023년 11월 학력평가 18 ~ 22번"). 문제 머리에는
Date·Time·점수 칸이 같이 앉으므로 **문제 머리에서만** 제목을 12pt 로 줄이고 기입칸을
오른쪽으로 민다. 어휘·해설 머리는 기입칸이 없어 18pt 그대로 둔다.
브랜드 아트워크가 VOL.1 보다 0.73mm 넓어 `--brand-w` 도 여기서 덮는다.
