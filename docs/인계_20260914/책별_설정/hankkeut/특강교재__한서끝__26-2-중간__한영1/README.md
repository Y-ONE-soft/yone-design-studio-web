# 한서끝 — 한영고1 26-2-중간 (문제형 내지, Vivliostyle)

한영고 서술형 끝. 한단끝·한문끝과 같은 **한끝 계열**의 특강 교재 중 **문제형**.
코드는 리포 `core/render_vivlio/series/hankkeut/` + `themes/hankkeut.css`, 이 폴더에는
config · 원고 · 자산 · 산출 PDF 만 둔다.

```
bin/viv "<이 폴더>" all        # data → build → print → verify
bin/viv "<이 폴더>" watch      # 라이브 미리보기
```

## 원고 (확정본 2026-09-13)

드라이브 `콘텐츠 관리/내신대비/2026년/고1/한영고1/3. 26-2-중간/한서끝` 의 **로컬 사본**(`원고/`).
원고가 바뀌면 다시 복사해 온다 — 드라이브 파일은 직접 건드리지 않는다.

- `한서끝 문제지.docx` — 머리 4줄 + `[서답형 N] 발문 〈출처〉` 40문항(세트·파트 표지 없음)
- `한서끝 정답및풀이_학생용.docx` — 빠른 정답 40줄 + 문항별 ▶지문 해석 / ▶요약문 해석 / ▶풀이 방법
- `원고/_초안/` 은 9/8 초안(형식이 달라 쓰지 않는다)

인식 게이트(`bin/viv … data`): 문항 번호 연속 · 원고 머리 구성 줄(어법 5 · 요약 13 …) == 구조 판정 ·
문항마다 지문·답란·출처 · 요약문 글자 칸 수 == 답란 첫 글자 수 · 빠른 정답/풀이 40 == 문항 ·
정답지 유형 이름·출처·정답 == 문제지. 게이트는 일부러 망가뜨린 입력으로 걸리는 것을 확인했다.

## 구성

앞 간지 1 → PART 01 간지 2 → 서답형 40제 → PART 02 간지 2 → 빠른 정답 → 문항별 풀이(2단)
→ MEMO → 뒤 간지 1. 총 면수는 `finish.multiple` 배수 — 기본 무선제본이라 2(짝수), 중철일 때만 4.

## 지면 규칙 (사용자 지시 2026-09-11)

- 문제는 **한 면 위·아래 두 칸**(칸 119.5mm)에 한 문항씩, 높이는 잰다(`heights.json`).
- 한 칸에 안 들어가는 문항은 한 면 통째 — 위 칸 차례면 아래 칸 삭제, 아래 칸 차례면 비우고 다음 면.
- 유형(요약·어법·내용 질문·일치·배열·낱말)은 칩 색으로 가른다(`palette.TYPE_COLORS`).
  파트 색은 여섯 벌(주색+보조색), 공통색은 표지 돌·종이 톤.
- 글리프 금지: `↓`·`▶`·`○/✕` 는 도형·칩으로, 밑줄 문자는 상자 테두리로.

## 남은 확인

- 표지 문구(`cover.grid`·`tagline`)는 한문끝 구성을 따른 임시값.
- 서체 TTJamak(표지) 없음 → 간지 명조는 마루부리.
- 제본이 무선·스프링이면 `finish.multiple` 을 2 로(MEMO 면이 줄어든다).
