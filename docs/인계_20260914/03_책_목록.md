# 03 책 목록 (config.json 이 있는 비블리오 책 전부)

`core/render_vivlio/book.py` 의 `discover()` 로 교재 트리(`Y.ONE STUDIO/조판/교재`)를 훑어 뽑았다. 2026-09-14 기준 **59권**, 내지 인쇄본 있음 **38권**.

동형모의고사(`mockexam`)는 계열 레지스트리 밖이라 여기 없다(02 문서 참고). 원본 표는 `책_목록.json`, 책마다의 config·README 사본은 `책별_설정/<계열>/`.
