## 3. 신규 기기 복구 절차 (순서대로)

1. **기초 환경**: macOS 로그인 → Apple ID(iCloud Drive 동기화 시작, `~/Documents/작업/…` 복원 대기) → Homebrew 설치 → `brew install cloudflared git`
2. **코드**: `git clone git@github.com:YONE-DESIGN/YONE-DESIGN-WEB.git ~/dev/yone-design-web` (+ `git worktree add ~/dev/yone-design-web-summer summer-2026`). GitHub 접근용 SSH 키 재발급 필요.
3. **의존성**: `pip3 install --user -r requirements.txt` — Flask 런타임이 `/usr/bin/python3`(3.9)이므로 반드시 시스템 python3의 `--user`로 (site-packages가 `~/Library/Python/3.9/…`에 놓여야 start_flask.sh의 PYTHONPATH와 일치).
4. **.env 재작성**: `~/dev/yone-design-web/.env`에 1절의 키 6종 기입 (STUDIO_ROOT는 `~/Documents/작업/Y.ONE STUDIO`, 비밀번호/시크릿은 재발급).
5. **start_flask.sh 재작성**: `~/start_flask.sh` — 저장소로 cd → `.env` source → `PYTHONPATH=~/Library/Python/3.9/lib/python/site-packages` → `exec /usr/bin/python3 app.py`.
6. **launchd 등록**: `~/Library/LaunchAgents/`에 plist 6종 재작성(레이블·스크립트 경로는 1절 표 참조, indesign-keepalive는 저장소 `scripts/`에 사본 있음) → `launchctl bootstrap gui/$(id -u) <plist>` → flask는 `launchctl kickstart -k gui/$(id -u)/com.yonestudio.flask`.
7. **InDesign 2026 설치**: Adobe CC → InDesign 2026 (스크립팅 권한 허용, 첫 실행 후 다이얼로그 정리). `/Applications/Adobe InDesign 2026.app` 경로 확인 (runner 콜드스타트가 이 경로를 사용).
8. **GDrive**: Google Drive 데스크톱 설치 → `etyrano11@gmail.com` 로그인 → `~/Library/CloudStorage/GoogleDrive-…` 마운트 확인 (final 엔진 추출 경로).
9. **Cloudflare Tunnel**: `cloudflared login` → 터널 재생성 또는 기존 터널에 신규 credential → `~/.cloudflared/config.yml` 재작성 (ingress: yonestudio.com → `http://localhost:5010`) → launchd cloudflared 기동 → 외부에서 yonestudio.com 접속 확인.
10. **검증**: localhost:5010과 yonestudio.com 양쪽 접속 → 샘플 엔진 1개 조판 E2E → `python3 -m pytest tests/ -q` (2026-07-06 기준 191 passed).

## 5. 리허설 결론

- **복구 가능 여부: 가능. 실측 추정 1~2일(집중) / 2~3일(여유)** — git·GDrive·iCloud 3축이 코드와 콘텐츠 대부분을 커버한다.
- 단 이 추정은 **계정 접근(Apple/Google/GitHub/Adobe/Cloudflare)과 .env 비밀값 재구성이 가능하다는 전제** 위에 있다. 4절 2번(구성 파일 공백)을 메우면 복구 소요가 반나절 이상 단축되고, 1번(data_corpus/jobs)을 메워야 "복구 후에도 잃는 것 없음"이 된다.
- 실제 백업 실행(아카이브 스크립트 변경, .env.example 추가, plist 추적 등)은 본 조사 범위 밖 — 별도 승인 후 진행할 것.
