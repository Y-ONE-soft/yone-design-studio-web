# Y.OS 시험범위 읽기 API — 요청서

조판(파이널 직전보충 등)이 **시험범위를 Y.OS 에서 직접 읽도록** 주소 하나를
열어 달라는 요청이다. 지금은 `/work/exam` 화면에만 있고 꺼내 줄 길이 없다.

## 왜 필요한가

조판은 시험범위로 **원고 폴더를 찾는다.** 지금까지는 워크북 파일 이름
(`…(리딩파워12강,14강)…`)을 읽었는데 그건 범위의 대역이라 새는 데가 있었다 —
어떤 학교는 시트에 적힌 교과서가 파일 이름에 없어 그 7지문이 통째로
'외부지문' 으로 잘못 들어갔다.

Y.OS 는 이미 범위를 **항목**으로 받고 있어서(구분·교재·범위·지문수) 이 문제가
구조적으로 사라진다.

## 무엇을 열어야 하나

```
GET /api/exam-scopes?school=명일여고&grade=고1[&week=3]
Authorization: Bearer <서비스 토큰>     ← 사람 세션 말고
```

돌려줄 것 — **`/work/exam` 이 이미 들고 있는 값 그대로**:

```jsonc
{
  "line": {
    "seriesId": "cmsgxbnrr…",
    "school": "명일여고", "grade": "고1", "instructor": "정다니엘"
  },
  "weeks": [{
    "weekNo": 3,
    "volNo": 3,
    "classDate": "2026-08-17T09:00:00.000Z",
    "scopeStatus": "COLLECTED",          // 조판을 막을지 결정한다
    "scopeText": "…",                    // '직접 입력' 원문 (있으면)
    "updatedAt": "2026-08-18T02:11:00Z", // 어느 제출본으로 조판했는지 기록용
    "seriesScopes": [
      { "kind": "교과서",   "book": "공통영어2_NE능률민병천",
        "range": "Lesson 1. Bonding with Others 1~9, Lesson 2. … 1~12",
        "count": 21 },
      { "kind": "모의고사", "book": "고1_2024_09월(인천시)",
        "range": "15~18, 20~24", "count": 9 }
    ]
  }]
}
```

## 지켜 주셔야 할 것 (정확도가 여기에 달려 있다)

1. **가공하지 말 것.** `공통영어2_NE능률민병천` 을 그대로 주면 된다.
   조판 쪽에 표기를 맞추는 코드(`normalize_book()`)가 **시험과 함께** 있다.
   양쪽이 각자 정규화하면 어긋나는 자리가 하나 더 생긴다.
2. **`count`(지문수)를 꼭 실어 줄 것.** 이건 단순 표시값이 아니다 —
   Y.OS 가 범위 글에서 **직접 센** 값이라, 조판 파서와 맞대 보는
   **독립적인 두 번째 구현**이 된다. 실제로 이 대조가 조판 파서의
   `Mini Test` 누락(25 vs 49)과 `(PART 01) 09 …` 오독(8 vs 16)을 잡아냈다.
   이게 없으면 범위를 잘못 읽어도 아무도 모른다.
3. **`scopeStatus` 를 실어 줄 것.** 미확정인데 조판이 돌면 안 된다.
4. **`직접 입력` 원문도 그대로.** 구조화로 안 낸 라인은 조판 쪽에서 글로 읽는다.
5. **읽기 전용.** 조판은 아무것도 쓰지 않는다.

## 왜 DB 직독이 아니라 API 인가

- Y.OS 가 컬럼을 바꾸면 바깥 SQL 은 **조용히** 빈 값이나 옛 값을 돌려준다.
  조판은 '범위 0건' 이 아니라 '범위가 좀 이상한 책' 을 만들어 낸다.
  API 는 Y.OS 저장소 안에 있어 모델이 바뀌면 그쪽에서 먼저 깨진다.
- `count` 는 저장된 값이 아니라 **앱 코드가 계산한** 값이다. DB 만 읽으면 그
  계산을 조판 쪽에서 다시 구현해야 하고, 그러면 대조가 아니라 **같은 실수의
  복사**가 된다. 위의 두 오독도 못 잡는다.

## 곁들여 봐 주실 것

`GET /api/projects` 가 **로그인 없이 전체 목록을 그대로 내준다**(직원 이름 포함
63건). 다른 `/api/*` 는 401 로 막혀 있는데 이것만 열려 있다.
