# 10. 워크북 leaf 코드별 부속 단락 표준 구조 (워크북-B)

작성일: 2026-05-26
대상: 146개 leaf 코드 (분류 체계 v1.1) → 발문 다음 따라오는 단락 종류 매핑

## 핵심 아이디어

분류기는 **발문**에 leaf 코드를 부여한다. 그러면 그 leaf 코드만 보고 "이 발문 다음에 무엇이 따라오는가"를 결정할 수 있어야 한다.

예: `OBJ-FLW-INSERT` 발문 다음에는 항상:
```
[주어진 문장 박스]    ← P-CONTEXT
[본문 ①~⑤ 위치 마커]  ← P
[선지 ① ② ③ ④ ⑤]   ← C (5개)
```

이 표준 구조가 정의되어 있으면, 단어 변화에 둔감하게 단락 종류를 결정할 수 있다.

## 부속 단락 구조 정의 (leaf 코드별)

표기:
- `+ N개`: N개 따라옴 (예: `+ C×5` = 선지 5개)
- `?`: optional (있을 수도, 없을 수도)
- `→`: 그 순서로 따라옴
- (괄호): 단락 내부 속성

## 부속 단락 식별 알고리즘

```python
def identify_subordinate_blocks(question_para, question_code, paragraphs):
    """발문 + leaf 코드 → 부속 단락 블록 식별"""
    structure = SUBORDINATE_STRUCTURE[question_code]  # 위 표

    blocks = []
    cursor = question_para.index + 1
    for expected in structure:
        # expected = "P-CONTEXT" | "P" | "P-A" | "C×5" | "Box" | "Cond" | "Answer" | ...
        block, cursor = consume_block(expected, paragraphs, cursor)
        blocks.append(block)
    return blocks


def consume_block(expected, paragraphs, cursor):
    """expected 종류의 단락 블록을 cursor부터 소비.

    예:
      consume_block("P-CONTEXT", paras, 5)
        → paras[5]가 영어 통문장이면 (block=[paras[5]], cursor=6) 반환
      consume_block("C×5", paras, 10)
        → paras[10]~paras[14]가 ①②③④⑤ 시작이면 (block=[10:15], cursor=15) 반환
    """
    # skip blank
    while cursor < len(paragraphs) and is_blank(paragraphs[cursor]):
        cursor += 1
    if cursor >= len(paragraphs):
        return None, cursor

    if expected == "P-CONTEXT":
        # 영어 통문장 1개 (또는 짧은 문장)
        return [paragraphs[cursor]], cursor + 1
    if expected == "P-A":
        # (A) <영문>으로 시작하는 단락
        if paragraphs[cursor].text.startswith("(A)"):
            return [paragraphs[cursor]], cursor + 1
    if expected == "C×5":
        # ①②③④⑤ 5개
        block = []
        for mark in "①②③④⑤":
            if paragraphs[cursor].text.startswith(mark):
                block.append(paragraphs[cursor])
                cursor += 1
        return block, cursor
    if expected == "Box":
        # <보기> 마커 또는 단독 "보기"
        if paragraphs[cursor].text.strip() in ("<보기>", "보기"):
            cursor += 1
            block = []
            while cursor < len(paragraphs) and not is_terminator(paragraphs[cursor]):
                block.append(paragraphs[cursor])
                cursor += 1
            return block, cursor
    if expected == "Cond":
        # <조건> 또는 단독 "조건"
        if paragraphs[cursor].text.strip() in ("<조건>", "조건"):
            cursor += 1
            block = []
            while cursor < len(paragraphs) and not is_terminator(paragraphs[cursor]):
                block.append(paragraphs[cursor])
                cursor += 1
            return block, cursor
    # ...

    # fallback: 그냥 다음 단락 1개
    return [paragraphs[cursor]], cursor + 1
```
