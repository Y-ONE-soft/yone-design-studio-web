# 03. 원고 분류 체계 v1 — 광범위 완성판

작성일: 2026-05-25
범위: 2025년 + 2026년 내신대비 전 학교 / 전 시험기간

분류 1차 기준 (사용자 확정):
- **Level 0**: 컨텐츠 분기 (A. 본문/분석 vs B. 문제)
- **Level 1**: 문제 유형 (B군 내)
- **Level 2**: 교재 유형
- **Level 3**: 변형 (발문/보기/정답/출처 표기)

A군은 간략히, B군은 leaf 유형까지 깊게.

---

## A군 — 본문/분석 자료 (간략 분류)

A군은 발문이 없으므로 "원고에 무엇이 담겼는가"로만 구분.

### A1. 본문 원고
- **A1-a. 영어 본문 단독**: 지문만, 한글 해석 없음 (드물게 등장)
- **A1-b. 영어 본문 + 한글 해석**: 문장 단위 1:1 대응 (워크북/포켓북의 기반 원고)
- **A1-c. 6자리 출처 코드 부착형**: `221120` 형태로 모의고사 출처(YY년 MM월 NN번) 표시. 본문 위 첫 줄.

### A2. 포켓북/분석본
- **A2-a. 본문 + 단어/표현**: 본문 + 어휘/표현 해설 (별도 박스)
- **A2-b. 본문 + 어법 해설**: 본문 + 문장별 어법 풀이 (밑줄 + 해설)
- **A2-c. 본문 + 단어 + 어법**: 통합형 (포켓북 표준)

### A3. 어휘/표현 정리
- **A3-a. 어휘 빈칸 해설지**: 문장 + 빈칸 + 알파벳 단어 시작 단서 (직전보충형)
- **A3-b. 어휘 단어장**: 표 형식 (영-한)
- **A3-c. 표현/구문 정리**: 본문 발췌 표현 + 해설

### A4. 교과서 본문
- 교과서 단원 단위 원고 (별도 가공 없는 원본)

### A5. 단어장 (전용)
- xlsx 표 (단어 / 품사 / 뜻 / 예문 / 강 / 회차)
- → 한영보카 엔진 기 자동화

## B군 — 문제 자료 (깊은 분류)

### B군 구조 개관

```
B. 문제 자료
├── B-I. 객관식
│   ├── 1. 어휘
│   ├── 2. 어법
│   ├── 3. 내용 이해
│   ├── 4. 글의 흐름
│   ├── 5. 세부 정보
│   ├── 6. 장문 독해 (1지문 N문항)
│   └── 7. 듣기 (별도)
└── B-II. 서술형
    ├── 1. 단어 채우기
    ├── 2. 어법 수정
    ├── 3. 우리말 정리
    ├── 4. 영작
    └── 5. 본문 발췌
```

## B-I. 객관식 (Level 1)

각 유형의 시그니처 발문 표제어, 변형 표기, 정답 표기 변형을 정리.

### B-I-1. 어휘 유형

| 코드 | 유형명 | 시그니처 발문 | 보기 표기 | 정답 |
|---|---|---|---|---|
| `OBJ-VOC-SYN` | 동의어 매칭 | "밑줄 친 어휘 중 동의어 관계가 잘못 짝지어진 것은?" | ①~⑤ 각 문장 + (=동의어) | 1개 |
| `OBJ-VOC-DEF` | 영영풀이 매칭 | "다음 영영풀이에 해당하는 단어가 아닌 것은?" | ①~⑤ 단어 | 1개 |
| `OBJ-VOC-APPLY` | 빈칸 적용 (한 단어가 어느 문장에 들어가나) | "다음 주어진 단어가 들어가기에 적절하지 않은 문장은?" | ①~⑤ 빈칸 포함 문장 | 1개 |
| `OBJ-VOC-PAREN` | 괄호 (A)(B)(C) 선택 | "다음 글의 괄호 (A), (B), (C) 안에서 문맥에 맞는 낱말로 가장 적절한 것은?" | ①~⑤ 각 (A)(B)(C) 조합 | 1개 |
| `OBJ-VOC-UND-WRONG` | 밑줄 OX (문맥상 어색) | "밑줄 친 부분 중, 문맥상 낱말의 쓰임이 적절하지 않은 것은?" | ①~⑤ 본문 밑줄 | 1개 |
| `OBJ-VOC-UND-WRONG-MULTI` | 밑줄 OX 복수 정답 | "...적절하지 않은 것끼리 짝지은 것은?" / "...두 개를 고르면?" | ①~⑤ + 짝 | 2개 |
| `OBJ-VOC-UND-MEAN` | 밑줄 의미 매칭 (다의어/유의어) | "밑줄 친 부분 중 문맥상 낱말의 풀이가 적절하지 않은 것은?" / "ⓐ~ⓔ 중 문맥상 의미가 같은 것만을 있는 대로 고른 것은?" | ①~⑤ | 1개 또는 모두 |

### B-I-2. 어법 유형

| 코드 | 유형명 | 시그니처 발문 | 보기 표기 | 정답 |
|---|---|---|---|---|
| `OBJ-GRM-UND-WRONG` | 밑줄 OX (어색) | "다음 글의 밑줄 친 부분 중 어법상 어색한 것은?" | ①~⑤ 본문 밑줄 | 1개 |
| `OBJ-GRM-UND-WRONG-MULTI` | 밑줄 OX 복수 정답 | "어법상 어색한 두 곳을 찾아..." (서술형으로 변환되기도) | ①~⑤ | 2개+ |
| `OBJ-GRM-UND-CORRECT` | 밑줄 옳은 것 (반대) | "어법상 옳은 것을 두 개 고르면?" | ①~⑤ | 2개+ |
| `OBJ-GRM-PAREN` | 괄호 (A)(B)(C) 선택 | "괄호 (A), (B), (C) 안에서 어법에 맞는 표현끼리..." | ①~⑤ 조합 | 1개 |
| `OBJ-GRM-MARK-CORRECT` | 마크 묶음 옳은 것 | "ⓐ~ⓕ 중 문법적으로 올바른 것으로 묶인 것은?" | ①~⑤ 마크 조합 | 1개 (조합) |

### B-I-3. 내용 이해 유형

| 코드 | 유형명 | 시그니처 발문 | 정답 |
|---|---|---|---|
| `OBJ-CTN-TITLE` | 제목 | "다음 글의 제목으로 가장 적절한 것은?" | 1개 |
| `OBJ-CTN-TOPIC` | 주제 | "다음 글의 주제로 가장 적절한 것은?" | 1개 |
| `OBJ-CTN-GIST` | 요지 | "다음 글의 요지로 가장 적절한 것은?" | 1개 |
| `OBJ-CTN-CLAIM` | 필자의 주장 | "다음 글에서 필자가 주장하는 바로 가장 적절한 것은?" | 1개 |
| `OBJ-CTN-PURPOSE` | 글의 목적 | "다음 글의 목적으로 가장 적절한 것은?" | 1개 |
| `OBJ-CTN-MOOD` | 분위기/심경 | "다음 글에 드러난 ~의 심경으로 가장 적절한 것은?" / "글의 분위기로..." | 1개 |
| `OBJ-CTN-TONE` | 어조/태도 | "다음 글에 드러난 ~의 어조로..." | 1개 |
| `OBJ-CTN-MATCH` | 일치/불일치 | "다음 글의 내용과 일치하지 않는 것은?" / "...일치하는 것은?" | 1개 |
| `OBJ-CTN-COUNT` | 일치 모두 (개수) | "내용을 바르게 이해한 것은 모두 몇 개인가?" | 개수 |
| `OBJ-CTN-INFO` | 도표/실용문 일치 | "도표의 내용과 일치하지 않는 것은?" / "안내문의 내용과..." | 1개 |
| `OBJ-CTN-PROVERB` | 속담 매칭 | "다음 글의 내용과 가장 관련 있는 속담은?" | 1개 |

### B-I-4. 글의 흐름 유형

| 코드 | 유형명 | 시그니처 발문 | 보기 표기 | 정답 |
|---|---|---|---|---|
| `OBJ-FLW-ORDER` | 순서 배열 | "주어진 글 다음에 이어질 글의 순서로 가장 적절한 것은?" | ①~⑤ 조합 ((A)-(C)-(B) 등) | 1개 |
| `OBJ-FLW-INSERT` | 문장 삽입 | "글의 문맥상 주어진 문장이 들어가기에 가장 적절한 곳은?" | ①~⑤ (A~E 위치) | 1개 |
| `OBJ-FLW-IRRELEVANT` | 무관한 문장 | "전체 흐름과 가장 관계없는 문장은?" | ①~⑤ 본문 문장 | 1개 |
| `OBJ-FLW-BLANK-WORD` | 빈칸 (단어) | "빈칸에 들어갈 말로 가장 적절한 것은?" + 단어 보기 | ①~⑤ 단어 | 1개 |
| `OBJ-FLW-BLANK-PHRASE` | 빈칸 (구) | 위 + 구 보기 | ①~⑤ 구 | 1개 |

| `OBJ-FLW-BLANK-AB` | 요약문 빈칸 (A)(B) | "한 문장으로 요약하고자 한다. 빈칸 (A), (B)에 들어갈 말로..." | ①~⑤ (A,B) 조합 | 1개 |
| `OBJ-FLW-BLANK-ABC` | 빈칸 (A)(B)(C) 셋 | "빈칸 (A), (B), (C)에 들어갈 말로 가장 적절한 것은?" | ①~⑤ (A,B,C) 조합 | 1개 |

| `OBJ-DTL-CAUSE` | 원인 / 사례 | "밑줄 친 ⓐ의 원인이 아닌 것은?" / "~에 해당하는 사례가 아닌 것은?" | 1개 |

## B-II. 서술형 (Level 1)

서술형은 변형이 매우 다양하므로 "행위 동사" 기준으로 분류.

### B-II-1. 단어 채우기

| 코드 | 유형명 | 시그니처 발문 |
|---|---|---|
| `SRV-WRD-BOX` | 빈칸 + 보기 (보기 중 선택) | "다음 문장의 빈칸에 알맞은 단어를 <보기>에서 골라 쓰시오" |
| `SRV-WRD-FROM-TEXT` | 본문 발췌 한 단어 | "본문에 찾아 한 단어로 쓰시오" |
| `SRV-WRD-FROM-TEXT-VAR` | 본문 발췌 어법 변형 가능 | "...본문에 찾아 한 단어로 쓰시오. (어법에 맞게 변형 가능)" |
| `SRV-WRD-START-LETTER` | 첫 글자 주어짐 | "괄호 안에 주어진 알파벳은 단어의 첫 글자임" / "빈칸에 주어진 철자에 맞게 쓰시오" |

### B-II-2. 어법 수정

| 코드 | 유형명 | 시그니처 발문 |
|---|---|---|
| `SRV-GRM-FIX-MARKED` | 다수 밑줄 → 각각 고치기 | "밑줄 친 문장 ⓐ~ⓔ의 어법상 어색한 부분을 각각 하나씩 찾아 바르게 고치시오" |
| `SRV-GRM-FIX-FIND-K` | 어법상 어색한 K곳 찾기 | "어법상 어색한 두 곳을 찾아 기호를 쓰고 바르게 고치시오" |
| `SRV-GRM-FIX-ALL` | 글 전체 읽고 틀린 부분 찾기 | "다음 글을 읽고 틀린 부분을 찾아 고치시오" (어법총정리 표준) |

### B-II-3. 우리말 정리

| 코드 | 유형명 | 시그니처 발문 |
|---|---|---|
| `SRV-KOR-CASES` | 사례/근거 우리말로 | "~에 해당하는 N가지 사례를 찾아 우리말로 쓰시오" |
| `SRV-KOR-MEAN` | 의미를 우리말로 | "~가 의미하는 바를 우리말로 쓰시오" |
| `SRV-KOR-REASON` | 이유를 우리말로 | "~한 이유를 본문에서 찾아 우리말로 쓰시오" |

### B-II-4. 영작

| 코드 | 유형명 | 시그니처 발문 | 보기/조건 |
|---|---|---|---|
| `SRV-WRT-COND` | 조건 영작 (단어 배열) | "다음 빈칸에 들어갈 말을 <조건>에 맞게 쓰시오" | 주어진 단어 모두 사용, 본문 단어 추가, N단어 이내, 변형 불가 |
| `SRV-WRT-COND-VAR` | 조건 영작 (변형 가능) | 위 + "필요 시 변형 가능" | 단어 변형 가능 |
| `SRV-WRT-SUMM` | 요약문 영작 (A)(B)(C) | "한 문장으로 요약하고자 한다. 빈칸 (A) ~ (C)에 들어갈 말을 본문의 단어를 활용하여 쓰시오" | 본문 단어 활용 |
| `SRV-WRT-KO-EN` | 우리말 → 영어 (자유) | "다음 우리말과 일치하도록 영어로 쓰시오" | 단어 힌트 |
| `SRV-WRT-ORDER` | 단어 배열 영작 | "주어진 단어를 바르게 배열하여 문장을 완성하시오" | 단어 배열 |

### B-II-5. 본문 발췌

| 코드 | 유형명 | 시그니처 발문 |
|---|---|---|
| `SRV-EXT-PHRASE` | 본문 구절 발췌 | "~를 의미하는 부분을 본문에서 찾아 쓰시오" |

## B-IV. Level 3 — 변형 표기 (모든 유형 공통)

leaf 유형 위에 적용되는 변형 차원. 같은 leaf 유형 안에서 다음 변형이 동시에 가능.

### V1. 보기 표기
- `V1-CIRCLE`: ① ② ③ ④ ⑤ (표준)
- `V1-NUMBER`: 1) 2) 3) 4) 5)
- `V1-PAREN-AB`: (A) (B) (C) (D) (E) (괄호 안 위치 표시)
- `V1-BRACKET-AB`: [A] [B] [C] (장문)
- `V1-MARK-CIRCLE`: ⓐ ⓑ ⓒ ⓓ ⓔ (마크 인용)

### V2. 정답 개수
- `V2-SINGLE`: 1개
- `V2-DUAL`: 2개 ("두 개를 고르면", "두 곳을 찾아")
- `V2-COMBO`: 조합 ("짝지은 것은", "묶인 것은")
- `V2-ALL`: 모두 ("있는 대로 고른", "모두 몇 개인가")

### V3. 정답 방향
- `V3-NEG`: 부정 (적절하지 않은 것, 일치하지 않는 것) — 한국 수능 영어 다수
- `V3-POS`: 긍정 (적절한 것, 일치하는 것)

### V4. 출처 마커
- `V4-NONE`: 출처 없음
- `V4-MOCK`: `[YY년 M월 N번]` (모의고사 출처)
- `V4-EBS`: `[EBS 강좌명 N강]`
- `V4-EXAM`: 학교 이름/연도 (자체 출제)

### V5. 묶음 단위
- `V5-SINGLE`: 단일 문항
- `V5-DOUBLE`: 1지문 2문항 (`[9~10]` 헤더)
- `V5-TRIPLE`: 1지문 3문항
- `V5-AB-LINK`: 2글 연계 (A/B 글)

### V6. 본문 내 마크 위치
- `V6-INLINE`: 본문 안 밑줄 (어휘 OX 등)
- `V6-PAREN`: 본문 안 괄호 (A)(B)(C)
- `V6-NUMBERED`: 본문 안 ① ② ③ ④ ⑤ (무관 문장 등)
- `V6-MARK`: 본문 안 ⓐ ⓑ ⓒ (지칭/의미 매칭)
- `V6-BOX-BLANK`: 본문 안 빈칸 박스

### V7. 보기 출처
- `V7-INDEP`: 독립 보기 (본문과 별개)
- `V7-INLINE-PICK`: 본문 안에서 픽 (밑줄 5개 중)
- `V7-COMBO-AB`: (A)(B)(C) 조합

## B-V. 채점/제시 변형 (보조 변형)

문제 본체에 부속되는 보조 요소:

- 점수 표시: `[3점]`, `[2점]` (가끔 발문 끝에 부착)
- 단어 수 제한: "N단어 이내", "N단어 이상 N단어 이하"
- 변형 허용: "어법에 맞게 변형 가능" / "원형으로 쓸 것" / "변형 불가"
- 중복 사용: "중복 사용 가능" / "중복 사용 불가"
- 본문 활용: "본문의 단어 활용" / "본문에 없는 단어 사용 가능"

이 보조 요소들은 채점 룰과 직결되므로 파서에서 별도 필드(`scoring_constraints[]`)로 분리해야 함.

## C. 분류 외 / 예외 영역 (Cross-check 대상)

광범위 추출 후 위 leaf 유형으로 분류되지 않은 발문은 별도 보관 → Phase 6에서 검증/추가.

예상 미분류:
- 듣기 문제 (mp3 의존)
- 학교 자체 출제 변형 (특이 발문)
- 작문 유도형 ("아래 표를 보고 한 단락의 글을 완성하시오" 등)

→ 광범위 추출 후 미분류 목록을 별도 부록으로 정리.
