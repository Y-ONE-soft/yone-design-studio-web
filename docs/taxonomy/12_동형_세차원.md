## 0) 동형의 특성

- 한 회분에 객관식 26 + 서술형 6 = 약 32문항 (학교별 변동)
- 한 시험지 통째로 자동화 (워크북처럼 STEP별 분리 X)
- 학교별 출제 패턴이 비슷 (수능 영어 표준 유형 망라)
- 광범위 추출 기준 발문 6,784건 (54개 폴더)
- 자주 등장하는 leaf 코드 top 10:
  - OBJ-FLW-BLANK-SENT (527)
  - OBJ-GRM-UND-WRONG (513)
  - OBJ-VOC-UND-WRONG (464)
  - OBJ-CTN-MATCH (435)
  - OBJ-FLW-ORDER (404)
  - OBJ-FLW-INSERT (401)
  - OBJ-FLW-BLANK-AB (372)
  - OBJ-CTN-TITLE (317)
  - OBJ-CTN-TOPIC (262)
  - OBJ-VOC-UND-MEAN (187)

이 외에 서술형 leaf 코드 다양: SRV-WRT-COND (24), SRV-GRM-FIX-MARKED (14) 등.

## A. 단락 종류 식별 시그니처

동형은 워크북과 거의 동일한 단락 종류를 가진다. 추가 종류:

| 코드 | 단락 종류 | 동형 특수 |
|---|---|---|
| GH | 그룹 헤더 (`[9~10]` 묶음 등) | 워크북과 동일 |
| TH | **시험지 헤더** (학교명/시험명/배점 표 등) | 동형 신규 |
| Q | 발문 | leaf 코드 부여 |
| Q-SUB | **묶음 내 서브 발문** (`[9~10]` 묶음 안 9번, 10번) | 동형 신규 |
| Q-INTRO | 묶음 도입 (`OBJ-LNG-HEADER`) | 워크북과 동일 |
| Q-SRV-NUM | **서술형 번호** (`서술형1.`) | 동형 표준 |
| P | 지문 | 워크북과 동일 |
| P-A / P-B | **A/B 글** (`OBJ-LNG-AB` 시) | 동형 신규 |
| P-CONTEXT | 배경 (주어진 문장 등) | 워크북과 동일 |
| C | 선지 ①~⑤ | 워크북과 동일 |
| C-COMBO | **조합 선지** ((A)/(B) 짝, 순서배열 조합) | 동형 표준 |
| Cond | 조건 박스 | 워크북과 동일 |
| Box | 보기 박스 | 워크북과 동일 |
| Box-COND-LIST | **조건 항목 (• N단어 이내, • 변형 가능)** | 동형 표준 |
| A | 정답 | 별도 정답지 페이지 |
| A-EXPL | 정답 해설 | 별도 |

### 동형 특화 시그니처

**TH (시험지 헤더)**: 시험지 첫 페이지 상단의 박스 — 학교 로고 + "고1 영어" + "26-1 중간고사" 등

| 우선순위 | 시그니처 |
|---|---|
| 1 | 페이지 1, 상단 박스 안 단락 |
| 2 | 학교 이름 + 학년 + 시험명 패턴 (`(고|중)\d (영어|English)`) |

→ 별도 마스터 페이지/스타일 적용.

**Q-SUB**: 묶음 내 서브 발문

| 우선순위 | 시그니처 |
|---|---|
| 1 | Q-INTRO (`OBJ-LNG-HEADER`) 또는 `[N~M]` 묶음 헤더 다음의 Q |
| 2 | 발문이 "윗글의" / "위 글의" 시작 (앞서 본 지문 참조 의미) |

**Q-SRV-NUM**: 서술형 번호

| 우선순위 | 시그니처 |
|---|---|
| 1 | `^서술형\s*\d+\.` 시작 |
| 2 | leaf 코드가 `SRV-*`이고 번호 prefix가 있음 |

**C-COMBO**: 조합 선지

| 우선순위 | 시그니처 |
|---|---|
| 1 | `^[①②③④⑤]\s*\(?[A-C]\)?\s*-\s*\(?[A-C]\)?` (순서 조합) |
| 2 | `^[①②③④⑤]\s*[a-zA-Z]+\s+[a-zA-Z]+` ((A)(B)(C) 단어 짝) |

## B. leaf 코드별 부속 단락 구조 (동형)

워크북 부속 구조와 거의 같지만 동형은 묶음(`[9~10]`)이 많다.

### 묶음 구조 표준

```
[OBJ-LNG-HEADER 또는 [9~10] 헤더] (Q-INTRO/GH)
  ↓
[P 지문] (공유)
  ↓
[Q-SUB N번] (첫 번째 서브 발문, leaf 코드 ①)
[C×5] (선지)
  ↓
[Q-SUB N+1번] (두 번째 서브 발문, leaf 코드 ②)
[C×5] (선지)
```

### A/B 2글 연계 구조 (`OBJ-LNG-AB`)

```
[Q-INTRO 또는 [20~21] 헤더]
  ↓
[P-A 글 A]
  ↓
[P-B 글 B]
  ↓
[Q-SUB 20번] [C×5]
[Q-SUB 21번] [C×5]
```

### 서술형 표준 구조

```
[Q-SRV-NUM 서술형N.]
  ↓
[Q 서술형 발문 본문]
  ↓
[P 지문] (서술형 전용 짧은 지문 또는 공유 지문 위 참조)
  ↓
[Box 보기 박스] (있는 경우)
  ↓
[Cond 조건 박스] (있는 경우, 보기 다음)
  ↓
[답 영역 (빈 단락 또는 답안 줄)]
```

`SRV-WRT-COND`:
```
서술형5. 다음 빈칸에 들어갈 말을 <조건>에 맞게 쓰시오.
  ↓
[P 지문 (또는 위 참조)]
  ↓
[<조건>]
  • 주어진 단어 (highlight / your / overshadow / them)
  • 7단어 이내
  • 변형 불가
  ↓
[답: ___________]
```

`SRV-WRT-SUMM`:
```
서술형6. 한 문장으로 요약하고자 한다. 빈칸 (A) ~ (C)에 들어갈 말을 본문의 단어를 활용하여 쓰시오.
  ↓
[P 지문]
  ↓
[Box 요약문]
  - "[The author argues that...] (A) reasons... (B) ... (C) ..."
  ↓
[답 (A): _____ (B): _____ (C): _____]
```

## C. 단락스타일 매핑 (신규 설계 안)

### 제안 단락스타일 그룹

InDesign 단락스타일 그룹: **"DONGYUNG"** (또는 `동형_표준`)

| GH | DONGYUNG > 묶음_헤더 (`[9~10]`) | 또는 마커 처리 |

| A | DONGYUNG_정답지 > 정답 | 별도 스토리 |

### 단락스타일 결정 함수 (제안)

```python
def resolve_dongyung_style(para, idx, paragraphs, prev_q_code):
    """동형 단락스타일 결정 — 분류 체계 기반."""
    kind = classify_paragraph(para, idx, paragraphs, prev_q_code)

    DONGYUNG_MAP = {
        "TH":           "DONGYUNG > 시험지_헤더",
        "GH":           None,  # 제거 (마커는 grouping에만 사용)
        "Q":            "DONGYUNG > 객관식_발문",
        "Q-SUB":        "DONGYUNG > 서브_발문",
        "Q-INTRO":      "DONGYUNG > 묶음_도입",
        "Q-SRV-NUM":    "DONGYUNG > 서술형_번호",
        "P":            "DONGYUNG > 지문",
        "P-A":          "DONGYUNG > 지문_A",
        "P-B":          "DONGYUNG > 지문_B",
        "P-CONTEXT":    "DONGYUNG > 배경",
        "C":            "DONGYUNG > 선지",
        "C-COMBO":      "DONGYUNG > 선지_조합",
        "Cond":         "DONGYUNG > 조건",
        "Box":          "DONGYUNG > 보기",
        "A":            None,  # 별도 정답지 스토리
    }
    return DONGYUNG_MAP.get(kind)
```

### Q-SUB의 발문 번호 자동 채번

동형은 발문 번호가 1~32 연속. 묶음의 경우 `[9~10]` 헤더 + 9번 + 10번이 묶음.

```python
def assign_dongyung_numbers(paragraphs):
    """동형 발문 번호 자동 채번."""
    num = 0
    in_group = False
    group_range = None
    for p in paragraphs:
        kind = classify_paragraph(p, ...)
        if kind == "GH":  # [9~10] 같은 묶음 헤더
            m = re.match(r"\[(\d+)~(\d+)\]", p.text)
            if m:
                group_range = (int(m.group(1)), int(m.group(2)))
                in_group = True
        elif kind in ("Q", "Q-SUB", "Q-SRV-NUM"):
            num += 1
            p.assigned_number = num
            if in_group and num > group_range[1]:
                in_group = False
                group_range = None
```

## D. 신규 엔진 구현 가이드

`engines/dongyung/` 폴더 신규 생성 시 권장 구조:

```
engines/dongyung/
├── __init__.py
├── config.json          # 학교/학기 정보, InDesign 템플릿 경로
├── engine.py            # DongYungEngine(BaseEngine) 클래스
├── parser.py            # 원고 → 구조화 JSON
├── style_resolver.py    # 단락 종류 → 스타일 결정 (위 함수)
└── jsx/
    └── run.jsx          # 구조화 JSON → InDesign 적용
```

### parser.py 핵심 흐름

```python
from engines._taxonomy import extract_text, classify

def parse_dongyung(path):
    text = extract_text(path)
    paragraphs = preprocess(text)  # 단락 분리, 정규화

    # 1. 단락 종류 결정 (워크북-A 시그니처)
    classified = []
    prev_q_code = None
    for i, p in enumerate(paragraphs):
        kind = classify_paragraph(p, i, paragraphs, prev_q_code)
        if kind in ("Q", "Q-SUB"):
            code, label, _ = classify(p.text)
            classified.append({"i": i, "p": p, "kind": kind, "code": code})
            prev_q_code = code
        else:
            classified.append({"i": i, "p": p, "kind": kind, "code": None})

    # 2. 발문별 부속 단락 묶음 (워크북-B 표준 구조)
    questions = group_into_questions(classified)

    # 3. 출력 JSON
    return {
        "header": extract_header(text),
        "questions": [{
            "number": q["number"],
            "code": q["code"],
            "blocks": [{"kind": b["kind"], "text": b["text"], "style": resolve_dongyung_style(...)} for b in q["blocks"]]
        } for q in questions]
    }
```

### run.jsx 핵심 흐름

```javascript
// 1. settings.json 읽기 → 구조화 JSON 받기
var data = readJSON(settingsPath + "/content.json");

// 2. InDesign 템플릿 열기
var doc = app.open(File(templatePath));

// 3. 발문 단위로 페이지 채우기
for (var i = 0; i < data.questions.length; i++) {
    var q = data.questions[i];
    var story = doc.stories[0];  // 메인 스토리

    for (var j = 0; j < q.blocks.length; j++) {
        var block = q.blocks[j];
        // 텍스트 삽입
        story.insertionPoints[-1].contents = block.text + "\r";
        // 스타일 적용
        var p = story.paragraphs[-2];  // 방금 삽입된 단락
        if (block.style) {
            p.appliedParagraphStyle = doc.paragraphStyles.itemByName(block.style);
        }
    }
}

// 4. 정답지 별도 스토리 채우기
// ...
```

## E. 학교별 변형

동형은 학교마다 미세한 차이가 있다 (메모리 `project_mockexam` 참조):
- 학교별 시험지 헤더 디자인
- 페이스보드(차트) 헤더 형식
- 정답 표기 (`①` vs `1`)
- 박스 처리 ([보기] vs <보기>)

학교별 분기는 config.json에서 처리:

```json
{
  "school": "한영고1",
  "version": "동형 v1",
  "indd_template": "/path/to/template_hanyoung.indd",
  "style_overrides": {
    "Q": "DONGYUNG_한영 > 객관식_발문"
  },
  "box_format": "bracket"  // [보기] 우선
}
```
