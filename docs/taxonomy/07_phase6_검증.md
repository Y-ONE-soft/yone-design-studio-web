| 영역 | 사유 |
|---|---|
| **듣기 문제** | mp3 의존, 텍스트 발문은 "다음을 듣고 ~" 변형 다수. 별도 트랙 |
| **학교 특이 발문** | 1~2개 학교만 사용. 학교 코드 부착으로 별도 분류 |

| **자체 출제 변형** | 학교 자체 출제 문제 (변형 차원 V4-EXAM에 해당) |

## 결론

### 분류 체계 성숙도
- **126개 leaf 코드 + 7개 변형 차원** — 한국 영어 내신/모의의 사실상 모든 표준 문제 유형 커버
- **86.1% 분류 성공률** — 대규모 광범위 데이터 기준 (학습지/특수 변형 제외 시 90%+)
- **잔여 14% 미분류** — 대부분 학교/원고 특이 변형, 빈도 < 30. 자동화 시 학교 코드/원고 코드 부착으로 별도 처리

### 자동화 신규 엔진 권장 (분류 결과 기반)
1. **engines/quiz_pool** (문제모음 전용) — 단일 hwpx 문항 라이브러리. 다른 교재의 소스 풀로 활용
2. **engines/dongyung** (동형 모의고사) — 객관식 26 + 서술형 6 표준 구조 자동 인식
3. **engines/grm_total** (어법총정리) — SRV-GRM-FIX-ALL 단일 유형, 자동화 ROI 큼
