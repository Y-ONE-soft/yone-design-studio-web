# docs/참고자료 — 외부에서 받아 온 참고자료

작업할 때 자주 들춰 보는, 이 리포 코드가 만들지 않은 자료를 모아 둔다(Y.OS·콘텐츠 팀·검증 보고 등).
**모든 세션이 같은 걸 보도록 리포 안에 두고, 원본 + 클로드가 읽기 쉬운 마크다운(README.md) + 기계용(JSON) 을 나란히 둔다.**

| 폴더 | 내용 | 먼저 볼 것 |
|---|---|---|
| `교재_블록_지도/` | 비블리오 전환 · 콘텐츠 유형 틀 검증(2026-09-15). 교재를 4개 층(블록 → 교재 구성 → 판형·제본 → 라인업·스킨)으로 나누고, **에셋·콘텐츠 연동 단위인 블록 11종(B1 원문지문 … B11 관리양식)** 의 필드·variant·실물, 라인업 12종의 블록 조합, 책 26종 × 블록 매트릭스, 블록이 아닌 것(틀·메타·속성·조립), 이름만 같은 함정, 미결 4건 | `README.md`(원본 전문 마크다운) → 표 단위 조회는 `교재_블록_지도.json`(`blocks.items`·`matrix.rows`·`compositions.items`) |

## 규칙

- 원본 파일(HTML·PDF 등)은 손대지 않고 그대로 둔다. 클로드는 원본 대신 `README.md`/JSON 을 읽는다.
- 새 자료를 받으면 `<자료명>/` 폴더를 만들고 원본 + `README.md`(무엇인지·핵심·찾는 법) 을 같이 넣는다. 갱신본이면 같은 폴더에 덮어쓰고 날짜를 바꾼다.
- 폴더 안에 `_extract.py` 가 있으면 원본에서 마크다운·JSON 을 다시 만드는 스크립트다(`python3 _extract.py <원본>`).
