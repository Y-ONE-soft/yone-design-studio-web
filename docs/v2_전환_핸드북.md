## 철칙 (위반 금지)
- v1 엔진(engines/<v1>/**)과 main 체크아웃(~/dev/yone-design-web) 절대 수정 금지
- 출력물은 `data_corpus/`만 (실서비스 조판/교재 폴더 금지)
- **InDesign에 넘기는 모든 경로 절대경로** (File(상대경로)는 InDesign 기준으로 풀림)

- 하트비트: 스타일 루프 50단락마다 wlog (러너 행 감지 300초)
- InDesign 실패: 러너 자동재시도 1회 → watchdog ensure 후 1회 → 3연속이면 "보류" 기록 후 오프라인 검증까지로 커밋 (**킬 루프 금지**). 이전 렌더가 락(/tmp/indesign_exec.lock) 점유 시 해당 프로세스 정리 후 진행. 반복 강제종료 후 "대화상자 활성화(30486)" 나오면 복구 폴더(`~/Library/Caches/Adobe InDesign/Version 21.0-J/ko_KR/InDesign Recovery`) 내용물을 `~/Backups/`로 **이동**(삭제 금지) 후 재기동.
- .env 로드: 드라이버 첫머리에서 `~/dev/yone-design-web/.env` 읽어 os.environ.setdefault
- 골든 코퍼스: `tests/corpus/<v1엔진>/` (없으면 `scripts/build_corpus.py`에 시그니처 추가해 선별 — jobs는 `~/dev/yone-design-web/jobs`). 코퍼스 불가(GDrive 의존)면 GDrive 원고로 블라인드 방식 검증.
