# 편집기 기능 기록

편집기 코드(core/units · routes/units.py · routes/catalog.py · templates/units_canvas.html · static/js/units_compose.js)를 고치기 **전에** 맨 끝에 한 줄을 적는다.
지킴 훅(.claude/hooks/editor-guard.py)이 이 줄이 90분 안에 적혔는지 보고 고치기를 허락한다. 절차: docs/편집기_재현/절차.md 「편집기 기능을 바꿀 때」.

- 꼴: `- 날짜 · 책/구성 · 무엇을 · 인디자인: <같은 기능 이름> · 근거: <원본 몇 쪽 · 잰 값> · 기본: <설정 안 했을 때 = 지금 동작>`
- 「근거:」는 늘, 「기본:」은 새 기능일 때(버그 · 지움 줄은 빼도 된다). 근거가 「편집기 결과가 원본과 달라서」뿐이면 기능이 아니라 차이의 원인부터.
- 인디자인에 같은 기능이 없으면 `인디자인: 없음` 으로 적고, 사용자에게 물어 허락받은 뒤 같은 줄에 `· 허락: <시각 · 사용자 말>` 을 더한다.
- 버그 고치기면 `인디자인: <인디자인이 원래 그렇게 하는 동작>` (예: `인디자인: 행간은 단락 값 — 작은 글이 행간을 안 키운다`).
