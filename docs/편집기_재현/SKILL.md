1. `docs/편집기_재현/절차.md` 를 처음부터 끝까지 읽는다. 거기 적힌 순서·합격 기준·막힘 규칙이 전부다. 이 파일과 다르면 절차.md 가 이긴다.
2. 작업 지시를 `docs/편집기_재현/진행표양식.md` 틀로 진행표로 만들어 사용자에게 보이고 확인받는다.
3. 단위를 하나씩: 기준 수치 → 대본 → 빠른 검사 → 비교 → (합격) 녹화 → `보고양식.md` 대로 보고.
4. 막히면 멈추고 사용자에게 한 줄 보고 후 기능 수정.
5. 사용자가 확인한 단위만 체크하고 다음 단위로.
