1. `docs/편집기_재현/절차.md` 와 `docs/편집기_재현/원고자리_규약.md` 를 처음부터 끝까지 읽는다. 거기 적힌 순서·합격 기준·막힘 규칙이 전부다. 이 파일과 다르면 절차.md 가 이긴다.
2. 사용자가 지정한 원본을 단위로 나눠 `docs/편집기_재현/진행표양식.md` 틀로 진행표로 만들어 사용자에게 보이고 확인받는다.
3. 단위를 하나씩: 만들기 ↔ 비교를 같아질 때까지(한 판 끝나면 틀린 것을 다 고치고 다음 판) → 8배속 녹화 → `보고양식.md` 대로 보고.
   - 고정 글만 있는 면(표지·간지)은 그리기만. 원고가 들어가는 글상자는 **자리 + 임시 글 + 스타일 → 원고 넣기** (절차.md 「원고가 있는 면」, 견본 02B).
   - 측정 보정으로 덮지 않는다 — 기준선 공식·원본 글자 위치로. 어긋나면 원인을 찾는다.
4. 막히면 고쳐서 단위를 끝낸다. 보고는 한 줄씩 `문제 → 기능 추가 / 기능 수정`.
5. 사용자가 영상을 확인한 단위만 체크하고 다음 단위로.
6. 편집기 코드를 고치면 끝낸 단위도 다른 포트로 같이 다시 돌려 깨지지 않았는지 본다.
