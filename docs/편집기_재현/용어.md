# 편집기 용어집 — 인디자인 말로 통일 (2026-10-12 초안 — 「분류 · 자동 상위 페이지 적용 · 템플릿 등록」 뜻과 「두 페이지짜리」 · 3칸/4칸 고르기는 사용자 확인, 나머지 말은 확인 전)

편집기 화면 · 절차 문서 · 원고 규약 · 대화에서 **이 말만** 쓴다. 옛말은 오른쪽에 적어 두지만 새로 쓰지 않는다.
저장 데이터의 이름(`repeat: each_set`, `bind` 같은 키)은 바꾸지 않는다 — 기존 책이 깨지지 않게. 화면 글자와 말만 바꾼다.

## 인디자인에 있는 말

**문서와 페이지**
- **문서** — 편집기에서 여는 한 벌. 옛말: 문서, 틀(편집 중일 때)
- **페이지** — 종이 한 쪽. 옛말: 쪽, 지면
- **펼침면** — 마주 보는 두 페이지(2·3페이지, 4·5페이지 …). 「문서 설정 > 페이지 마주보기」를 켜면 생긴다
- **페이지 크기** — 문서 설정의 폭 × 높이(A4 · A5 · 포켓북 148×210). 옛말: 판형
- **재단선 · 도련** — 잘리는 선과 그 바깥 여분(3mm)

**상위 페이지(마스터)**
- **상위 페이지** — 페이지 모양 하나(배경 · 띠 · 텍스트 프레임 · 데이터 필드 자리). 페이지는 상위 페이지를 적용해서 만든다. 옛말: 면, 구성(만드는 단위일 때)
- **1페이지 상위 페이지 / 펼침면 상위 페이지** — 상위 페이지는 한 페이지짜리이거나 두 페이지(펼침면)짜리다. 펼침면 상위 페이지를 적용하면 두 페이지가 같이 생긴다(포켓북 암기 TEST + 정답, 워크북 STEP 간지 + 차례, 분석본 분석 펼침면). 편집기: 첫 페이지의 페이지 패널 **「두 페이지짜리」** 체크(데이터 키 `펼침면`). 페이지 이름으로 짐작하지 않는다. 옛말: 펼침면 면, 붙어 다니는 쪽

**데이터 병합(원고 넣기)**
- **데이터 병합** — 원고를 템플릿의 데이터 필드에 넣어 페이지를 만드는 일. 옛말: 원고 넣기
- **레코드** — 원고 한 건(지문 하나의 분석 · 노트 · 암기 · STEP 시작 …). 옛말: 원고 덩어리, 덩어리, 세트
- **데이터 필드** — 레코드의 칸 하나(지문 · 해석 · 단원 …). 텍스트 프레임이나 그림 프레임에 연결한다. 옛말: 자리, 원고 자리, 자리 이름
- **레코드마다** — 레코드 하나마다 그 상위 페이지로 페이지를 만든다(인디자인 「여러 레코드」). 옛말: 원고마다, 지문마다 한 장
- **샘플 레코드** — 템플릿 미리보기에 넣는 레코드 한 건. 옛말: 견본 원고
- **병합된 문서 만들기** — 레코드를 모두 넣어 책을 만든다. 옛말: 책 만들기

**텍스트**
- **텍스트 프레임** — 글이 들어가는 상자. 옛말: 글상자
- **그림 프레임** — 그림이 들어가는 상자. 옛말: 그림 칸
- **텍스트 스레드** — 프레임 여럿에 글 하나를 이어 흘리기. 옛말: 글 잇기
- **넘침** — 프레임에 다 안 들어간 글(빨간 +)
- **스마트 텍스트 리플로우** — 넘치면 페이지를 더해 이어 받는다. 옛말: 넘치면 이어 갈 면, 덧쪽
- **단락 스타일 · 문자 스타일** — 옛말: 단락 서식, 글자 꾸밈
- **단락 컴포저** — 문단 전체를 보고 줄 끝을 고르는 기능(양끝 정렬)
- **강제 줄 바꿈** — Shift+Enter. 옛말: 줄 나눔, 손 줄 나눔
- **윗주** — 글자 위나 아래의 작은 글(문장 성분 S · V · O 등)
- **고정 개체** — 글에 붙어 다니는 상자. 옛말: 옆 메모
- **균등 배치** — 양끝 정렬에서 낱말 간격 · 자간의 최소 · 최대

**개체**
- **레이어 · 개체 스타일 · 프레임 맞춤 옵션 · 표 · 글머리 기호** — 인디자인 그대로

## 인디자인에 없어서 우리가 정한 말

- **분류** — 상위 페이지에 붙이는 꼬리표. 레코드에 같은 꼬리표가 오면 그 상위 페이지를 쓴다(포켓북: 모양은 같고 색만 다른 「교과서」 · 「모의고사」). 옛말: 구분. 데이터 키는 `구분` 그대로
- **자동 상위 페이지 적용** — 레코드가 오면 데이터 필드가 가장 잘 맞는 상위 페이지를 골라 페이지를 만든다(인디자인은 사람이 원고를 보고 손으로 고른다 — 그 판단을 그대로 옮긴 것). 옛말: 원고 덩어리마다 면 고르기. 고르는 차례:
  1. 레코드의 데이터 필드 이름이 가장 많이 맞는 상위 페이지
  2. 분류가 레코드의 분류와 같은 상위 페이지(색만 다른 상위 페이지)
  3. 레코드에 없어 비는 데이터 필드가 적은 상위 페이지(그림 없는 지문 → 그림 프레임 없는 상위 페이지)
  4. 같은 데이터 필드가 여럿인 상위 페이지는 그 개수가 레코드 목록 길이와 같은 것(흐름 3개 → FLOWNOTE 3칸) — 사람이 세서 고르는 것과 같다. 원고에 칸 수를 따로 적어 보내지 않는다(2026-10-12 사용자 확정)
- **템플릿** — 다 만든 디자인 한 벌(관리 화면의 카드). 옛말: 틀, 디자인, 카드
- **템플릿 등록** — 편집기 문서를 관리 화면의 템플릿으로 올리는 단추. 옛말: 관리에 등록
- **원본** — 따라 만드는 목표 PDF. 옛말: 원본, 목표 PDF, PDF 등록 카드
- **상위 페이지 나누기** — 원본 PDF 를 보고 상위 페이지 후보를 나누는 판정(절차 2단계). 옛말: 구성 나누기, 면 나누기
- **원본 페이지 차례** — 원본에서 상위 페이지가 어떤 차례로 되풀이되나. 옛말: 원본 차례 견본, 되풀이 묶음

## 검사 말

- **고정 요소** — 어떤 원고가 와도 같은 것(띠 · 이름표 · 그림). 원본과 0.3mm
- **데이터 필드 요소** — 원고마다 바뀌는 것. 들어가나 · 넘치나 · 윗주 높이만 본다(줄 바꿈 · 가로 위치는 기록만)
- **1분 시험** — 고친 동작만 떼어 확인. 전체 검사 전에 반드시
