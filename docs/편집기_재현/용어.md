# 편집기 용어집 — 인디자인 말로 통일 (2026-10-12 사용자 확정 — 인디자인 말 그대로, 화면에 나오는 우리 말은 「분류」 「템플릿 등록」 둘뿐)

편집기 화면 · 절차 문서 · 원고 규약 · 대화에서 **이 말만** 쓴다. 옛말은 오른쪽에 적어 두지만 새로 쓰지 않는다.
저장 데이터의 이름(`repeat: each_set`, `bind` 같은 키)은 바꾸지 않는다 — 기존 책이 깨지지 않게. 화면 글자와 말만 바꾼다.

## 인디자인에 있는 말

**문서와 페이지**
- **문서** — 편집기에서 여는 한 벌. 옛말: 문서, 틀(편집 중일 때)
- **페이지** — 종이 한 쪽. 옛말: 쪽, 지면
- **펼침면** — 마주 보는 두 페이지(2·3페이지, 4·5페이지 …). 「문서 설정 > 페이지 마주보기」를 켜면 생긴다
- **페이지 크기** — 문서 설정의 폭 × 높이(A4 · A5 · 포켓북 148×210). 옛말: 판형
- **페이지 번호** — 옛말: 쪽 번호, 쪽번호
- **미리 보기** — 페이지를 작게 그린 그림(관리 카드 · 템플릿 보기). 옛말: 견본, 견본 그림, 견본 사진
- **재단선 · 도련** — 잘리는 선과 그 바깥 여분(3mm)

**상위 페이지(마스터)**
- **상위 페이지** — 페이지 모양 하나(배경 · 띠 · 텍스트 프레임 · 데이터 필드 자리). 페이지는 상위 페이지를 적용해서 만든다. 옛말: 면, 구성(만드는 단위일 때)
- **1페이지 상위 페이지 / 펼침면 상위 페이지** — 상위 페이지는 한 페이지짜리이거나 두 페이지(펼침면)짜리다. 펼침면 상위 페이지를 적용하면 두 페이지가 같이 생긴다(포켓북 암기 TEST + 정답, 워크북 STEP 간지 + 차례, 분석본 분석 펼침면). 편집기: 첫 페이지의 페이지 패널 **「펼침면 상위 페이지」** 체크(데이터 키 `펼침면`). 페이지 이름으로 짐작하지 않는다. 옛말: 두 페이지짜리, 펼침면 면, 붙어 다니는 쪽

**데이터 병합(원고 넣기)**
- **데이터 병합** — 원고를 템플릿의 데이터 필드에 넣어 페이지를 만드는 일. 옛말: 원고 넣기
- **레코드** — 원고 한 건(지문 하나의 분석 · 노트 · 암기 · STEP 시작 …). 옛말: 원고 덩어리, 덩어리, 세트
- **데이터 필드** — 레코드의 칸 하나(지문 · 해석 · 단원 …). 텍스트 프레임이나 그래픽 프레임에 연결한다. 옛말: 자리, 원고 자리, 자리 이름
- **단일 레코드 · 여러 레코드** — 인디자인 데이터 병합의 레코드 옵션. 단일 레코드 = 레코드 하나에 페이지 한 장, 여러 레코드 = 페이지 한 장에 레코드 여럿. 옛말: 원고마다, 지문마다 한 장, 지문 2개씩 한 장, 레코드마다
- **레코드 미리 보기** — 템플릿에 레코드 하나를 넣어 미리 보기(인디자인 데이터 병합 「미리 보기」). 옛말: 견본 원고, 샘플 레코드
- **병합된 문서 만들기** — 레코드를 모두 넣어 책을 만든다. 옛말: 책 만들기
- **자리 표시자 텍스트** — 레코드가 없을 때 프레임에 보이는 임시 글. 옛말: 견본 글, 임시 글

**텍스트**
- **텍스트 프레임** — 글이 들어가는 상자. 옛말: 글상자
- **그래픽 프레임** — 그림이 들어가는 상자. 옛말: 그림 칸, 그림 프레임, 그림(도구 이름)
- **텍스트 스레드** — 프레임 여럿에 글 하나를 이어 흘리기. 옛말: 글 잇기
- **스토리** — 텍스트 스레드로 이어진 글 하나. 옛말: 이야기(텍스트 스레드의 글 뜻)
- **넘침** — 프레임에 다 안 들어간 글(빨간 +)
- **스마트 텍스트 리플로우** — 넘치면 페이지를 더해 이어 받는다. 옛말: 넘치면 이어 갈 면, 덧쪽
- **단락 스타일 · 문자 스타일** — 옛말: 단락 서식, 글자 꾸밈
- **재정의 · 재정의 지우기** — 문단 하나만 단락 스타일 값(앞 · 뒤 간격 · 들여쓰기 · 첫 줄 · 오른쪽 · 행간)을 바꾸기. 스타일은 그대로, 이름 뒤 「+」. 편집기: 글 고치기 창 막대 둘째 줄(¶ 스타일 이름). 옛말: 문단 하나만 서식 바꾸기
- **단락 컴포저** — 문단 전체를 보고 줄 끝을 고르는 기능(양끝 정렬)
- **강제 줄 바꿈** — Shift+Enter. 옛말: 줄 나눔, 손 줄 나눔
- **윗주** — 글자 위나 아래의 작은 글(문장 성분 S · V · O 등). 윗주 하나만 글꼴 · 크기(문자 스타일) · 거리 — 글 고치기 창 막대의 윗주 줄(인디자인 윗주 대화 상자)
- **고정 개체** — 글에 붙어 다니는 상자. 옛말: 옆 메모, 앵커 개체
- **균등 배치** — 양끝 정렬에서 낱말 간격 · 자간의 최소 · 최대
- **탭 위치** — 탭이 멈추는 자리(mm). 옛말: 탭 자리

**개체**
- **레이어 · 개체 스타일 · 표 · 글머리 기호 · 인세트** — 인디자인 그대로
- **사각형 도구** — 도구 막대의 사각형. 옛말: 면(도구 이름)
- **프레임 맞춤** — **비율에 맞게 내용 맞추기**(옛말: 틀 안에 다 보이게) · **비율에 맞게 프레임 채우기**(옛말: 틀 채우고 자르기) · **내용을 프레임에 맞추기**(옛말: 틀에 맞게 늘이기)
- **색상 견본** — 이름 붙인 색. 인디자인 말 그대로라 안 바꾼다. 단락 · 문자 · 개체 스타일과 함께 **문서마다 따로** 둔다(편집기 「스타일 · 색상 견본」 — 옛 「브랜드 · 옷」 묶음은 2026-10-13 지움)
- **[없음]** — 색상 견본의 투명(인디자인 [없음]). 정답 칸(정답 글을 감추고 그 폭만큼 밑줄)은 문자 스타일 「글자 색 [없음] + 밑줄 · 밑줄 색」으로 만든다. 옛 기능: GREP 「글 폭 칸」(2026-10-13 지움)
- **칸 이름도 인디자인 그대로**(2026-10-13) — 단 균형 맞추기(옛 「차례로 채우기」 — 기본을 인디자인처럼 첫 단부터 채우기로 뒤집음) · 페이지 마주보기(옛말: 펼침) · 단락 음영(바탕) · 동일한 스타일 단락 사이(같은 스타일 사이) · 인라인 고정 개체(문장 끝에 붙이기, 글 끝에 붙이기) · 글머리 기호(글머리) · 인세트 간격(안쪽 여백) · 줄 바꿈 없음(줄바꿈 안 함) · 셀 인세트(칸 여백) · 행 높이 최소(줄 최소 높이) · 열 칠(열마다 칸 색) · 문자 · 단락(글자) · 여백 및 단(여백)

## 바꾸지 않는 것(문맥 예외)

- 방향을 뜻하는 「쪽」: 왼쪽 · 오른쪽 · 안쪽 · 바깥쪽 · 위쪽 · 아래쪽 · 양쪽 · 한쪽 · 제본쪽
- 상자의 네 변을 뜻하는 「쪽」: 쪽마다 · 네 쪽 → 변마다 · 네 변(텍스트 프레임 인세트)
- 위치 · 공간을 뜻하는 「자리」: 커서 자리 → 커서 위치, 「들어올 자리 · 들어갈 자리 · 글 자리 · 그 자리만큼 · 쌓기 자리」는 그대로
- 색 바탕을 뜻하는 「색 면」(형광 · 번호 배지) · 색상 견본 · 견본 이름(색상 견본 이름)
- 「원고」 — 지문 같은 내용 자체를 말할 때는 그대로(레코드 한 건일 때만 레코드)
- 「틀」 — 문서를 뜻하면 문서(틀 저장 실패 → 문서 저장 실패), 템플릿을 뜻하면 템플릿

## 인디자인에 없는 우리 말 — 화면에 나오는 것은 「분류」 「템플릿 등록」 「블록」 셋뿐

(「템플릿」은 인디자인 말(.indt). 「자동 상위 페이지 적용」은 기능 설명, 「원본 · 상위 페이지 나누기 · 원본 페이지 차례」는 재현 절차 말 — 편집기 화면에는 안 나온다)

- **분류** — 상위 페이지에 붙이는 꼬리표. 레코드에 같은 꼬리표가 오면 그 상위 페이지를 쓴다(포켓북: 모양은 같고 색만 다른 「교과서」 · 「모의고사」). 옛말: 구분. 데이터 키는 `구분` 그대로
- **자동 상위 페이지 적용** — 레코드가 오면 데이터 필드가 가장 잘 맞는 상위 페이지를 골라 페이지를 만든다(인디자인은 사람이 원고를 보고 손으로 고른다 — 그 판단을 그대로 옮긴 것). 옛말: 원고 덩어리마다 면 고르기. 고르는 차례:
  1. 레코드의 데이터 필드 이름이 가장 많이 맞는 상위 페이지
  2. 분류가 레코드의 분류와 같은 상위 페이지(색만 다른 상위 페이지)
  3. 레코드에 없어 비는 데이터 필드가 적은 상위 페이지(그림 없는 지문 → 그래픽 프레임 없는 상위 페이지)
  4. 같은 데이터 필드가 여럿인 상위 페이지는 그 개수가 레코드 목록 길이와 같은 것(흐름 3개 → FLOWNOTE 3칸) — 사람이 세서 고르는 것과 같다. 원고에 칸 수를 따로 적어 보내지 않는다(2026-10-12 사용자 확정)
- **템플릿** — 다 만든 디자인 한 벌(관리 화면의 카드, 인디자인 템플릿). 옛말: 틀, 디자인, 카드
- **템플릿 등록** — 편집기 문서를 관리 화면의 템플릿으로 올리는 단추. 옛말: 관리에 등록
- **블록** — 왼쪽 패널에 저장해 두고 끌어다 쓰는 디자인 조각. 놓은 뒤에도 원본과 이어져 있고(인디자인 「연결된 콘텐츠」와 같다), 안의 데이터 필드 이름으로 어떤 원고가 들어올지 안다 — 이 마지막이 인디자인에 없어 우리 말로 둔다(2026-10-13 사용자 확정)
- **하위 폴더** — 관리 폴더 안의 칸(포켓북 · 워크북 …, 데이터 키 series). 옛말: 틀(폴더 칸일 때)
- **템플릿 보기** — 관리에서 템플릿을 누르면 나오는 화면 — 「상위 페이지」 · 「원본 페이지 차례」 두 칸. 「페이지 보기」 단추로 연다. 옛말: 지면 보기. 편집기 템플릿의 그림은 「템플릿 PDF」(레코드 미리 보기로 그린 것), PDF 등록 카드는 「원본 PDF」. 옛말: 기준 PDF
- **원본** — 따라 만드는 목표 PDF. 옛말: 원본, 목표 PDF, PDF 등록 카드
- **상위 페이지 나누기** — 원본 PDF 를 보고 상위 페이지 후보를 나누는 판정(절차 2단계). 옛말: 구성 나누기, 면 나누기
- **원본 페이지 차례** — 원본에서 상위 페이지가 어떤 차례로 되풀이되나. 옛말: 원본 차례 견본, 되풀이 묶음

## 검사 말

- **고정 요소** — 어떤 원고가 와도 같은 것(띠 · 이름표 · 그림). 원본과 0.3mm
- **데이터 필드 요소** — 원고마다 바뀌는 것. 들어가나 · 넘치나 · 윗주 높이만 본다(줄 바꿈 · 가로 위치는 기록만)
- **1분 시험** — 고친 동작만 떼어 확인. 전체 검사 전에 반드시
