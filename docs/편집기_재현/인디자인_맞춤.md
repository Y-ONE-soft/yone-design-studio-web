# 편집기 인디자인 맞춤 (2026-10-14 전면)

편집기의 모든 칸 · 단추 · 메뉴를 인디자인 이름과 동작에 맞춘 목록. 정본이다 — 편집기에 칸을 더하거나 이름을 바꿀 때 여기부터 고친다.
전수 조사(132곳)를 바탕으로 사용자 결정(2026-10-14): **이름 · 동작은 인디자인대로, 인디자인에 없는 편법 기능은 없애고 인디자인 기능으로 바꾼다,
제품 바탕 기능(데이터 병합 확장 · 블록 · 템플릿 등록)은 인디자인 위에 얹는다.**

## 원칙

1. **템플릿과 책을 나눈다.** 템플릿(데이터 필드 · 스타일)은 표준 값만 가진다. 원본이 쪽마다 손으로 고친 곳은 템플릿에 넣지 않고
   책(병합된 문서)에서 재정의 · 윗주 · 고정 개체로 고친다(검사는 「원본 손 고침」으로 적는다). 템플릿에서 원본 한 쪽을 맞추려고 기능을 늘리지 않는다.
2. **인디자인에 있는 기능만.** 이름 · 단위 · 부호 · 기본값까지 인디자인 한국어판과 같게. 브라우저로 못 하는 것은 칸을 두지 않는다(값만 저장되는 칸 금지).
3. **제품 바탕 기능은 위에 얹는다.** 데이터 필드 연결 · 레코드 옵션(한 번만 · 펼침면) · 블록 · 템플릿 등록 · 원고 표시 읽기는 인디자인 데이터 병합의 확장으로 남긴다.
   이름에 인디자인 말을 빌려 쓰지 않는다(뜻이 다르면 우리 말).

## 동작을 인디자인대로 바꾼 것

- **단락 음영:** 음영은 글 자리를 바꾸지 않는다. 오프셋 위쪽 · 아래쪽 · 왼쪽 · 오른쪽(밖 +), 너비 열 · 텍스트, 모퉁이 크기. 잇닿은 같은 음영 문단은 한 상자.
- **단락 테두리:** 음영과 따로. 획 두께 · 색상 · 오프셋 4방향 · 너비.
- **단락 경계선(위 · 아래):** 기준선에서 잰 오프셋, 글을 밀지 않는다. 두께 · 색상 · 오프셋 · 너비(열 · 텍스트).
- **기준선 이동:** pt, 위가 +.
- **자동 행간:** 글자 크기의 120%.
- **첫 번째 기준선 오프셋:** 어센트 · 캡 높이 · 행간 · x 높이 · 고정, 최소.
- **세로 균등 배치:** 위쪽 · 가운데 · 아래쪽 · 양쪽.
- **정렬:** 왼쪽 · 가운데 · 오른쪽 · 양쪽 정렬(마지막 줄 왼쪽 · 가운데 · 오른쪽) · 모두 정렬.
- **균등 배치:** 단어 간격 최소 · 권장 · 최대 %, 문자 간격 최소 · 권장 · 최대 %(공백 폭 기준).
- **탭:** 마지막 탭 정지 뒤로는 기본 탭 정지(12.7mm 마다).
- **자동 크기 조정:** 끔(기본) · 높이만 · 너비만 · 높이 및 너비, 기준점.
- **고정 개체:** 위치 인라인 · 줄 위 · 사용자 정의. 인라인 Y 오프셋은 위가 +. 내용은 텍스트 프레임 또는 그룹(부품).
- **윗주:** 한 글자에 하나. 위치 위 · 아래, 글꼴 · 크기, 오프셋 X · Y(본문 글자 상자에서), 정렬 왼쪽 · 가운데 · 오른쪽 · 양쪽.
- **GREP 스타일:** 대상 텍스트 → 스타일 적용(문자 스타일)만.
- **밑줄 · 취소선:** 두께 · 오프셋 pt, 유형, 색상.
- **표:** 칸 사이 간격 없음 — 셀 획(두께 · 색상)과 셀 인세트로.
- **획 유형:** 실선 · 파선 · 점선.
- **텍스트 감싸기:** 경계 상자 감싸기, 오프셋 위 · 아래 · 왼 · 오른, 감싸기 옵션.
- **글머리 기호 및 번호 매기기:** 단락 스타일에. 목록 유형 · 글머리 기호 문자 · 번호 형식 · 텍스트 뒤(탭) · 탭 위치.
- **데이터 병합:** 데이터 소스 선택 · 레코드 미리 보기 · 병합된 문서 만들기(새 문서 — 책을 고치는 곳).

## 없앤 편법 기능 → 인디자인 기능

- GREP 규칙의 직접 꾸밈(굵게 · 색 · 크기 · 서체 …) → GREP 스타일은 문자 스타일만. 「줄 바꿈 없음」은 문자 스타일 속성으로.
- 문자 스타일 바탕 · 바탕 여백 · 바탕 모서리 · 띠 → 밑줄 옵션(두께 · 오프셋 · 색상)으로. 둥근 바탕 꼬리표는 인라인 고정 개체(칠 · 모퉁이 있는 텍스트 프레임).
- 한 글자 위 · 아래 윗주 둘 → 윗주 하나 + 고정 개체.
- 옆 메모 → 고정 개체(사용자 정의 위치 · 텍스트 프레임).
- 데이터 필드 「앞에 붙이기 · 폭 · 뒤」 → 같은 단락에 필드 둘(«번호»⇥«발문») — 번호는 문자 스타일, 자리는 탭 정지.
- 데이터 필드 직접 서식(굵게 · 기울임 · 상자 · 들여쓰기 · 앞 간격 · 글머리) → 단락 스타일로만.
- 고정 개체 「첫 문단만 · 끝 문단만 · 띄어 붙이기」 → 템플릿 단락에서 개체가 필드 앞인가 뒤인가, 그 사이 공백 문자.
- 블록 안 「인라인 고정 개체(다른 글 끝을 따라감)」 → 그 글 안의 인라인 고정 개체.
- 양끝 줄 낱말 최소 ‰ · 양끝맞춤 글자까지 · 낱말 사이 ‰ → 균등 배치로만.
- 표 칸 사이 가로 · 세로 → 셀 획.
- 페이지 좌우 반전 → 펼침면 상위 페이지(왼 · 오른).
- 레코드마다 아래로 쌓기 → 표 · 텍스트 스레드로.
- 대소문자 「소문자」, 기울이기 세로, 중복 인쇄(출력에 안 들어감), 클리핑 패스 경로 입력 → 없앰. 도형 경로는 「기준점 경로」(직접 선택 도구로 옮기는 기준점)와 다각형 도구(면 수 · 별모양 인세트)로.
- 문장 번호 배지(문자 스타일 바탕) → 번호를 따로 데이터 필드로 두고 「다음 필드와 같은 단락」 + 인라인 고정 텍스트 프레임(칠 · 모퉁이 크기 · 인세트). 필드 뒤는 탭 · 공백 · 엔 · 엠 · 가는 · 아주 가는 공백(인디자인 특수 문자).
- 데이터 필드 사이 mm 간격 → 필드 뒤 공백 문자(가장 가까운 고정 폭 공백).
- 원고 윗주에 문자 스타일 이름이 오면(서술형★) 그 스타일의 글꼴 · 크기 · 색상을 그 윗주 값으로(인디자인 윗주 대화 상자 칸).
- 텍스트 프레임 「굵게 · 기울임」 체크 → 글꼴 스타일.

## 이름만 바꾼 것

전수 조사 132곳 중 이름만 다른 곳은 그대로 인디자인 이름으로(도구 · 메뉴 · 패널 · 스타일 창). 편집기 화면과 `docs/편집기_재현/용어.md` 가 정본.
