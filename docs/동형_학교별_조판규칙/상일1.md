## 2. 지면 골격

- **2단**, 단 사이 **세로 괘선 있음**.
- **쪽 전체를 감싸는 테두리 상자 있음** — 각진 모서리. 머리표와 두 단을 모두 안에 넣는다.
  푸터 문장만 테두리 **바깥** 아래에 놓인다.
- 단 괘선은 테두리 **윗변에서 아랫변까지 통짜로** 내려온다. 문단 길이에 맞춰 잘리지 않고,
  마지막 쪽의 빈 단에도 그대로 있다.
- 푸터 문장 **위에** 지면 전폭 가로 괘선 한 줄. 상단 가로 괘선은 없다(머리표 표가 그 역할).

| 쪽번호 | 별도 요소 없음. 푸터 문장 안에 `[1/7]` 로 들어간다. |

### 머리표 표 구조

```
┌───────────────────────────────────────────────────┬────┬────────┬───────────────┐
│ 상일여자고등학교 2026학년도 1학기 중간고사 4월 30일 2교시 │    │ 선택형 │ (1)번~(30)번  │
│                     (병합, 굵게, 가운데)              │ 문 │        │ 【총 25점】    │
├──────┬───┬────────┬──────────┬────────┬───────┤ 항 ├────────┼───────────────┤
│ 학년 │ 1 │ 과목명 │ 공통영어1 │ 과목코드 │  03   │(세로)│ 서답형 │ 없음          │
│(음영)│   │ (음영) │          │ (음영)  │       │(음영)│        │ 【총 0점】     │
├──────┴───┴────────┴──────────┴────────┴───────┴────┴────────┴───────────────┤
│ ◐ 이 시험문제의 저작권은 상일여자고등학교에 있습니다. 무단 전송·복제·배포시     │
│   저작권법에 의거 처벌될 수 있습니다. ◑            (전폭 병합, 회색 음영, 가운데) │
└───────────────────────────────────────────────────────────────────────────────┘
```

- 저작권 감싸기 글자: 앞 `◐`(U+25D0), 뒤 `◑`(U+25D1).
- `문항` 칸은 **세로쓰기**(한 글자씩 두 줄), 회색 음영. `선택형`/`서답형` 칸은 흰색.
- 범위 표기 `({a})번~({b})번`, 총점 표기 `【총 {n}점】`.
- **서답형이 없는 회차에도 서답형 행을 지우지 않고** `없음 / 【총 0점】` 을 넣는다.

### 첫머리 안내문 (▶ = U+25B6, 1쪽 좌단, 머리표 바로 아래)

```
▶ 이 시험지는 7쪽까지 있습니다.
▶ 각 문항 끝에 배점이 표시되어 있습니다.
▶ 선택형 1번부터 5번 문제는 듣고 답하는 문제입니다. 한 번만 들려줍니다. 방송을 잘 듣고 답을 하시기 바랍니다.
```

줄바꿈되면 ▶ 아래로 들어가지 않고 단 왼쪽에 붙는다(내어쓰기 0).

### 듣기 종료 안내 (5번 뒤, 같은 단, 테두리 없음)

```
▶ 이제 듣기 문제가 끝났습니다. 6번부터는 문제지의 지시에 따라 답을 하시기 바랍니다.
```

## 4. 단락 역할별 수치

정본이 사진이라 pt 실측이 불가능하다. 아래는 **폰트에 무관한 비율**(확실)과 거기서
유도한 **추정 pt**(±1.5pt)다.

| 실측 (2000px 기준) | 값 |
|---|---|
| 행간 | **48.5px** |
| 행간 / 단폭 | **0.0541** |
| 행간 / 테두리폭 | 0.0254 |
| 글자 띠 높이 | 34.5px |
| 양끝맞춤 한 줄 영문 자수 | **72자** |

표본줄: `straightforward to fit pieces together, at other times it will take more`

| 역할 | 규칙 |
|---|---|
| 서체 | 본문·발문·선지·머리표까지 **전부 고딕(산세리프) 한 계열**. 배재처럼 본문을 명조로 쓰지 않는다. 휴머니스트 산세리프로 보이나 스캔이라 폰트명 확인 불가. 영문 평균 자폭이 좁다(자당 12.5px) → 장평 85~90% 또는 음수 자간으로 추정. |
| 발문 | 볼드 아님. **핵심어만 굵게+밑줄**(`않는` `틀린` `잘못된` `모두` `2개`). 번호는 단 왼쪽 끝. 되풀이 줄에 **고정 내어쓰기 약 1em**. |
| 지문 | 첫 줄만 **한 글자 들여쓰기**, 양끝맞춤, 하이픈 분철 없음. |
| 선지 | 지문과 같은 크기. 마커 뒤 반각 공백. 되풀이 줄은 **마커 뒤 본문 시작 위치로 내어쓴다**. 선지 블록 앞에 빈 줄 한 줄. |
| 배점 | 발문보다 **한 급 작다(약 80%)**, 볼드 아님. |
| 문항 번호 | 발문과 **같은 서체·같은 크기**. 배재처럼 숫자만 키우지 않는다. |
| 추정 pt (B4) | 본문·발문·선지 **≈10.5pt**, 행간 **≈17.3pt**(약 165%) |

### 발문 내어쓰기 — 확정된 세부

한 자리 번호일 때는 발문 첫 글자와 딱 맞지만 두 자리일 때는 **맞지 않는다**.
→ 번호 폭에 맞춘 정렬이 아니라 **고정값(약 1em)**이다.

```
9. 다음 글의 밑줄 친 부분 중, 문맥상 낱말의 쓰임이 적절하지 않은
   것은? (0.8점)          ← '다음'과 정확히 맞음

10. 다음 글의 밑줄 친 부분 중, 문맥상 낱말의 쓰임이 적절하지 않은
    것은? (0.7점)         ← '다음'보다 왼쪽
```

## 5. 문제 유형별 차이

**들여쓰기·행간·여백은 유형 무관하게 균일하다.** (지문 첫 줄 1글자 들여쓰기, 선지
내어쓰기, 발문 내어쓰기, 행간, 단 여백 — 전부 같다.) 달라지는 것은 **선지 배치와
부속 요소**뿐이다.

| 유형 | 다른 점 |
|---|---|
| 듣기 (1~5) | 지문 없음. 응답 유형(4·5번)은 발문 아래 `Man: ` + 단 오른쪽까지 긴 밑줄 한 줄, 그 아래 선지. |
| 어법 네모 (6) | 지문 안 `speaks / speaking` 을 **실제 사각 테두리**로 두른다. `(A)` 는 상자 바깥 왼쪽에 굵게. 3열 짝 선지표. |
| 어법 밑줄 (7·19) | 선지 블록 **없음**(지문 안 ①~⑤). |
| 어법 개수 (14·21) | ⓐ~ⓚ 를 지문에 박고 선지는 `① 3개 … ⑤ 7개` **인라인 한 줄**. |
| 어휘 영영풀이 (12) | 선지 한 줄씩, 내어쓰기. |
| 공통 단어 (13) | `< 예 문 >` 상자 + `·` 항목 + 선지 **3 + 2 두 줄 격자**. |
| 어휘 관계 (30) | `< 보 기 >` 상자에 기준쌍 한 줄만, ⓐ~ⓙ 열 개는 **상자 밖 2열 5행 격자**, 선지는 `N개` 인라인. |
| 빈칸 (8·16) | 지문 안 밑줄. (A)(B)(C) 다중이면 3열 짝 선지표, 단일이면 한 줄씩. |
| 순서 | (A)(B)(C) 문단을 지문 뒤에 놓고 선지는 `① (A) - (C) - (B)` 인라인. |
| 삽입 (17·23) | 주어진 문장 상자를 지문 **위**에, 지문 안에 `( ① )`~`( ⑤ )`. 선지 블록 없음. |
| 요약 (18·27) | 아래 6절 참조. 두 형식이 공존한다. |
| 문장 제거 (22) | ①~⑤ 인라인, 선지 블록 없음. |
| 다의어 (29) | ①~⑤ 를 단 **왼쪽 여백 칸**에 따로 세우고 오른쪽에 `· 예문` 두 줄. |
| 한글 해석 대조 (11) | 영어 선지 아래에 `☞ 한글 해석`(U+261E) 을 한 단 들여 붙인다. |
| 장문 | **관측 없음** — 두 회차 모두 장문 세트가 없다. |

## 6. 보기 / 조건 / 요약 / 주어진문장

### 캡션-온-보더 상자 — 이 학교의 핵심 관용

캡션이 상자 **윗변 선 위에 걸쳐** 놓이고 그 자리만큼 선이 끊긴다. 캡션은 굵게, 가운데.
한글 두 글자를 **벌려 쓴다**(`보 기`).

```
        ─────────────────  < 보 기 >  ─────────────────
       │                                               │
       │            trifling - considerable            │
       └───────────────────────────────────────────────┘
```

| 회차 | 캡션 | 모서리 |
|---|---|---|
| **26-1-중간 (정본)** | `< 예 문 >` `< 요 약 >` `< 보 기 >` | 각진 |
| 25-1-기말 | `| 조 건 |` `| 보 기 |` `| 요 약 문 |` | 둥근 |

- `<보기>` 를 **본문 안에서 가리킬 때**는 공백 없는 `<보기>` 를 쓴다(조건 항목 1번 문장).
  캡션의 벌린 형태와 다르다.
- 내용 정렬: 보기 = 가운데, 조건 = 왼쪽(번호 `1.` + 내어쓰기), 요약 = 왼쪽(첫 줄 들여쓰기).

### 요약 — 두 형식이 한 회차 안에 공존

| | 형식 A (18번) | 형식 B (27번) |
|---|---|---|
| 순서 | 발문 → 지문 → **⬇** → 무캡션 상자 → (A)(B) 표 | 발문 → 지문 → `< 요 약 >` 캡션 상자 → (A)(B) 표 |
| 화살표 | **⬇ (U+2B07)** 속이 꽉 찬 굵은 화살표, 가운데 | 없음 |
| 상자 캡션 | 없음 | `< 요 약 >` |

빈칸 표기: `(A)` 를 **굵게 해서 밑줄 위에 얹는다**. `(A) ______` 처럼 괄호 뒤에 밑줄을
따로 두지 않는다.

> 동형에서는 **원고에 화살표(U+F003B)가 있으면 형식A, `[요약문]` 라벨만 있으면 형식B**
> 로 가르는 것이 원고 구조와 가장 잘 맞는다(추론 — 9절 참조).

### 주어진 문장 (문장삽입)

캡션 없는 테두리 상자. 3표본이 서로 다르다.

| 표본 | 폭 | 정렬 | 볼드 |
|---|---|---|---|
| 26-1-중간 17번 | 단보다 좌우 안쪽(들여쓴 상자), 안여백 넉넉 | 왼쪽 | ✗ |
| 26-1-중간 23번 | 단 전폭 | 양끝맞춤 | **✓** |
| 25-1-기말 19번 | 단 전폭 | 양끝맞춤 | ✗ |

→ 다수결로 **단 전폭 + 양끝맞춤 + 볼드 아님**을 기본값으로 둔다. (학교 표기가 흔들린다.)

## 7. 문항 묶음 표기

**없다.** 26-1-중간(30문항)·25-1-기말(선택형 19 + 서답형 7) **두 회차 어디에도**
`【 6-7 】` `[7~8]` 같은 묶음 머리표기가 없다. 지문을 공유하는 문항이 나와도 각 문항이
자기 발문을 온전히 갖는다.

그런데 **원고에는 묶음이 회당 2개 있다**(`다음 글을 읽고 물음에 답하시오. [1과]`).
정본에서 확인된 규칙이 아니므로 아래는 **원고 구조에서 유도한 안**이다. 사용자 확인 필요.

> 묶음 머리표기를 만들지 말고, 공유 지문을 **첫 문항 아래에 한 번만** 놓고,
> 두 번째 문항은 번호 + `윗글의 …` 발문만 갖게 한다.

근거: 원고가 이미 그렇게 쓰여 있다. 두 번째 문항 발문이 전부 `윗글의` / `윗글에서` /
`윗글을` 로 시작한다 (1회 242·248·360·367행, 2회 266·271·347·353행).

## 8. 서답형 / 서술형 라벨  `src: 25-1-기말`

정본(26-1-중간)에는 서답형이 **0문항**이라 25-1-기말에서 가져왔다.

```
┏━━━━━━━━━━┱──────────┐
┃ 서답형 1  ┃ 서논술형 │  【0.9점】   (반드시 문장으로 작성하시오.)
┗━━━━━━━━━━┹──────────┘
   ↑ 검정 배경 흰 글자        ↑ 배점은 표 바깥 평문
```

- **표는 2칸**: ①반전 칩(검정 바탕·흰 글자·굵게, `서답형 {n}`, 라벨어와 번호 사이 반각 공백)
  + ②유형 칸(흰 바탕·테두리·굵게, `서논술형` 또는 `단답형`).
- **배점은 칸이 아니라 표 오른쪽 바깥 평문**이고 괄호는 **`【 】`**.
- 안내문 `(반드시 문장으로 작성하시오.)` 은 **서논술형에만** 붙고 단답형에는 없다.
- 번호는 선택형과 **별도 연번**(서답형 1, 2, 3, …).

> ⚠ 고2(상일2)가 3칸(칩 + 유형칸 + **배점칸**)이라 하더라도, **상일1 고1은 2칸 + 바깥 배점**이다.
> 25-1-기말 서답형 1·2·3·6·7 다섯 표본이 전부 같다.

관측 표본:

| | 유형 | 배점 | 안내문 |
|---|---|---|---|
| 서답형 1 | 서논술형 | 【0.9점】 | (반드시 문장으로 작성하시오.) |
| 서답형 2 | 단답형 | 【0.9점】 | — |
| 서답형 3 | 단답형 | 【1.0점】 | — |
| 서답형 6 | 서논술형 | 【1.7점】 | (반드시 문장으로 작성하시오.) |
| 서답형 7 | 서논술형 | 【1.8점】 | (반드시 문장으로 작성하시오.) |

### 서답형 본문 구조

```
[반전칩][유형]  【X.X점】  (안내문)
다음 글을 읽고, 물음에 답하시오.       ← 지문 안내(있을 때)
  (지문)

[문제] 윗글의 빈칸에 들어갈 가장 적절한 말을 <조건>에 맞추어
       완성하시오.                     ← [문제] 굵게, 되풀이 줄 내어쓰기

  ┈┈┈ | 조 건 | ┈┈┈
  1. …
     (…)
  2. …

  ┈┈┈ | 보 기 | ┈┈┈
  (낱말들, 가운데 정렬)

  ┈┈┈ | 요 약 문 | ┈┈┈   ← 요약 완성형일 때만

[답] : ____________________________________  (0.4점)
```

상자 순서는 **조건 → 보기 → 요약문**으로 고정이다.

### 답란

| 형태 | 표기 |
|---|---|
| 기본 | `[답] : ` + 단 오른쪽 근처까지 밑줄 + 오른쪽 끝에 `(0.4점)` |
| 첫머리 지정 | `[답] : It is ____________` |

## 9. 배점 표기

### 표기 형태

| 항목 | 값 |
|---|---|
| 괄호 | **`( )` 반각 둥근괄호** (U+0028 / U+0029) |
| 붙는 자리 | **발문 끝** |
| 앞 공백 | 반각 한 칸 — `것은? (0.7점)` |
| 소수 자릿수 | **1자리 고정** |
| 정수일 때 | **`(1.0점)`** — 정답표에는 `1` 이지만 시험지에는 `1.0점` 으로 찍힌다 |
| 크기 | 발문의 **약 80%**, 볼드 아님 |
| 넘칠 때 | 다음 줄로 내려가 **단 오른쪽 끝에 오른쪽 정렬** (6·17·23·30번) |
| 꼬리말 | `부분점수 없음` 같은 꼬리말을 **쓰지 않는다**. 대신 `(반드시 문장으로 작성하시오.)` 처럼 작성 조건을 붙인다. |
| 서답형 총점 | `【0.9점】` (라벨 표 오른쪽 바깥) |
| 부분배점 | `(0.3점)` (답란 밑줄 오른쪽 끝 / 답 표 마지막 칸) |

### (A)(B)(C) 짝맞추기 선지 표

머리행 `(A) (B) (C)` **굵게, 각 값 열 위 가운데**. 값은 **왼쪽 정렬**, 구분자는 고정 탭 위치.

```
        (A)              (B)             (C)
①  think about      ...   stability   ...   willingness
②  take into account ...  plasticity  ...   unwillingness
```

⚠ 구분자 점 개수가 한 회차 안에서 **3점 / 7점 / 없음** 세 가지로 흔들린다.
사실상 탭 채움점(dot leader)이고 남는 폭에 따라 달라진 것으로 본다.
→ **열 3개면 `...`, 열 2개(요약)면 `.......`** 로 정본 표본을 그대로 따른다.

### 밑줄 관행

- 빈칸은 밑줄만. 밑줄 길이는 고정.
- 어휘 (A)~(E) 유형과 요약문 빈칸은 `(A)` 를 **굵게 해서 밑줄 위에 얹는다**.
- 발문 강조는 **굵게 + 밑줄** 동시(`않는` `틀린` `모두` `2개`).

## 12. 원고 규칙

원고: `26-1-중간 상일1 동형 1회 원고.hwpx` (378단락) / `2회 원고.hwpx` (361단락)

### 원고가 주는 것

- 발문, 지문, 선지, `<보기>` 항목, `[요약문]` 라벨, 묶음 지시문
- 묶음 구조(`다음 글을 읽고 물음에 답하시오. [N과]` + `윗글의 …` 두 문항)

### 원고가 **안** 주는 것 → 조판이 만들어 넣어야 한다

머리에 `선택형 30` **한 줄뿐**이다. 서답형 줄도, 학교명·회차 줄도 없다.

1. **문항 번호 1~30** (`{n}.`) — 원고에 번호가 전혀 없다
2. **문항별 배점** `(X.X점)` — 원고에 배점이 전혀 없다. 9절 유형 표로 총 25.00점을 맞춘다
3. 머리표 전체(학교명·고사명·날짜·교시·학년·과목명·과목코드·문항 범위·총점)
4. 저작권 문구, 첫머리 안내문 3줄, 듣기 종료 안내, 마지막 ※ 확인 사항 상자
5. 푸터 문장 + 쪽번호 `[p/n]`
6. 마무리 문장 `This is the end of the test.`
7. 쪽 테두리 상자 · 단 괘선 · 푸터 위 가로 괘선
8. 요약 화살표 `⬇` (원고 PUA 글자를 치환)
9. **상자화** — 원고의 `<보기>` / `[요약문]` 평문 라벨을 캡션-온-보더 상자로
10. 묶음 문항의 지문 1회 게재 + `윗글의 …` 배치 (원고에 묶음 번호가 없다)

### 반드시 제거해야 하는 것

| 무엇 | 형태 |
|---|---|
| **발문 끝 정답** | `… 것은? ④` · `… 고르시오. ➁` · `… 모두 고르시오. ➁, ➃` · `… 것은? ➄ : ⓔ disperse → gather` |
| 출처 태그 | `[올림포스 영어독해 기본1 UNIT 03 Practice 02]` (1회 15개) |
| 원 기출 번호 | `[21번]` `[22번]` `[23번]` `[24번]` `[31번]` `[32번]` `[33번]` `[34번]` |

| `① (A) － (C) － (B)② (B) － (A) － (C)` | 두 선지로 분리 | 한 단락에 붙어 있다 |

### 그 밖

- 원고 오타를 임의로 고치지 않는다(1회 17행 `overlfow`). 검수자 확인 후 처리.
- 지문 앞에 반각 공백 하나가 붙은 줄이 많다(들여쓰기 흉내). 조판의 첫 줄 들여쓰기와
  겹치지 않게 정리한다.
- 회차별 개수: 1회 = 선택형 30 · 묶음 2 · `<보기>` 4 · 화살표 1 /
  2회 = 선택형 30 · 묶음 2 · `<보기>` 6 · 화살표 1.

## 13. 현행과 달라 고쳐야 할 것

대상: `조판/교재/동형모의고사/고1/26-1-중간/상일여고/상일1_동형모의고사(1회)_3.pdf`
(7쪽, 263×370mm, 2단 113.6mm, 본문 11pt / 행간 18pt)

### 치명

1. **문항 번호가 두 번 찍힌다.** `1.  1. 다음을 듣고…`, `30. 30. 다음 ⓐ~ⓙ중…`.
   원고에 번호가 없으므로 파서가 발문 앞에 번호를 심고 렌더러가 또 붙인 것으로 보인다.
2. **배점이 하나도 없다.** 정본은 30문항 전부 `(0.6점)`~`(1.1점)` 이 붙는다.
   첫머리 안내문에 "각 문항 끝에 배점이 표시되어 있습니다"라고 적어 놓고 배점이 없다.
   → 9절 배분 규칙으로 총 25.00점을 채워야 한다.
3. **머리표 문항 칸이 실제 내용과 다르다.** 현행 `선택형 (1)번~(23)번 [총 16점]` /
   `서답형 (1)번~(6)번 [총 9점]` 인데 실제로는 선택형 30문항, 서답형 0개다.
   총점 괄호도 `[ ]` 인데 정본은 `【 】`.
4. **듣기 안내 두 줄이 빠졌다.** 첫머리 3번째 줄(선택형 1~5번 듣기 안내)과
   5번 뒤의 종료 안내. 현행은 서답형용 3번째 줄을 쓰는데 서답형이 없다.
5. **마무리가 통째로 없다.** `This is the end of the test.` 도, `※ 필요한 사항(…)` 상자도
   없어 마지막 쪽 오른쪽 단이 통째로 비어 있다.

### 상자·기호

6. **`<보기>` `<예문>` `<요약>` 상자를 안 만든다.** 정본은 캡션이 상자 윗변 선 위에
   걸친 테두리 상자. 현행은 `<보기>` `<예문>` 을 평문 한 줄로 찍고(13번은 상자 자체가 없다),
   30번은 상자 **안 첫 줄**에 `<보기>` 를 넣었다.
7. **30번 짝 목록 배치가 다르다.** 정본은 상자 안에 기준쌍 `trifling - considerable` 만
   가운데 정렬, ⓐ~ⓙ 열 개는 **상자 밖 2열 5행 격자**. 현행은 열 개를 전부 상자 안에 세로로.
8. **어법 네모(6번)를 상자로 그리지 않는다.** 정본은 지문 안 `speaks / speaking` 을
   실제 사각 테두리로 두른다. 현행은 `[speaks / speaking]` 대괄호 + 밑줄이고
   발문도 "각 **괄호** 안에서"로 바뀌었다(정본은 "각 **네모** 안에서").
9. **요약 화살표 모양이 다르다.** 정본 `⬇`(U+2B07, 속이 꽉 찬 굵은 화살표),
   현행 `↓`(U+2193, 가는 화살표).
10. **요약문 빈칸 형태가 다르다.** 정본은 `(A)` 를 굵게 해 밑줄 위에 얹는다.
    현행은 `(A) __________`.
11. **어휘관계 짝의 붙임표가 섞여 있다.** 현행 30번에 `–`(en dash)와 `-`(hyphen)가
    섞였다. 정본은 전부 `-`.

### 문자열

12. **첫머리 쪽수**: 현행 `[ 7 ]쪽까지` → 정본 `7쪽까지`(괄호 없음).
13. **푸터 과목 표기**: 현행 `[공통영어1]과 원안 [1/7]` → 정본 `공통영어1 원안 [1/7]`.

### 조판 디테일

14. **(A)(B) 짝 선지 구분자**: 정본은 베이스라인 점(3열 `...`, 2열 요약 `.......`).
    현행은 중간 높이 `⋯` 이고 개수가 항상 3. 머리행 `(A) (B) (C)` 도 정본은 굵게
    각 열 위 가운데인데 현행은 굵지 않고 왼쪽으로 치우쳐 있다.
15. **짧은 선지 인라인 배치**: 정본은 `① 3개 … ⑤ 7개` 다섯 개를 단 전폭에 고르게 벌린다.
    현행은 왼쪽에 몰아 붙인다. 13번 한 낱말 선지도 정본은 3+2 두 줄, 현행은 한 줄 다섯 개.
16. **본문 밀도**: 정본은 양끝맞춤 한 줄에 영문 약 **72자**, 현행은 약 **64자**.
    같은 단폭에서 정본이 12% 작다 → 현행 11pt 기준 **약 9.8pt** 로 줄이고
    행간은 지금(18pt)과 비슷한 **17.3pt** 를 유지해야 정본 밀도가 된다.
17. **발문 내어쓰기가 없다.** 정본은 되풀이 줄이 약 1em 내어쓰기 된다. 현행은 단 왼쪽에 붙는다.
18. **22번 양끝맞춤이 벌어진다.** 낱말 사이가 눈에 띄게 벌어졌다(자간/장평 미조정).
    정본은 장평이 좁아 같은 폭에서 벌어지지 않는다.

## 14. 자료가 없어 못 정한 것

1. **26-1-기말 기출이 없다.** ⚠ 정본을 26-1-중간으로 대체했다. 두 회차 사이에서 실제로
   바뀐 항목이 넷(상자 캡션 괄호, 푸터 과목 표기, 마무리 문장, 총점 괄호)이라,
   직전 회차가 오면 그 넷을 다시 맞춰야 한다. **사용자 요청 필요.**
2. **지면 크기 미확정.** 사진 촬영본이라 mm 실측이 불가능하고 쪽마다 미디어박스가 다르다.
   테두리 상자 종횡비(약 1.40)로는 A4·B4를 구분하지 못한다. B4로 가정하고 테두리 폭을
   237mm로 두어 환산했다. **평판 스캔본이나 학교 HWP 원본이 오면** `page.측정_비율` 에
   곱하는 계수만 바꾸면 된다.
3. **본문 크기·행간 pt 미확정.** `행간/단폭 = 0.0541` 과 `한 줄 영문 72자` 는 확실하다.
   거기서 유도한 10.5pt / 17.3pt 는 장평 가정에 따라 ±1.5pt 흔들린다.
4. **서체 미확정.** 스캔이라 임베드 폰트명이 없다. 고딕 한 계열인 것만 확실하다.
5. **문항 묶음 표기를 관측하지 못했다.** 두 회차 모두 그런 문항이 없었다.
   '없는 게 규칙'인지 '없었을 뿐'인지 구분되지 않는다. 원고에는 회당 2개 있으므로
   반드시 정해야 한다 — 7절의 안을 확인받을 것.
6. **조건 상자 캡션이 정본 회차에 없다.** `| 조 건 |`(25-1-기말)을 그대로 쓸지,
   정본 스타일에 맞춰 `< 조 건 >` 으로 통일할지 결정 필요. 26-1-중간에는 서답형 자체가
   없어 판단 근거가 없다.
7. **25-1-기말 6/7쪽이 스캔에서 빠졌다.** 서답형 4·5번의 유형·배점·조건 상자를 못 봤다
   (합계로 두 문항 합 2.7점만 확인).
8. **(A)(B) 짝 구분자 점 개수가 흔들린다.** 3/7/없음 세 가지. 탭 채움점으로 보이지만
   확정하지 못했다. 점이 마침표(U+002E)인지 가운뎃점 계열인지도 해상도로는 구분 불가.
9. **주어진 문장 상자의 볼드 여부가 흔들린다.** 3표본 중 1개만 볼드. 다수결로
   '볼드 아님'을 기본값으로 두었다.
10. **선·테두리 두께 미확정.** 0.4~0.6pt 추정. 쪽 테두리·단 괘선·상자 테두리가 모두
    같은 두께로 보인다.
