## 3. 러닝 요소 — **홀·짝이 다르다**

| | 홀수 쪽 (1·3·5) | 짝수 쪽 (2·4·6) |
|---|---|---|
| 머리 | 저작권 문구(가운데) | `강 동 고 등 학 교`(오른쪽) |
| 꼬리 오른쪽 | `뒷면에 계속` | `다음 장에 계속` |

마지막 쪽(6쪽)에는 계속 표시가 **없다**. 종이 앞면/뒷면 개념이다.

### 저작권 (홀수 쪽만, 테두리 상자 위 · 가운데)

```
이 문제의 저작권은 강동고등학교에 있습니다. 무단 전송.복제.배포 시 저작권법에 의거 처벌될 수 있습니다.
```

- 구분자가 **마침표**이고 앞뒤 공백이 없다 — `전송.복제.배포`. 쉼표가 아니다.
- `있습니다.` 뒤 공백은 **한 칸**. 문장 끝 마침표 있음.
- 돋움 계열 고딕 볼드, 약 11pt(B4 환산·근사). 상자 위 테두리에서 약 6mm 위.

### 러닝헤드 (짝수 쪽만, 오른쪽)

`강동고등학교` — 돋움 계열 고딕 볼드, **자간을 크게 벌려** 실물은 `강 동 고 등 학 교` 로 보인다(약 +40~60%).
짝수 쪽에는 저작권 줄이 없다. 두 줄이 같이 나오는 쪽은 없다.

### 머리표 (1쪽만, 테두리 상자 **안** 맨 위)

본문 전체 폭(양 단을 가로지름)을 차지하는 **2행 표**.

```
┌─────────────────────────────────────────────────────────────────┐
│           2026학년도 (공통영어1) 1학기 기말고사                    │   ← 병합 행
├────────┬────┬────────┬──────┬────────┬───────────┬──────┬───────┤
│ 과목코드 │ 03 │ 인쇄매수 │ 290매 │ 대상학년 │ 1학년 1~8반 │ 시험일 │ 2026. 7. 2. [목] │
└────────┴────┴────────┴──────┴────────┴───────────┴──────┴───────┘
```

- 표제: 돋움 계열 고딕 ExtraBold, 약 **24pt**(B4 환산·근사), 가운데, 자간 +5~10%.
  자간은 **글꼴 자간**으로 준다 — 글자 사이에 공백 문자를 끼워 넣지 않는다.
- 메타 칸: 고딕 볼드 약 13pt, 가운데 정렬.
- `1학년 1~8반` — 물결 앞뒤 공백 없음.
- `2026. 7. 2. [목]` — 마침표 뒤 한 칸씩, 월·일에 0 을 안 붙이고, **요일은 대괄호**.
- 인쇄매수는 회차마다 바뀌는 값(26-1 중간·기말 290매, 25-1-기말 260매).
- **감독 확인란은 없다.**

### 쪽번호 (테두리 상자 아래 · 가로 가운데)

직사각형 안에 왼쪽 아래→오른쪽 위 **대각선**을 긋고 왼쪽 위에 현재 쪽,
오른쪽 아래에 총 쪽수를 넣는다(`1 ⁄ 6`).
상자 크기 약 **30.4 × 9.0mm**(테두리 상자 폭의 0.129 — 1·2·5·6쪽에서 모두 일치),
테두리 상자 아래 테두리에서 약 2.8mm 아래.

### 계속 표시

쪽번호 상자와 같은 높이대, 오른쪽. 고딕 볼드 약 13pt, 자간 약간 넓힘.
본문 오른쪽 끝에 딱 붙지 않고 약 10~13mm 안쪽에서 끝난다(원근 왜곡 가능 — § 13).

### 1쪽 듣기 안내 상자 (동형에서는 안 씀 — 정본 기록용)

전부 **단 폭 테두리 상자**, 한글 고딕, 강조어에 밑줄.


## 5. 문제 유형별 차이 — **본문 수치는 균일하다**

지문 첫 줄 들여쓰기(1칸), 선지 내어쓰기 규칙, 발문 내어쓰기 규칙은 **전 유형 동일**했다.
유형에 따라 달라지는 것은 두 가지뿐이다.

1. **선지 배치** (§ 6 아래 표)
2. **지문을 상자에 넣는가** (§ 6 지문 상자 규칙)

| 유형 | 특이점 |
|---|---|
| 어휘(6~15) | 영문 문장 + 우리말 해석 대괄호 줄 + 한 줄 5개 선지. 묶음 머리에만 발문 |
| 빈칸(24~27) | 묶음 머리에만 발문, 개별은 **번호만 단독 줄** + 지문. 배점은 지문 끝 |
| 순서 | 주어진 글 **상자** → (A)(B)(C) 문단(상자 없이 라벨 인라인) → 3개씩 두 줄 선지 |
| 삽입 | 주어진 문장 **상자** → 지문 안 `( ① )` 자리표시, **선지 줄 없음** (src: 26-1-중간) |
| 요약 | 지문 **상자** → `⇓` → 요약문 **상자** → (A)(B) 짝 선지 격자 |
| 장문(30~31) | 지문 하나를 **상자**에, 그 아래 30·31 문항이 각자 발문+선지 |
| 도표 | 그래프 이미지를 단 가운데에 **상자 없이**, 그 아래 설명 지문(상자 없음) |
| 서답형 | 발문 내어쓰기 0. 상자·표는 전부 단 폭 |

## 6. 보기 / 조건 / 요약 / 주어진문장 렌더

### `<보기>` — **테두리에 걸터앉은 캡션** (이 학교의 가장 뚜렷한 표식)

```
      ──────────── < 보 기 > ────────────────
     │  99.8 percent / as / disposed of / the remaining / waste / with  │
      ──────────────────────────────────────
```

- 상자의 **위 선이 끊기고 그 자리에 캡션이 들어간다.** 캡션은 자간을 벌려 `< 보 기 >` 로 보인다.
- 꺾쇠는 ASCII `<` `>`. 상자 폭은 단 폭 전체.
- 내용은 ` / `(앞뒤 공백 있는 슬래시)로 이어 **가운데 정렬 한 줄**(넘치면 두 줄). 세로 나열 아님.
- 발문 안에서 언급할 때는 자간 없이 `<보기>`.

실측 표본:
```
99.8 percent / as / disposed of / the remaining / waste / with
no / at all / we / sensory capacity / which / have / properties
① abstain / ② dehydration / ③ hydration / ④ immortal / ⑤ inactive / ⑥ prevent / ⑦ release / ⑧ retain
```

**조건영작(서답형 4·5)** 은 세 상자를 위아래로 맞대어 쌓는다 —
① `<보기>` 상자 → ② 우리말 문장 상자 → ③ 영작 답란 상자. 26-1-기말 4·5번이 둘 다 이 순서다.

### `<조건>` — 26-1-기말에는 **상자가 없다**

조건은 발문 끝, 배점 앞에 괄호로 접어 넣는다.

```
… 완성하시오. (단, <보기>에 없는 표현을 추가할 것) [4점]
… 바르게 고치시오. (단, 각각 한 단어로 쓸 것) [4점, 각 1점]
```

동형 원고는 `<조건>` + `- …할 것` 목록을 쓴다. 항목이 하나면 발문 괄호로 접고,
여럿이면 상자로 두되 캡션은 `<보기>` 방식을 따른다 — **정본에 표본이 없는 추정**이다.

### 요약

`지문 상자 → ⇓(U+21D3) → 요약문 상자`.
`<요약문>` 같은 라벨은 인쇄하지 않는다. 화살표는 두 상자 사이 빈 줄에 가운데 정렬로 홀로 놓인다(상자 밖).
서답형 9번은 여기에 `<보기>` 상자와 답란 줄이 더 붙는다.

### 주어진 글 / 주어진 문장 (src: 26-1-중간)

발문 바로 아래, 단 폭 테두리 상자 안에 한두 줄. 볼드 아님.

```
┌──────────────────────────────────────────────────────────┐
│ The old rules no longer work, however, as everything gains speed. │
└──────────────────────────────────────────────────────────┘
```

### 지문 상자 규칙 (강동 시그니처)

| 상자에 넣는다 | 상자 없이 흘린다 |
|---|---|
| 여러 문항이 공유하는 **세트 지문** | 한 문항만 쓰는 보통 지문(16~27번) |
| (A)(B)(C)(D) 라벨이 붙은 지문 토막 | 서답형 6번의 그래프 설명 지문 |
| 요약 지문·요약문, 영작 우리말 문장·영작 답란, `<보기>` | 도표·그래프 이미지 자체 |
| 순서·삽입의 주어진 글/문장 | |

**캡션 두 종류를 섞지 말 것.**
`(A)` `(B)` 류는 상자 **바깥 위**에 가운데 정렬(명조)로 놓고 테두리를 끊지 않는다.
`<보기>` 만 테두리에 걸터앉는다(고딕).

### 선지 배치

| 유형 | 배치 |
|---|---|
| 영문 선지 | 한 줄에 하나, 마커 폭만큼 내어쓰기 |
| 한글 긴 선지 | 한 줄에 하나, 내어쓰기 거의 0 |
| 한글 짧은 선지 | 한 줄 5개(듣기 1번 `①풍선 ②탁자 ③케이크 ④현수막 ⑤꽃병`) 또는 한 줄 2개 |
| 어휘 단어 선지 | 한 줄 5개 균등 배분 |
| 순서 | 3개씩 두 줄, 구분자 ` - ` — `① (B) - (C) - (D)   ② (B) - (D) - (C)   ③ (C) - (B) - (D)` |
| 어법 기호 | 한 줄 5개 `① (a) ② (b) ③ (c) ④ (d) ⑤ (e)` — 지문에는 **소문자 괄호 `(a)~(e)`** |
| 삽입 | **선지 줄 없음.** 지문 안 `( ① )` ~ `( ⑤ )` |
| (A)(B) 짝 | 한 행에 **두 짝**, 머리행 `(A) (B) (A) (B)`, 구분자 `…`(U+2026), 괘선 없음 |

```
        (A)              (B)            (A)              (B)
①  incompetence  …  energetic   ②  incompetence  …  unhurried
③  indifference   …  protective   ④  indifference   …  efficient
⑤  intelligence   …  relaxed
```

> ⚠ **선택형 어법은 지문에 `(a)~(e)`, 서답형 어법은 `ⓐ~ⓔ`** 로 기호 계열이 다르다.
> 26-1-기말 30번(선택형)이 `(a)~(e)`, 서답형 3번이 `ⓐ~ⓔ` 였다.

## 7. 문항 묶음 표기

```
※ [선택형 {a}~{b}] {지시문} [각 {n}점]
※ [선택형 {a}~{b}, 서답형 {m}] {지시문}
※ [서답형{a}-{b}] {지시문}                       ← 서답형 전용 묶음, src: 26-1-중간
```

- `[선택형 …]` 라벨은 **볼드에 한 치수 작고**, 뒤따르는 지시문은 보통 굵기다.
- 대괄호 안쪽 공백 없음. `※` 다음에 전각 한 칸 정도, `선택형` 과 숫자 사이 반각 한 칸.
- 되풀이 줄은 **내어쓰기 없이 `※` 위치로 되돌아온다**.
- 묶음 안 개별 문항은 **발문을 되풀이하지 않는다.**
  - 내용이 한두 줄이면 번호와 같은 줄 — `6. She took her _______ route to school.`
  - 지문이 딸리면 **번호만 단독 줄** — `24.` 다음 줄부터 지문

정본 26-1-기말 표본 8개 전부:

```
※ [선택형 6-9] 다음 문장의 우리말 해석에 근거하여 빈칸에 들어갈 말로 가장 적절한 것을 고르시오. [각 0.6점]
※ [선택형 10~11] 다음 문장의 빈칸에 들어갈 말로 문맥상 가장 적절한 것을 고르시오. [각 1.5점]
※ [선택형 12~13] 다음 문장의 밑줄 친 부분과 의미가 가장 유사한 것을 고르시오. [각 1점]
※ [선택형 14~15] 다음 문장의 밑줄 친 부분과 의미가 정반대인 것을 고르시오. [각 1점]
※ [선택형 22-23] 다음 글의 밑줄 친 부분 중, 문맥상 낱말의 쓰임이 적절하지 않은 것을 고르시오.
※ [선택형 24-27] 다음 빈칸에 들어갈 말로 가장 적절한 것을 고르시오.
※ [선택형 28~29, 서답형 3] 다음을 읽고, 물음에 답하시오.
※ [선택형 30~31] 다음을 잘 읽고 물음에 답하시오.
```

> ⚠ **범위 구분자는 정본 자체가 흔들린다** — 물결 `~` 5개, 하이픈 `-` 3개.
> **다수인 물결 `~` 로 통일한다.**
> 26-1-중간은 반대로 전부 하이픈이고 `선택형` 뒤 공백도 없었다(`[선택형20, 서답형3]`).

## 8. 서답형 라벨

```
【서답형 {n}.】 {발문} [{배점}]
```

- 대괄호는 `【 】`(U+3010/U+3011), **번호 뒤 마침표가 괄호 안에** 들어간다.
- 고딕 **볼드**, 자간 넓힘, 발문보다 한두 치수 크다. 라벨 뒤 반각 공백 하나.
- 번호는 선택형과 **별도 연번**(1~9).
- 발문 되풀이 줄은 **내어쓰기 없이** 단 왼쪽에 붙는다.

```
【서답형 3.】 밑줄 친 ⓐ~ⓔ 중에서 어법상 틀린 것을 두 개 골라 그 기호를 쓰고, 이를
각각 바르게 고치시오. [6점, 기호 각 1점, 바르게 고친 것 각 2점]

【서답형 7.】 다음 글 (A)의 내용에 근거하여 (B)의 질문에 답하고자 할 때, 빈칸 ⓐ~ⓒ에
각각 들어갈 가장 적절한 한 단어를 (A)에서 찾아 그대로 쓰시오. [6점, 각 2점]
```

### 서답형 답란 — 정본에서 관측된 네 가지

| 형태 | 언제 | 렌더 |
|---|---|---|
| **2열 표** | 어법 고치기 · 도표 불일치 · 요약 오류 고치기 | 단 폭 2열, 머리행(고딕·가운데) + 빈 답 행 N개. 머리행이 답 행보다 낮다 |
| **기호 줄** | 짧은 답 2~4개 | `ⓐ ______________  ⓑ ______________` / `ⓐ - ____  ⓑ - ____  ⓒ - ____  ⓓ - ____` |
| **상자 안 인라인 빈칸** | Q&A형·에세이형(7·8번) | 별도 답란 없이 (B) 상자 문장 안 `ⓐ __________` 에 바로 적게 한다 |
| **영작 줄** | 조건영작(4·5번) | 영작 답란 상자 안에 영어 문두 + 상자 폭 끝까지 밑줄, 넘치면 다음 줄 통째 밑줄 |

관측된 표 머리행:
`일치하지 않는 단어 | 바르게 고친 것` · `어법상 틀린 낱말의 기호 | 바르게 고친 것` ·
`일치하지 않는 것 | 바르게 고친 것` · (중간) `어법상 틀린 곳의 기호 | 바르게 고친 것` ·
(중간) `적절하지 않은 낱말의 기호 | 바르게 고친 것`

## 9. 배점 표기

**대괄호 `[ ]`**, 소수 한 자리, 정수는 `3점`, 앞에 반각 공백 하나.

| 상황 | 붙는 자리 | 예 |
|---|---|---|
| 단독 문항 | **발문 끝** (마침표/물음표 뒤 한 칸) | `18. 다음 글의 제목으로 가장 적절한 것은? [2.6점]` |
| 묶음(어휘·어법 단문) | **※ 줄 끝**, 개별 문항엔 안 붙임 | `… 고르시오. [각 0.6점]` |
| 묶음(독해 세트) 안 개별 문항 | **지문 마지막 문장 뒤에 이어 붙음** | `… lack some kind of benefit. [2.7점]` |
| 서답형 | 발문 끝, 부분배점을 쉼표로 이어 씀 | `[6점, 기호 각 1점, 바르게 고친 것 각 2점]` |

> 세트 안 개별 문항은 발문이 없으므로 배점이 **지문 본문 흐름 안에** 들어간다.
> 별행 오른쪽 정렬이 아니다. 이걸 놓치면 배점이 갈 곳이 없어진다.

서답형 꼬리말 표본:
`[4점, 각 1점]` · `[4점, 각 2점]` · `[6점, 각 2점]` · `[6점, 각 1.5점]` ·
`[3점, 일치하지 않는 것 1점, 바르게 고친 것 2점]` · `[6점, 기호 각 1점, 바르게 고친 것 각 2점]` ·
(중간) `[4점, 기호 및 바르게 고친 것 각 2점]`

관측 배점대: 듣기 1.1~1.8 / 어휘 각 0.6~1.5 / 독해 2.2~3.1 / 서답형 3~6.
**머리표에 총점 칸은 없다** — 총점은 마지막 쪽 점수표에서 밝힌다.

## 10. 마무리

`- 끝 -` 같은 문구는 **없다.** 마지막 쪽에 **점수표 + 확인 사항 상자**가 마무리다.

### 점수표 (마지막 문항 뒤 · 확인 사항 상자 앞)

문항별 배점표가 아니라 **영역별 합계표**다. 단 폭의 약 2/3, 단 안에서 가운데 정렬.

```
┌──────────┬─────────┬───────┐
│          │ 문항 수 │ 점수  │
├──────────┼─────────┼───────┤
│ ◎ 선택형 │ 31문항  │ 60점  │
│ ◎ 서답형 │  9문항  │ 40점  │
│ ◎ 합계   │ 40문항  │ 100점 │
└──────────┴─────────┴───────┘
```

> 26-1-중간은 앞 두 행을 `31` `9` 로만 적고 합계만 `40문항` 이었다.
> **직전 회차 기준으로 세 행 모두 `N문항`.**

### 확인 사항 (단 폭 테두리 상자, 고딕 볼드)

```
※ 확인 사항
 문제가 모두 끝났습니다. 답안지의 해당란에 필요한 내용을 정확히
기입(표기)했는지 확인하시기 바랍니다.
```

- `확인 사항` 은 **띄어 쓴다**(`확인사항` 아님).
- `기입(표기)했는지` — `기입(표기) 하였는지` 가 아니다.
- 둘째 줄 첫머리만 1칸 들여쓴다.
- 26-1-기말·중간 동일.

## 12. 원고 규칙

원고: `강동고1 동형 1회 원고.hwpx` (224단락) / `강동고1 동형 2회 원고.hwpx` (237단락)

**원고가 주지 않는 것 — 전부 조판이 만들어 넣어야 한다**

- **머리 메타 줄이 아예 없다.** 학교명·회차·문항 수·과목코드·시험일을 원고에서 못 얻는다.
- 문항 번호 없음 · 서답형 표시 없음 · 배점 없음.
- 묶음 표시는 부분적 — 세트 지문 앞에 `다음 글을 읽고 물음에 답하시오.` 한 줄만 있고
  범위·`※`·`[선택형 N~M]` 은 없다. 세트 안 둘째 문항부터 발문이 `윗글의 …` 로 시작한다.
- 듣기 구간 없음(정본 1~5번 + 서답형 1~2에 해당). 듣기 안내 상자 3종은 동형에서 안 쓴다.

> 선택형/서답형 판정은 **선지(①~⑤)의 유무와 밑줄 답란·`<보기>`·`<조건>`의 유무**로 해야 한다.

**정규화 필요**

| 항목 | 처리 |
|---|---|
| `➀~➄` (U+2780~) 20회 ↔ `①~⑤` (U+2460~) 55회 | **`①~⑤` 로 통일** (한 원고 안에서 두 계열이 섞임) |
| `↓` (U+2193) 3~5회 | **`⇓` (U+21D3)** 로 치환 |
| 순서 선지 `① (A) - (C) - (B)② (B) - (A) - (C)` | 한 줄에 두 개가 붙어 있다 → **3개씩 두 줄** 재배치 |
| 어휘 선지 `① eager② extinct③ mature…` | 마커가 앞 낱말에 붙어 있다 → **균등 배분 5열** |

**제거 대상**

| 항목 | 위치 | 비고 |
|---|---|---|
| 출처 태그 `[YY년 M월 N번]` | 발문 단락 맨 끝 | 1회 16개 / 2회 16개. `[25년 3월 21번]`, `[26년 3월 41~42번]` 등 |
| 정답 | **한글 미주(endNote)** 로 발문 끝에 달림 | 텍스트만 긁으면 `… 가장 적절한 것은? ④` 처럼 붙어 나온다 |
| 서답형 정답 전문 | 발문 끝 | `(1) ⓐ providing → to provide, (2) ⓑ go → are gone` |

**원고 답란 형식**
`ⓐ ________________________` / `(1)_________________ → _________________` /
`(A)___________` / `ⓐ ____________________, ⓑ ____________________`

**형식 변환이 필요한 유형**
문장삽입 원고는 지문에 `( A ) … ( E )` 를 넣고 `➀ (A) ➁ (B) …` 선지 줄을 따로 둔다.
**강동 관행은 지문 안 `( ① )` 자리표시 + 선지 줄 없음**이므로 변환해야 한다.

### 구조 — 이게 제일 크다

1. **묶음 문항의 번호가 통째로 어긋난다.** 현행은 `1. ※ [1-4] 다음 문장의 …` 처럼
   **※ 묶음 줄에 문항 번호를 매기고** 묶음 안 개별 문장에는 번호를 안 준다.
   정본은 반대다 — ※ 줄은 번호 없는 지시문이고 개별 문항이 `6. 7. 8. 9.` 를 갖는다.
   현행 1회는 전 문항이 6블록(1~6)으로만 번호가 매겨져 있다.
2. **묶음 라벨에 `선택형` 이 빠졌다.** `※ [1-4]` → `※ [선택형 6-9]`.
   서답형이 끼면 `※ [선택형 28~29, 서답형 3]`.
3. **배점이 한 곳도 없다.** 정본은 모든 문항에 배점이 있고,
   세트 안 개별 문항은 **지문 끝**에 붙는다.
4. **서답형 라벨이 두 번 찍힌다.**
   4쪽 `【서답형 3.】 【서답형 3.】 아래 우리말 문장과 …`,
   6쪽 `【서답형 7.】 [서답형 7] 다음 글을 읽고 …`.
5. **원고 출처 태그가 인쇄된다.**
   4쪽 `[선택형 22, 서답형 2] 다음을 읽고, 물음에 답하시오. [26년 6월 32번]`
   — 태그 제거 + 앞에 `※` 붙이기.

### 상자·표

6. **`<보기>` 가 상자가 아니다.** 현행은 `〈보기〉`(U+3008/9)를 왼쪽 정렬 맨 줄로 놓고
   내용을 좌측 정렬 문단으로 흘린다. 정본은 **테두리 상자 + 위 선에 걸터앉은 `< 보 기 >`
   캡션 + 가운데 정렬 슬래시 나열**이고 꺾쇠도 ASCII `<` `>` 다.
7. **(A)(B)(C) 지문 토막이 상자가 아니다.** 라벨은 상자 **위 가운데**, 문단은 **상자 안**.
8. **어법 답표가 표가 아니다.** 현행 4쪽은 `적절하지 않은 낱말의 기호` / `바르게 고친 것`
   을 그냥 두 줄 텍스트로 찍는다. 정본은 머리행 + 빈 답 행을 가진 **2열 표**.
9. **요약에 `⇓` 가 없고 상자도 없다.** 지문 상자 → `⇓` → 요약문 상자.
10. **세트 지문을 상자에 안 넣는다.** (현행은 문장삽입의 주어진 문장만 상자 처리)

### 러닝 요소·문구

11. **저작권 줄이 6쪽(짝수)에도 찍힌다.** 2·4쪽은 맞게 처리했는데 **마지막 6쪽만**
    저작권 줄로 잘못 나간다 — 짝수 쪽은 `강 동 고 등 학 교` 여야 한다.
12. **저작권 구분자** — 현행 `무단 전송, 복제, 배포 시` → 정본 `무단 전송.복제.배포 시`.
    `있습니다.` 뒤 공백도 현행은 두 칸이다.
13. **시험일** — 현행 `2026.07.11.(토)` → 정본 `2026. 7. 2. [목]`.
14. **대상학년** — 현행 `1학년 1 ~ 8반` → 정본 `1학년 1~8반`.
15. **표제 자간을 공백 문자로 냈다** — 현행 `2 0 2 6 학년도 ( 공통영어1 )  1 학기 기말고사`.
    글꼴 자간으로 벌려야 한다.
16. **마무리 문구** — 현행 `※ 확인사항` / `기입(표기) 하였는지` →
    정본 `※ 확인 사항` / `기입(표기)했는지`.

### 조판 품질

17. **선지 마커가 앞 낱말에 붙어 있다** — `① eager② extinct③ mature④ formal⑤ civil`,
    `① (B) - (C) - (D)② (B) - (D) - (C)`. 단 폭에 균등 배분해야 한다.
18. **행간이 헐겁다.** 정본 영문 지문 112% / 한글 문단 135%. 현행은 문단 사이 빈 줄까지
    넣어 훨씬 성기다 — 같은 분량이 정본보다 쪽을 많이 먹는다.
19. **6쪽 테두리 밖에 `< 조 건 >` 조각이 흘러나와 있다**(오버플로 잔재).
20. **문장삽입 형식이 학교 관행과 다르다.** 현행 `(A)…(E)` + `① (A) ② (B) …` 선지 줄 →
    강동 관행은 지문 안 `( ① )` 자리표시 + **선지 줄 없음**.
21. **점수표는 형식이 맞다.** 값(`선택형 25문항 60점 / 서답형 6문항 40점 / 합계 31문항 100점`)만
    잡별로 맞추면 된다.

## 14. 자료가 없어 못 정한 것

- **용지 실치수.** 6장 모두 종이 가장자리가 프레임 밖으로 잘려 실측 불가.
  A4 는 강동2 프로파일의 확정치를 따른 것이다. A4·B4 는 종횡비가 같아 B4 환산치는
  영향받지 않지만, **쪽 테두리 상자가 용지에서 차지하는 비율(특히 상·하 여백)** 은 추정이다.
- **테두리 상자의 세로 비율.** 실측 1.284 가 현행 B4 템플릿 1.379 와 7% 차이 난다.
  원근 잔차인지 실제 차이인지 사진으로는 못 가른다 — 평판 스캔본이 필요하다.
  지금은 현행 템플릿 상자를 두고 **가로 비율만** 맞추기를 권한다.
- **서체 크기 절대값(±1pt).** 확실한 것은 비율뿐 —
  영문 행간 112%, 한글 행간 135%, `[선택형 …]` 라벨이 지시문보다 한 치수 작고 볼드,
  `【서답형 N.】` 이 발문보다 한두 치수 크고 볼드.
- **괘선 굵기의 정확한 pt.** 스캔 번짐에 묻혔다. 상대비(쪽 테두리 ≈ 단 괘선의 2배)만 확실.
- **우리말 해석 줄 `[ … ]` 의 대괄호 안쪽 공백 유무.** 공백이 있는 것처럼 보이나 확정 못 함.
- **듣기 발문의 마침표.** 1·3·4·5번은 `고르시오 [1.1점]` 처럼 마침표가 안 보이고 2번만
  `고르시오. [1.3점]` 이다. 학생 필기 밑줄에 가려졌을 가능성이 커
  **마침표 있음**을 표준으로 잡았다 — 확인 필요.
- **`<조건>` 을 상자로 낼 때의 렌더.** 26-1-기말·중간 어디에도 표본이 없다.
  지금 값은 `<보기>` 관행에서 유추한 추정이다.
- **문장삽입 `( ① )` 이 26-1-기말에도 같은지.** 기말에는 삽입 문항이 없어 중간 표본이다.
- **계속 표시의 정확한 오른쪽 들여쓰기.** 본문 오른쪽 끝보다 10~13mm 안쪽으로 측정됐으나
  원근 왜곡일 수 있어 '오른쪽 정렬' 로만 확정했다.
