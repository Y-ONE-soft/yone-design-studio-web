## 5. 문제 유형별 차이

**대부분 균일하다.** 어휘·빈칸·어법·제목·주제·요지·일치/불일치는 서체·크기·행간·
지문 첫 줄 들여쓰기(2칸)·선지 내어쓰기(0)가 전부 같다. 실제로 갈리는 곳만 적는다.

| 유형 | 다른 점 |
|---|---|
| **글의 순서** | 주어진 글 **상자 없음**(26-1-기말 23번). 조각 라벨은 `(A)(B)(C)` 또는 `(a)~(f)`. **조각의 되풀이 줄은 라벨 아래로 들여쓴다** — 선지의 '내어쓰기 0' 규칙과 반대다. 선지는 폭에 맞춰 한 줄에 2~3개. ⚠ 25-1-중간 4번은 주어진 글을 **상자에 넣었다** — 직전 회차 기준 상자 없음. |
| **문장삽입** | 주어진 문장 **테두리 상자**(두 회차 모두). 지문 안 자리 표시 `( ① )`(괄호 안쪽 좌우 공백 한 칸). |
| **요약** | 지문 → **화살표(가운데)** → 요약문 **테두리 상자** → (A)(B) 열 표. 빈칸은 `(A)__________`. |
| **안내문/도표** | **지문 전체를 큰 테두리 상자**에 넣는다. 25-1-중간 9번 정본 [109.4, 148.2, 193.6, 241.2](높이 93mm), 안여백 좌 2.3mm. 선지는 상자 밖. |
| **심경 변화** | 선지가 2열 표 + `→`(U+2192). `① satisfied  →  heartbroken` (26-1-중간 2번). |
| **두 지문 비교** | 각 지문 위에 `[A]` `[B]` 를 **가운데 정렬 단독 줄**로. 발문에서도 `[A]와 [B]에 대한 설명으로…` 로 인용(26-1-기말 2번). |
| **어법 (A)/(B)/(C) 슬래시형** | 지문 안 `(A) relies / rely` 인라인, 선지는 3열 표. |
| **장문** | **없다.** 광문2는 지문 하나에 문항 하나가 원칙이고, 물음이 여럿이면 서답형 하위번호로 푼다(→ 7·9절). |
| **서답형** | 발문(+조건 괄호)+`[배점]` → 지문 → (하위번호 `N-1.`/`N-2.`) → (보기 상자) → **답란**. 답란이 반드시 붙는다(→ 9절). |

## 6. 보기 / 조건 / 요약 / 주어진문장

광문2는 **상자를 많이 쓴다.** 전부 0.36pt 얇은 선. 그런데 캡션의 위치가 상자마다
다르므로 한 스타일로 뭉뜽그리면 안 된다.

### 보기 — 캡션이 **테두리 선 위에 얹힌** 상자

```
        ┌────────────< Word Bank >──────────────┐
        │ by itself / even fewer / much less / far more /  │
        │ at random / with assistance / with support /     │
        │ without help / far higher/ far worse             │
        └──────────────────────────────────────┘
```

- 캡션 **`< 보기 >`** — 꺾쇠 **안쪽에 공백 한 칸씩**. 영어 발문 문항에서는
  **`< Word Bank >`** 로 바뀐다.
- 위 변에 캡션 폭만큼 **틈이 나 있고** 캡션이 그 틈에 **가운데 정렬**로 앉는다.
- 내용은 ` / ` 로 이어 쓰고 줄이 차면 넘긴다. 되풀이 줄은 들여쓰기 없이
  상자 안여백에 맞춘다.
- ⚠ **발문 안에서 가리킬 때는 공백 없는 `<보기>`** 다:
  `[서답형 5] 다음 글의 빈칸에 들어갈 말을 <보기>의 단어를 모두 한 번씩만 사용하여 …`
  → **캡션과 인라인 표기가 다르다.**

**회차마다 달랐다.** 26-1-기말 = 캡션 온 보더 / 26-1-중간 = `[보기]` 가 상자 **안**
첫 줄 / 25-1-중간 = 상자 안 첫 줄에 `<보기>` 를 쓰고 내용이 같은 줄에 이어짐.
**직전 회차 기준 캡션 온 보더.**

### 조건 — 같은 '캡션 온 보더' (src 25-1-중간)

```
                    ─── < 조건 > ───
┌────────────────────────────────────────┐
│ 1. 밑줄 (A)의미: 질문이 아무리 순진해 보이더라도 무엇이  │
│                 든 기꺼이 물어보는데                  │
│ 2. 다음 단어들을 반드시 사용하시오 (어형변화 금지):      │
│   [ naive /  matter /  may /  the /  how / seem ]     │
│ 3. 총 8단어로 영작하시오..                            │
│    (조건대로 쓰지 않으면 감점되거나 0점 처리됨)          │
└────────────────────────────────────────┘
```

- 정본 실측: 상자 [109.4, 200.7, 196.4, 233.8], 위 변이 x145.8 에서 끊겼다가
  x162.3 에서 다시 시작하고 그 틈(x146.2~159.4)에 `< 조건 >` 이 앉는다.
- **캡션만 한 급 크다** (9.95pt vs 본문 8.99pt).
- 항목 마커 `1.` `2.` `3.`, 되풀이 줄은 항목 글자에 맞춰 손으로 들여쓴다.
- ⚠ **src = 25-1-중간.** 직전 회차에는 조건 상자가 나오는 문항이 없다(영작 서답형이
  조건 대신 `(어형변화 금지, 단어추가 금지)` 를 발문 괄호로 처리했다).
  26-1-기말의 보기 상자가 같은 '캡션 온 보더' 형식이라 일관성은 확인된다.

### 요약 — 라벨 없음, **상자 있음**

발문 → 지문 → **화살표(단 가운데)** → **요약문 테두리 상자** → (A)(B) 열 표.
`<요약문>` 같은 라벨은 인쇄하지 않는다. 상자 안 행간이 본문보다 넓다(14.3pt).
빈칸은 **`(A)__________`** (라벨 뒤에 밑줄).

⚠ 25-1-중간은 `     (A)     `(라벨을 밑줄이 감쌈)였다 — 직전 회차 형식을 쓴다.

### 주어진 문장 / 주어진 글

- **문장삽입의 주어진 문장 = 테두리 상자** (26-1-기말 9번, 25-1-중간 6번 모두).
  상자 안 행간이 본문보다 넓다(14.5pt).
- **글의 순서의 주어진 글 = 상자 없음** (26-1-기말 23번). ⚠ 25-1-중간 4번은
  상자였다 — 직전 회차 기준 상자 없음.

### 확인 사항 — 캡션이 상자 **안**

```
┌────────────────────────────────────────┐
│ ※ 확인 사항                                  │
│ · 답안지의 해당란에 필요한 내용을 정확히 기입(표기)했  │
│   는지 확인하시오.                            │
└────────────────────────────────────────┘
```

**보기·조건과 반대다.** 캡션이 테두리에 걸치지 않고 상자 안 첫 줄 왼쪽에 들어간다.
상자 폭은 단 너비 그대로. 세 회차 동일. (→ 10절)

## 7. 문항 묶음 표기

### **광문2는 문항 묶음 표기를 쓰지 않는다.**

세 회차(26-1-기말 24문항 / 25-1-중간 26문항 / 26-1-중간 24문항)를 통틀어
`【 N – M 】` / `[N~M]` / `[선 N, 서 M]` 같은 묶음 머리가 **0건**이다.
선택형은 전부 자기 지문을 갖는 단독 문항이다.

한 지문에 물음이 여럿 필요하면 묶음이 아니라 **서답형 하위번호**로 푼다:

```
[서답형1] 다음 글을 읽고 물음에 답하시오. (기호표기 필수) [4점]
   Astronomical stars, the ones visible in the sky at night and scattered …

1-1. Choose the appropriate expressions from the Word Bank to complete blanks (A) and (B).
(Do not change the form of the word.)  [2점, 각1점씩]
        ┌──────────< Word Bank >──────────┐
        │ by itself / even fewer / much less / …   │
        └────────────────────────────────┘
(A) ______________  ______________
(B) ______________  ______________

1-2. Complete the following topic sentence with ONE word from the passage in a
grammatically correct form. [2점]

Stars attract audiences simply by their (C)__________.
```

- 하위 번호 = **`{서답형번호}-{순번}.`**
- 하위 물음마다 자기 배점이 붙는다. 서답형 머리에는 **총점**이 붙는다.
- 하위 발문은 한국어일 수도 영어일 수도 있다(26-1-기말 1번=영어, 2번=한국어).
  원고가 주는 언어를 그대로 둔다.
- `다음 글을 읽고 물음에 답하시오.` 는 **묶음 지시문이 아니라 서답형 발문 본문**이다.

> **엔진 주의.** `engines/mockexam/parser.py` 는 `[N~M]` / `[선택형 N~M]` 묶음
> prefix 를 만들고, 같은 계열 광문3 v1 산출물에는 실제로 `[선26, 서2] 다음 글을 읽고
> 물음에 답하시오.` 가 찍혀 있다. **광문2에는 그대로 넣으면 안 된다.**

## 8. 서답형 라벨

```
[서답형1] 다음 글을 읽고 물음에 답하시오. (기호표기 필수) [4점]
[서답형4] 주어진 단어들을 모두 한 번씩만 사용하여 밑줄 친 문장을 완성하시오. (필요시 어형변화, 단어추가 금지) [4점]
```

- **`[서답형{n}]`** — 대괄호, **번호 앞에 공백 없음**, 뒤에 공백 한 칸 두고 발문
- 선택형과 **별도 번호**(선택형 1~24 / 서답형 1~6)
- 라벨 뒤에 곧바로 발문 (별행 아님). 되풀이 줄은 **내어쓰기 0** — 단 왼쪽으로 되돌아옴
- 발문 끝 구성: `발문 (조건 괄호) [배점]`

⚠ **학교 표기가 흔들린다.** 직전 회차 6개 중 `[서답형1]`·`[서답형2]`·`[서답형3]`·
`[서답형4]` 는 공백 없음, `[서답형 5]`·`[서답형 6]` 은 공백 있음.
다수형인 **공백 없음**으로 통일한다.

⚠ **볼드 여부.** 25-1-중간은 텍스트층에서 `HCRBatang-Bold` 로 **확정**(6개 전부).
26-1-기말은 스캔 판독상 본문과 같은 굵기로 보인다 → 직전 회차 기준 **볼드 아님**.
확신도 중간 — 텍스트층 있는 26학년도 기출이 오면 다시 봐야 한다.

## 9. 배점 표기

- 괄호 **`[ ]` (U+005B / U+005D)**, 발문 끝에 **공백 한 칸** 두고 붙인다
- 소수 한 자리. 정수면 `[3점]`
- 서답형 소문항 배점은 **한 대괄호 안에 쉼표로**: `[4점, 각 2점씩]`
- **머리표에 총점 칸 있음**: `선택형 24문제(70점)  서답형 6문제(30점)  [총100점]`
- **`부분점수 없음` 꼬리말을 쓰지 않는다** (배재 계열과 갈리는 지점)

```
1. 다음 글의 내용과 일치하지 않는 것은? [2.5점]
[서답형3] 다음 글의 밑줄 친 부분 중 어법상 틀린 두 곳을 찾아 번호를 쓰고, 바르게 고치시오 (기호표기 필수) [4점, 각 2점씩]
1-1. … (Do not change the form of the word.)  [2점, 각1점씩]
```

### ⚠ 26학년도부터 괄호가 바뀌었다

| 회차 | 선택형 | 서답형 소문항 |
|---|---|---|
| **26-1-기말 (정본)** | `[2.5점]` | `[4점, 각 2점씩]` |
| 26-1-중간 | `[2.7점]` | `[6점, 각 3점씩]` |
| 25-1-중간 | `(2.6점)` | `(각 2점씩 총 10점)` |

25-1-중간의 둥근 괄호와 `총 N점` 어순을 베끼면 안 된다.

`각` 뒤 공백도 흔들린다 — 직전 회차에 `[2점, 각1점씩]`(붙임)과 `[4점, 각 2점씩]`
(띄움)이 같이 나온다. 다수형인 **`각 N점씩`(띄움)** 으로 통일한다.

### 배점 합 검산 (조판 게이트로 쓸 것)

- **선택형 24문항 합 = 정확히 70.0점.** 26-1-기말 실측 24개
  (2.5·3·2.5·3.5·3·3.2·3.2·3.1·2.5·3.3·2.7·2.5·2.5·3.3·2.5·3.3·2.5·3.5·2.5·2.5·3.5·3.5·2.5·2.9)
  를 더하면 정확히 70.0. 단위 0.1, 범위 2.5~3.5.
- **서답형 6문항 합 = 정확히 30점** (4+8+4+4+4+6).

### 답란 (서답형에 반드시 붙는다)

| 유형 | 답란 |
|---|---|
| 빈칸 (A)/(B) | `(A) ______________  ______________` / `(B) …` |
| 기호 빈칸 ⓐ/ⓑ | `ⓐ ____________     ⓑ ____________` (한 줄에 나란히) |
| 영작·한 문장 쓰기 | `정답 : ______________________________` (단 너비 가까이, 길면 둘째 줄까지) |
| 어법 오류 2곳 | `(1) 틀린 번호: ______` / `    바르게 고친 표현: ____________` / `(2) …` |
| 어법 오류 문장 3곳 | `(1) 틀린 문장 번호: ______` / `    틀린 부분: ____________` / `    바르게 고친 표현: ____________` / `(2) …` / `(3) …` |
| 주제문 완성 | 완성할 문장을 한 줄로 놓고 빈칸에 밑줄 (상자 없음) |

- 되풀이 줄은 `(1) ` 폭만큼 들여쓴다(내어쓰기 방식).
- 밑줄은 텍스트 밑줄 속성이 아니라 **그리기 선 0.36pt**.
- ⚠ `정답` 뒤 콜론 공백이 흔들린다(26-1-기말 8쪽 `정답:` / 9쪽 `정답 :`).
  **`정답 : `(앞뒤 한 칸)** 으로 통일한다.

## 11. 기타 글리프 · 밑줄 관행

| 항목 | 값 |
|---|---|
| 요약 화살표 | **굵은 아래 화살표 `⬇`** (U+2B07 **추정**) — 획이 굵고 화살촉 양 갈래가 뒤로 젖혀진 모양. 단 가운데. |
| (A)(B) 짝 선지 구분자 | **없음** — 열 위치로만 맞춘다 |
| 순서 조각 구분자 | 하이픈 `-`, 공백 없음 (`(a)-(d)-(f)-(e)-(b)-(c)`) |
| 심경 변화 화살표 | `→` (U+2192) |
| 문장삽입 자리 표시 | `( ① )` (괄호 안쪽 좌우 공백 한 칸) |
| 원문자 | 선지·지문 표시 `①`~`⑤` (U+2460~) / 빈칸 표시 `ⓐ`~`ⓔ` (U+24D0~) |
| 안내문 불릿 | `○` (U+25CB), 하위는 `-` |
| 확인 사항 | `※` (U+203B) + `·` (U+00B7) |

### ⚠ 요약 화살표가 회차마다 다르다

| 회차 | 글리프 |
|---|---|
| **26-1-기말 (정본)** | 굵은 단선, 화살촉 뒤로 젖혀짐 → `⬇` 계열 |
| 26-1-중간 | 가는 단선 → `↓` (U+2193 로 보임) |
| 25-1-중간 | **`⇓` (U+21D3)** — 텍스트층 확정. 이중선 + 열린 V 화살촉 |

정본이 스캔이라 코드포인트를 못 뽑는다. 25-1-중간의 `⇓` 를 실제로 렌더해 보니
**26-1-기말 글리프와 모양이 명백히 다르다**(이중선 vs 굵은 단선). 같은 계열
광문3 v1 산업물이 `⬇` 를 쓰고 있어 `⬇` 로 본다. → 못 정한 것 참조.

### (A)(B) 짝 선지 — 열 표, 구분자 없음

```
       (A)              (B)
①  viable           inevitable
②  workable         avoided
③  feasible         diminished
④  practicable      unlikely
⑤  ambitious        generated
```

머리행에 `(A) (B) (C)` 를 각 열 위에 가운데 정렬. 원문자는 값 열보다 왼쪽의
별도 열. 정본 열 x (단 원점 108.9 기준):
2열형 ① 111.7 / (A) 117.7 / (B) 146.8, 3열형 ① 110.7 / (A) 118.7 / (B) 140.4 / (C) 167.1.

⚠ 25-1-중간은 열 사이에 **`…`(U+2026)** 를 40회 썼다. 직전 회차는 **구분자 없음**.

### 밑줄 · 볼드 관행 (광문2는 밑줄을 많이 쓴다)

| 대상 | 26-1-기말 | 25-1-중간 |
|---|---|---|
| 발문의 부정어(않는·않은·없는·틀린·잘못된·못한) | **볼드 + 밑줄** | 밑줄만 |
| 발문의 개수 지정(2개·3개) | **볼드 + 밑줄** | 밑줄 |
| 발문에 인용된 지문 구절 | 밑줄 | 밑줄 |
| 지문 안 ①~⑤ / ⓐ~ⓔ 표시 부분 | 밑줄 | 밑줄 |
| 지문 안 빈칸 | 밑줄(글자 없음) | 밑줄 |

원고를 받기 전에도 확정된 것:

1. **묶음 머리(`【 】` / `[N~M]`)를 만들어 넣으면 안 된다.**
2. 서답형이 물음 여럿을 가지면 `[서답형N] … 물음에 답하시오. (…) [총배점]` +
   `N-1.` `N-2.` 로 풀어야 한다.
3. 배점을 원고가 주지 않으면 **선택형 합 70.0 / 서답형 합 30** 이 되도록 배정한다
   (0.1 단위, 선택형 2.5~3.5).

## 현행과 달라 고쳐야 할 것

**현행 광문2 동형 산출물이 없다.**
`조판/교재/동형모의고사/고2/26-1-기말|26-1-중간/` 에 광문고 폴더가 없고,
`최종파일/` 에 `광문N_동형모의고사(N회).indd` 가 없으며, `인디자인 원본/` 에
`[원본]광문2_동형모의고사.indd` 가 없다. `engines/mockexam/config.json` 은 광문고
고1·2·3 을 등록해 두었지만 **실제 조판이 나간 적이 없다.**
(`core/structure/style_map.json` 의 `_광문_보류` 주석 — 광문 템플릿은 표준 단락스타일이
정비돼 있지 않아 v2 지원이 보류 상태다.)

그래서 아래는 **항목별 대조가 아니라**, (a) 같은 계열 광문3 의 v1 산출물
(`tests/fixtures/template_spec_dh_광문3.json`, 원본 `광문3_동형_2.indd`)과
(b) 엔진 기본 동작에서 읽어낸 **첫 조판 때 그대로 두면 틀릴 지점** 목록이다.

1. **배점 괄호** — 광문3 v1 산출물은 `(2.7점)` 둥근 괄호. 광문2 직전 회차는
   **`[2.5점]` 대괄호**. 26학년도부터 바뀐 것이라 구 산출물을 베끼면 틀린다.
2. **묶음 머리** — 파서가 `[N~M]` / `[선택형 N~M]` prefix 를 만들고, 광문3 v1
   산출물에는 `[선26, 서2] 다음 글을 읽고 물음에 답하시오.` 가 실제로 찍혀 있다.
   **광문2에는 묶음 표기가 3회차 통틀어 0건.** 서답형 하위번호로 풀어야 한다.
3. **(A)(B) 짝 선지 구분자** — 25-1-중간의 `…` 를 관행으로 굳히면 안 된다.
   직전 회차는 **구분자 없이 열 정렬**.
4. **요약 화살표** — 25-1-중간의 `⇓`(U+21D3, 이중선)를 쓰면 안 된다.
   직전 회차는 **굵은 단선 `⬇` 계열**(광문3 v1 산출물도 `⬇`).
5. **보기 상자 캡션** — 상자 **안** 첫 줄에 넣으면 안 된다(26-1-중간·25-1-중간 방식).
   직전 회차는 **테두리 선에 얹힌** `< 보기 >` / `< Word Bank >`.
   반대로 **`※ 확인 사항` 은 상자 안** 첫 줄 — 두 상자를 같은 스타일로 만들면
   둘 중 하나가 반드시 틀린다.
6. **마무리 문구** — `- 끝 -` / `- 수고하셨습니다. -` 를 붙이면 안 된다.
   광문2는 마무리 문구 없이 `※ 확인 사항` 상자로 끝난다.
7. **머리표 결재란** — 25-1-중간을 베끼면 결재 6칸이 들어간다. **26학년도부터 없다.**
8. **머리표·러닝헤드 고사명** — `[ 기말 ]고사` 가 아니라
   `정기시험 (기말고사) 문제지`. 러닝헤드에도 `1학기 정기시험   기말고사   문제지`
   로 '정기시험'이 들어간다.
9. **문항 번호 크기** — 배재 계열처럼 번호만 키우면 안 된다. 번호·마침표·발문이
   전부 같은 크기(11.01pt).
10. **선지 내어쓰기 0** — 두 줄짜리 선지의 둘째 줄이 원문자 아래로 들어가면 틀린다.
    단, **글의 순서 조각 `(a)~(f)` 만은 반대로 라벨 아래로 들여쓴다.**
11. **부정어 강조** — 직전 회차는 볼드 + 밑줄 **둘 다**. 밑줄만 그으면 25학년도 관행.
12. **괘선 두 종류** — 지면 괘선 1.079pt(굵음) vs 본문 상자·밑줄 0.36pt(가늘음).
    한 값으로 뭉치면 안 된다.
13. **배점 합 검산** — 선택형 24문항 합 70.0 / 서답형 6문항 합 30. 게이트로 넣을 것.

## 자료가 없어 못 정한 것

1. **요약 화살표의 코드포인트.** 정본이 사진 스캔이라 문자를 못 뽑는다. 모양
   (굵은 획 + 뒤로 젖혀진 화살촉)으로 `⬇`(U+2B07)로 추정했고, 광문3 v1 산출물이
   `⬇` 를 쓰는 것이 방증이다. 확정하려면 텍스트층 있는 26학년도 기출이나 광문2 원고가
   필요하다.
2. **`[서답형N]` 이 볼드인지.** 25-1-중간은 `HCRBatang-Bold` 확정, 26-1-기말은
   스캔 판독상 본문과 같은 굵기. 텍스트층 있는 26학년도 기출 필요.
3. **머리표 1행의 대괄호 안 공백.** 26-1-기말은 `[영어I ]과` 로, 26-1-중간은
   `[ 영어I ]과` 로 보인다. 스캔 해상도 한계.
   (25-1-중간 텍스트층은 `[ 영어I ]과` 로 확정 — 과목 글자는 **ASCII 대문자 I**,
   로마숫자 Ⅰ 이 아니다.)
4. **26-1-기말의 mm 실측이 없다.** 여백·단 폭·괘선 두께는 전부 25-1-중간(A4
   텍스트층)에서 가져왔다. 골격이 육안상 같지만, 25→26 학년도에 머리표에서
   결재란이 빠졌으므로 **1쪽 본문 상단 시작 y** 는 달라졌을 수 있다.
5. **`< 조건 >` 상자 규칙이 직전 회차 근거가 아니다.** 26-1-기말에 조건 상자가
   나오는 문항이 없어 25-1-중간에서 가져왔다. 26학년도 회차에서 조건 상자가
   나오는 기출을 확보하면 캡션 표기가 `< 조건 >` 그대로인지 확인해야 한다.
6. **보기 상자의 폭 규칙.** 25-1-중간의 보기 상자는 84.1mm(단 86.9mm)로 단보다
   2.8mm 좁고, 조건 상자는 87.0mm 로 단보다 살짝 넓다. 26-1-기말 스캔에서는
   단 너비에 거의 꽉 차 보인다. hwp 표 폭이 손으로 잡혀 있어 일관 규칙이 없을
   가능성이 크다 — 조판에서는 **단 너비 정렬**로 통일할 것을 권한다(정본과 최대 1.5mm 차).
7. **원고를 못 봤다.** 12절 전체가 비어 있다.
8. **서답형 하위 발문의 언어 규칙.** 26-1-기말 서답형1은 하위 발문이 영어,
   서답형2는 한국어다. 회차 하나로는 기준을 알 수 없다 — 원고가 주는 대로 두는 것이
   안전하다.
