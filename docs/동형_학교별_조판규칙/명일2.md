## 2. 지면 골격

- **쪽 전체를 감싸는 테두리 상자가 있다.** B4 재단면 기준 (11.0, 20.0)–(246.0, 344.0),
  굵기 **1.0pt**. 8쪽 전부. (도련본 좌표로는 (14, 23)–(249, 347).)
- 2단. **단 사이 세로 괘선** x **128.5mm** = 테두리 상자의 **정확한 가로 중앙**, 0.5pt.
  테두리 위끝~아래끝까지. 1쪽만 머리표 표 아래(y≈54)에서 시작한다.
  - 정본 8쪽 실측: 테두리 왼쪽을 0, 오른쪽을 1 로 뒀을 때 괘선 위치
    0.488 / 0.489 / 0.487 / 0.487 / 0.503 / 0.503 / 0.510 / 0.470 → **중앙**.
- 단 원점 **12.3 / 131.6mm**, 단 폭 약 **113.4mm**, 단 간격 약 5.9mm
- **상·하단 가로 괘선은 없다.** 테두리 상자와 가운데 세로선, 이 둘뿐.
- 쪽번호 문장과 저작권 문구는 **테두리 상자 밖(아래)**, `다음 쪽에 계속 ⬇` 는 **안**.

> **측정 방법** — 스캔이라 절대 mm 를 잴 수 없다. 인쇄된 테두리 상자를 기준자로 삼아
> 비율만 확정하고, mm 값은 현행 InDesign 골격(비율이 정본과 일치함을 확인)을 채택했다.
> 축척 검증: 26-1-중간 1쪽에서 테두리 윗변↔머리표 윗변 간격이 12px 인데 현행 조판의
> 같은 간격이 2mm → 5.73px/mm. 테두리 가로 1347px ÷ 5.73 = 235mm 로 현행과 일치.

> ⚠ 다만 **테두리 상자의 세로 비율은 살짝 다르다.** 정본 세로/가로 = 1.409,
> 현행 = 324/235 = 1.379. 정본 비율을 그대로 옮기면 235 × 331mm(상하 여백 16.5mm)다.
> 측정 오차(±2%)와 같은 크기라 강제하지 않고 `gaps` 에 남겼다.

## 5. 문제 유형별 차이

**들여쓰기·행간·크기는 유형과 무관하게 균일하다.** 갈리는 것은 배치뿐이다.

| 유형 | 다른 점 |
|---|---|
| 어휘 | 지문 안 표기가 `(A)[intended / opposite]` (대괄호 + 슬래시 + 밑줄). 선지는 (A)(B)(C) 열 표, 구분자 **`…`** |
| 빈칸 | 지문 안 빈칸은 긴 밑줄 한 줄 (`only ________________. If`). 선지는 한 줄 하나 |
| 순서 | (A)(B)(C)(D) 지문 토막을 **각각 테두리 상자**에 넣고 라벨을 상자 위에 얹는다. 선지는 **2+2+1** |
| 삽입 | 주어진 문장을 **내용 폭 상자**로 단 가운데. 지문 안 자리표는 `( ① )` |
| 요약(선택형) | **상자 없음.** ⇩ 아래 문단 + (A)(B)(C) 열 표, 구분자 **`-`** |
| 요약(서답형) | **테두리 상자**, 화살표 없음. 발문 → 요약문 상자 → `<조 건>` 상자 → 답란 |
| 장문/묶음 | 묶음 머리 뒤 지문 하나, 개별 문항이 번호+발문+배점을 **온전히** 갖는다 |
| 글(가)/(나) 재구성 | **(가)는 맨문단, (나)만 상자.** 학생이 채워 넣을 쪽만 두른다 |
| 짧은 선지 | `① (a)  ② (b)  ③ (c)  ④ (d)  ⑤ (e)` 처럼 **한 줄에 5개** |
| 도표·안내문 | 두 회차에 없어 **확인 못 함** |

- **캡션의 `보`/`기`, `조`/`건`, `요`/`약`/`문` 사이에 한 칸이 들어간다.** 발문 본문
  안에서 참조할 때는 붙여서 `<보기>` `<조건>` 으로 쓴다. (`<주제문>` 은 붙어 있다.)
- 선 굵기는 **0.4pt 안팎**(근사). 페이지 테두리 1pt 보다 확실히 얇고 단 괘선 0.5pt 과
  비슷하거나 조금 얇다.
- `<조 건>` 항목은 **`1. ` `2. ` `3. ` 아라비아 숫자 + 마침표**. 항목 안 강조는 굵게+밑줄.
- 낱말 목록형 `<보 기>` 는 **슬래시 앞뒤 공백**으로 이어 쓰고 가운데 정렬로 줄바꿈:

## 7. 문항 묶음 표기

```

[5, 서답형 2] 다음 글을 읽고, 물음에 답하시오.

```

- 괄호는 **대괄호**, **안쪽 공백 없음**. 범위 구분자는 **`~`**(공백 없음).
- 선택형+서답형 혼합은 **쉼표 + 공백**: `[2~3, 서답형 1]`, `[5, 서답형 2]`.
  선택형이 하나뿐이어도 범위 없이 번호만 적는다.
- 지시문은 **같은 줄**, 라벨 뒤 한 칸.
- **지시문의 '읽고' 뒤에 쉼표가 있다** (`읽고, 물음에`). 원고에는 없으므로 조판이 넣는다.
- 묶음 안 개별 문항은 **번호 + 발문 + 배점을 온전히 다시 갖는다.** 번호만 갖는 형태는
  없다. 발문은 `윗글의 …`, `윗글에 관한 …` 으로 시작한다.

## 8. 서답형 라벨

```
[서답형 3] 다음 글에서 문맥상 적절하지 않은 단어(들)이 포함된 한 문장을 찾아,
이를 흐름에 맞게 고쳐서 문장 전체를 바르게 다시 쓰시오. *주의: 답은 단어가
아니라 문장이어야 함. [3점]
```

- 형식 **`[서답형 N]`** + 한 칸 + 발문. 라벨은 본문보다 약간 굵어 보인다.
- 번호는 선택형과 **따로** 돈다 (머리표 `서답형 문항번호 1번 ~ 6번`).
- 묶음에 속한 서답형은 묶음 안 제자리에, 묶음이 없는 서답형은 선택형이 다 끝난 뒤
  뒤쪽에 몰린다. 26-1-기말: 서답형1 = `[2~3]` 묶음 안, 서답형2 = `[5]` 묶음 안,
  서답형3~6 = 21번 뒤.
- 주의사항은 꼬리말이 아니라 **발문 안에 `*주의: …`** 로 적는다.

> ⚠ **회차마다 괄호가 바뀐다.** 26-1-기말 `[서답형 N]`, 26-1-중간 `<서답형 N>`
> (라벨 뒤 공백 두 칸). 기존 동형 생성기는 `서답형 N.` 을 썼다 — **셋 다 다르다.**
> 직전 회차 기준이므로 **`[서답형 N]`**.

### 답란 — 유형마다 다르다

| 유형 | 답란 |
|---|---|
| 빈칸 단어형 | `(A): ________________` 를 줄 하나에 하나씩, 왼쪽 정렬, 상자 밖 |
| 문장 완성형 | **상자 안 인라인 밑줄** |
| 문장 다시쓰기형 | **답란 없음** — 밑줄도 괄호도 없이 아래에 여백만 |
| 문장별 채우기형 | `(1)` ~ `(6)` 둥근 괄호 번호로 문장을 나열하고 각 문장 안에 밑줄. 문항 사이 빈 줄 한 줄 |

26-1-중간은 **괄호형**을 많이 썼다: `1) 줄 번호 (      )`,
`2) 틀린 단어 (        ) → 고친 단어 (        )`, `(A)(i        ),  (B)(s      )`.
직전 회차 기준이므로 밑줄형.

## 9. 배점 표기

- 괄호 **`[ ]`** (U+005B / U+005D), 발문 **맨 끝**, 앞에 반각 공백 한 칸.
- 정수는 소수점을 붙이지 않는다: `[4점]` `[3점]`. 반점이면 `[3.5점]` `[4.5점]`.
- **소문항 부분배점은 같은 대괄호 안에 쉼표로** 잇는다.
  `[3점, 각 1점]` / `[4점, 각 2점]` / `[각 0.5점, 총 3점]`
  — 어느 쪽을 앞에 두는지는 문항마다 다르다. (26-1-중간엔 `[총 4점, 각 2점]` 도 있다.)
- **`부분점수 없음` 같은 꼬리말은 쓰지 않는다.** 필요하면 발문 안 `*주의: …`.
- 머리표에 총점 칸 없음.

### 총점 구조 — 선택형 80 / 서답형 20

26-1-중간 정본 9쪽의 학교 배점표 원문:
`선택형만점 80.00 / 서답형만점 20.00 / 기타점수 0.00 / 가산점 0.00 / 과목만점 100.00`.
26-1-기말도 실측 합이 정확히 80 + 20 이다.

| 회차 | 선택형 | 배점 |
|---|---|---|
| 26-1-기말 | 21문항 | **3.5×10, 4×9, 4.5×2 = 80.0** |
| 26-1-중간 | 20문항 | 3.5, 3.7, 3.9×6, 4.1, 4.2×4, 4.3×4, 3.5 … = 80.00 (0.1 단위) |
| 23-2-기말 | 26문항 | 2.6 / 2.8 대 |

| 회차 | 서답형 | 배점 |
|---|---|---|
| 26-1-기말 | 6문항 | 3, 4, 3, 4, 3, 3 = 20 |
| 26-1-중간 | 6문항 | 4, 3, 3, 2, 4, 4 = 20 |

> **문항 수가 바뀌면 배점 폭이 통째로 바뀐다.** 21문항이면 0.5 단위, 20문항이면
> 0.1 단위. 동형은 원고 문항 수(선택형 20 + 서논술형 6)에 맞춰 **합 80 / 20** 만
> 맞추면 된다.

26-1-기말 실측 배점 (문항번호 → 점수):

```
1:3.5  2:4    3:3.5  4:4    5:4    6:4    7:4    8:4
9:3.5 10:3.5 11:4   12:3.5 13:4.5 14:4   15:3.5 16:3.5
17:3.5 18:4  19:4.5 20:3.5(역산) 21:3.5
서답형 1:[3점, 각 1점] 2:[4점, 각 2점] 3:[3점] 4:[4점] 5:[3점] 6:[각 0.5점, 총 3점]
```

> 20번 발문은 사진의 접힌 자국에 가려 읽지 못했다. 나머지 20개 합이 76.5 이고
> 선택형 총점이 80 이므로 3.5로 역산했다.

## 10. 마무리

**두 줄이 한 벌**이다. 마지막 문항 바로 뒤에 `수고하셨습니다!` 를 가운데 정렬로 놓고,
오른쪽 단 **맨 아래**(테두리 상자 안쪽 바닥)에 `- 끝 -` 을 가운데 정렬로 놓는다.

```
                수고하셨습니다!

                    (여백)

                   - 끝 -
```

26-1-기말과 26-1-중간이 **같다**. 배재처럼 회차마다 흔들리지 않는다.
마지막 쪽에는 `다음 쪽에 계속` 이 없다.

## 11. 기타 글리프

| | |
|---|---|
| 요약 화살표 | **`⇩` (U+21E9, 속이 빈 윤곽선 화살표)** — 26-1-기말 16번에서 6배 확대로 확정. 획이 두 줄이고 화살촉이 삼각 윤곽이다. |
| 계속 표시 화살표 | **속이 찬 굵은 검은 화살표** (`⬇` 계열). 요약 화살표와 **다른 글리프**다. |
| (A)(B)(C) 짝 선지 구분자 | **어휘·재구성형 `…`** / **요약형 `-`** |
| 순서 선지 구분자 | 공백 없는 하이픈: `(B)-(D)-(C)` |
| 문장삽입 자리표 | `( ① )` — 괄호 안쪽 좌우 공백 |
| 지문 안 밑줄 표시 | 소문자 원문자 `ⓐ~ⓔ`, 선지는 `①~⑤` 로 그것을 가리킨다 |
| 밑줄 관행 | 발문 부정어 = 굵게+밑줄 / 조건 항목 강조 = 굵게+밑줄 / 어휘 짝 `(A)[intended / opposite]` = 밑줄 / (A)(B)(C) 머리행 = 밑줄 |
| 각주 | 지문 바로 뒤 단독 줄 `*hominid: 인류`, `*forage: … **comb: …` |

> ⚠ **요약 화살표는 회차마다 바뀐다.** 26-1-중간은 얇은 `↓`(U+2193) 한 획이었다.
> 직전 회차 기준이므로 **`⇩`**.

## 12. 원고 규칙

표본: `26-1-중간 명일2 동형 1회 원고.hwpx` (324단락) · `2회 원고.hwpx`

| 항목 | 원고가 주는가 |
|---|---|
| 머리 메타 | `선택형 20 서논술형 6` — 첫 단락 한 줄. 콜론 없이 공백만, **'서답형' 이 아니라 '서논술형'**. 인쇄 금지. |
| 문항 번호 | **안 준다** |
| 서답형 표시 | **안 준다** — `쓰시오/완성하시오/배열하시오` + 답란(`→`/`▶`/`정답:`) 조합으로 판정 |
| 묶음 표시 | **안 준다** — `다음 글을 읽고 물음에 답하시오.` 뒤 지문 + 이어지는 `윗글의 …` 발문들 |
| 선지 마커 | `①`(U+2460) · **`➀`(U+2780)** · `ⓐ` · `(A)` |
| 출처 태그 | **준다 → 제거** `[23년 6월 39번]` `[23년 6월 31번 변형]` `[3과]` `[1과]` (회당 14건) |
| 상자 표기 | `<보기>` `<조건>` (공백 없음) |
| 조건 항목 번호 | **안 준다** — `· ` 글머리표거나 표기 없음. `1. 2. 3.` 은 조판이 매긴다 |
| 답란 | `→ ______`, `▶ ______`, `정답: ______`, `(A) ______ (B) ______`, `(A)____________` |

### 반드시 해야 할 정규화

1. **`➀~➄`(U+2780) → `①~⑤`(U+2460) — 분류·판정 이전에.**
   1회 60:40, 2회 70:30 으로 뒤섞여 있다. 안 하면 선지 판정에 안 걸려 ③④가 지문으로 샌다.
2. **발문 끝에 붙은 정답 제거.**
   `… 적절하지 않은 것은? ③` / `… 모두 고르시오. ➀, ➁` /
   `… 어색한 것은? ➀ : ⓐ has contributed → have contributed` (해설까지) /
   서답형 `… 쓰시오. approaching tasks that you don't …` (정답 문장 전체).
   지시동사(`쓰시오`/`고르시오`/`것은?`/`완성하시오`/`배열하시오`)까지만 남기고 자른다.
   단 `(단, …)` `<한 단어는 추가할 것>` 같은 단서절은 **발문의 일부이므로 보존**.
3. 출처 태그 `[YY년 M월 N번]` `[N과]` 제거.
4. 한 줄에 붙어 버린 선지 분리: `③ (B) - (C) - (A)④ (C) - (A) - (B)` → 두 항목.
5. 순서 선지 구분자 ` - ` → `-` (공백 제거).
6. (A)(B)(C) 짝 선지의 탭 → 학교 구분자 (`…` 또는 `-`).
7. 요약 화살표 `↓` → `⇩`.
8. 묶음 지시문 `읽고 물음에` → `읽고, 물음에`.
9. 원고 마커 `<보기>`/`<조건>` 줄은 **상자 캡션으로 흡수**하고 본문에서 지운다.
10. 원고 답란 머리표(`→`/`▶`/`정답:`)는 기출에 없다. 유형에 맞는 기출 답란으로 교체.

### 원고의 함정

- 발문에 `?` 가 빠진 오타(`… 것은 ➁`)나 `모두 고르시오`(물음표 없이 종결)가 있다.
  발문 판정을 `?` 에만 의존하면 안 된다.
- **출처 태그 · 정답 꼬리 · 머리 메타** 셋이 원고→조판 사이 대표적 누출 경로다.
  실제로 현행 산출물에서 머리 메타가 새어 나갔다.
