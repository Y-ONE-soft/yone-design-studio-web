## 0. 이 문서의 수치를 읽는 법 (먼저 읽을 것)

강동2 정본은 **두 회차 모두 손으로 찍은 사진 스캔**이고, 6쪽 어디에도 종이
가장자리가 온전히 들어오지 않았다. 그래서 **절대 mm 를 확정할 수 없었다.**

- 1차 값은 **인쇄된 쪽 테두리 상자를 1.0 으로 본 비율**이다. 6쪽 각각에서 테두리
  상자 네 꼭짓점을 잡아 원근 보정(homography)한 뒤 2000×2600px 캔버스로 펴서 쟀다.
  보정이 등방인지는 **①(원문자) 글리프가 정원이 되는지**로 검증했다 —
  쪽 전역에서 31~33px 정사각으로 나왔다.
- mm 은 그 비율을 **현행 B4 템플릿 상자(11/20 – 246/344, 즉 235×324mm)** 에 얹은
  파생값이다. 상자 자체의 절대 크기가 바뀌면 같이 움직인다.
- `typography.approx: true`.

**그래서 이 문서에서 믿을 것은 (a) 문자열·표기·상자 규칙 전부, (b) 비율 수치,
(c) 배점 표. 믿지 말 것은 절대 mm 한 자리다.**

## 2. 지면 골격

- **쪽 전체를 감싸는 테두리 상자가 있다.** 저작권 줄·쪽번호 상자·계속 표시는
  전부 이 상자 **바깥**에 놓인다. 1쪽은 상자 **안** 맨 위에 머리표(표)가 들어간다.
- 2단. **단 사이 세로 괘선이 상자 정가운데**(폭의 49.98%)를 관통한다.
  1쪽은 머리표 아래부터, 나머지 쪽은 위 테두리부터 아래 테두리까지.
- 본문이 테두리에 **바짝 붙는다.**

| 항목 | 상자 대비 비율 | B4 환산(파생) |
|---|---|---|
| 본문 좌 안쪽 여백 | 0.58 % | 약 1.4mm |
| 단 폭 | 48.25 % | 약 113.4mm |
| 단 간격 | 2.35 % | 약 5.5mm |
| 단 괘선 x | 49.98 % (정중앙) | — |
| 단 괘선 두께 | 상자 폭의 0.15 % | 0.3~0.5pt (스캔 번짐 포함) |

> 보정 캔버스(폭 2000px) 실측: 좌 본문 11.5 → 976, 괘선 999.5, 우 본문 1023 → 1988.5.
> 현행 템플릿(단 폭 ~111.7mm, 안쪽 여백 ~2.3mm, 괘선 정중앙)과 **사실상 같다.**

1행은 제목 한 칸(병합), 2행은 8칸. 표는 테두리 상자 폭의 97.3%.

```

과목코드 │ 03 │ 인쇄매수 │ 270매 │ 대상학년 │ 2학년 1~8반 │ 시험일 │ 2026. 7. 2. [목]
```

- 시험일: `2026. 7. 2. [목]` — 0 패딩 없음, 점 뒤 공백 한 칸, **요일은 대괄호**.

## 4. 단락 역할별 수치

전부 근사. 1차 값은 상자 비율, pt 는 현행 B4 상자에 얹은 파생값.

| 역할 | 서체 | 크기 | 행간 | 정렬·들여쓰기 |
|---|---|---|---|---|
| 발문 | 돋움 계열 고딕 | 상자 폭 대비 em 3.6% ≈ 11.7pt | 13.8pt | 왼쪽, 번호/라벨 폭만큼 **내어쓰기** |
| 지문 | 바탕/명조(영문 세리프) | em 3.42% ≈ 11.7pt | **13.8pt (= 118 %)** | 양끝맞춤, 첫 줄 1칸 들여쓰기 |
| 선지 | 지문과 동일 | 11.7pt | 13.8pt | 마커 다음 글자에 **내어쓰기** |
| 보기 | 지문과 동일 | 11.7pt | 13.8pt | 가운데 |
| 서답형 라벨 | 고딕 **볼드** | 11.7pt | — | 인라인, 발문은 보통 굵기 |
| 문항 번호 | 고딕 | 11.7pt | — | 발문과 **같은 크기**(배재처럼 키우지 않는다) |

**이 학교의 핵심 지표는 행간이다.**

- 정본: 행송 38~39px / 상자 높이 2600px = 1.50 % → 글자 크기의 **약 118 %**
- 현행 산출물: 11pt / 17pt = **155 %**

글자 크기는 사실상 같다(단 폭 대비 em: 정본 3.42 %, 현행 3.47 %). 벌어진 것은
행간뿐이고, 그 하나 때문에 정본 6쪽 분량이 현행에서 7~8쪽이 되고 마지막 쪽 한 단이
통째로 빈다.

문항 사이 앞여백은 약 1.2~1.5행.

## 6. 상자 규칙 — 강동2의 정체성

두 회차 6쪽씩, 전 쪽에서 교차 확인했다.

### 상자를 두른다

- 묶음(2문항 이상)이 공유하는 지문
- 대화문 지문 (`Beth`/`Neil`, `S1:`/`S2:`)
- 서답형의 지문, 그리고 `(A)` / `(B)` 블록 각각
- `<보 기>` — **캡션 걸침**
- `< 그림 N >` — **캡션 걸침**
- 순서의 주어진 글 / 삽입의 주어진 문장
- 요약문
- 영작 서답형의 답란 블록(한글 원문 + `↓` + 영어 답란)
- 1쪽 듣기 안내문 2개
- 마지막 쪽 `※ 확인 사항`

### 상자를 두르지 않는다

- **단일 선택형 문항의 지문** — 주제·제목·빈칸·어법·어휘·일치 전부 맨줄
- 선지 목록
- (A)(B) 짝 선지표
- 순서의 (A)(B)(C) 단락
- 삽입 문항의 본문
- 마지막 쪽 배점 표(괘선은 있지만 바깥을 감싸지 않는다)

### 캡션 걸침(`boxed_caption_on_border`) 이란

상자의 **위 테두리 선 가운데에 캡션이 앉고 그 자리에서 선이 끊긴다.**

```
 ─────────────── <보 기> ───────────────
│  account, budget, interest, withdrawal, purchasing, recording  │
 ───────────────────────────────────────
```

- 캡션은 `<보 기>` — **`보`와 `기` 사이에 공백 한 칸.**
- 발문 본문 안에서 인용할 때는 공백 없이 `<보기>`. 두 표기가 다르다.
- 그림은 `< 그림 1 >` — **꺾쇠 안쪽에 공백**(보기와 형태가 다르다). 실물 그대로.
- 상자 안 내용은 가운데 정렬. 단어 나열은 `/` 로 잇고 접는다.

### 지문이 둘인 묶음/서답형

각 상자 **위 가운데**에 `(A)` `(B)` 를 상자 밖 별행으로 놓는다(캡션 걸침 아님).

### 각주

지문 상자 **안** 맨 아래에 오른쪽 정렬 이탤릭.

```
                                       * wand: (마술사의) 지팡이
                        ** cast a spell: 요술을 걸다, 마법을 부리다
```

## 7. 문항 묶음 표기

**`[a-b] 지시문`** — 대괄호, 하이픈(U+002D), **괄호 안쪽 공백 없음**, 자동번호 없음.

```
[4-7] 아래의 우리말 해석을 참조하여 문장의 빈칸에 들어갈 가장 적절한
      단어를 고르시오. [각 1.8점]
[8-10] 아래 문장의 빈칸에 들어갈 가장 적절한 단어를 고르시오. [각 1.9점]
[11-12] 아래 문장의 밑줄 친 표현과 가장 유사한 뜻을 가진 단어를 고르시오. [각 1.8점]
[15-17] 다음을 읽고 물음에 답하시오.
[30-31] 다음을 읽고 물음에 답하시오.
```

**혼합(선택형 + 서답형)**

```
[14, 서답형3] 다음을 읽고 물음에 답하시오.
```

- 쉼표 뒤 공백 한 칸.
- `서답형` 과 숫자 **사이에 공백 없고 마침표도 없다** — 라벨 `【서답형 3.】` 과 다르다.

**묶음 안 개별 문항은 자기 번호와 자기 발문을 온전히 갖는다.** 번호만 남기고
발문을 생략하는 학교(배재)와 다르다.

지시문이 한 줄에 안 들어가면 둘째 줄이 **지시문 첫 글자에 내어쓰기** 정렬된다.

## 8. 선지

- 기본은 **한 줄에 하나**, 마커 뒤 공백 한 칸, 둘째 줄은 내용 첫 글자에 내어쓰기.
- **어휘 문항(짧은 단어 5개)** 은 한 줄에 균등 배치하고 **마커와 단어 사이에 공백이
  없다.**
  `①distinguished ②impartial ③anxious ④eccentric ⑤dilute`
- **순서**는 3+2 격자, 마커 뒤 공백 한 칸, 구분자는 하이픈(공백 없음).
  ```
  ① (A)-(C)-(B)     ② (B)-(A)-(C)     ③ (B)-(C)-(A)
  ④ (C)-(A)-(B)     ⑤ (C)-(B)-(A)
  ```
- **삽입**
  - 본문 안 자리 표시는 `( ① )` — 괄호 안쪽에 공백 한 칸씩.
  - 자리 표시가 `①`~`⑤` 면 **선지 목록을 따로 두지 않는다** (26-1-기말 27번).
  - 자리 표시가 `ⓐ`~`ⓔ` 면 `① ⓐ  ② ⓑ  ③ ⓒ  ④ ⓓ  ⑤ ⓔ` 를 한 줄 균등 배치
    (26-1-기말 16번).
- **밑줄형(어법·어휘)**
  - 지문 안 표시는 원문자를 낱말 **바로 앞에 공백 없이** 붙이고 밑줄은 낱말에만
    (`①where`, `③having`). 원문자에는 밑줄을 긋지 않는다.
  - 자기 지문을 바로 위에 갖는 문항은 **선지 줄이 없다** (26-1-기말 22번).
  - `윗글` 을 참조하는 문항은 `①    ②    ③    ④    ⑤` 만 한 줄 균등 배치
    (26-1-중간 14·15번).
- **(A)(B) 짝 선지** — 열 표, **상자 없음**
  ```
             (A)          …          (B)
             ‾‾‾                     ‾‾‾
  ①        shared         …       productive
  ②        unified        …       temporary
  ```
  - 머리행 `(A)` `(B)` 에 **밑줄**, 각 열 가운데.
  - 구분자는 가운데 높이 점 세 개 `…`.
  - 3열형은 `(ㄱ) (ㄴ) (ㄷ)` 라벨도 쓴다(26-1-중간 18번).
- **소라벨 선지** `① ⓐ: Ramps are designed to be used flexibly, …`
  (원문자 + 공백 + 동그라미 소문자 + 콜론 + 공백, 둘째 줄은 내용에 내어쓰기)

## 9. 서답형 라벨

```
【서답형 1.】 다음을 들은 한 학생이 아래와 같이 작성하였다. 각 빈칸 ⓐ-ⓒ에 들어갈
             가장 적절한 한 단어를 <보기>에서 골라 그대로 쓰시오. (단, 중복하여
             사용할 수 없음) [3점, 각 1점]
```

- `【` + `서답형` + 공백 + `{n}.`(숫자 뒤 **마침표**) + `】`
- **라벨만 굵고**, 이어지는 발문은 보통 굵기.
- 번호는 선택형과 **별도 연번**(1..6).
- 발문이 두 줄 이상이면 라벨 폭만큼 내어쓰기 되어 발문 첫 글자에 정렬.
- 빈칸 기호 범위는 `ⓐ-ⓒ` / `ⓐ-ⓓ` — **하이픈**(물결 아님).
- 단서는 둥근괄호 `(단, …)`.

**답란은 지문/보기 상자 안 인라인이다.** 별도 답란 줄을 두지 않는다.

```
ⓐ__________ and hold their breath to avoid drawing attention to themselves.
```

예외는 영작 서답형 — 한 개의 상자 안에

```
      이러한 과정이 그 신발 회사가 자신의 사업을 성장시키는 데
          필요한 자금을 모으는 것을 쉽게 만들어 줍니다.        ← 이탤릭 + 밑줄, 가운데
                          ↓                                   ← U+2193, 가운데
  This process makes ______________________________________
  ________________________________________________________ .
```

> **화살표는 `↓`(U+2193) 그대로다.** 배재처럼 `⇓`(U+21D3) 로 바꾸지 않는다.

## 10. 배점

**`[N.N점]`** — 대괄호, 소수 첫째 자리, 발문 끝(물음표/마침표) 뒤 공백 한 칸.

- 정수 배점은 `2점`으로 쓰고 `2.0점`으로 쓰지 않는다(26-1-기말 14번).
- 묶음은 `[각 1.8점]`.
- 서답형은 빈칸 하나면 `[4점]`, 여럿이면 `[8점, 각 2점]` — **쉼표 + `각`**.
  `부분점수 없음` 류 꼬리말은 강동에 **없다**.
- 발문이 길어 마지막 줄에 배점이 안 들어가면 **다음 줄 오른쪽 끝**에 단독으로
  내려 붙인다(26-1-기말 23번, 26-1-중간 24번·`[11-12]` 묶음).
- 머리표에는 총점 칸이 없다.

### 26-1-기말 전수 배점표 (검산 완료)

| 구간 | 배점 |
|---|---|
| 1 / 2 / 3 (듣기) | 1.6 / 1.7 / 1.7 |
| [4-7] | 각 1.8 |
| [8-10] | 각 1.9 |
| [11-12] | 각 1.8 |
| 13 | 1.8 |
| 14 / 15 / 16 / 17 | 2.0 / 2.4 / 2.2 / 2.3 |
| 18 / 19 / 20 / 21 / 22 | 2.1 / 2.2 / 2.3 / 2.4 / 2.2 |
| 23 / 24 / 25 / 26 / 27 / 28 | 2.2 / 2.4 / 2.5 / 2.2 / 2.3 / 2.5 |
| 29 / 30 / 31 | 2.7 / 2.3 / 2.5 |
| **선택형 합** | **65.0 (31문항)** |
| 서답형 1~6 | `[3점, 각 1점]` `[8점, 각 2점]` `[4점]` `[6점, 각 1.5점]` `[8점, 각 2점]` `[6점, 각 2점]` |
| **서답형 합** | **35.0 (6문항)** |
| **총계** | **100.0 (37문항)** |

**배분 패턴**

- 듣기(1~3) 1.6~1.7 — 가장 낮다
- 어휘·해석 단문(4~13) 1.8~1.9
- 독해(14~31) 2.0~2.7 — 대체로 뒤로 갈수록 커진다
- 서답형 = 빈칸 수 × 각 배점(1~2점) → 3~8점

**선택형 65 / 서답형 35 / 합계 100 은 두 회차 모두 같다 — 학교 상수로 본다.**

## 11. 마무리

**`- 끝 -` 류 마무리 문구가 없다.** 마지막 쪽은 배점 표 → 확인 사항 상자로 끝난다.

### 배점 표 (마지막 쪽, 마지막 단 안에서 가운데)

|  | 문항 수 | 점수 |
|---|---|---|
| ◎ 선택형 | 31문항 | 65점 |
| ◎ 서답형 | 6문항 | 35점 |
| ◎ 합계 | 37문항 | 100점 |

- 라벨 칸만 왼쪽 정렬(`◎` + 공백 + 이름), 숫자 칸은 가운데. 전부 굵은 고딕.
- 머리행 아래와 합계행 위의 가로 괘선이 나머지보다 굵다.
- 값은 **실제 조판된 문항 수**로 채우되 점수는 65 / 35 / 100 을 지킨다.

### 확인 사항 (테두리 상자)

```
※ 확인 사항
◦문제가 모두 끝났습니다. 답안지의 해당란에 필요한 내용
  을 정확히 기입(표기)했는지 확인하시기 바랍니다.
```

- `※` 뒤 공백 한 칸, `확인 사항` **사이에 공백**.
- `◦` 바로 뒤에 공백 없이 본문. 넘친 줄은 `문` 자리에 내어쓰기.
- `기입(표기)했는지` — `표기)` 와 `했는지` 사이 공백 없음.

## 13. 원고 규칙

원고: `강동고2 동형 1회 원고 최종.hwpx`(단락 343) / `강동고2 동형 2회 원고_최종.hwpx`(단락 331)

### 원고가 주는 것

- 머리 메타 3줄 — `강동고2 동형 {N}회` / `선택형: 27문항` / `서술형: 8문항`
  (2회는 `강동고2 동형 2회 원고` 로 `원고` 까지 붙어 있다)
  → **인쇄하면 안 된다.**
- 묶음 표기 `(1~3)` `(4~7)` `(8~9)` — **둥근괄호 + 틸드**
- 묶음 지시문 `다음 글을 읽고 물음에 답하시오.`
- `<보기>` (1회 7건 / 2회 4건), `<조건>` (2회 1건), `<그림>`, `[A] [B] [C]`, `(A) (B)`
- 출처 태그 `[25년 3월 21번]` (1회 19건 / 2회 20건)
- 짝 선지는 **탭 구분** — 머리줄 `      (A)\t\t(B)`, 항목 `① idealistic\t\tslower`
- 그림 1건(`BinData/image1.png`)
- 화살표 `↓` U+2193

### 원고가 안 주는 것 → 조판이 만들어야 하는 것

- **배점이 하나도 없다.** 전부 10절의 패턴으로 만들어 넣어야 한다.
- **서답형 표시가 전혀 없다.** `쓰시오/배열하시오/적으시오` + 밑줄 기입란의 존재로
  구조 판정해야 한다.
- 쪽 테두리·머리표·러닝·안내문·계속 표시·배점 표·확인 사항 전부.

### ⚠ 문항 번호 불균일 — 이 학교 원고의 최대 함정

| 범위 | 원고 상태 |
|---|---|
| 1 ~ 9 | `1. `, `2. ` … 정상 |
| 10 | 1회 `10 아래 문장의…` (**마침표 없이 발문에 붙음**) / 2회 `10. 아래 문장의…` |
| 11 이후 | **번호 없음** (`윗글의 주제로 가장 적절한 것은? ①` 처럼 발문만) |

원고 전체에서 번호줄은 9~10개뿐이다. 따라서

1. 번호는 **전부 조판이 다시 매긴다** (`numbering.question.source = auto`).
2. 발문 머리에 남은 번호 잔재(`10 `, `10. `)를 **떼어낸다.**

> 현행 1회 산출물은 2번을 못 해서 `4.\t 10 아래 문장의 밑줄 친 표현과 반대되는 뜻을
> 가진 단어는?` 로 번호가 두 개 찍혀 나갔다.

### ⚠ 정답 누출 — 스트립 필수

원고에는 정답이 **두 번** 들어 있다.

```
다음 글의 주제로 가장 적절한 것은? ④ [25년 3월 30번]     ← 발문 줄 끝
④                                                        ← 다음 줄에 반복
```

```
The philosopher attempted to turn concrete experiences into a
universal theory of human behavior. ① abstract            ← 지문 줄 끝에도 붙는다
```

서답형은 정답이 문장/목록이다.

```
… 쓰시오. (단, 필요시 변형 가능) ⓐ misconception(s), ⓑ risk. ⓒ derogatory, ⓓ equipped [26년 3월 21번]
retrieve → retrieving
(a) ①, (b) ④, (c) ②, (d) ③
찬의, 우솔, 희건
if they did not have (those) commitments 또는 if it were not for (those) commitments
```

출처 태그는 **정답 뒤**에 온다. 태그를 앵커로 `발문 … <정답> [출처]` 를 잘라내고,
바로 다음 줄이 그 정답의 반복이면 그 줄도 지운다.
**태그가 없는 문항도 있으므로 태그만 믿으면 안 된다.**

### 정규화

| 원고 | 조판 |
|---|---|
| `➀`~`➄` (U+2780~, 2회 10건) | `①`~`⑤` (U+2460~) |
| `(1~3)` | `[1-3]` |
| 발문 앞 `10 ` / `10. ` | 제거 후 자동번호 |
| `↓` U+2193 | **그대로** (정본이 ↓) |
| 짝 선지 탭 구분 | `…` 구분 3열 + 머리행 밑줄 |
| 지문 뒤 별도 답란 줄 `ⓐ______, ⓑ______` | 지우거나 상자 안 인라인 빈칸으로 흡수 |
| 발문 안 `<보기>` | 그대로 (상자 캡션만 `<보 기>`) |

### 문항 수 불일치

원고는 **선택형 27 + 서술형 8 = 35**, 학교 정본은 **선택형 31 + 서답형 6 = 37**이다.
배점 표는 실제 조판 수로 채우되 65 / 35 / 100 총계는 지킨다.

## 15. 자료가 없어 못 정한 것

1. **절대 치수(mm).** 정본 두 회차가 모두 손사진이고 종이 가장자리가 어느 쪽에도
   온전히 안 잡혀, 쪽 테두리 상자의 실제 mm 를 확정할 수 없었다. 이 문서의 mm 는
   전부 상자 비율 × 현행 B4 템플릿 상자로 낸 파생값이다.
   → **평판 스캔본 또는 학교 원본 PDF/HWP 가 있으면** 여백·테두리 두께·글자 크기를
   확정할 수 있다.
2. 테두리 상자 두께와 단 괘선 두께의 차이. 원근 보정 잔차가 선 두께보다 커서
   구분 불가. 현행 0.5pt 를 유지했다.
3. 제목의 `Ⅰ` 이 전각 로마숫자(U+2160)인지 라틴 대문자 `I` 인지.
4. 짝 선지 구분자가 `…`(U+2026)인지 `⋯`(U+22EF)인지.
5. **`<조건>` 렌더.** 정본 두 회차 모두 사례가 없다. 2회 원고에 1건 있으므로
   `<보 기>` 규칙을 유추 적용했으나 **추정이다** — 조판 전 확인 필요.
6. 1쪽 하단 계속 표시(기말 사진이 아래를 잘랐다). 26-1-중간 1쪽의 `뒷면 계속` 으로
   홀수 쪽 규칙을 확정했다.
7. 서체 이름. 스캔이라 임베드 정보가 없어 '돋움 계열 고딕' / '바탕 계열 세리프'
   수준까지만 적었다.
8. 문항 사이 앞여백이 유형별로 다른지 — 표본 부족.
