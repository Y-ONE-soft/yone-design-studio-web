## 6. 보기 / 조건 / 요약 / 주어진문장

- **`<보기>` = 테두리 없는 맨줄.** 단독 줄에 **가운데 정렬**(정본 x 146.2, 단 원점
  107.3 → 들여쓰기 38.9mm), 내용은 그 아래 지문과 같은 크기로 이어 쓴다.
  근거: 정본 7쪽 전체에 사각형 그리기가 **0개**다.
- 한 문항에 보기가 둘이면 `<보기1>` `<보기2>` 로 번호를 단다 (src 26-1-중간).
- **`<조건>` 표기를 쓰지 않는다.** 배재는 `[정답 작성 안내]` 뒤에 `(1) …` `(2) …` 를
  줄 단위로 적는다.
- **요약문에 라벨도 테두리도 없다.** 발문 → 지문 → (화살표) → 요약 문단 →
  (A)(B) 선지표 순. 원고의 `<요약문>` 라벨은 **조판에서 지운다**.
- 문장삽입의 주어진 문장도 상자 없이 문단으로. 지문 안 자리 표시는 `( ① )`.

## 7. 문항 묶음 표기

```
【 8 – 9 】 다음 글을 읽고 물음에 답하시오.
【 28 – 29 】 다음 글의 내용을 한 문장으로 요약하고자 한다. 빈칸 (A), (B)에 …
```

- 렌티큘러 괄호 `【 】`, **안쪽 좌우 각 한 칸**
- 범위 구분자 **en dash `–` (U+2013), 앞뒤 공백 있음**
  ⚠ 26-1-중간은 하이픈 `-`, 공백 없음(`【 7-8 】`)이었다. **직전 회차 기준이므로 en dash.**
- 지시문은 **같은 줄**에 이어 쓴다
- 묶음 안 개별 문항은 발문을 되풀이하지 않고 **`28. 〔3.6점〕` 처럼 번호+배점만**
  갖는 경우가 있다(묶음 머리에 발문 전체가 온 경우)
- 선택형+서답형 혼합 (src 26-1-중간): `【 6, 서답형 1 】` `【 10, 서답형 2 】` `【 25, 서답형 3 】`

## 8. 서답형 라벨 (src 26-1-중간)

```
 [서답형 1] <보기>에 주어진 의미를 가지고 있는 단어를
윗글에서 찾아 쓰시오. 〔5점, 부분점수 없음〕
```

- `[서답형 {n}]` 대괄호, 번호 앞뒤 한 칸, **줄 맨 앞에 반각 공백 하나**
- 선택형과 **별도 번호**(1부터)
- 라벨 뒤에 곧바로 발문이 이어진다(별행 아님)
- 25-2-기말은 `서술형` 이라는 낱말과 `〔서술형4〕` 형태도 섞여 있었다 — 직전 회차 기준
  **`서답형`** 을 쓴다

## 9. 배점 표기

- 괄호 **`〔 〕` (U+3014 / U+3015)**, 발문 끝에 **공백 없이** 붙인다
- 소수 한 자리. 정수면 `〔3점〕`
- 서답형 꼬리말 `〔5점, 부분점수 없음〕`
- 머리표에 총점 칸 없음

⚠ 정본 30개 표기 중 `〔〕` 17 / `[〕` 10(여는 대괄호 + 닫는 거북등 — **학교 오타**) /
`[]` 3. 학교 자체 표기가 흔들린다. **전부 `〔〕` 로 통일**한다.
25-2-기말은 반대로 `[]` 가 표준이었다.

## 11. 기타 글리프

- 요약 화살표 **`⇓` (U+21D3)** — src 26-1-중간(3회). 직전 회차에는 요약 화살표가
  안 나온다(요약 문항이 묶음 머리 발문형이라 화살표 없이 문단만 놓임).
- **(A)(B)(C) 짝 선지 구분자 = 하이픈 다섯 개 `-----`**. 머리행에 `(A) (B) (C)`,
  각 행은 `① wipe out ----- minor ----- fail` 처럼 열 표로.
- 문장삽입 자리 표시 `( ① )`
- 원문자 `①`~`⑤` (U+2460 계열)

## 12. 원고 규칙

원고: `배재1 동형 1회 원고.hwpx`, `배재1 동형 2회 원고.hwpx`

머리 메타 세 줄:
```
배재고1 동형 1회
선택형: 23문항
서술형: 4문항
```

| 항목 | 원고가 주는가 |
|---|---|
| 문항 번호 | **안 준다** — 조판이 자동번호로 만든다 |
| 서답형 표시 | **안 준다** — 구조로 판정해 `[서답형 N]` 을 만들어 넣는다 |
| 묶음 표시 | **안 준다** — `다음 글을 읽고 물음에 답하시오.` 지시문으로만 묶음이 드러난다. `【 】` 머리는 조판이 만든다 |
| 선지 마커 | `①` `ⓐ` `(A)` |
| 출처 태그 | 없음 |
| 상자 표기 | `<보기>` `<요약문>` `[정답 작성 안내]` |
| 답란 | `답: ______`, `(A) ______, (B) ______`, `(1) (   )번`, `(2) (틀린 부분: )`, `→ (고친 부분: )` |

정규화가 필요한 것:
- **라틴 악센트 → ASCII** (`Á`→`A`). 지문 서체에 글리프가 없어 □ 로 빠진다.
- 한 줄에 붙어 있는 `④⑤` 분리
- 원고 화살표 `↓`(U+2193) → 기출 `⇓`(U+21D3)
- 원고의 `<요약문>` 라벨은 기출에 인쇄되지 않으므로 **제거**

## 현행과 달라 고쳐야 할 것

1. 화살표가 `↓`(U+2193) — 정본은 **`⇓`(U+21D3)**
2. (A)(B) 짝 선지가 탭 정렬 — 정본은 **`-----` 다섯 하이픈**
3. 배점 괄호가 `[]` 인 산출물이 있다 — 직전 회차 기준 **`〔〕`**
4. 마무리가 `- 수고하셨습니다.-` 인 산출물이 있다 — 직전 회차 기준 **`- 끝 -`**

## 자료가 없어 못 정한 것

- 묶음 안 개별 문항이 '번호+배점만'인지 '번호+발문+배점'인지는 문항 유형에 따라
  갈린다. 유형별 규칙을 더 모아야 한다.
- 서답형 답란(밑줄 길이·들여쓰기) mm 실측이 26-1-중간 기준이다. 직전 회차에
  서답형이 없어서 확인하지 못했다.
