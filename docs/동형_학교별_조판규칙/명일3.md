「지문 명조·발문 고딕」은 절반만 맞다. 정확히는

> **영문 = 바탕(명조) 계열 비례 폭 / 한글 = 전부 고딕**

영문은 i 가 좁고 m 이 넓은 비례 폭이며 이탤릭도 쓴다.

## 6. 보기 / 조건 / 요약 / 주어진문장 렌더 방식

### <보 기> 상자 — 캡션이 테두리선에 걸친다

```
        ────────────── <보 기> ──────────────
       │  apple / as / banana / have / much  │
       │  instead / really / times / worth   │
        ─────────────────────────────────────
```

- 캡션 `<보 기>` — **`보` 와 `기` 사이에 공백 한 칸.** 상자 위 테두리선 위에 가운데
  정렬로 얹히고, 캡션 자리만큼 선이 끊긴다.
- 내용은 각 줄 가운데 정렬. 낱말은 ` / `(공백-슬래시-공백)로 잇는다.
- 상자는 단 폭 전체. 가는 홑선.
- **주의:** 조건 문장 안에서 보기를 가리킬 때는 공백 없는 `<보기>` 다
  (`−<보기>에 주어진 단어를 모두 사용할 것`). 캡션과 참조를 섞지 말 것.

### <조 건> 상자 — 같은 형식, 내용만 왼쪽 정렬

```
        ────────────── <조 건> ──────────────
       │ −<보기>에 주어진 단어를 모두 사용할 것 │
       │ −필요시 단어를 추가할 것              │
       │ −필요시 <보기>의 단어의 형태를 변형할 것 │
        ─────────────────────────────────────
```

- 각 항목 줄머리에 대시 `−` 하나, **뒤에 공백 없이** 곧바로 내용.
- 마침표 없음. `~할 것` 으로 끝난다.
- 보기 상자와 조건 상자가 둘 다 있으면 **<보 기> 먼저, <조 건> 다음**.

### 요약문 — 캡션 없는 상자 + 위에 화살표

순서: 발문 → 지문 → (빈 줄) → **화살표(가운데)** → **요약문 상자** → 선지표 또는 답란

- `<요약문>` 같은 라벨은 인쇄하지 않는다. 원고에 있으면 지운다.
- 화살표가 **두 종류**다:
  - 선택형 요약 → `↓` (U+2193) 가늘고 긴 선 화살표
  - 서답형 요약 → `⬇` (U+2B07) 속이 꽉 찬 굵은 화살표 (계속 표시와 같은 글리프)
  - 24-1-중간은 서답형에도 가는 `↓` 를 썼다. 한 회차 안에서도 흔들린다.
- 요약문 안 빈칸은 `(A)________`. 서답형이면 상자 아래에 `(A) ___` `(B) ___` 답란.

### 주어진 글 / 주어진 문장 — 캡션 없는 상자

- **순서 문항의 주어진 글**과 **문장삽입의 주어진 문장** 둘 다 테두리 상자에 넣는다.
- 상자 다음에 오는 (A)(B)(C) 문단은 상자에 **넣지 않는다.** 각 문단은 `(A) ` 로
  시작하고 둘째 줄부터 라벨 폭만큼 내어쓰기.
- 지문 안 삽입 자리 표시는 **`(①)` — 괄호 안쪽 공백 없음.**

## 7. 문항 묶음 표기

| 형태 | 템플릿 | 실측 예 |
|---|---|---|
| 선택형끼리 | `[{a}-{b}]` | `[1-2]` `[7-8]` `[11-12]` `[16-17]` `[18-19]` `[21-22]` |
| 선택형+서답형 | `[{n}, 서{m}]` | `[3, 서1]` `[10, 서4]` |
| 서답형끼리 | `[서{a}-서{b}]` | `[서5-서6]` |

- 범위 구분자 **하이픈 `-` (U+002D)**. 괄호 안쪽 공백 없음.
- **서답형은 `서N` 으로 줄여 쓴다.**
- 지시문은 **같은 줄**에 이어진다: `[1-2] 다음 글을 읽고 물음에 답하시오.`
  (쉼표 없음)

**묶음 안 개별 문항은 두 갈래로 갈린다.**

| 묶음 머리 | 개별 문항 |
|---|---|
| 일반형 — `[1-2] 다음 글을 읽고 물음에 답하시오.` | 각 문항이 자기 발문을 온전히 갖는다. 발문은 **`윗글의 …`** 로 시작(`다음 글의` 아님). 배점도 각자. |
| 발문 지고 있는 형 — `[16-17] 다음 글의 제목으로 가장 적절한 것은? [각 3.2점]` | 각 문항은 `16. ` 뒤에 **곧바로 지문**. 발문을 되풀이하지 않는다. 배점은 묶음 머리에 `[각 N점]` 한 번만. |

**오타 하나:** `[5, 서2].` 만 닫는 대괄호 뒤에 마침표가 붙어 있다. 나머지 9곳은 없다.
재현하지 말 것.

> ⚠ **신뢰도 낮음.** 명일2 26-1-중간·26-1-기말은 물결표 방언을 쓴다 —
> `[2~3, 서답형 1] 다음 글을 읽고, 물음에 답하시오.` (물결표 + `서답형 N` 전체 표기 +
> `읽고,` 쉼표). 학년 차이인지 2026년 개편인지 확정 못 했다. §14 참조.

## 9. 배점 표기

- 괄호 **`[ ]` (U+005B/U+005D)**, 발문 **끝**에 붙는다. 앞에 공백 한 칸.
- 발문 줄이 꽉 차면 배점만 다음 줄로 넘어가 **오른쪽 정렬**로 앉는다(25-1 2번).
- 선택형은 **소수 첫째 자리**(`[3.7점]`), 서답형은 **정수**(`[4점]` `[2점]`).
- 묶음은 `[각 3.2점]`.
- 소문항 부분배점: `[3점, 각 1.5점]` `[4점, 각 2점]` `[3점, 각 1점]` (24-1).
- `부분점수 없음` 같은 꼬리말은 **쓰지 않는다** (배재와 다름). 두 회차 관측 0건.
- 머리표에 총점 칸 없음.

### 총점 규칙 — 이 문서에서 가장 단단한 값

## 11. 기타 글리프

| 항목 | 값 |
|---|---|
| 계속 표시 화살표 | `⬇` U+2B07 (속 찬 굵은 화살표). 인디자인에서는 서체 사설 영역 글리프로 나감(현행 U+E406) |
| 요약 화살표 | 선택형 `↓` U+2193 / 서답형 `⬇` U+2B07 |
| 삽입 자리 | `(①)` — **괄호 안 공백 없음** |
| 원문자 | 숫자 ①~⑤ (U+2460~), 라틴 ⓐ~ⓕ (U+24D0~). 24-1은 ⓕ 까지 쓴 문항 있음 |
| 밑줄 | 지문 안 선지 대상 어구에 밑줄. 원문자는 어구 **앞**에 붙고 밑줄에 포함되지 않음 |
| 범위 구분자 | 묶음 번호는 하이픈 `-`, 선지 범위는 물결표 `~` (`ⓐ~ⓔ`). **다른 문자다** |

**선지 배치 5종** — 이걸 구분 못 하면 반드시 틀린다.

| 유형 | 배치 | 예 |
|---|---|---|
| 제목·주제·요지·일치·지칭·언급 | 한 줄에 하나 | `① The biological drive to overconsume food` |
| 어법·어휘 (ⓐ~ⓔ) | **한 줄에 5개** | `① ⓐ  ② ⓑ  ③ ⓒ  ④ ⓓ  ⑤ ⓔ` |
| 어법·어휘 (지문 안 ①~⑤) | **선지 목록 없음** | 밑줄 부분이 지문 안에서 매겨짐 |
| 순서 | **2열 3행** (행 우선) | `① (A)-(C)-(B)  ② (B)-(A)-(C)` / `③ ④` / `⑤` |
| (A)(B)(C) 짝 | 머리행 있는 열 표 | 구분자 3종 ↓ |

**(A)(B)(C) 짝 선지의 구분자는 문항 유형마다 다르다.**

| 문항 유형 | 열 | 구분자 | 예 |
|---|---|---|---|
| 요약 (25-1 4번) | 2 | **`…` 점 셋** (U+2026) | `① strict standards … irregularities` |
| 어휘 (25-1 20번) | 3 | **`‥` 점 둘** (U+2025) | `① express ‥ impractical ‥ extensive` |
| 순수 2빈칸 (25-1 5번) | 2 | **없음** | `① reflective        deliberate` |

같은 시험지 안에서 갈린다(학교가 출처 다른 자료를 붙여 쓴 흔적). 24-1-중간은 요약에
더 긴 점열(`……`, 대여섯 개)을 썼다.

어휘 괄호선택형은 지문 안 인라인: 25-1 `(A)[suppress / express]` / 24-1 `(A) [retract / continue]`
— `(A)` 뒤 공백 유무가 회차마다 흔들린다. 직전 회차(25-1) 기준 **공백 없음**.

### 출처 태그 — 다른 학교와 형식이 다르다

```
[14강 4번]
[6강 2번]
[2027수능특강(영어) 3강 1번]
[2027수능특강(영어) 17강 4번]
```

발문 바로 앞 단독 줄에 붙는 **EBS 강 출처 태그**. 두 방언이 섞여 있다.
다른 학교의 `[25년 3월 21번]`(모의고사 회차형)과 형식이 다르므로 **회차형 정규식으로는
안 잡힌다.** 기출 문제지에는 출처 태그가 전혀 인쇄되지 않으므로 **전부 제거.**

### 정답/해설 블록 — 발문 앞에 끼어 있다

출처 태그와 발문 사이에 정답·해설 덩어리가 들어 있고 표기가 제각각이다.

```
[정답] ⑤            [해설]              정답 ④
[정답]  ①           [해설]              정답: ②
[정답] ④ decreased를 increased와 같은 단어로 바꿔야 한다.      정답:⑤
< 26-1 중간 명일여고3 동형 1회 정답 >
```

리터럴 화이트리스트로 잡지 말 것. 특히 세 개의 함정:

1. **해설 뒤에 선지의 한글 번역이 ①~⑤ 로 붙어 있다.**
   `① 문학이 창의적 능력을 억압하는 방법` … 선지 마커만 보고 남기면 한글 선지가
   그대로 인쇄된다.
2. **정답 줄이 선지 마커로 시작하기도 한다.**
   `④ (C)-(A)-(B)로 이어지는 것이 자연스럽다.`
3. **답안지 제목이 발문 꼬리에 붙어 있다.** 1회 첫 발문:
   `주어진 글 다음에 이어질 글의 순서로 가장 적절한 것은?< 26-1 중간 명일여고3 동형 1회 정답 >`

### 서술형 판정 — 마커가 없어 어미로만 갈린다

원고는 서술형을 표시하지 않는다. 발문 어미로만 구분된다.

- 서술형: `쓰시오` `서술하시오` `영작하시오` `배열하시오` `완성하시오`
- 객관식: `것은?` `곳은?` **`고르시오.`**

두 겹의 함정:

- 객관식에도 `~시오` 어미가 있다 — `글의 흐름으로 보아, 주어진 문장이 들어가기에 가장
  적절한 곳을 **고르시오.**`
- 서술형 어미 **뒤에 괄호가 붙는다** — `… 쓰시오. **(주어진 첫 철자로 완성)**`,
  `… 그대로 쓰시오. **(각 한 단어)**`. 문장 끝 리터럴 정규식으로는 놓친다.

즉 `고르시오` = 객관식, 그 밖의 `~시오` = 서술형으로 **구조 판정**해야 한다.

### 정규화 목록

| 원고 | 조판 |
|---|---|
| **`U+F003B`** (사설 영역, HWP 기호 글꼴) | 요약 화살표 `↓`(선택형) / `⬇`(서답형). **이 문자를 지우면 요약 화살표가 통째로 사라진다.** 1회 2개·2회 3개 |
| `( ① )` | `(①)` |
| `<보기> the point / nothing / …` (라벨이 내용과 같은 줄) | 라벨을 떼어 캡션 `<보 기>` 로 테두리에 올리고 내용만 상자에 가운데 정렬 |

## 13. 현행 산출물과 정본의 차이

### 치명

1. **1회 머리표가 명일2(고2) 것이다.**
   `2` 학년 / `영어 Ⅱ` / 과목코드 `12` / `1번 ~ 24번 (24문항)` / `1번 ~ 7번 (7문항)` /
   `11쪽`, 푸터도 `( 2 )학년 ( 영어Ⅱ )과`. → `3` / `영어 독해와 작문` / `66` /
   `1번 ~ 25번 (25문항)` / `1번 ~ 6번 (6문항)` 이어야 한다.
   2회는 학년·과목·코드는 맞지만 서답형 칸이 `1번 ~ 5번 (5문항)` 으로 원고(6)와도
   자기 본문(서답형 9개)과도 어긋난다.

2. **문항이 빠졌다 / 번호가 깨졌다.**
   원고 1회 = 객관식 25 + 서술형 6 = 31문항. 1회 산출물 = 객관식 24 + 서답형 3 =
   **27문항** (4문항 증발).
   2회 산출물은 문항 번호가 `1..18` 뒤에 **다시 `1,2,3`** 으로 리셋되고 서답형 라벨이
   `<서답형 1번>`~**`<서답형 9번>`** 까지 9개 생겼다(원고는 6). 서술형/객관식 분류와
   번호 매기기가 둘 다 깨져 있다.

3. **배점이 하나도 없다.** 1·2회 전체에서 `[N점]` 표기 **0건.**
   정본은 선택형 25 + 서답형 6 전부에 배점이 붙고 합이 정확히 80.0 / 20.0 이다.

4. **빈 쪽이 나간다.** 1회 11쪽 중 9·10쪽이 테두리·푸터만 있는 백지, 11쪽에 `- 끝 -`
   만. 머리표의 `11쪽` 도 이 백지를 세고 있다.

### 표기·배치

5. 묶음 표기 0건 (엔진에 묶음 경로 자체가 없어 보인다).
6. 1회에 첫머리 안내문 `※ 문제를 정확하게 읽고 …` 가 없다(2회에는 있다).
7. **본문 영문이 고정폭이다.** 산출물은 BatangChe(바탕체)로 모든 라틴 글자의 진행폭이

   가장 눈에 띄는 품질 차이.
8. 순서 문항 선지가 **3열**. 정본은 **2열 3행**.
9. 순서의 주어진 글 / 삽입의 주어진 문장에 **테두리 상자가 없다.** 정본은 둘 다 상자.
10. 삽입 자리 표시 `( ① )`. 정본 `(①)`.
11. `<보기>` 상자가 **24-1 형식**이다 — 라벨이 상자 **안** 왼쪽 위에 내용과 같은 줄로
    붙어 있다. 직전 회차(25-1)는 캡션 `<보 기>` 를 테두리선에 얹고 내용만 가운데 정렬.
12. `<조건>` 도 같은 문제 + 조건 항목에 `−` 대시가 없다. 게다가 조건 항목 한 줄이 상자
    **바깥**으로 밀려나간 쪽이 있다 (1회 8쪽 `주어진 어구를 제외하고 12단어로 영작할 것`).
13. 서답형 발문을 테두리 상자에 넣은 쪽이 있다(1회 8쪽). 정본은 상자에 넣지 않고
    `<서답형 N번> ` 라벨 뒤 평문. 그 쪽에는 라벨 자체도 빠져 있다.
14. 1회 8쪽 왼쪽 단 맨 아래에 내용 없는 답란 가로줄이 홀로 남아 있다(레이아웃 잔여물).
15. 발문과 지문 사이에 빈 줄이 하나 들어간다. 정본은 발문 다음 줄에서 곧바로 지문이
    시작되고 지문 첫 줄만 한 글자 들여쓴다.
16. 행간이 정본보다 약간 빽빽하다(현행 12pt/17pt = 142%, 정본 근사 152%). 오차 범위와
    겹치므로 위 항목을 다 고친 뒤 육안으로 다시 볼 것.

## 14. 자료가 없어 못 정한 것

**가장 먼저 필요한 것: 26-1-기말(최소한 26-1-중간) 명일여고 고3 기출.**
정본으로 쓴 25-1-중간은 조판 시점(26-2-중간) 기준 1년 이상 지난 회차다.

아래 넷은 명일2 최신 회차에서 **이미 다른 모습이 관측된다.** 학년 차이인지 2026년
학교 전체 개편인지 확정 못 했다. 26-1 명일3 기출이 오면 이 순서로 다시 볼 것.

| 항목 | 명일3 25-1-중간 (채택) | 명일2 26-1-중간·기말 (학년 다름 — 추정) |
|---|---|---|
| 묶음 표기 | `[1-2]` `[3, 서1]` `[서5-서6]`, `다음 글을 읽고 물음에 답하시오.` | `[2~3, 서답형 1]`, `다음 글을 읽고, 물음에 답하시오.` |
| 서답형 라벨 | `<서답형 1번>` | `[서답형 5]` |
| 조건 항목 | `−` 대시 | `1.` `2.` `3.` 번호 |
| 부분배점 | `[3점, 각 1점]` (총→각) | `[각 0.5점, 총 3점]` (각→총) |

그 밖에 못 정한 것:

- **`<보 기>` 상자 형태** — 24-1(라벨 상자 안) → 25-1(캡션 테두리 걸침)로 **이미 한 번
  바뀌었다.** 26-1 에서 또 바뀌었을 수 있다.
- **(A)(B) 짝 구분자** — 24-1 `……` → 25-1 `…`/`‥` 로 흔들리고, 한 시험지 안에서도
  유형별로 다르다.
- **지면 mm 실측** — 정본이 휴대폰 사진(원근·기울기)이라 종이 폭을 확정하지 못했고
  B4 환산 계수를 못 냈다. §2 의 mm 는 현행 산출물 실측치이고 정본과는 비율(±3%)로만
  대조했다. **평판 스캔본이나 학교 원본 PDF가 있으면 여백·단 폭·본문 pt 를 다시 재야
  한다.**
- **본문 크기·행간 pt** — 근사 11.5pt / 17.5pt (±10%).
- **테두리·괘선 선 두께 pt** — 사진에서 절대 두께 측정 불가. 현행 산출물 값
  (테두리 1.0pt / 단 괘선 0.5pt)을 잠정 채택.
- **배점 자동 배정 알고리즘** — 총합 80.0/20.0 은 확정이지만, 문항 수가 25가 아닐 때
  어떤 값 집합을 쓰는지는 표본 둘(22·25문항)로는 규칙을 못 뽑았다. 24-1은 값이 거의 다
  다르고(3.1~4.2), 25-1은 5종을 5개씩 균등 배분했다.
- **묶음 안 문항이 서로 다른 배점을 갖는 경우의 표기** — 25-1 은 `[각 N점]` 만 관측.
- **회차마다 배점표가 함께 배포되는지** — 24-1-중간 폴더에만 학교 내부 배점표가 들어
  있다. 26-1 배점을 이런 식으로 확보할 수 있는지 확인 필요.
