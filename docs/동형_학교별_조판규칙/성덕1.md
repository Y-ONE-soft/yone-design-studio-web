## ⚠ 먼저 읽을 것 — 이 학교는 정본 사정이 가장 나쁘다

세 겹으로 나쁘다.

1. **기출DB에 성덕고 고1 기출이 한 장도 없다.** `학교기출DB/성덕고 기출모음/` 에는
   고2 것만 있다.
2. 그래서 사용자 지시로 Google Drive `내 드라이브/콘텐츠 관리/내신대비/인디자인
   파일/동형모의고사/성덕고/성덕고1(24-1-중간).pdf` 를 임시 정본으로 썼다.
   **이 파일이 실제 학교 기출인지 우리 동형 산출물인지 먼저 판별했고, 실제 기출이
   맞다** (근거는 아래 1절).
3. 다만 회차가 **24-1-중간** 이다. 조판 시점(26-2-중간)의 직전 회차는 26-1-기말이므로
   **2년 · 4회차가 비어 있다.** 게다가 파일이 스캔도 아닌 **휴대폰 촬영본**(쪽당
   1080×1440px)이라 **mm·pt 실측이 불가능**하다.

그래서 이 문서의 규칙은 두 종류로 갈린다.

| | 신뢰도 | 대상 |
|---|---|---|
| **문자열·구조·표기** | 높음 | 배점 괄호, 묶음 템플릿, 서술형 라벨, 조건 표 구조, 마무리, 계속 표시, 안내문 문구, 선지 배열 |
| **치수** | 낮음 | 단 폭·단 간격·여백·서체 크기·괘선 두께 — 전부 **비율 역산 근사치**(±3mm, ±0.5pt) |

값마다 JSON 쪽에 `conf`(high/mid/low)와 `src` 를 달아 두었다. 이 학교에서는
**확정값보다 "무엇을 모르는지"가 더 중요하다** — 마지막 두 절을 반드시 읽을 것.

## 2. 지면 골격

- 2단. **단 괘선은 단 간격의 정중앙**에 세로로 한 줄.
  (근거: 정본 p2 간격 491–533px 안에서 세로 잉크 최대 x=509, p4 간격 507–558px 안에서 x=528)
- **쪽 전체를 감싸는 테두리 상자 없음.**
- 가로 괘선은 **머리 아래 한 줄뿐**. 본문 아래(푸터 위)에는 없다.
- 1쪽 안내문 3줄 아래에 **굵은 가로 괘선** — 좌측 단 폭만 차지한다.
  (정본 사진에서 8~9px, 같은 사진의 머리 괘선은 1px → 대략 4~5pt 상당)

### 치수 (전부 근사치 — 원 자료가 사진이다)

정본 5개 쪽(2·3·4·6·7)에서 본문 잉크의 좌우 끝을 잡아 낸 비율:

| 관측 | px |
|---|---|
| p2 | col1 45–491 / col2 533–967 |
| p3 | col1 57–489 / col2 525–989 |
| p4 | col1 52–507 / col2 558–1007 |
| p6 | col1 50–502 / col2 534–981 |
| p7 | col1 46–527 / col2 541–1006 |

→ 단 폭 / 텍스트 전폭 ≈ **0.481**, 단 간격 / 텍스트 전폭 ≈ **0.037**

텍스트 폭을 현행 산출물과 같은 217.7mm 로 두면:

| | 정본 비율 환산 | 현행 산출물 |
|---|---|---|
| 텍스트 좌/우 | 20.0 / 237.7mm | 20.0 / 237.7mm |
| 단 폭 | **≈ 104.7mm** | 102.5mm |
| 단 간격 | **≈ 8.3mm** | 13.5mm |
| 단 괘선 | 간격 정중앙 | x 128.4mm, 0.75pt |

> 오차 ±3mm 는 각오할 것. 사진 원근 때문이다. 다만 **현행이 단 간격을 3~5mm 더
> 벌리고 단을 그만큼 좁혔다**는 방향성은 다섯 쪽에서 일관되게 나온다.

### 본문 밀도는 현행이 맞다

| | |
|---|---|
| 정본 본문 행 피치 | 24.0~25.25px (p4·p6), 단 폭 ≈452px → **행간/단폭 = 0.0544** |
| 현행 | 행간 15.5pt(5.47mm) / 단 폭 102.5mm → **0.0534** |

2% 차. **현행의 본문 10.0pt / 행간 15.5pt 는 정본에 부합한다.** 단 폭을 104.7mm 로
넓힌다면 행간은 16.1pt 쪽이 비율상 맞는다.

### 머리

**1쪽**

```
       2024학년도 1학기 중간고사 문제지 (  2024년   4월   26일   1교시 )
제 1 학년            영어 [과목코드 : 03]                            1/8
──────────────────────────────────────────────────────────────────────
```

- 1행 가운데 정렬, 굵은 고딕. 괄호 안쪽 좌우에 공백, 날짜 항목 사이가 넓게 벌어짐
  (빈칸 채우기 서식의 흔적).
- `제 1 학년` — 학년 숫자만 크다.
- `영어 [과목코드 : 03]` — 지면 최대 크기, 굵은 고딕. 콜론 좌우에 공백.
- `1/8` — 이탤릭, 괘선 위 오른쪽 끝.

**2쪽 이후**

```
1학년                영어[과목코드 : 03]                              3/8
──────────────────────────────────────────────────────────────────────
```

- 좌측이 `제 N 학년` → `N학년`(이탤릭)으로 짧아진다.
- 1쪽은 `영어 [` 로 띄고 2쪽 이후는 `영어[` 로 붙어 보이지만 **사진 해상도 한계라
  확정 못 함**.

### 문항수 표 (1쪽 좌상단)

3행 표. 좌측 라벨열은 1·2행이 각각 `선 택 형` / `서 술 형`(글자 사이 공백),
3행은 좌측 셀이 비고 우측 두 칸이 병합된다.

| 선 택 형 | 26  문항 | 70  점 |
|---|---|---|
| **서 술 형** | 6  문항 | 30  점 |
| | **서술형 답지에 작성** ||

> 좌측 라벨열의 회색 음영 여부는 **판정 못 했다**. 사진의 좌→우 광량 기울기와
> 구분이 안 된다(라벨 셀 176 vs 이웃 셀 190). 육안으로는 흰색.
> **현행 산출물은 10% 회색(RGB 0.90)을 깔고 있다.**

우측에는 같은 높이로 **빈 사각 상자**(점수 기입란). 정본에는 채점자가 `73.2` 를
빨간 펜으로 적어 놓았다 — 인쇄물은 빈 상자다.

### 첫머리 안내문 (1쪽, 볼드, 양끝정렬)

```
◦먼저 문제지의 학년과 과목, 문항수를 확인하시오.
◦OMR카드에는 반드시 컴퓨터용 수성 사인펜을 사용하시오.
◦서술형 문항은 반드시 서술형 답안지에 흑색이나 청색펜을 사용하여 서술하시오. (연필 사용 금지)
```

- 불릿은 **`◦` 작은 속 빈 원**(검은 `•` 아님). 불릿과 글자 사이 **공백 없음**.
- 3번째 줄은 두 줄로 흐르고, 이어지는 줄(`용하여 서술하시오. (연필 사용 금지)`)은
  **불릿 폭만큼 들여쓴다**.
- 성덕2 26-1-중간과 문구가 **완전히 같다** → 안정적.

바로 아래에 **굵은 가로 괘선**(좌측 단 폭).

### 서술형 구분 표제 — 성덕 고유

선택형이 끝나고 서술형이 시작되는 자리(정본 p7 좌측 단 중간)에:

```
                        < 서 술 형 >
※ 반드시 서술형 답지에 기록하세요.
```

- `< 서 술 형 >` : 큰 볼드 명조, 가운데 정렬, 본문의 1.8~2.0배.
  반각 부등호 `<` `>`, **글자 사이가 벌어져 있다**.
- 그 아래 줄 `※ 반드시 서술형 답지에 기록하세요.` 좌측 정렬.
- 성덕2 26-1-중간에도 동일.

### 계속 표시

```
☞ 뒷면에 선택형, 서술형 문항 계속      ← 홀수 쪽(용지 앞면)
☞ 다음 장에 선택형 문항 계속           ← 짝수 쪽(용지 뒷면)
```

- 글리프 `☞` (U+261E), 본문보다 **작게**.
- 각 쪽 **우측 단 맨 아래, 오른쪽 정렬**. 마지막 쪽에는 없다.
- **`{유형}` 부분만 볼드 + 밑줄.**
- `{유형}` 은 **다음 쪽에 실제로 나오는 종류**를 적는다.

정본 8쪽 전수:

| 쪽 | 문구 |
|---|---|
| 1 | ☞ 뒷면에 **선택형, 서술형 문항** 계속 |
| 2 | ☞ 다음 장에 **선택형 문항** 계속 |
| 3 | ☞ 뒷면에 **선택형 문항** 계속 |
| 4 | ☞ 다음 장에 **선택형 문항** 계속 |
| 5 | ☞ 뒷면에 **선택형 문항** 계속 |
| 6 | ☞ 다음 장에 **선택형, 서술형 문항** 계속 |
| 7 | ☞ 뒷면에 **서술형 문항** 계속 |
| 8 | (없음) |

> ⚠ **성덕2 26-1-중간에서는 `☞ 다음 쪽에 {유형} 계속` 하나로 통일돼 있다**
> (앞면/뒷면 구분 없음). 2년 사이 학교 서식이 바뀌었을 가능성이 높다.
> 성덕1 최신 기출이 없으므로 **정본(24-1) 기준을 유지**하되 잠정값으로 본다.
> 현행 산출물도 `뒷면에`/`다음 장에` 를 쓰고 있어 지금은 정본과 일치한다.

## 4. 단락 역할별 수치

정본이 저해상도 사진이라 **pt 실측이 불가능**하다. 확인한 것은 **상대 관계**뿐이다.

| 역할 | 확인한 것 |
|---|---|
| 발문 | 지문·선지와 **같은 크기**. 볼드 아님. 양끝정렬. **번호 폭만큼 내어쓰기(hanging)** |
| 문항번호 | **볼드**, 본문보다 조금 큼 |
| 지문 | 첫 줄 **들여쓰기 있음**(한 글자 정도). 양끝정렬 |
| 선지 | 지문과 같은 크기. **마커 폭만큼 내어쓰기(hanging)** |
| 조건(표 안) | 본문보다 조금 작아 보임(약 90%) |
| 묶음 라벨 | **볼드**, 이어지는 지시문은 일반. **내어쓰기 없음** |
| 서술형 라벨 | **볼드** |
| 안내문 | **볼드**, 양끝정렬 |
| 저작권 | 지면 최소, 돋움 계열 |
| 머리 과목명 | 지면 최대, 굵은 고딕 |
| 학년·쪽번호 | 이탤릭 |
| `< 서 술 형 >` | 굵은 명조, 본문의 1.8~2.0배, 자간 넓게 |

**내어쓰기 규칙이 두 갈래로 갈린다 — 여기가 성덕의 미세한 특징이다.**

```
8. (A), (B), (C)의 각 네모 안에서 어법에 맞는 표현으로 가장 적     ← 번호 발문: hanging
   절한 것은? [2.7점]                                              (‘절한’이 ‘(A)’와 같은 x)

[23~24] 다음 글의 밑줄 친 부분 중, 문맥상 낱말의 쓰임이 적          ← 묶음 머리: flush
절하지 않은 것을 고르시오.                                          (둘째 줄이 단 왼쪽에 붙음)

⑤ stay in the sidelines, preparing to play on the                ← 선지: hanging
   field
```

## 5. 문제 유형별 차이 — **들여쓰기·간격은 균일하다**

정본 전 8쪽에서 유형별로 들여쓰기·행간·여백이 달라지는 지점은 **발견되지 않았다.**
지문 첫 줄 들여쓰기, 선지 내어쓰기, 행간 모두 전 유형 동일. (확인한 것도 결과다.)

유형마다 달라지는 것은 두 가지뿐이다.

**(1) 선지 배열**

| 유형 | 배열 |
|---|---|
| 주제·제목·요지·빈칸·내용일치·목적 | `one_per_line` |
| 순서 | **`grid2`** — `① (A) - (C) - (B)` / `② (B) - (A) - (C)` 좌우 2열, ⑤는 왼쪽에 홀로 |
| 문장삽입·어법기호·낱말쓰임 (기호 하나만 고르는 유형) | **`inline`** — `① ⓐ  ② ⓑ  ③ ⓒ  ④ ⓓ  ⑤ ⓔ` 한 줄에 다섯 개 |
| 복수 기호 조합 (정본 18번) | **`grid3`** — `① ⓐ, ⓕ, ⓖ  ② ⓑ, ⓒ, ⓓ  ③ ⓐ, ⓒ, ⓕ` / `④ … ⑤ …` |
| (A)(B)(C) 짝 맞추기 | 열 표 (6절 참조) |

순서형 값 구분자는 **하이픈 앞뒤 공백** `(A) - (C) - (B)`. en dash 아님.

**(2) 지문에 테두리 상자를 두르는지** (6절)

## 6. 보기 / 조건 / 요약 / 주어진문장 — **학교 색깔이 가장 진한 곳**

### 6-1. 조건 = 2열 표 (성덕의 가장 큰 특징)

`<조건>` 이라는 **라벨 줄을 쓰지 않는다.** 표로 앉힌다.

```
┌────────┬───────────────────────────────────────┐
│░░░░░░░░│ · 틀린 문장의 기호(A~G)를 쓰고, 수정 부분을 포함한 │
│░░ 조건 ░│   밑줄 부분 전체를 쓸 것                        │
│░░░░░░░░├───────────────────────────────────────┤
│░░░░░░░░│ · 내용 없이 문장 기호만 쓰는 경우: 부분 점수 없음   │
└────────┴───────────────────────────────────────┘
```

- 좌측 셀: `조건` 한 단어, **전체 행 세로 병합**, 세로·가로 가운데. 표 폭의 15~18%.
- 우측 셀: **조건 항목 1개당 1행**, 행 사이에 가는 가로 구분선.
- 항목 마커 **`·` (가운뎃점) + 공백 한 칸**. 번호(1. 2.)가 아니다.
- 조건 문장 안 핵심어에 **볼드 + 밑줄** (`그대로`, `밑줄 부분 전체`, `문장 전체`).
- 항목 끝 마침표는 문항마다 있기도 없기도 하다 — **원고 그대로**.

> **좌측 라벨 셀 음영이 정본 안에서도 흔들린다.** 서술형1(p2)·5·6(p8)은 회색,
> 서술형2·3·4(p7)는 흰색이다. 성덕2 26-1-중간은 관측 5개가 **전부 회색**.
> → 회색으로 통일하는 것이 최신 관행에 가깝다고 보되, 학교 원본이 흔들린다는 사실을
> 기억할 것.

정본 조건 항목 실측 표본:

```
· 지문에서 찾아서 그대로 쓸 것              · 7단어 이내로 쓸 것
· 주어진 글에서 찾아 그대로 쓸 것.          · (A)는 7단어, (B)는 6단어로만 쓸 것.
· 주어진 글이 아닌 경우, 점수 부여하지 않음.  · 필요한 경우 단어를 변형할 것
· 주어진 단어 누락의 경우는 점수 부여하지 않음
· 본문의 단어만 사용하되, 필요하면 단어를 변형할 것
· (A)는 9단어, (B)는 13단어로 쓸 것
· 안내문의 내용과 일치하게 <Tom's diary>의 내용을 수정할 것
```

### 6-2. 보기/단어 — ⚠ 정본에 근거가 없다

**성덕1 정본(24-1-중간)에는 `<보기>`/`<단어>` 상자가 한 번도 나오지 않는다.**
주어진 단어를 상자 없이 **답란 바로 아랫줄에 괄호로** 줬다:

```
(A) ______________________________
    (use, from, bottle caps, make)

(B) ______________________________
    (design, in, that, an eco-friendly way, be)
```

반면 **성덕2 26-1-중간**에는 테두리 상자가 있고, 캡션 `<단어>` 가 **상자 안 첫 줄
가운데**에 작게 들어간다:

```
┌────────────────────────────────────────┐
│                  <단어>                  │
│  must / more / hard / the / area          │
│  / work / have / surface / you            │
└────────────────────────────────────────┘
```

그리고 **성덕1 동형 원고**에는 `<보기>` · `<단어>` 라벨이 둘 다 있다.
→ **어느 형태로 앉힐지 정본 근거가 없다.** 사용자 확인 필요.

### 6-3. 요약

```
                    ↓                      ← 굵고 속이 찬 아래 화살표, 가운데, 별행
┌────────────────────────────────────────┐
│ Though describing animal characters in a  │
│ more natural way is a trend, it is still  │
│ general to ____(A)____ them with          │  ← 밑줄 가운데에 (A) 라벨이 얹힘
│ childlike features to make them more      │
│ ____(B)____ .                             │
└────────────────────────────────────────┘
         (A)                    (B)
   ①    defy       …       assertive
   ②    defer      …       artificial
```

- `<요약문>` 같은 **라벨을 인쇄하지 않는다.**
- 요약문은 **테두리 상자**, 폭 = 단 폭.
- 빈칸은 `______(A)______` — 밑줄이 라벨 좌우로 이어진다.
- 화살표: 굵고 짧으며 화살촉이 넓은 **속이 찬** `↓`. 명조 볼드 U+2193 로 보이나
  `⬇`(U+2B07) 가능성 배제 못 함.

### 6-4. (A)(B)(C) 짝 선지 = 열 표

```
        (A)                (B)               (C)
 ①   producing   ……      to seek   ……       is
 ②   producing   ……      seeking   ……      are
 ⑤   produced    ……      to seek   ……       is
```

- 머리행 `(A)` `(B)` `(C)` **가운데 정렬**, 각 열 값도 **가운데 정렬**.
- 구분자는 **점 리더**. 배재의 `-----`(하이픈 다섯) 가 아니다.
  2열 표(요약)에서는 점 3개 폭 `…`, 3열 표(어법)에서는 점 6개 폭 `……` 로 관측
  → 실체는 `…`(U+2026) 1개 / 2개일 가능성이 높다. 코드포인트 확정 불가.

### 6-5. 주어진 글 / 주어진 문장 = 테두리 상자

순서·문장삽입 모두 상자. 볼드 아님. 지문 안 삽입 자리는 **`( ① )`** — 괄호 안
좌우에 공백 한 칸씩. 원문자를 소문자로 쓰는 문항에서는 `( ⓐ )`.

### 6-6. 어법 (A)(B)(C) 네모

지문 안 선택지를 **얇은 네모 상자**로 감싼다. 발문도 이것을 '네모'라 부른다
(`(A), (B), (C)의 각 네모 안에서 …`).

```
… at jobs they hate, (A) producing / produced  things they have no love for.
                        └────────────────┘
```

### 6-7. 어느 지문이 상자에 들어가는가 — 성덕은 상자를 자주 쓴다

**항상 상자**
- **서술형 문항의 지문 전부** (정본 서술형 1~6 모두)
- 순서·문장삽입의 주어진 글/문장
- 요약문
- 안내문(공지문) 지문
- 제목이 붙은 지문 (예: `Architecture Reborn`)
- 편지글 (`To whom it may concern,` … `Yours sincerely,`)
- 서술형1의 영어 질문 줄

**상자 없음** — 그 밖의 일반 선택형 지문은 맨 문단.

부속 규칙:
- 상자 안 제목은 **볼드 가운데 정렬** 첫 줄. 대괄호를 두르기도 한다
  (`[Punt Returners in American Football]`, `[Coxwains in Rowing]`, `<Tom's diary>`).
- 각주는 상자 안 마지막 줄 **오른쪽 정렬**로 `*coxwain 키잡이` (별표 + 영단어 + 공백 + 우리말).
- 안내문 상자 안 소제목(`Articles`, `Rewards`, `Notes`)은 볼드 좌측 정렬,
  항목은 `•` 불릿.

## 7. 문항 묶음 표기

```
[9~10] 다음 글에서 전체 흐름과 관계 없는 문장을 고르시오.
[4, 서술형1] 다음 글을 읽고, 질문에 답하시오.
```

| 항목 | 값 |
|---|---|
| 괄호 | **`[` `]` 대괄호**, 안쪽 공백 **없음** |
| 범위 구분자 | **`~`**, 좌우 공백 없음 (전각/반각 구분 불가) |
| 혼합(선택형+서술형) | `[{n}, 서술형{m}]` — 쉼표 뒤에만 공백, **`서술형` 과 숫자는 붙는다** |
| 서체 | 라벨(`[…]`)만 **볼드**, 이어지는 지시문은 일반 |
| 지시문 | **같은 줄** |
| 지시문 둘째 줄 | **내어쓰기 없음** (단 왼쪽에 붙음) |

> **주의: `[4, 서술형1]`(공백 없음) vs `[서술형 1]`(공백 있음).**
> 같은 시험지 안에서 묶음 머리와 문항 라벨의 표기가 다르다. **실물 그대로** 재현한다.

정본 묶음 전수: `[4, 서술형1]` `[9~10]` `[12~15]` `[16~17]` `[19~20]` `[21~22]` `[23~24]`

### 묶음은 두 종류이고 멤버 표기가 다르다 — 성덕 묶음의 핵심

**A. 공통 발문형** — 발문 전체가 묶음 머리에 온다. 멤버는 **번호+배점만**.

```
[9~10] 다음 글에서 전체 흐름과 관계 없는 문장을 고르시오.
9. [2.7점]
   (지문)
   ① ⓐ  ② ⓑ  ③ ⓒ  ④ ⓓ  ⑤ ⓔ
10. [2.7점]
```

**B. 공통 지문형** — 지문이 하나, 문항이 여럿. 멤버가 **발문 전체**를 갖고
지문을 `윗글의 …` 로 가리킨다.

```
[21~22] 다음 글을 읽고, 물음에 답하시오.
   (지문)
21. 윗글의 흐름으로 보아, 주어진 문장이 들어가기에 가장 적절한 곳은? [2.3점]
22. 윗글의 제목으로 가장 적절한 것은? [2.3점]
```

지시문에 **쉼표가 들어간다**: `다음 글을 읽고, 물음에 답하시오.`
(원고는 쉼표 없이 준다 → 넣어야 한다.)

## 8. 서술형 라벨

```
[서술형 1] 위 글을 읽고, 아래 질문에 대한 답을 본문에서 찾아
           조건에 맞추어 영어로 쓰시오. [4점, 부분점수 있음]
```

| 항목 | 값 |
|---|---|
| 템플릿 | `[서술형 {n}]` — **`서술형` 과 숫자 사이 공백 한 칸** |
| 서체 | **볼드** |
| 번호 | 선택형과 **별도 카운터** (선택형 1~26, 서술형 1~6) |
| 위치 | 발문 맨 앞, 곧바로 발문이 이어짐(inline) |
| 둘째 줄 | ⚠ 정본 24-1(고1)은 **라벨 폭만큼 들여쓰기**, 성덕2 26-1(고2)은 **왼쪽에 붙음**. 정본 기준(들여쓰기)을 택했으나 근거가 한 회차뿐 |

**`서답형` 이라는 말은 성덕이 쓰지 않는다.** 성덕은 `서술형` 이다.
(문항수 표도 `서 술 형`, 구분 표제도 `< 서 술 형 >`, 안내문도 `서술형 문항은…`.)

## 9. 배점 표기

```
1. 다음 글의 내용과 일치하는 것은? [2.3점]
[서술형 4] 다음 글을 읽고, 정리한 아래 MEMO의 우리말을 조건에 맞추어 영작하시오. [6점, 부분점수 있음]
```

| 항목 | 값 |
|---|---|
| 괄호 | **`[` `]` 일반 대괄호** (배재의 `〔〕` 아님). 성덕2 26-1도 동일 |
| 붙는 자리 | **발문 끝**, 앞에 **공백 한 칸** |
| 줄 넘침 | 줄 끝에 안 들어가면 다음 줄로 밀린다(별행 우측처럼 보이지만 규칙은 '발문 끝 이어쓰기') |
| 소수 | 선택형 **1자리**, 서술형은 정수(`4점`, `6점`) |
| 서술형 꼬리말 | **`부분점수 있음`** — 배재의 `없음` 과 **반대**. 정본 6문항 전부 `있음` |
| 소문항 부분배점 | 인쇄하지 않음 |
| 머리표 총점 칸 | 있음 (문항수 표) |

### 정본 배점 분포

| 값 | 문항 | 계 |
|---|---|---|
| 2.3 | 1, 2, 3, 4, 6, 21, 22 (7문항) | 16.1 |
| 2.7 | 5, 8, 9, 10, 12, 13, 16, 17, 19, 26 (10문항) | 27.0 |
| 2.9 | 7, 14, 15, 23, 24 (5문항) | 14.5 |
| 3.1 | 11, 18, 20, 25 (4문항) | 12.4 |
| **선택형 합** | **26문항** | **70.0** |
| 서술형 4점 | 서술형 1, 2, 3 | 12 |
| 서술형 6점 | 서술형 4, 5, 6 | 18 |
| **서술형 합** | **6문항** | **30.0** |

> ⚠ **배정 규칙은 확정 못 했다.** 값의 집합(2.3/2.7/2.9/3.1)과 총합(70.0)은 확실하나,

> 쓴다** — 22문항으로 70.0 을 맞추는 배정표가 따로 필요하다. 서술형도 5문항으로 30점.

## 10. 마무리

```
                       -끝-
┌──────────────────────────────────────────┐
│ ※ 확인사항                                  │
│ ◦ 답안지의 해당란에 필요한 내용을 정확히 표기했는지 확인하 │
│ 시오.                                       │
└──────────────────────────────────────────┘
```

- **`-끝-`** — 하이픈·끝·하이픈 사이에 **공백이 없다**. 배재의 `- 끝 -` 와 다르다.
- 마지막 문항이 있는 **단 안에서** 가운데 (지면 전체 가운데가 아니다).
- 본문보다 작아 보인다(약 85%).
- 그 아래에 **`※ 확인사항` 테두리 상자**. `◦` 뒤에 **공백이 있다**(머리 안내문은 없다).
  두 번째 줄이 넘칠 때 이어지는 줄(`시오.`)은 들여쓰지 않고 상자 왼쪽에 붙는다.

24-1-중간(고1)과 26-1-중간(고2) 둘 다 `-끝-` → **2년 간격으로 같으므로 안정적.**
회차별 변형은 관측되지 않았다(회차가 하나뿐이라 관측할 수도 없었다).

## 12. 원고 규칙

원고: `조판/교재/동형모의고사/원고/성덕1 동형 {1,2}회 원고.hwpx`

### 머리 메타 — **성덕은 4줄** (`총계:` 가 하나 더 있다)

```
성덕고1 동형 1회
선택형: 22문항
서술형: 5문항
총계: 27문항
```

두 회차 모두 22 / 5 / 27. **이 4줄은 산출물에 인쇄되면 안 된다.**

### ⚠ 문항 수가 기출과 다르다

| | 선택형 | 서술형 |
|---|---|---|
| 동형 원고 | 22 | 5 |
| 성덕1 기출 24-1-중간 | 26 | 6 |
| 성덕2 기출 26-1-중간 | 26 | 6 |

1쪽 문항수 표와 배점(70/30)을 **원고 기준(22/5)** 으로 찍을지 **학교 기출
기준(26/6)** 으로 찍을지 정해야 한다. 현행 산출물은 **회차마다 다르게** 찍혀 있다
(1회 22/5, 2회 26/6).

### 원고가 주지 않는 것 (전부 조판이 만든다)

- 문항 번호 (`1.` 같은 번호 줄이 원고 어디에도 없다)
- 서술형 라벨 (`서술형`/`서답형` 이라는 말이 **한 번도 없다**)
- 묶음 머리 `[a~b]` / `[n, 서술형m]`
- 배점
- `< 서 술 형 >` 표제, `※ 반드시 서술형 답지에 기록하세요.`
- 계속 표시, 마무리 `-끝-`, `※ 확인사항` 상자

### ☠ 정답이 **미주(endNote)** 로 달려 있다 — 누출 위험 1순위

정답이 본문이 아니라 `<hp:endNote>` 안에 있다. 회차당 **27개**(선택형 22 + 서술형 5).
미주를 본문으로 평탄화하면 발문 끝에 정답이 붙어 인쇄된다.

```
선택형:  " ➁"   " ⑤"   " ➂, ➃"
서술형:  " (A) Despite feeling exhausted, she continued working on her project. …"
         " (1) ⓐ Providing → to provide, (2) ⓑ go → are gone"
         " (A) morality 또는 fairness, (B) conservation, (C) self-construct, (D) learning"
```

**조치**: hwpx 파싱에서 `<hp:endNote>…</hp:endNote>` 서브트리를 **먼저 통째로 제거**한 뒤
단락 텍스트를 뽑을 것.
※ 함정 — 비탐욕 정규식 `<hp:p>.*?</hp:p>` 로 단락을 잡으면 **미주 안쪽의
`</hp:p>` 에 먼저 걸려 바깥 단락이 잘린다.** 미주 제거를 먼저 해야 한다.

### 출처 태그

`[25년 3월 23번]` 형태로 **발문 줄 맨 끝, 미주 앵커 뒤**에 붙는다. 회차당 14개
(단독 문항에만 붙고 묶음 문항에는 없다). **제거.**

### 묶음 표시

`다음 글을 읽고 물음에 답하시오. `(끝에 공백 하나) 줄 하나로만 표시 — 회차당 5개.
그 뒤에 지문이 오고, 이어지는 문항들이 `윗글의 …` 로 시작한다.
**묶음 범위(`[a~b]`)는 원고가 주지 않으므로 `윗글`/`주어진 글` 로 시작하는 문항을
세어 조판이 만들어야 한다.** 기출 표기는 쉼표가 들어간 `다음 글을 읽고, 물음에
답하시오.` 다.

### 정규화가 필요한 것

| 원고 | → | 비고 |
|---|---|---|
| `➀➁➂➃➄` (U+2780~) | `①②③④⑤` (U+2460~) | **한 원고 안에서 두 계열이 섞인다** — 1회 60:50, 2회 55:55. 앞쪽 묶음 구간이 ➀ 계열, 뒤쪽 단독 구간이 ① 계열 |
| U+F09F (HWP 사설영역) | `•` | 1회 원고 안내문 문항에 5회. 2회 원고는 이미 `•`(U+2022) |
| `–` (en dash, 순서 선지) | `-` (하이픈) | 원고 안에서 섞인다 — 1회 66행 `- ` / 103행 `– `. 기출은 하이픈 |
| `↓` (U+2193) | 유지하되 **볼드·가운데** | |
| `<조건>` 라벨 + 항목 줄들 | **2열 표** (좌 `조건` 셀 + 항목당 1행 + `·`) | |

### 선지가 한 줄에 두 개 붙어 있다

순서 유형 선지가 원고에서 한 줄에 둘씩 오는데, **구분 공백이 없는 줄이 있다**:

```
➀ (A) - (C) - (B)          ➁ (B) - (A) - (C)      ← 공백 있음
① (A) – (C) – (B)② (B) – (A) – (C)               ← 공백 없음
```

파서가 `②③④⑤` 앞에서 잘라야 한다.

### 답란 표기가 제각각

```
→ _____________________________________________________
(A)___________  (B)___________
(1)_________________ → _________________
답: ___________________________________________________________
```

정본 관행(13절 아래)으로 통일해야 하며, 특히 **`답:` 은 성덕 표기가 아니다.**

### 부속물

- 1회: `BinData/image1.png` 1개 — 도표 문항(`다음 도표의 내용과 일치하지 않는 것은?`)
- 2회: 3행 3열 표 1개 — 안내문 문항의 워크숍 프로그램표(`Time / DIY Item / Things to Do`)
- 두 회차 모두 안내문(공지문) 문항 1개씩. 정본에도 안내문 문항이 있다
  (p8 `Call for Articles`) → **상자 + 볼드 소제목 + `•` 불릿**으로 앉힌다.

### 정본 답란 관행 (원고 답란을 이것으로 바꾼다)

| 유형 | 형태 |
|---|---|
| 화살표형 | `→ ________________________________.` |
| 리드인형 | `That's because ______________________.` |
| (A)(B)형 | `(A) ______________________` / `(B) ______________________` (항목 사이 한 줄 비움) |
| 번호콜론형 | `(1) : ______________________.` (src: 성덕2, 학년 다름) |
| 어법수정형 | `(1) 문장 기호: (      )` / (들여쓰기) `수정된 문장:______________________.` |
| 수정만 | `(1) 수정된 문장: ______________________.` |

밑줄 오른쪽 끝에 **마침표**를 찍는다. `수정된 문장:` 은 콜론 바로 뒤부터 밑줄이
시작한다(사이 공백 없음).

## 13. 현행 산출물과 정본의 차이

대조 대상: `조판/교재/동형모의고사/고1/26-1-기말/성덕고/성덕1_동형모의고사(1회).pdf`,
`…(2회)_2.pdf` (2026-06-23, 각 7쪽, B4 257×364mm, 텍스트층 있음)

> 이 산출물은 26-1-기말 원고로 만든 것이라 지금 손에 있는 26-2-중간 원고와 내용이
> 다르다. 아래는 **조판 관행**의 대조다.

### 치명

1. **원고 머리 메타가 본문에 인쇄된다.**
   1·2회 모두 1쪽 좌측 단 첫머리에
   `성덕고1 동형 {N}회 원고` / `선택형: 26문항` / `서답형: 6문항` 3줄이 그대로 찍혀 있다.
   `서답형` 은 성덕이 쓰지 않는 말이고, 숫자도 1회 산출물의 머리표(22/5)와 어긋난다.

2. **배점이 하나도 없다.** 산출물 전체에서 `점]` 패턴 **0건**.
   정본은 선택형 전 문항 `[2.3점]`~`[3.1점]`, 서술형 `[4점, 부분점수 있음]` /
   `[6점, 부분점수 있음]`.

3. **묶음 표기가 하나도 없다.** `[a~b]` 패턴 **0건**,
   `다음 글을 읽고 물음에 답하시오` **0건**. 원고의 묶음 5개가 통째로 사라지고 문항이
   개별 번호로 흩어졌다 — 묶음 안 문항이 `윗글의 …` 로 시작하므로
   **지시 대상이 어긋나 있다.**

4. **서술형 라벨이 두 번 찍힌다.**
   1회: `[서술형 1] 서답형 1. 다음 (A), (B)의 …` — 엔진이 만든 `[서술형 1]` 과
   원고에서 온 `서답형 1.` 이 겹쳤다.
   2회: 반대로 `[서술형 N]` 이 없고 `서답형 N.` 만 남았다. **두 회차가 서로 다르게 나갔다.**

5. **페이지 밖에 유령 텍스트.** 1·2회 모두 6·7쪽 좌상단
   (x ≈ 2.9mm, y ≈ **-0.4mm** — 지면 위쪽 밖)에 `<보 기>` 가 **각 2개씩** 찍혀 있다.
   조판 로그의 `페이스트보드 헤더 발견: 화살표,보기 / 배치: 3개` 가 원인.

6. **본문 위에 계속 표시가 겹쳐 찍힌다.** 1회 1쪽 우측 단 4번 지문 마지막 줄
   (`However, ③small steps in the right`) 위에 `☞ 뒷면에 선택형 문항 계속` 이 포개져 있다.

### 중

7. **계속 표시의 유형이 항상 `선택형 문항` 으로 고정.** 서술형만 남은 6→7쪽에서도
   `선택형 문항 계속` 이라고 쓴다. 정본은 다음 쪽 실제 유형을 적는다.
8. **`조건` 을 표가 아니라 상자로 앉힌다.** 현행은 테두리 상자 안에 `〈조건〉` 캡션 +
   항목 줄 나열. 정본은 **2열 표**(세로 병합된 `조건` 셀 + 항목당 1행 + 행 구분선).
   캡션 문자도 다르다(현행 꺾쇠 `〈 〉` / 정본은 캡션 자체가 없다).
9. **조건 항목에 `·` 마커가 없다.**
10. **답란이 `답: ____`.** 성덕 표기가 아니다.
11. **서술형 지문에 테두리 상자를 안 두른다.** 정본은 서술형 지문 6개가 **전부** 상자.
12. **요약 화살표가 가늘고 왼쪽에 붙는다.** 정본은 굵고 속이 찬 `↓` 를 **가운데** 별행에.
13. **(A)(B) 짝 선지에 구분자가 없다.** 현행은 공백으로만 벌린다. 정본은 점 리더 `…` /
    `……` + **각 열 가운데 정렬**.
14. **`※ 반드시 서술형 답지에 기록하세요.` 가 없다.** 산출물에 0건.

### 경

15. **문항 번호와 발문 사이가 탭으로 크게 벌어지고 발문이 다음 줄로 간다.**
    정본은 `1. 다음 글의 …` 로 공백 한 칸.
16. **단 간격이 넓고 단이 좁다.** 현행 102.5 / 13.5mm ↔ 정본 비율 환산 ≈104.7 / 8.3mm.
    (정본이 사진이라 ±3mm — 확신도 낮음.)
17. **1쪽 문항수 표 좌측 라벨열에 10% 회색이 깔려 있다.** 정본 사진에서는 흰 셀로 보인다
    (판정 확신도 낮음).
18. **안내문 3줄이 PDF 안에 두 겹으로 들어 있다.** 텍스트 추출 시 각 줄이 정확히 2회.
    `제       학년` · `1/7` 도 2회. 완전히 겹쳐 있어 육안으로는 안 보인다.

### 일치하는 것 (건드리지 말 것)

`-끝-`(공백 없음) · `※ 확인사항` 상자와 문구 · 저작권 상자 문구 · 학교 로고 푸터 ·
`{N}학년 {과목}` 우측 푸터 · `☞` 글리프와 `뒷면에`/`다음 장에` 교대 규칙 ·
`◦` 안내문 불릿 · 배점 대괄호 종류 · 머리 구성(시험명 줄 + 학년/과목/쪽번호 + 가로 괘선) ·
**본문 밀도**(행간/단폭 0.053 vs 정본 0.054) · 굵은 안내문 괘선 ·
문장삽입 주어진 문장 상자.

## 현행과 달라 고쳐야 할 것 (우선순위)

1. 원고 머리 메타 3줄 인쇄 제거 — **정답·메타 누출과 같은 급의 사고**
2. 페이지 밖 유령 `<보 기>` 제거, 계속 표시 겹침 해소
3. 배점 부여 (배정표 확정 필요 — 아래 참조)
4. 묶음 표기 복원 (`[a~b]`, `[n, 서술형m]`, 지시문 쉼표, 멤버 표기 A/B 구분)
5. 서술형 라벨 중복 제거 → `[서술형 N]` 하나로. `서답형` 이라는 말 금지
6. `조건` 을 2열 표로 (좌 `조건` 셀 + `·` 마커 + 행 구분선), 회색 음영
7. 답란을 정본 형태로 (`→ ____.` / `(A) ____` / `문장 기호: (  )` + `수정된 문장:____.`)
8. 서술형 지문에 테두리 상자
9. 요약 화살표를 굵게·가운데로, (A)(B) 선지에 점 리더 + 열 가운데 정렬
10. `※ 반드시 서술형 답지에 기록하세요.` 추가
11. 계속 표시의 `{유형}` 을 다음 쪽 실제 내용에 맞추기
12. 문항 번호 뒤 탭 → 공백 한 칸
13. (확신도 낮음) 단 간격 13.5 → 8~9mm, 문항수 표 라벨열 음영 제거

## 사용자에게 요청할 자료

> 이 학교는 지금 **2년 전 시험지를 휴대폰으로 찍은 사진 한 벌**로 버티고 있다.
> 아래 자료 중 **①만 들어와도 이 문서의 절반이 확정값으로 바뀐다.**

### ① (최우선) 성덕고 **고1** 최신 회차 기출 시험지 — 26-1-기말

- **왜**: 조판 시점(26-2-중간)의 직전 회차다. 지금 정본은 24-1-중간으로 **4회차가 비어
  있고**, 같은 학교 고2 자료에서 이미 **계속 표시 문구가 바뀐 것**이 확인됐다
  (`뒷면에`/`다음 장에` → `다음 쪽에`). 세부 표기가 더 바뀌었을 가능성이 크다.
- **이걸로 확정되는 것**: 계속 표시 문구, 과목명(`영어` vs `공통영어1`),
  배점 배정, 조건 표 음영, `<보기>`/`<단어>` 상자 형태, 서술형 발문 내어쓰기,
  문항수 표 라벨열 음영.
- **없으면**: 26-1-중간 → 25-2-기말 순으로 **가장 최근 것 아무거나**. 회차가 하나
  더 들어오는 것만으로도 "회차마다 바뀌는 항목"과 "안 바뀌는 항목"을 가를 수 있다.

### ② (최우선과 동급) **원본 파일 또는 제대로 된 스캔**

지금 자료의 결정적 한계는 회차보다 **품질**이다.

- **1순위**: 학교가 배포한 **PDF 원본**(텍스트층 있는 것). 있으면 `rolemeasure.py` 로
  서체·크기·행간·들여쓰기·여백을 **mm/pt 단위로 한 번에** 뽑을 수 있다.
- **2순위**: **평판 스캐너 스캔**(300dpi 이상, 기울기 없이, 지면 네 변이 다 들어오게).
  판형·여백·단 폭·괘선 두께를 실측할 수 있게 된다.
- **최소한**: 지금 같은 촬영본이라도 **채점 낙서가 없는 깨끗한 사본**으로,
  **지면 전체가 프레임 안에 들어오게** 정면에서 찍은 것. 이것만 있어도 판형과
  여백이 나온다.
- **왜**: 현재 `page.*` 와 `typography.*` 의 mm/pt 값은 **전부 추정치**다.
  "단 간격을 13.5mm 에서 8mm 로 줄여야 한다" 같은 지적을 지금은 확신을 갖고 할 수 없다.

### ③ 성덕고 고1 **동형 배점 배정 정책**

- **왜**: 학교 기출은 26문항 70점인데 **동형 원고는 22문항**이다. 정본의 배점 분포
  (2.3×7 / 2.7×10 / 2.9×5 / 3.1×4)를 그대로 못 쓴다. 서술형도 6문항 30점 → 5문항 30점.
- **필요한 것**: 22문항으로 70.0 을, 5문항으로 30.0 을 맞추는 배정표.
  (한영고·상일여고처럼 학교별 배점 규칙이 이미 정해진 사례가 있으니, 성덕도
  같은 방식으로 정해 주면 그대로 프로파일에 넣는다.)

### ④ 1쪽 문항수 표를 **원고 기준**으로 찍을지 **학교 기출 기준**으로 찍을지
