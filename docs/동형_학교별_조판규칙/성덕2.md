### ⚠ 26-1-기말 기출이 필요하다

기출DB `성덕고 기출모음/` 에 26-1-기말이 **없다**(폴더: 25-1-중간, 25-1-기말, 25-2-중간,
25-2-기말, 26-1-중간). 조판 시점이 26-2-중간이므로 직전 회차는 26-1-기말인데, 한 회차
앞선 26-1-중간을 정본으로 썼다. 큰 틀은 안 바뀌지만 세부(마무리 문구·배점 괄호·계속
문구·`<단어>`/`<보기>` 표기·조건 불릿)는 회차마다 흔들리므로 **26-1-기말 실물 확보가
최우선**이다. `_reference_manifest.json` 의 `요청필요` 목록에도 성덕2가 들어 있다.

### ⚠ 수치는 전부 근사값이다

정본이 손으로 찍은 사진이라 `rolemeasure` / `refscan` 이 쓸 수 없다. 대신

1. 9쪽 전부 PNG 로 렌더해 눈으로 읽고,
2. 종이 네 변을 검출해 원근 보정한 뒤 **A4 210×297 격자(10px/mm)** 에 얹어
3. 픽셀 비율로 환산했다.

그래서 프로파일에 `typography.approx: true` 를 뒀다. 특히 **세로 절대 위치는 쪽마다
±2~3mm 흔들린다**(머리말 괘선 y 가 p2 17.7 / p3 21.5 / p7 19.6mm). 다만 같은 쪽 안의
상대 거리는 믿을 만하다 — 머리말 괘선 → 저작권 상자 아래가 p2 269.7mm, p3 269.9mm 로
0.2mm 안에서 일치한다.

판형을 A4 로 **가정**한 근거: 종이 네 변에서 복원한 종횡비가 0.677~0.712(평균 0.692)로
ISO 비율(0.7071) 부근이고, 실측 판면 폭 ≈171mm 가 한글 A4 판면과 정합한다. 종횡비만으로는
A4 와 B4 를 못 가른다(둘 다 0.707). B4 원지였다면 실측치를 ×1.2238 해야 하고 환산 계수는
1이 된다.

### 보조 자료 — 기출DB hwp 재구성본

`성덕고 기출모음/{25-1-중간, 25-1-기말, 25-2-중간, 25-2-기말, 26-1-중간}/(개정)*.hwp`.
**레이아웃 근거로 못 쓴다** — 배점도 재구성자가 임의로 `[1점]`/`[2점]` 을 붙였다.
문구·회차 변동 관측에만 썼다. 여기서 얻은 것:

- 서술형 단어뱅크 라벨이 25-x 회차 `<보기>` → 26-1-중간 `<단어>` 로 바뀌었다.
- 조건 항목 마커가 25-x `1. 2.` → 26-1-중간 `·` 로 바뀌었다.
- 26-1-중간 출제범위 = 교과서 YBM(박준언) 1과·2과 + 모의고사 21년 9월.

## 5. 문제 유형별 차이

**글자 규격(서체·크기·행간·들여쓰기)은 유형이 달라도 균일하다.** 달라지는 것은 배치뿐이다.

| 유형 | 달라지는 점 |
|---|---|
| 어휘/문맥 | 없음. 지문 안에 ①~⑤ 를 직접 박고 선지는 세로 1열 |
| 빈칸 | 지문 안 빈칸은 밑줄 `________`. 선지가 낱말이면 **2열 격자** |
| 순서 | 주어진 글 = 테두리 상자. (A)(B)(C) 문단 **사이에 가로 괘선**. 선지 2열 격자 |
| 삽입 | 주어진 문장 = 테두리 상자. 지문 안 자리 표시 `( ① )`. 선지 없음(번호+배점만) |
| 요약 | 지문 → **굵은 ↓** → 테두리 상자 요약문 → (A)(B) 열 표 |
| 어법 | 지문에 ⓐ~ⓔ. 조합형 선지는 **3열 격자**. (A)(B)(C) 골라짝짓기는 **열 표** |
| 자료(도표) | 테두리 표 + 표 **위**에 `[Key Indicators of Market Trends]` 대괄호 캡션 가운데 |
| 장문 | 정본에 없음 — 규칙 미확정 |
| 서술형 | 발문 내어쓰기 없음. 조건 표 + `<단어>` 상자 + 답란. 지문은 대체로 테두리 상자 |

## 6. 보기 / 조건 / 요약 / 주어진 문장 렌더

### 조건 — **2열 표, 회색 라벨 셀, 꺾쇠 없음**

```
┌────────┬────────────────────────────────────────────────┐
│▓▓▓▓▓▓▓▓│ · 주어진 <단어>만을 모두 사용할 것(어형 변형 불가) │
│▓▓▓▓▓▓▓▓├────────────────────────────────────────────────┤
│▓ 조건 ▓│ · 밑줄 친 우리말 (가)와 같은 의미의 완성된 한   │
│▓▓▓▓▓▓▓▓│   문장으로 영작할 것                           │
│▓▓▓▓▓▓▓▓├────────────────────────────────────────────────┤
│▓▓▓▓▓▓▓▓│ · '가 목적어'를 활용하여 영작 할 것             │
└────────┴────────────────────────────────────────────────┘
```

- 단 폭 전체. 왼쪽 라벨 셀 폭 **9.8mm** (8.0), **연회색 음영**, `조건` 가로·세로 가운데,
  여러 행에 걸쳐 병합.
- **조건 하나 = 표 한 행.** 각 행이 `· ` 불릿으로 시작하고, 되풀이 줄은 불릿 뒤 글자로 내어쓴다.
- 테두리 ≈0.4pt, 모든 셀에 선.
- **꺾쇠를 쓰지 않는다.** 라벨도 `조건`, 발문 본문도 `아래의 조건에 맞추어`.

정본 조건 원문 전량(13개)은 프로파일 `cond.관측_원문` 에.

### 보기 = `<단어>` — **캡션이 상자 안 첫 줄**

```
┌──────────────────────────────────────────┐
│                  <단어>                  │
│      must / more / hard / the / area     │
│      / work / have / surface / you       │
└──────────────────────────────────────────┘
```

단 폭 전체 테두리 상자. `<단어>` 는 **상자 안 첫 줄 가운데**(테두리 선에 걸치지 않는다),
본문보다 작게. 단어는 ` / ` 로 이어 가운데 정렬하고, 줄이 넘어가면 다음 줄이 `/` 로 시작한다.

발문이 `괄호 안의 단어를 활용하여` 라고 하면 상자 없이 괄호 인라인:

```
        ( camping / equipment / Jane / find / which / know / a shop / I / at / can )
```

괄호 안쪽 좌우에 공백 한 칸씩, 가운데 정렬.

> **회차 변동**: 25-x 회차는 `<보기>` 였고 26-1-중간에서 `<단어>` 로 바뀌었다. 정본 기준 `<단어>`.

### 요약

지문 → 빈 줄 → **속이 찬 굵은 아래 화살표**(단 가운데) → **테두리 상자 요약문** → (A)(B) 열 표.
요약문은 `○ ` 로 시작하고 빈칸은 밑줄 위에 `(A)`/`(B)` 를 얹는다.

```
                        ⬇
┌──────────────────────────────────────────────────────┐
│ ○ Universal design maximizes ___(A)___ by minimizing │
│ barriers, ultimately resulting in the ___(B)___ of all.│
└──────────────────────────────────────────────────────┘
```

> 정본 요약문 끝에 짝 없는 닫는 큰따옴표(`of all."`)가 남아 있다. 원문 오타이므로 승계하지 않는다.

### 주어진 문장 / 주어진 글

둘 다 **단 폭 전체 테두리 상자**(≈0.4pt), 양쪽 정렬, 라벨 없음.
순서 문항의 (A)(B)(C) 문단은 상자가 아니라 **문단 사이 가로 괘선**으로 나눈다 —
(A) 위와 (C) 아래에는 선이 없다. 라벨 `(A)` 는 왼쪽에 매달고 본문은 일정 들여쓰기로 정렬한다.

### 서술형 지문

원칙 **테두리 상자**. 정본에서 서술형 1·4·5·6과 묶음 자료(대화문)는 모두 상자였고,
서술형 3(글에서 단어 찾아쓰기)만 상자 없이 맨 문단이었다. 회차가 하나뿐이라 규칙인지
실수인지 판별 못 했다.

## 7. 문항 묶음 표기

```
[7~11] 다음 빈칸에 들어갈 말로 가장 적절한 것을 고르시오.
7. 〔2.7점〕
   Relativity works as a general mechanism for the mind, …
```

- 템플릿 **`[{a}~{b}] {지시문}`** — 대괄호, 물결 `~`(U+007E), **괄호 안쪽 공백 없음**,
  `]` 뒤 공백 한 칸. 고딕 굵게. 지시문은 같은 줄. 둘째 줄로 넘어가면 단 왼쪽에 붙는다(내어쓰기 없음).
- 혼합 템플릿 **`[{n}, 서술형 {m}] {지시문}`** — 쉼표+공백.

**구성원이 발문을 갖는지 갖지 않는지는 묶음 머리가 무엇이냐로 갈린다.**

| 묶음 머리 | 구성원 |
|---|---|
| 실제 발문 (`…고르시오.`) | 발문 없이 **`{n}. 〔{s}점〕`** 한 줄만 |
| 자료 공유 안내문 (`다음 자료를 읽고 물음에 답하시오.`) | 각자 **온전한 발문 + 배점** |

정본 관측 전량:

```
[7~11] 다음 빈칸에 들어갈 말로 가장 적절한 것을 고르시오.
[12~13] 다음 글의 밑줄 친 부분 중, 문맥상 낱말의 쓰임이 적절하지 않은 것을 고르시오.
[17~18] 다음 글의 흐름으로 보아, 주어진 문장이 들어가기에 가장 적절한 곳을 고르시오..
[20~21] 다음 글의 주제로 가장 적절한 것을 고르시오.
[26, 서술형 1] 다음 자료를 읽고 물음에 답하시오.
```

> `[17~18]` 지시문 끝이 마침표 두 개다(원문 오타). 동형에서는 하나로 정정한다.

## 8. 서술형 라벨

```
[서술형 1] 위 글의 밑줄 친 우리말 (가) 부분을 아래의 조건에
맞추어 주어진 <단어>를 활용하여 영작하시오. 〔5점, 부분점수 있음〕
```

- 템플릿 **`[서술형 {n}]`**, 고딕 굵게, **라벨 안쪽 자간을 넓힌다**(`[ 서 술 형   1 ]` 처럼 보인다).
- 번호는 선택형과 **별도 연번**(1~6). 발문과 같은 줄, 라벨 뒤 공백 한 칸.
- **내어쓰기 없음** — 둘째 줄이 `[` 위치(단 왼쪽)로 붙는다.

### 서술형 섹션 헤더

단독 서술형 블록이 시작되는 쪽(정본 8쪽) 맨 위:

```
                    < 서 술 형 >
※ 반드시 서술형 답지에 기록하세요.
```

`< 서 술 형 >` 은 **바탕(명조) 굵게, 글자 사이 한 칸씩 벌려 단 가운데**. 아래 줄은 명조 보통, 왼쪽 정렬.

> 묶음 안에 섞인 서술형(`[26, 서술형 1]`, 정본 7쪽)은 이 헤더보다 **앞에** 나온다.

### 답란 형태 (정본 관측 전량)

| 형태 | 예 |
|---|---|
| 화살표 + 밑줄 | `→ ______________________________________.` |
| 화살표 + 인쇄문구 섞임 | `→ ________ relative to volume, ________ to stay warm.` |
| 번호 + 콜론 | `(1) :__________________________.` |
| 기호 + 문장 | `(1) 문장 기호: (      )` / (들여쓰기) `수정된 문장:______________.` |
| 표 완성형 | 표 셀 안 `• (1) ______` + 표 아래에 `(1) :` `(2) :` 답란 |

밑줄은 단 오른쪽 끝까지 긋고 **끝에 마침표**를 찍는다. 서체는 고딕.

## 9. 배점 표기

- 괄호 **`〔〕`** (U+3014 / U+3015, 거북등 괄호). 대괄호 `[]` 가 **아니다** — 확대 판독으로 확정.
- 소수 **한 자리**(선택형), 서술형은 정수 `5점`.
- 발문 끝에 **공백 한 칸** 뒤 인라인.
- **그 줄에 자리가 없으면 다음 줄로 넘어가 단 오른쪽 끝에 오른쪽 정렬로 홀로 놓인다.**
  발문이 몇 줄인지와 무관하고, 마지막 줄에 배점이 들어갈 폭이 남았는지로만 갈린다.

```
1. 다음 글의 요지로 가장 적절한 것은? 〔2.3점〕          ← 인라인
4. 다음 표의 내용을 바탕으로 작성된 글의 내용 중, 표와 일치하
   지 않는 것은? 〔2.3점〕                              ← 2행 끝에 인라인
6. 다음 글의 밑줄 친 부분 중, 어법상 틀린 것만을 고른 것은?
                                            〔3.1점〕   ← 별행 오른쪽 정렬
```

- 묶음 구성원은 `{n}. 〔{s}점〕` 한 줄. 예: `9. 〔2.7점〕`, `17. 〔2.7점〕`
- 서술형 꼬리말 **`부분점수 있음`** — 배재의 `부분점수 없음` 과 **반대**다.
  예: `〔5점, 부분점수 있음〕`, `〔6점, 부분점수 있음〕`
- 소문항 부분배점은 찍지 않는다.
- 머리표 총점 칸 있음: 선택형 26문항 70점 / 서술형 6문항 30점.

관측 배점 세트 — 선택형 {2.3, 2.7, 2.9, 3.1}, 서술형 {3, 4, 5, 6}(합 30, 정확히 일치).
선택형 26문항을 눈으로 읽어 합산하면 70.2가 나온다(필기 표시에 가려 한 문항 0.2 오독 추정).
표기 규칙은 확정이나 **문항별 배점 목록은 확정이 아니다.**

## 11. 기타 글리프

| 항목 | 값 |
|---|---|
| 계속 표시 | `☞` U+261E, 본문보다 작게 |
| 요약 화살표 | 속이 찬 굵은 아래 화살표. `↓`(U+2193) 굵게 / `⬇`(U+2B07) / `⇩`(U+21E9) 후보 — **코드포인트 미확정** |
| (A)(B)(C) 구분자 | **`…`** (U+2026). 한글 글꼴이 가운데 높이로 그려 가운뎃점 세 개처럼 보인다. `-----` 가 **아니다** |
| 순서 선지 구분자 | ` – ` (en dash U+2013 추정, 공백 있음) — 본문 하이픈보다 뚜렷이 길다 |
| 삽입 자리 표시 | `( ① )` — 괄호 안쪽 공백 한 칸씩 |
| 선지 마커 | `①`~`⑤` (U+2460~) |
| 어법 표시 | `ⓐ`~`ⓔ` (U+24D0~) |
| 빈칸 | 밑줄 `________`. (A) 등은 밑줄 위에 얹는다(`___(A)___`) |
| 밑줄 관행 | 발문의 부정어(`않는`·`틀린`·`없는`·`다른`)에 밑줄. 선지에는 없음 |

### 선지 배치

- 기본 한 줄에 하나, 되풀이 줄은 마커 뒤 글자로 내어쓴다.
- **짧으면 격자로 눕힌다** — 낱말 한두 개는 2열, `ⓐ, ⓑ` 같은 기호 조합은 3열.
  마지막 행이 덜 차면 왼쪽부터 채운다.

```
① reduction         ② interruption          ① ⓐ, ⓑ    ② ⓐ, ⓓ    ③ ⓑ, ⓔ
③ comparison        ④ obliviousness         ④ ⓒ, ⓔ    ⑤ ⓓ, ⓔ
⑤ extinction
```

- (A)(B)(C) 짝 선지는 **열 표**. 머리행에 `(A) (B) (C)` 가운데, 값도 각 열에서 가운데 정렬,
  `…` 가 별도 열. `①` 마커는 맨 왼쪽 열에 따로.

```
        (A)               (B)
①   Specifically    …   Otherwise
②   Let's say       …   However
③   In contrast     …   Moreover
```

### 원고가 주는 것 / 안 주는 것

| | |
|---|---|
| 머리 메타 | `성덕고2 동형 {N}회 원고` / `선택형: 26문항` / `서술형: 6문항` — **조판 대상 아님** |
| 문항 번호 | **없음** |
| 서술형 표시 | **없음** |
| 묶음 표시 | **없음** — `다음 글을 읽고 물음에 답하시오.` 한 줄만 |
| 배점 | **없음** |

번호·묶음 머리(`[7~11]`, `[26, 서술형 1]`)·서술형 라벨·**배점**은 전부 조판이 만들어 넣는다.

### ⚠ 원고는 발문 끝에 **정답을 붙여 놓는다**

반드시 제거해야 한다. 세 가지 형태:

```
윗글의 밑줄 친 ⓐ~ⓔ중 어법상 틀린 것은? ➃          ← 원문자 하나
… <조건>에 따라 쓰시오. We just have to wait for …  ← 정답 문장
… 본문의 단어를 활용하여 쓰시오. (A) mastery (B) curiosity (C) contradictory
```

### 선지 마커

`➀~➄`(U+2780~)와 `①~⑤`(U+2460~)를 **섞어 쓴다** — 1회 80:55, 2회 86:51.
그 밖에 `ⓐ`(U+24D0), `(A)`, `(㉮)` 사용.

### 정규화 항목

1. `➀~➄` → `①~⑤`
2. 발문 끝 정답 제거(위 3형태)
3. 머리 메타 3줄 제거
4. 출처·부가 태그 제거 — `[21년 9월 22번]`, `[20번]`, `[38번]`, `[39번]`, `[40번]`, `[1과]`, `[Further Reading]`
5. 요약 화살표 `↓`(U+2193) → 정본의 굵은 속찬 화살표
6. `<보기>` → `<단어>`
7. `<조건>` → 꺾쇠 없는 `조건` 회색 라벨 셀 표
8. `답: ____` → `→ ____.`
9. (A)(B)(C) 짝 선지의 탭 정렬 → `…` 구분자 + 머리행 열 표
10. 순서 선지 ` - ` → ` – `

### 서술형 판정

원고에 표시가 없으므로 구조로 가른다.
서술형은 원고 뒤쪽에 몰려 있고, `<조건>`+`<보기>`+`답:` 세트가 있거나
`쓰시오/영작하시오` 로 끝나면서 **선지(①~⑤)가 없는** 문항이다.

> **선지가 있으면 선택형이다.** `…배열한 것을 고르시오` 처럼 `고르시오`로 끝나도
> 선지가 있으면 선택형. (현행 산출물이 여기서 틀렸다 — §13.)

### 그 밖에

- 묶음 소속 문항은 발문이 `윗글의 …` 로 시작한다 — 이 접두로 묶음 소속을 판정할 수 있다.
- `<조건>`·`<보기>` 줄 앞에 공백 3칸이 붙어 있다(들여쓰기가 아니라 원고 잔재 — 버린다).
- 원고 안에서도 조건 항목 마커가 `(1)`형과 `-`형으로 섞인다. 정본은 전부 `·` 로 통일.
- 답란 표기: `답: ____`, `답: The music played in workplaces ____.`, `(A) : ______`

## 13. 현행과 달라 고쳐야 할 것

현행 산출물: `고2/26-1-중간/성덕고/성덕2_동형모의고사(1회).pdf` (7쪽),
`…(2회).pdf` (7쪽), `…(2회)_2.pdf` (8쪽). 모두 B4 도련본 263×370mm.

### 치명

1. **배점이 하나도 없다.** 1회·2회 모두 `〔N.N점〕` 0건. 정본은 전 문항에 배점이 붙고,
   위치 규칙(줄 끝 인라인 / 넘치면 다음 줄 오른쪽 정렬)도 있다.
2. **묶음 표기가 없다.** `[7~11]` / `[26, 서술형 1]` 0건. 현행은 `다음 글을 읽고 물음에
   답하시오.` 를 맨줄로 흘릴 뿐이다. 묶음 구성원이 `9. 〔2.7점〕` 로 축약되는 규칙도 없다.
3. **서술형 분류가 틀렸다.** 1회의 `[서술형 1]`은 순서배열 객관식(①~⑤ 선지 있음),
   `[서술형 2]`·`[서술형 3]`·`[서술형 6]`도 객관식이다. 반대로 진짜 서술형(조건+단어+답란)은
   라벨이 아예 없이 `·` 불릿만 붙어 나온다. 2회는 라벨이 **7개** 찍혀 원고의 `서술형: 6문항`
   과도 어긋난다.
4. **원고 머리 메타 3줄이 본문에 인쇄된다** — 1쪽 왼쪽 단 첫머리에
   `성덕고2 동형 1회 원고 / 선택형: 26문항 / 서술형: 6문항`.
5. **출처·부가 태그가 인쇄된다** — 1회 `[Further Reading]` `[20번]` `[38번]` `[39번]` `[40번]`,
   2회 `[18번]` `[21번]` `[30번]` `[35번]` `[36번]` `[40번]`.

### 문구·표기

6. **계속 문구가 다르고 두 종류가 섞여 있다.** 현행 `☞ 뒷면에 선택형 문항 계속` /
   `☞ 다음 장에 선택형 문항 계속`. 정본은 `☞ 다음 쪽에 선택형 문항 계속` 한 가지이고,
   서술형 구간에서 `선택형(서술형) 문항` → `서술형 문항` 으로 갈아탄다.
7. **머리표 과목명에 Ⅰ이 빠졌다.** 현행 1쪽 `영어 [과목코드 : 03]`, 2쪽 이후
   `영어[과목코드: 03]`. 정본은 1쪽 `영어 Ⅰ [과목코드 : 03]`, 2쪽 이후 `영어 1[과목코드 : 03]`.
   꼬리말도 현행 `2학년 영어`, 정본 `2학년   영어 Ⅰ`.
8. **서술형 섹션 헤더가 없다** — `< 서 술 형 >` + `※ 반드시 서술형 답지에 기록하세요.`
9. **마지막 확인사항 상자가 없다** — `※ 확인사항 / ∘ 답안지의 해당란에 …`.
   (`-끝-` 자체는 현행도 정본과 일치한다.)
10. **부정어 밑줄이 원고 의존이다.** 정본은 `않는`·`틀린`·`없는` 에 일관되게 밑줄을 두른다 —
    원고에 없어도 조판이 넣어야 한다.

### 상자·표·배치

11. **조건이 정본 형태가 아니다.** 현행은 `· <조건>` 한 줄을 띄우고 아래 별도 상자에
    조건 항목과 `<보기>` 를 한꺼번에 담는다. 정본은 회색 `조건` 라벨 셀이 붙은 2열 표
    (조건 1개 = 1행, `·` 불릿)이고 단어뱅크는 `<단어>` 캡션이 든 **별도** 상자다.
    꺾쇠도 정본은 `조건`(없음) / `<단어>`(있음)로 갈린다.
12. **답란 형식이 다르다.** 현행 `답: ______`(원고 그대로). 정본은
    `→ ______.` / `(1) :______.` / `문장 기호: (  )` + `수정된 문장:______.`
13. **(A)(B)(C) 짝 선지에 `…` 구분자와 머리행이 없다.** 현행은 탭 정렬만 하고,
    6쪽처럼 열이 무너져 값이 세로로 흩어진 곳도 있다.
14. **짧은 선지 격자 배치가 없다.** 정본은 낱말 선지 2열, 기호 조합 3열로 눕힌다.
15. **문항 번호 조판이 다르다.** 현행은 `1.` 뒤 탭이 들어가 간격이 넓고 번호가 굵지 않다.
    정본은 명조 굵게에 본문보다 크고, 마침표+공백 한 칸 뒤 바로 발문, 둘째 줄은 내어쓴다.

### 잔재·충돌

16. **서술형 발문 앞에 정체불명의 `·`(백틱 계열) 글리프**가 찍힌다 — 6쪽
    `· 다음 글의 밑줄 친 (A)를 …`, `· <조건>`. 앵커 잔재로 보인다.
17. **요소 겹침** — 6쪽에서 `[서술형 4]` 라벨이 앞 문항 답란 밑줄 위에 겹쳐 찍혔다.

> 1쪽 머리표 오른쪽 빈 상자는 현행·정본 모두 왼쪽 표와 같은 높이라 **차이가 아니다**
> (검수 과정에서 한 번 오판했다가 정정).

   (마무리 문구·배점 괄호·계속 문구·`<단어>`/`<보기>`·조건 불릿)를 직전 회차 기준으로
