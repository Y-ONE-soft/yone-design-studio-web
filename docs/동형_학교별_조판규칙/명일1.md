## 3. 러닝 요소

### 머리표 — **1쪽에만**, 3행 표

쪽 테두리 상자 안쪽으로 약 1.5mm 들어간 표. 표 안 글자는 전부 **고딕 볼드**.

```
┌──────────────────────────────────────────────────────────────────────────┐
│  2026학년도 [ 1 ]학기 [ 기말 ]고사  [ 7 ]월 [ 2 ]일        10:40 ~ 11:20  │
├────┬──────┬──────────┬────────┬──────────────────┬─────────────────┬─────┤
│    │ 학년 │   과목   │ 과목코드│ 선택형 문항번호  │ 서답형 문항번호 │총 쪽수│
│(배지)├──────┼──────────┼────────┼──────────────────┼─────────────────┼─────┤
│    │  1   │ 공통영어1│   12   │1번 ~ 23번 (23문항)│1번 ~ 2번 (2문항)│ 8쪽 │
└────┴──────┴──────────┴────────┴──────────────────┴─────────────────┴─────┘
```

- 1행 = 전체 병합(표제 + 시간), 2·3행 = 7열, 1열(학교 배지)은 두 행 병합.
- 표 상단 24.5 / 하단 53.0mm (B4). 행 높이 10.0 / 9.1 / 9.4mm.
- 표제 대괄호는 **안쪽 좌우 각 한 칸**, 닫는 괄호 뒤 조사는 붙임 — `[ 1 ]학기` `[ 기말 ]고사` `[ 7 ]월` `[ 2 ]일`.
- 시간 구분자 ` ~ `. 시간은 오른쪽 끝.
- `과목` 칸 값(`공통영어1`)만 표 안에서 가장 크다(라벨의 약 1.6배).
- 칸 값 템플릿: `1번 ~ {마지막}번 ({n}문항)` / `{n}쪽`.

### 꼬리말 — 매 쪽, 테두리 상자 **바깥** 두 줄

```
                    ( 1 )학년 ( 공통영어1 )과 ( 8쪽 ) 중 ( 1쪽 )
     <본 시험 문제의 저작권은 명일여자고등학교에 있으며 무단 사용 시 저작권법에 의거 처벌될 수 있습니다.>
```

- 둘 다 **가운데 정렬, 바탕(명조)**. 윗줄 11pt(y 350.6), 아랫줄 9.5pt(y 356.7). (B4)
- 괄호 안쪽 좌우 각 한 칸, `)` 뒤 조사는 붙임.
- 저작권 줄은 꺾쇠 `<` `>` 로 감싼다.
- 25-1-기말은 첫 괄호만 `(1)학년` 으로 공백이 없었다 — 직전 회차 기준 `( 1 )학년`.

### 계속 표시

```
                                                        다음 쪽에 계속 ⬇
```

- **단 2의 오른쪽 끝**, 쪽 테두리 상자 아랫변 바로 위(본문이 어디서 끝나든 바닥에 붙는다).
- **고딕 볼드**. 화살표는 굵은 아래 화살표(사각 축 + 넓은 삼각 머리, 속 채움) —
  `↓`(U+2193, 가는 것)도 `⇩`(U+21E9, 속 빈 것)도 **아니다**. 형태상 `⬇`(U+2B07)에 가장 가깝다.
- **1~7쪽에만.** 마지막 쪽에는 같은 자리에 `- 끝 -` 이 온다.

### 없는 것

- **감독 확인란 없음.**
- **첫머리 안내문 없음.** 26-1-기말·26-1-중간 모두 머리표 바로 아래에서 본문이 시작한다.
  현행 산출물이 넣고 있는 `※ 문제를 정확하게 읽고 옳은 답을 답안지에 표기하시오.` 는 근거가 없다.

## 4. 단락 역할별 수치

**지문·발문·선지·묶음머리·꼬리말이 전부 바탕(명조) 계열이다.** 라틴은 **비례폭
세리프**(HCR Batang/Batang 계열)이지 고정폭 바탕체가 아니다.
고딕(볼드)은 ①머리표 전 칸 ②`<서답형 N번>` 라벨 ③`다음 쪽에 계속 ⬇` 세 곳뿐이다.

> 사전 힌트에는 "발문은 고딕"이라고 되어 있었으나 **정본에서 그렇지 않다.**
> 발문도 지문과 같은 바탕(명조)이고, 핵심어(`없는` `틀린` `않는` `2개` `모두` `다른`)만
> **볼드 + 밑줄**이다. 그 밖에 볼드를 쓰지 않는다.

| 역할 | 크기(B4/정본) | 행간(B4/정본) | 들여쓰기 | 비고 |
|---|---|---|---|---|
| 발문 | 12.2 / 10.0pt | 18.8 / 15.4pt | 0, **내어쓰기 0** | 앞에 빈 줄 1줄 |
| 발문 번호 | 12.2 / 10.0pt | — | 0 | **발문과 같은 크기**(배재처럼 키우지 않는다) |
| 지문 | 12.2 / 10.0pt | 18.8 / 15.4pt | 첫 줄 **3.9 / 3.2mm**(1글자) | 양끝 정렬 |
| 선지 | 12.2 / 10.0pt | 18.8 / 15.4pt | 0, **내어쓰기 0** | 이어지는 줄도 단 왼쪽에 붙는다 |
| 각주 | 12.2 / 10.0pt | — | — | **오른쪽 정렬** |
| 묶음 머리 | 12.2 / 10.0pt | — | 0 | |
| 서답형 라벨 | 12.2pt **고딕 볼드** | — | 0, 내어쓰기 0 | |
| 쪽번호 줄 | 11.0 / 9.0pt | — | 가운데 | |
| 저작권 줄 | 9.5 / 7.8pt | — | 가운데 | |

- 대화체 지문(`Klara:` `Host :`)은 첫 줄 들여쓰기 없이 **화자 뒤 내어쓰기** —
  이어지는 줄이 화자 라벨 폭만큼 들어간다.
- 크기 근거: x-높이 14.3px, 줄 피치 46px 에서 역산(±0.7pt). 현행 산출물이 쓰는
  B4 12pt 와 일치한다.

**빈 줄 1줄**(B4 18.8pt / A4 5.3mm)이 기본이다. 정본 관측 간격은 4.7 / 7.0 / 9.3 /
13.4 / 22.5mm — 전부 빈 줄 정수배다(학교가 단 높이를 맞추려고 손으로 벌린 자리).

## 5. 문제 유형별 차이

**들여쓰기·크기는 유형에 관계없이 균일하다.** 지문 첫 줄 1글자 들여쓰기, 선지
내어쓰기 0, 발문 내어쓰기 0 이 전 유형 공통이다. **유형별로 갈리는 것은
'무엇을 상자에 넣는가'와 '선지를 몇 열로 놓는가' 둘뿐이다.**

| 유형 | 상자 | 선지 배치 | 그 밖 |
|---|---|---|---|
| 어휘 | 없음 | 한 줄에 하나 | 지문에 `ⓐ어구`(붙임) + 밑줄 |
| 빈칸 | 없음 | 한 줄에 하나 | 빈칸 = 인라인 밑줄 |
| 순서 | **주어진 글 boxed** | **2열** (src 26-1-중간) | (A)(B)(C) 문단에 **내어쓰기 있음** |
| 삽입 | **주어진 문장 boxed** | 한 줄에 5개(`① ⓐ ② ⓑ …`) 또는 없음 | 자리표시 `(ⓐ)` |
| 요약(서답형) | **요약문 boxed** | — | `⇓` 가운데 → 상자 → 답란 |
| 요약(선택형) | **요약문 boxed** | (A)(B) 짝 선지표 | **화살표 없음** |
| 일치·있는대로 | **ⓐ~ⓖ 진술 boxed** | 한 줄에 하나 또는 2열 | `① ⓐ,ⓓ,ⓕ` (쉼표 뒤 공백 없음) |
| 안내문·도표 | **없음** | 한 줄에 하나 | 제목을 `<…>` 로 감싸 가운데, `●` 대분류 / `"` 소분류 |
| 장문 | — | — | 고1 정본에 없음 |

## 6. 보기 / 조건 / 요약 / 주어진문장

명일1은 **상자를 두 종류**로 쓴다.

### (a) 캡션 없는 맨 사각형 — 주어진 문장·주어진 글·진술 목록·요약문(26-1)

```
┌─────────────────────────────────────────────┐
│ A mysterious chronic illness often caused   │
│ her to stay in bed for days on end.         │
└─────────────────────────────────────────────┘
```

- **좌우가 단 폭 전체**(정본 8쪽 전수 확인 — 상자 변이 단 안 텍스트 좌·우끝과 일치).
- 테두리 약 0.5pt, 안여백 약 1.5mm. 안쪽 글은 지문과 같은 크기·양끝 정렬, 볼드 아님.

### (b) 캡션이 테두리에 걸친 상자 — `<조 건>` `<보 기>` `<질 문>` `<요약문>`

```
────────────────── <조 건> ──────────────────
 1. 틀린 부분의 번호와 바르게 고친 내용을 모두 적을 것
 (두 가지 요소가 모두 맞아야 정답으로 인정하며 …)
 2. 바르게 고칠 때 본문 안에 있는 단어만을 활용할 것
 3. 다음 작성 예시를 참고하여 쓸 것
   예시) 틀린 부분의 번호 -> 바르게 고친 내용
└────────────────────────────────────────────┘
```

- 윗변 괘선이 캡션 좌우로 **끊기고** 그 사이에 라벨이 가운데로 앉는다.
- **두 글자 라벨은 가운데에 공백을 넣어 벌린다** — `<조 건>` `<보 기>` `<질 문>`.
  세 글자인 `<요약문>` 은 안 벌린다.
- 조건 항목은 `1.` `2.` `3.`, 이어지는 줄은 상자 안 왼쪽에 붙는다(내어쓰기 0).
  하위 예시 줄만 한 칸 들여쓴다.
- src = 25-2-기말. **26-1 두 회차에는 이 상자가 한 번도 안 나온다.**

### 요약 문항 구성

```
   (지문)
   * primatologist: 영장류학자 **affiliation: 제휴      ← 오른쪽 정렬
                        ⇓                              ← 단 가운데
┌─────────────────────────────────────────────┐
│ Frans de Waal argues that humans … use      │
│ technical language to (A)m________ …        │
└─────────────────────────────────────────────┘

(A)m________________        (B)s________________
```

- 화살표 **`⇓` (U+21D3)**, 단 가운데에 홀로 한 줄. **서답형 요약에만.**
  선택형 요약(빈칸 (A),(B) 고르기)에는 **화살표가 없다**.
- 26-1 두 회차의 요약문 상자에는 **캡션이 없다**(25-2-기말에는 `<요약문>` 이 있었다 —
  직전 회차 기준이므로 캡션 없음).
- 답란: **두 칸이면 한 줄에 나란히**, **세 칸이면 줄마다 하나씩**.
  `(A)` 와 밑줄 사이에 공백을 넣지 않는다. 주어진 첫 글자가 있으면 `(A)m____`.

## 7. 문항 묶음 표기

```
※ [2~3] 다음 글을 읽고 물음에 답하시오.
```

- **`※` 로 시작**한다. `※` 뒤 한 칸, `]` 뒤 한 칸.
- 대괄호 `[ ]`, **안쪽 공백 없음**.
- 범위 구분자 **물결표 `~` (U+007E)**, 앞뒤 공백 없음.
- 지시문은 **같은 줄**. 문장은 `다음 글을 읽고 물음에 답하시오.` (쉼표 없음).
- 26-1-기말 묶음: `[2~3]` `[5~6]` `[10~11]` `[19~20]` `[22~23]` — 전부 2문항.
  26-1-중간에 3문항 묶음 `[1~3]` 이 하나 있다.
- **묶음 안 개별 문항은 번호 + 발문 + 배점을 모두 갖는다.** 번호만 갖는 형태는 없다.

**발문 첫머리 규칙 (정본 23문항 전수 일치)**

| | |
|---|---|
| 묶음 소속 문항 | **`윗글의…` / `윗글에서…`** |
| 단독 문항 | **`다음 글의…` / `다음 빈칸에…`** |

**선택형+서답형 혼합** (src 25-1-기말)

```
[20, 서답형 6] 다음 글을 읽고, 물음에 답하시오.
```

⚠ 25-1-기말의 혼합 묶음은 **`※` 가 없고** 지시문에 쉼표가 있다. 26-1 두 회차에
혼합 묶음 표본이 없어서, 26-1 관행(`※` 있음, 쉼표 없음)과 어느 쪽으로 합칠지
확정하지 못했다.

## 8. 서답형 라벨

```
<서답형 1번> (A)는 m, (B)는 s로 시작하는 1단어로 다음 글의 요약문을
완성하시오. 주어진 철자를 포함하여 답을 작성하시오. [각 2.5점, 5점]
```

- **꺾쇠 `<` `>`(ASCII), 안쪽 공백 없음.** `<서답형 {n}번>` — **`번` 을 붙인다.**
- 라벨만 **고딕 볼드**, 뒤에 한 칸 띄고 발문은 바탕(명조).
- 줄 맨 앞에서 시작하고 **이어지는 줄은 단 왼쪽에 붙는다**(내어쓰기 0).
- 선택형과 **별도 번호**(1부터).

| 회차 | 형태 |
|---|---|
| 26-1-기말 (정본) | `<서답형 1번>` |
| 26-1-중간 | `<서답형 1번>` |
| 25-2-기말 | `<서답형 4>` — `번` 없음 |
| 25-1-기말 | `<서답형 6>` — `번` 없음 |

→ 25년 회차는 `번` 이 없었다. **직전 회차 기준이므로 `번` 을 붙인다.**

## 9. 배점 표기

- 괄호 **`[ ]` (ASCII 대괄호)**, 발문 끝에 **한 칸 띄고** 붙인다.
- 소수 한 자리. **정수면 `[4점]`** (`[4.0점]` 안 씀).
- 네 회차(26-1-기말/중간, 25-2-기말, 25-1-기말) 전부 `[]` — 배재처럼 흔들리지 않는다.
- **발문 마지막 줄에 안 들어가면 다음 줄 오른쪽 끝에 홀로 놓는다.** 왼쪽으로 흘리지 않는다.

```
3. 윗글에서 ⓐ~ⓔ 어휘의 문맥상 영영풀이가 틀린 것을 2개 고르면?
                                                    [3.5점]
```

- 서답형: `[각 {소문항}점, {합계}점]` — 26-1-기말 `[각 2.5점, 5점]`, 26-1-중간 `[각 2점, 6점]`.
  (25-2-기말은 `[각 1점, 총 2점]` 처럼 `총` 을 붙였다 — 직전 회차 기준 `총` 없음.)
- 머리표에 총점 칸 없음.

### ★ 총점 배분 규칙 — **선택형 90점 / 서답형 10점 = 100점**

| 회차 | 선택형 | 서답형 |
|---|---|---|
| 26-1-기말 | 23문항 **90.0** (3.7~4.3) | 2문항 5+5 = **10** |
| 26-1-중간 | 28문항 **90.0** (2.7~3.6) | 2문항 6+4 = **10** |

근거: 26-1-중간 별지 배점표 전수 합산 = 90.0. 26-1-기말은 판독 가능한 22문항 합
86.0 + 미판독 7번 4.0 = 90.0 으로 맞아떨어진다.
문항 수가 많을수록 개별 배점이 낮아지고, 난도가 높은 유형(장문·2개 고르기·어법)이
0.3~0.6점 높다.

## 10. 마무리

```
                                                              - 끝 -
```

- **마지막 쪽 단 2의 오른쪽 끝**, 쪽 테두리 상자 아랫변 바로 위 —
  `다음 쪽에 계속 ⬇` 가 놓이던 그 자리다. **가운데 정렬이 아니다.**
- 바탕(명조) 12.2pt, 볼드 아님, 하이픈 앞뒤 한 칸.
- 26-1-기말 / 26-1-중간 / 25-2-기말 / 25-1-기말 **네 회차 모두 `- 끝 -`.** 흔들리지 않는다.

## 11. 기타 글리프

| | |
|---|---|
| 요약 화살표 | **`⇓` (U+21D3)** — 속 빈 두 줄 화살표, 단 가운데 |
| 계속 표시 화살표 | 굵은 아래 화살표, `⬇`(U+2B07) 근사 |
| 문장삽입 자리표시 | **`(ⓐ)`** — 괄호 안쪽 공백 **없음** |
| 원문자 | `①`~`⑤`(U+2460~), `ⓐ`~`ⓖ`(U+24D0~) |
| 어법·어휘 마커 | `ⓐto do` 처럼 **밑줄 어구 바로 앞에 공백 없이** 붙임. 밑줄은 어구에만. |
| (A)(B) 짝 구분자 | 하이픈 `-`, 앞뒤 한 칸. 머리행 `(A)` `(B)` 에 **밑줄** |
| 진술 조합 선지 | `① ⓐ,ⓓ,ⓕ` — 쉼표 뒤 공백 없음 |
| 빈칸 | 밑줄 연속(인라인). 길이 고정 아님 |

**문장삽입 자리표시 — 회차별로 흔들린다**

| 회차 | 형태 |
|---|---|
| 26-1-기말 2·8번 | `(ⓐ)`~`(ⓔ)` 공백 없음 + 선지줄 `① ⓐ ② ⓑ …` |
| 26-1-기말 16번 | `(①)`~`(⑤)` 공백 없음, 선지줄 없음 |
| 26-1-중간 6·13번 | `(ⓐ)`~`(ⓔ)` + 선지줄 |
| 26-1-중간 18·25번 | `( ① )`~`( ⑤ )` **공백 있음**, 선지줄 없음 |

→ 직전 회차 다수형인 **`(ⓐ)` + 선지줄**을 기본으로 한다.

**어법 마커도 흔들린다** — 26-1-기말은 `ⓐ~ⓔ`(4·10·22번)가 다수인데 19번만
지문에 `①~⑤` 를 쓰면서 선지는 `① ⓐ ② ⓑ …` 로 냈다(학교 오타).
원고가 `ⓐ~ⓔ` 를 주므로 **ⓐ~ⓔ + 선지줄**로 통일한다.

## 12. 원고 규칙

원고: `26-1-중간 명일1 동형 1회 원고.hwpx` (178단락), `…2회 원고.hwpx` (207단락)

머리 메타 **한 줄뿐**:
```
객관식 27개 서답형 3개
```

| 항목 | 원고가 주는가 |
|---|---|
| 문항 번호 | **안 준다** — 조판이 자동번호로 만든다 |
| 서답형 표시 | **안 준다** — 서술형 지시문 + `<조건>` + 답란 조합으로만 드러난다 |
| 묶음 표시 | **안 준다** — `다음 글을 읽고 물음에 답하시오. [4과]` 지시문으로만 |
| 배점 | **안 준다** — 90/10 배분으로 조판이 만든다 |
| 선지 마커 | `①` `ⓐ` `(A)` |
| 상자 표기 | `<보기>` `<조건>` `<조 건>` (섞여 있다) |
| 출처 태그 | **있다** — `[25년 3월 23번]` `[23년 3월 41-42번]` `[4과]` (회당 16~17건) |
| 답란 | `(A)___________`, `(A)____________________, (B)____________________`, `(A) : _______________` |
| 화살표 | `↓`(U+2193), `→`, `↔` |

**⚠ 원고 발문 줄 끝에 정답이 붙어 온다.**
```
다음 단어의 영영풀이로 적절하지 않은 것은?	②
```
지문 앞에도 정답만 있는 줄(` ②`)이 있다. **조판 전에 반드시 떼어낸다.**

정규화가 필요한 것:

1. `↓`(U+2193) → **`⇓`(U+21D3)**, 단 가운데 정렬. **선택형 요약에서는 화살표를 지운다.**
2. `<조건>` → **`<조 건>`**, `<보기>` → **`<보 기>`** (두 글자 라벨은 가운데 공백)
3. 출처 태그 `[YY년 M월 N번]` `[N과]` **제거**
4. 발문 끝·지문 앞의 인라인 정답 **제거**
5. (A)(B) 짝 선지: 탭 정렬 유지 + 머리행 `(A)` `(B)` 에 **밑줄** 추가
6. 순서 선지 **3열 → 2열**로 재배치 (원고는 `① (A)-(C)-(B)\t② …\t③ …`)
7. 삽입 자리표시 `(A)~(E)` → **`(ⓐ)~(ⓔ)`**, 선지줄 `① (A)` → `① ⓐ`
8. 배점 생성 — 선택형 합 90 / 서답형 합 10
9. 머리표 문항번호 칸은 **원고 실제 개수**(객관식 27 / 서답형 3)로

**치명적**

4. **1쪽에서 `다음 쪽에 계속 ⬇` 가 본문 선지 위에 겹쳐 인쇄된다.**
5. **서답형 라벨이 겹쳐 나온다** — 텍스트층에 `<서답형 1>` + `<서답형 1번>` 두 벌.

**표기·서체**

6. **첫머리 안내문 `※ 문제를 정확하게 읽고 옳은 답을 답안지에 표기하시오.` 를 넣고 있다.**

7. **본문 서체가 BatangChe(바탕체)** — 라틴이 고정폭이라 영문이 타자기처럼 벌어진다.
   정본 라틴은 **비례폭 명조**다. (크기 12pt(B4)는 맞다.)
8. **선지 이어지는 줄에 내어쓰기가 들어간다.** 정본은 **내어쓰기 0**.
9. **지문 첫 줄 들여쓰기가 없다.** 정본은 1글자(B4 3.9mm).
10. **어법·어휘 마커 뒤에 공백** — 현행 `ⓐ independence`, 정본 `ⓐindependence`.
11. **꺾쇠 안쪽에 공백** — 현행 `< How to Write an Essay >`, `< 보 기 >`.

**요약·짝선지·각주**

7. **`다음 쪽에 계속` 화살표의 코드포인트.** 굵은 아래 화살표라는 형태만 확실하고
   `⬇`(U+2B07)은 형태 근사치다.
8. **긴 각주의 정렬.** 오른쪽 정렬은 표본 8건으로 확실하지만, 두 줄이 될 때 왼쪽으로
   흐른 표본이 1건(26-1-중간 8쪽) 있다.
9. **상자 테두리 굵기.** 스캔에서 0.5pt 로 근사했다. 쪽 테두리(1.0pt)보다 확실히
   가늘고 단 괘선과 비슷하다는 것까지만 확인됐다.
