### ⚠ 판형 정정 — 세종은 B4 가 아니라 A4 다

지시서에 "세종은 실제 시험지 판형이 B4(257.2×364.1mm)라 환산 계수가 거의 1"이라는
힌트가 있었으나 **틀렸다.**

- 세 PDF 모두 MediaBox 는 729×1032pt(= 257.2×364.1mm, B4)다. 여기까지는 힌트대로다.
- 그런데 내용 스트림 첫 줄의 클립 패스가
  `0 1032 m 597.36 1032 l 597.36 185.88 l 0 185.88 l h W n` —
  이 사각형은 **597.36 × 846.12pt = 210.0 × 298.4mm = A4** 다.
- 즉 한글 편집용지는 A4 이고, 맥에서 "B4 용지"로 인쇄해 A4 조판면이 B4 캔버스
  좌상단에 그대로 얹힌 것이다. (메타: `creator=한글`, `producer=macOS Quartz PDFContext`)
- 실제 본문은 x 16.4~195.1mm, y 16.3~287.3mm 만 차지한다. B4 로 보면 우측 62mm ·
  하단 77mm 가 통째로 비는 셈인데, 정본 사진에서는 본문이 종이 폭을 거의 채운다.
- A4 로 보면 여백이 **좌 16.4 / 우 15.6 / 상 16.3 / 하 9.7mm** 로 지극히 평범하다.

**결론: 환산 계수 = 257 ÷ 210 = ×1.2238** (배재1의 1.2244와 사실상 동일).
아래 수치는 전부 B4 환산치, **괄호가 정본 실측치(A4)** 다.

### 3.3 푸터

하단 가로 괘선(y 336.0) 아래로 두 줄:

```
☞ 본 시험문제 정답 및 해설의 저작권은 서울세종고등학교에 있습니다. 무단전송ㆍ복제ㆍ배포시 저작권법에 의거 처벌될 수 있습니다.
                    1 / 8        (     )학년 (    )반 (    )번 성명 :  (             )
```

| 요소 | 값 |
|---|---|
| 저작권 | 가운데, Gulim 9.85 / 8.05pt, y 340.0 (277.8), x 36.2~221.6 (29.6~181.1). **줄 전체에 밑줄**(y 344.0 / 281.1, 0.36pt). 매 쪽 반복. |
| 쪽번호 | `{p} / {n}` — 숫자 사이 공백. Gulim 10.94 / 8.94pt, y 346.9 (283.5). |
| 기입란 | `(     )학년 (    )반 (    )번 성명 :  (             )` — Gulim 11.76 / 9.61pt, 같은 줄 오른쪽. |

**문자 주의**
- 머리 글리프는 **`☞` U+261E**. `▶`·`※` 가 아니다.
- 구분자는 **`ㆍ` U+318D (한글 아래아)**. 가운뎃점 `·`(U+00B7)도 `・`(U+30FB)도 아니다.
  (렌더된 화면에서는 가운뎃점처럼 보인다. 현행 산출물도 U+318D 로 맞게 쓰고 있으니 건드리지 말 것.)
- 기입란 괄호 안 공백 수를 실물 그대로: **학년 5칸 / 반 4칸 / 번 4칸 / 성명 13칸**,
  `성명 :` 뒤에 **공백 두 칸** 후 여는 괄호.

### 3.4 계속 표시

```
【다음 페이지에 계속됩니다.】
```

`【 】` = U+3010 / U+3011, 괄호 안쪽 공백 없음. **마지막 단(2단)의 맨 끝 줄,
오른쪽 정렬.** 마지막 쪽에는 넣지 않는다.

> **묶음이 아니라 진짜 '다음 쪽 계속' 표시다.** (지시서에서 확인을 요청한 항목)
> 26-1-기말 8쪽 중 5쪽(2·3·5·6·7쪽)에 나오는데, 5·6·7쪽은 2단 맨 아래 오른쪽으로
> 정상 배치, **2·3쪽은 1단 맨 위**에 있다. 후자는 앞 쪽이 하단 괘선까지 꽉 차서
> 문단이 밀려난 원고 사고다(앞 쪽에 여백이 0). 4쪽에는 없는데, 4쪽에서 문항이 딱
> 끝나고 5쪽이 새 문항으로 시작하기 때문이다.
> → **쪽 경계에서 지문/문항이 잘릴 때만, 쪽 마지막 줄 오른쪽에.**

회차 변동:

| 회차 | 문구 |
|---|---|
| **26-1-기말** | `【다음 페이지에 계속됩니다.】` (오른쪽 정렬) |
| 26-1-중간 | `☞ 다음 장에서 이어집니다.` / `☞ 서답형 5번, 6번 문제가 다음 장에서 이어집니다.`(2줄) — 단 가운데 정렬, 13.07 / 10.68pt |

## 5. 문제 유형별 차이

**결론: 균일하다.** 26-1-기말 8쪽 · 26-1-중간 8쪽을 전수로 훑어 유형별 편차를
찾았으나, 지문 첫 줄 들여쓰기(1.7mm) · 선지 내어쓰기(0) · 행간(14.4pt)은
어휘 · 빈칸 · 순서 · 삽입 · 요약 · 장문 · 서답형 **전부에서 같다.**
유형이 바꾸는 것은 **배치**뿐이다.

| 유형 | 배치 차이 |
|---|---|
| 어휘 | 밑줄 낱말에 ①~⑤ 인라인. 선지가 없거나 **인라인 5열 격자**(`①ⓐ ②ⓑ ③ⓒ ④ⓓ ⑤ⓔ`) |
| 빈칸 | 지문 안 밑줄 공백. (A)(B) 둘이면 선지가 **열 표**로 바뀜 |
| 순서 | 주어진 글 = **캡션 없는 사각 상자**, (A)(B)(C) 문단은 상자 아래 각각 빈 줄로 띄움, 선지 **2열 격자** |
| 삽입 | 주어진 문장 = **캡션 없는 사각 상자**, 지문 안 자리 표시 `( ① )` |
| 요약 | 요약문 = `<요 약>` **캡션이 상단선에 걸친 상자**, 아래에 (A)(B) 열 표 |
| 장문 | 묶음 머리 `[a-b]` 로 묶고 지문 1회 게재, 멤버 발문은 `위 글의 …` |
| 서답형 | 라벨 `서{n}.`, **배점 미표기**, 답란 밑줄, 조건/보기는 캡션 상단선 상자. 선택형 24문항이 전부 끝난 뒤 별도 구역 |

## 6. 보기 / 조건 / 요약 / 주어진문장 — **여기가 세종의 얼굴이다**

### 6.1 `<보 기>` · `<조 건>` · `<요 약>` = **캡션이 상단 테두리 선에 걸친 상자**

테두리 사각형을 그리되 **상단 가로선을 캡션 폭만큼 끊고 그 자리에 캡션을 앉힌다.**
캡션 베이스라인이 상단선보다 살짝 위에 있어 선 위에 걸친 모양이 된다.

```
 ───────────────  <보 기>  ───────────────
│ he / did / a classic combination / he / know / created /│

### 6.2 캡션 표기 — 자간을 벌린다

정본에 두 형태가 공존한다(예: 조건 상자 안 `[조건 1] <보기>의 단어들 중, …`).

```

### 6.4 조건 항목 마커 — 회차·문항마다 다르다

### 6.5 주어진 글 / 주어진 문장 — **캡션 없는 완전한 사각형**

<보기>/<조건>과 **다르다.** 상단선을 끊지 않는다. 0.24pt, 상자 폭은 단 폭에 맞춤,

## 7. 문항 묶음 표기 — **세 가지 형태**

전부 26-1-기말에서 관측됐다. 대괄호 안쪽 공백 없음, 닫는 괄호 뒤 한 칸.

### (a) 지문 공유형 `[{a}-{b}] {지시문}`

```
[10-11] 다음 글을 읽고, 물음에 답하시오.
  (공유 지문)
10. 위 글의 내용과 일치하지 않는 것은?
  ① … ⑤
11. 위 글의 빈칸 (A)에 들어갈 말로 가장 적절한 것은?
  ① … ⑤
```

멤버가 각자 발문을 갖고 지칭어는 **`위 글의 …`**(`윗글` 아님).
지시문 `다음 글을 읽고**,** 물음에 답하시오.` — **쉼표가 있다**(원고는 없다).

### (b) 발문 공유형 `[{a}-{b}] {공통발문}` — **세종 방언**

```
[14-15] 다음 글의 내용과 일치하지 않는 것은?
14.
  (14번 지문)
  ① … ⑤
15.
  (15번 지문)
  ① … ⑤
```

**발문이 공통이고 지문이 각각**이다. 묶음 머리에 발문 전체가 오고,
각 멤버는 **번호만 단독 줄**에 놓은 뒤 다음 줄부터 자기 지문·선지를 갖는다.
다른 학교에 없는 형태이므로 조판 엔진이 반드시 지원해야 한다.

### (c) 선택형+서답형 혼합 `[객관식 {n}번, 서술형 {m}번]`

```
[객관식 24번, 서술형 1번]
24. 글의 흐름으로 보아, 주어진 문장이 들어가기에 가장 적절한 곳은?
```

**지시문이 없다.** 라벨만 한 줄이고 곧바로 멤버 발문이 이어진다.
낱말이 `서답형` 이 아니라 **`서술형`** 이고, 두 번호 모두 **`번`** 이 붙는다.

### 범위 구분자 — 회차마다 흔들린다

| 회차 | 구분자 | 예 |
|---|---|---|
| **26-1-기말** | **하이픈 `-` (U+002D), 공백 없음** | `[10-11]` `[14-15]` |
| 26-1-중간 | 물결 `~` | `[1~4]` `[15~16]` · 혼합 `[5~6, 서답형 1]` `[8~9, 서답형 2번]` `[19, 서답형 3번]` |
| 25-2-중간 | 물결 연산자 `∼` (U+223C) | `[1∼2]` `[3∼4]` |

**직전 회차 기준으로 하이픈.**

## 8. 서답형 라벨과 구역

### 8.1 라벨 = `서{n}.`

```
서1. 위는 벤자민 프랭클린의 일과에 대한 글의 일부이다. 밑줄 친 우리말 (A)와 (B)에 맞게 <보기>의 단어들을 아래 <조건>에 맞게 사용하여 영작하시오.
서2. 글의 빈칸 (A)와 (B)에 들어갈 내용을 문맥에 맞는 적절한 영어 표현으로 쓰시오. [(A),(B)에 각각 최소 3개 이상 최대 5단어까지 사용하여 완성할 것]
```

- **단 왼쪽에 붙여** `서1. ` 로 시작하고 곧바로 발문이 이어진다.
- 대괄호도 `서답형` 세 글자도 쓰지 않는다.
- 선택형과 **별개 카운터**(서1~서6).

> ⚠ 지시서 힌트 `[서답형 1번]` 은 **26-1-중간** 값이다. 직전 회차(26-1-기말)에서
> `서{n}.` 로 바뀌었다. (26-1-중간에는 `[서답형. 4번]` 이라는 오타도 있다.)

### 8.2 서답형 구역 머리 블록 — 26-1-기말 신설

선택형 24문항이 전부 끝난 뒤:

```
              [서답형 6문항, 총 30점]
┌──────────────────────────────┐
│ ※ 답안 작성 시 유의사항                        │
│ 1. 답안지의 문항번호와 답안이 일치하도록 작성하시오. │
│   (문항번호와 답안이 일치하지 않는 경우 0점 처리됨) │
│ 2. 소문항 및 기호(예: (1), (2), (A) 등)를 명확히 작성 │
│    하시오.                                   │
│ 3. 문장의 첫단어는 대문자로 시작하시오.           │
└──────────────────────────────┘
```

- 제목 `[서답형 6문항, 총 30점]` — 가운데, 볼드, 본문보다 큼(약 13.5pt B4, **추정**).
- 상자는 **캡션 없는 사각형**, 0.24pt.
- `※ 답안 작성 시 유의사항` 은 볼드·나머지보다 큼.
- 1번 항목의 괄호 줄 `(문항번호와 … 0점 처리됨)` 은 **볼드 + 밑줄**.
- 항목 되풀이 줄은 숫자 아래로 들여씀(여기만 내어쓰기가 있다).
- 26-1-중간에는 이 블록이 없다.

## 9. 배점 표기 — **문항에 안 쓴다**

**세종은 문항 옆에 배점을 전혀 쓰지 않는다.**

### 12.2 ⚠ 정답 누출 — **이 원고는 정답을 본문에 심어 놓는다**

**선택형**: 발문 줄 맨 끝에 정답 원문자가 붙는다.

```
다음 글의 밑줄 친 부분 중, 문맥상 낱말의 쓰임이 적절하지 않은 것은? ④
주어진 글 다음에 이어질 글의 순서로 가장 적절한 것은? ④
```
→ 발문 종결(`?`/`.`) 뒤 공백 + 단독 원문자면 제거.

**서답형**: 발문 뒤에 정답 문장이 그대로 이어 붙는다.

```
서답형 1. … 문장을 완성하시오. 단, 필요시 어형 변화 가능. I thought of what was valuable in life
서답형 3. … 작성하시오. 단, 필요시 어형 변화 가능. (A) judgment, (B) intentions
서답형 5. … 쓰시오. (A) an hour, (B) melting chocolate, (C) Yosemite National Park, (D) scenery, (E) …
```
→ 발문 종결 어미(`…시오.` / `…것]`) 이후 잔여 텍스트는 정답이다.

현행 산출물에는 이 정답들이 인쇄되지 않았다(제거 로직이 이미 도는 것으로 보인다).
그래도 **게이트로 못 박아 둘 것.**

### 12.3 정규화 목록

1. 발문 끝 정답 원문자 제거 / 서답형 발문 뒤 정답 텍스트 제거
2. `[N과]` 과 표시 제거
3. `서답형 {n}.` → `서{n}.`
4. `다음 글을 읽고 물음에 답하시오.` → `다음 글을 읽고**,** 물음에 답하시오.`
5. 요약 화살표 `↓`(U+2193) → `⬇`
6. 순서 선지 구분자 en dash `–`(U+2013) → 하이픈 `-`
7. (A)(B) 짝 선지 구분자 `……` 제거 후 열 정렬
8. `<보기>` / `<조건>` → **상자 캡션으로 쓸 때만** `<보 기>` / `<조 건>` 으로 벌림
   (발문·조건 본문 안 언급은 붙여 쓴 채로 둔다)
9. 한 줄에 붙어 있는 선지 분리
   (`① (A) – (B) – (C)② (B) – (A) – (C)`, `① ⓐ, ⓑ, ⓒ② ⓑ, ⓒ, ⓓ③ …`)
10. 원고 지문 문단 사이 빈 줄로 인한 문단 쪼개짐 정리 — 정본은 한 지문이 이어진 문단
11. 묶음 멤버 발문 지칭어 `윗글` → `위 글` (26-1-기말 기준)

## 13. 현행과 달라 고쳐야 할 것

대조 대상: `~/Documents/…/동형모의고사/고1/26-1-기말/세종고/세종1_동형모의고사(1회).pdf`
(B4 257×364, **5쪽**)

### 뿌리 — 확대 계수를 글자에 안 먹였다

판형은 이미 B4 로 맞다(제품 상수라 옳다). 그런데 정본 A4 → B4 확대(**×1.2238**)를
**글자 크기·행간·들여쓰기·괘선 두께에 함께 적용하지 않았다.**

| | 현행 | 정본 환산 |
|---|---|---|
| 지문 크기 | 9.0pt | **11.01pt** |
| 행간 | 10.7pt | **17.62pt** |
| 지문 첫 줄 들여쓰기 | 4.0mm | **2.1mm** |
| 발문 한글 장평 | 약 72% | **압축 없음** |

그래서 정본 8쪽 분량이 5쪽으로 줄었다. 아래 다수 항목의 뿌리다.

### 빠진 요소

1. **마무리 문구가 아예 없다.** → `- The End -`
2. **배점표가 없다.** 마지막 쪽 서답형 6 답란 아래가 통째로 빈 채 끝난다.
   → 마무리 아래에 가로 3밴드 13열 배점표(선택형 24 + 서답형 6)
3. **계속 표시가 없다.** → 쪽 경계에서 잘릴 때 마지막 단 끝 오른쪽에 `【다음 페이지에 계속됩니다.】`
4. **서답형 구역 머리 블록이 없다.** → `[서답형 6문항, 총 30점]` + `※ 답안 작성 시 유의사항` 상자
5. **저작권 문구 밑줄이 없다.** → 줄 전체에 0.36pt 밑줄

### 표기가 틀린 것

6. **서답형 라벨이 원고 표기 그대로다.** 현행 `서답형 1.` → **`서1.`**
   게다가 라벨의 단 왼쪽 붙임이 들쭉날쭉하다 — 서답형 1·3 은 단 원점보다 **4.0mm 안으로**
   밀려 있고(x 135.5, 단 원점 131.5) 서답형 2·4·5·6 은 붙어 있다. 정본은 전부 붙는다.
7. **묶음 머리가 만들어지지 않는다.** 원고의 `다음 글을 읽고 물음에 답하시오.` 를
   번호 없이 그대로 인쇄한다. → `[3-4] 다음 글을 읽고, 물음에 답하시오.`,
   서답형이 섞이면 `[객관식 24번, 서술형 1번]`.
   현행에서 유일하게 잡힌 묶음은 4쪽의 `[25~26] 다음 글을 읽고 물음에 답하시오.`
   뿐인데 결함이 넷이다 — ① 구분자가 물결(정본은 하이픈) ② **선택형이 24문항인데
   25·26 번호가 나왔다**(서답형을 선택형 번호열에 넣어 세는 계산 오류) ③ 같은
   좌표(x 19.8, y 294.9)에 **두 번 그려져 있다** ④ 지시문에 쉼표가 없다.
8. **`<보기>` / `<조건>` 캡션이 붙어 있다.** → `<보 기>` / `<조 건>`
9. **순서 선지 구분자가 en dash.** 현행 `① (A) – (B) – (C)` → `(A) - (B) - (C)`
10. **요약 화살표가 원고 그대로 `↓`.** → `⬇`
11. **문항 번호만 크게 조판했다.** 현행 번호 `1.` 은 BatangChe **12.0pt**, 발문은
    HCRDotum **9.5pt**. 정본은 번호와 발문이 **같은 크기·같은 고딕 계열**(9.0pt)이다.
    번호를 키우는 것은 배재 방식이지 세종이 아니다.
12. **푸터 기입란 괄호 안 공백 수가 다르다.**
    현행 `(       )학년 (     )반 (      )번 성명 :   (                  )`
    → `(     )학년 (    )반 (    )번 성명 :  (             )`
13. **1쪽 안내 상자 문구가 26-1-중간 판이다.**
    현행 `※ 선택형 24문항 70점, 서답형 6문항 (각각 5점) 30점` / `= 총 100점`
    → `*선택형 (24)문항 70점, 서답형 (6)문항 30점` / `총 100점`(둘째 줄 가운데)

### 상자 형태가 틀린 것

14. **`<보기>`/`<조건>` 상자가 캡션을 상단선에 걸치지 않는다.**
    현행은 완전한 사각형 안에 캡션을 첫 줄로 넣거나(보기) 캡션을 상자 바깥에 둔다(조건).
    → 상단 가로선을 캡션 폭(B4 20.4mm)만큼 끊고 그 자리에 캡션.
    **세종 조판에서 가장 눈에 띄는 차이다.**

### 조판 사고

15. **발문 한글이 장평으로 눌려 어절이 붙어 보인다.**
    텍스트에는 공백이 정상적으로 들어 있다(추출값 `1. 다음 글의 밑줄 친 부분 중, …`).
    그런데 렌더 결과는 `다음 글의밑줄친부분중,문맥상낱말의쓰임이적절하지않은것은?` 처럼 붙는다.

    정본은 압축이 없다(9.0pt 자당 약 3.0mm). 한글 word-spacing 이 장평에 같이 눌린 것이 원인.
16. **지문이 문단마다 빈 줄로 끊겨 있다.** 원고 줄바꿈이 그대로 문단 경계가 됐다.
    → 한 지문 = 빈 줄 없는 하나의 문단.

18. **쪽번호 총수가 하드코딩돼 있다.** 5쪽 문서에 `1 / 8` ~ `5 / 8`.

## 14. 자료가 없어 못 정한 것

1. **정본(26-1-기말)이 휴대폰 사진이라 mm/pt 를 하나도 못 쟀다.**
   지면 골격·서체·크기·행간·상자 치수는 전부 26-1-중간 값이고, 두 회차가 같다는
   근거는 사진 육안 대조뿐이다. → **26-1-기말의 원본 PDF(사진 아님)가 필요하다.**
2. `[서답형 6문항, 총 30점]` 제목과 `※ 답안 작성 시 유의사항` 상자의 글자 크기·상자
   치수는 사진 비율 추정치다(제목 약 13.5pt B4).
3. **요약 화살표의 정확한 코드포인트를 확정 못 했다.** 굵고 속이 찬 아래 화살표라
   U+2B07 로 근사했으나, 한글 딩벳(사설 영역 글리프)일 가능성이 있다.
4. `- The End -` 의 서체·크기가 추정이다(세리프 볼드 약 12pt B4).
5. **배점표의 mm 치수**(칸 폭·행 높이·표 위치)를 26-1-기말에서 못 쟀다.
   26-1-중간의 세로형 표 치수는 형태가 달라 그대로 쓸 수 없다.
6. **개별 문항 배점**(2.7·2.8·…)은 학교가 정하는 값이라 동형에서는 사용자가 넣어야 한다.
   정본 값을 그대로 베끼면 안 된다(문항 유형이 다르다).
   확정된 것은 총합 규칙뿐 — **선택형 70.0 / 서답형 6문항 각 5점 = 30.0 / 계 100.0.**
7. 25-1-중간·25-2-중간은 본문이 이미지라 마무리 문구·서답형 라벨·묶음 혼합 표기를
   확인하지 못했다. **회차 변동 추적이 2회차분(26-1-중간·기말)밖에 안 된다.**
8. 묶음 세 형태(지문 공유 / 발문 공유 / 혼합) 중 어느 것을 쓸지는 문항 유형이
   결정하는데, "멤버 발문이 같으면 발문 공유형" 이라는 규칙이 **두 회차 4개 표본**
   에서만 검증됐다.
