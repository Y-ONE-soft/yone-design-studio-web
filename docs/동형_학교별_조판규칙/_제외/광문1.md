## 5. 문제 유형별 차이

**균일하지 않다.** 광문 고1은 유형마다 상자·배치가 눈에 띄게 달라진다. 아래가 실제로 갈리는 지점이다.

| 유형 | 갈리는 지점 |
|---|---|
| 어휘 (1~6번) | 지문이 아니라 **한 문장**. 번호 뒤에 바로 이어 쓰고 문단 들여쓰기 없음. 선지는 **한 줄에 여러 개 흘려 놓기**(5개가 들어가면 한 줄, 안 들어가면 3+2). 대상 낱말에 밑줄, 빈칸형은 밑줄 공백. |
| 빈칸 | 본문 안 긴 밑줄 공백 + 마침표. 그 밖은 균일. |
| 순서 | 주어진 글을 **얇은 상자**에. 선지는 **한 줄에 두 개(grid2)**, 항목 구분자 ` - `. *(26-1-기말에 순서 문항이 없어 25-1-중간 8번에서 가져옴)* |
| 삽입 (20번) | 주어진 문장을 **얇은 상자**에 넣어 **발문 아래·지문 위**. 지문 안 자리 표시 `( ① )`. |
| 요약 (23번·서답형 7) | 지문 → **`⇩` 단독 줄 가운데** → **요약문 얇은 상자** → (A)(B) 열 표. |
| 도식 (26번·서답형 4) | 제목을 `[…]` 로 감싸 **단독 줄 가운데·굵게**. 그 아래 얇은 상자를 세로로 쌓아 화살표로 잇는다. 첫/마지막 칸은 글자 가운데 정렬 + 회색 바탕, 가운데 칸들은 왼쪽 정렬. |
| 장문 묶음 (10~12) | 지문이 **굵은 상자**(신문 기사). 묶음 머리 아래에 번호+발문+배점이 이어진다. 들여쓰기 차이 없음. |
| 두 글 연계 ([A]/[B]) | `[A]` `[B]` 를 **단독 줄 가운데 정렬**. 상자 없음. 두 글 사이 빈 줄 하나. |
| 안내문/매뉴얼 (15번) | 캡션 `[SMART SALES MANUAL]` 을 **단독 줄 가운데**, 그 아래 **굵은 상자** 안에 ①~⑤ 목록. |
| 서답형 | `[서답형 N]` 굵게 인라인 + 발문 + `(기호표기 필수)` + 배점. 답란은 발문·지문 아래. **답란이 단 끝에 걸리면 다음 단 맨 위로 넘어간다**(정본 8쪽 서답형 4: 지문·도식 1단, 답란 (a)~(f) 2단 맨 위). |

**밑줄 관행** — 발문의 부정 조건 낱말에 밑줄(`틀린`, `않는`, `관계없는`, `먼`). 지문의 어법·어휘
대상 어구에 밑줄. 인용 어구는 밑줄 + 큰따옴표(`"heal their wounded hearts"`).

**각주** — `*unjust 부당한` 처럼 별표 + 낱말 + 우리말. 지문 맨 끝 **오른쪽 정렬**
(상자 지문이면 상자 안 오른쪽 아래). 25-1-중간에는 왼쪽 정렬 각주도 있었다.

## 6. 보기 / 조건 / 요약 / 주어진문장 — **광문은 거의 다 상자다**

- **`<보기>` = 얇은 테두리 상자 + 상자 안 왼쪽 첫 줄에 캡션.**
  캡션이 상자 밖에 있거나 테두리 선에 걸치지 않는다. 상자는 단 폭 전체.
  ⚠ 25-1-중간은 `<보기>` 를 **상자 위 가운데**에 놓았다(실측 x 147.2 = 단 중앙). **직전 회차 기준이므로 상자 안 왼쪽.**
  - 낱말 목록을 주는 워드뱅크형은 같은 상자 안에서 `낱말 / 낱말 / 낱말` 로 **슬래시** 구분해 흘린다(8쪽 서답형 4).
- **`<조건>` 표기를 쓰지 않는다.** 두 회차 어디에도 없다. 서답형 작성 지시는 발문 안에
  괄호로 붙인다 — `(기호표기 필수)`, `(어형변화 금지)`, `(필요시 어형을 변화시킬 것)`.
  - 조건 대신 **'기준 목록 상자'** 가 나온다: 캡션을 대괄호로 감싸 상자 안 첫 줄 왼쪽에 놓고
    항목은 가운뎃점 `·` 로 단다 — `[Chloe's Values (from her writing task)]` (6쪽 32번).
- **요약문은 얇은 상자.** 라벨(`<요약문>`)은 인쇄하지 않는다. 빈칸은 `(A) ______`.
- **주어진 문장/주어진 글도 얇은 상자.** 안여백 좌·상 약 1.1~1.3mm(A4 실측).

| **굵은 상자** | **≈1.0pt (추정)** | 편지·이메일(7번) · 대화문(서답형 2) · 신문 기사(10~12) · 매뉴얼 선지(15번) · 소설(32번) · 기준 목록(32번) · 인터뷰(35번) |

> **'실물 자료를 본뜬 지문'은 굵은 테두리로 감싼다.** 일반 설명문 지문은 상자를 두르지 않는다.
> 굵기 차이는 육안으로 뚜렷하지만 촬영본이라 pt 실측이 안 된다 → 마지막 절 참조.
>
> 상자 안 **서체를 바꾸기도 한다** — 편지 지문(7번)은 본문 명조가 아니라 **고딕 계열**,
> 신문 기사(10~12)는 제목이 굵은 고딕·리드 문장이 이탤릭·본문이 명조다.
> 상자 안 모서리에 **작은 그림 아이콘**(책·전구)을 넣은 예도 있다(32번 두 상자).

## 7. 문항 묶음 표기

```
[1~3] 다음 밑줄 친 단어의 우리말 의미로 가장 적절한 것을 고르시오. [각 0.5점]
[4~6] 다음 빈칸에 들어갈 가장 적절한 것을 고르시오. [각 0.6점]
[10~12] Grandma Moyo에 대한 신문 기사를 읽고, 물음에 답하시오.
[21~22] 다음 글을 읽고 물음에 답하시오.
[서답형4, 35] 다음 글을 읽고 물음에 답하시오.
```

- **대괄호 `[ ]`, 안쪽 공백 없음.** 범위 구분자 **물결 `~` (U+007E), 앞뒤 공백 없음**
- **접두 기호 없음.** 25-1-기말 '시험지 틀'(조판 전 원안)에는 `* [1~2, 서답형 1]` 처럼 별표가
  있지만 **인쇄본에는 없다** — 원안의 편집 기호이므로 조판에서 제거한다.
- 지시문은 **같은 줄**에 이어 쓴다. 지시문 문구는 묶음마다 다르다(지문 성격을 그대로 적는다).
- **혼합 묶음은 문서에 나오는 순서 그대로** — `[서답형4, 35]`(서답형 먼저),
  `[4, 서답형 2]`(선택형 먼저, 25-1-중간 실물). 종류별로 재정렬하지 않는다.
- 묶음 안 개별 문항은 **번호 + 발문 전체 + 배점**을 모두 갖는다. 번호만 갖는 형태는 정본에 없다.
- 구성원 배점이 같으면 **묶음 머리에 `[각 0.5점]`** 을 달고 개별 문항엔 안 단다(1~3, 4~6).
  배점이 다르면 묶음 머리에 안 달고 **개별 문항마다** 단다(10~12, 21~22).

## 8. 서답형 라벨

```
[서답형 1] 다음 (a), (b)의 빈칸에 들어갈 알맞은 단어를 주어진 철자로 시작하여 쓰시오. (기호표기 필수) [총 2점, 각 1점]
```

- `[서답형 {n}]` **대괄호, 라벨만 볼드**, 뒤 발문은 보통 굵기
- 선택형과 **별도 연번**(1~7)
- 라벨 뒤에 곧바로 발문이 이어진다(별행 아님)

⚠ **학교 자체 표기가 흔들린다.** 정본 7개 중
`[서답형 1]`·`[서답형 5]`·`[서답형 6]` = 공백 있음(3),
`[서답형2]`·`[서답형3]`·`[서답형4]`·`[서답형7]` = 공백 없음(4).
25-1-중간은 6개 전부 `[서답형 N]` 으로 통일돼 있었다 → **공백 있는 형태로 통일한다.**

`(기호표기 필수)` 도 서답형 5만 `(기호 표기 필수)` 로 벌어져 있다 → **붙여 쓴 형태로 통일.**

## 9. 배점 표기

- 괄호 **대괄호 `[ ]`**, 발문 물음표 뒤에 **반각 공백 하나**를 두고 붙인다 — `… 것은? [2.0점]`
- **소수 한 자리를 항상 유지한다.** 정수여도 `[2.0점]` (`[2점]` 형태 없음)
- 발문이 길어 배점이 줄에 안 들어가면 **다음 줄 오른쪽 끝**에 배점만 단독으로(9번·34번)
- 묶음 공통 배점 `[각 0.5점]` / 서답형 `[총 3점, 각 1.5점]`
- **꼬리말('부분점수 없음' 등)을 쓰지 않는다.** 대신 발문 끝에 `(기호표기 필수)` 가 오고 그 뒤가 배점
- 머리표 총점 칸 **있음** — `선택형 35문제(70점)  서답형 7문제(30점)  [총100점]`

⚠ **괄호 종류가 회차마다 바뀐다.**

| 회차 | 배점 괄호 |
|---|---|
| 26-1-기말 (정본) | **`[2.0점]`** 대괄호 |
| 25-1-기말 (틀) | `[1.9점]` 대괄호 |
| 25-1-중간 | `(1.8점)` 둥근 괄호, 정수는 `(2점)` |

### 실제 배점 구성 (정본 전수 검산 — 합이 정확히 70.0 / 30.0)

**선택형 70.0점**

| 배점 | 문항 |
|---|---|
| 각 0.5 | 1·2·3 (어휘 의미) |
| 각 0.6 | 4·5·6 (어휘 빈칸) |
| 2.0 | 7·8·9 |
| 2.1 | 10·11·12·14 |
| 2.2 | 13·17·24·29·34 |
| 2.3 | 15·16·18·19·28 |
| 2.4 | 20·22·23·25·27 |
| 2.5 | 21·26·30·35 |
| 2.6 | 31·32·33 |

짧은 어휘 문항만 0.5~0.6 으로 낮고, 나머지는 **2.0~2.6 사이에서 0.1 단위 차등**.
대체로 뒤로 갈수록 커지지만 단조 증가는 아니다(24번 2.2, 29번 2.2).

**서답형 30.0점** — 소문항 1개당 1점 또는 1.5점, 총점 = 소문항 수 × 개당 점수.

| 서답형 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|---|---|---|---|---|---|---|---|
| 배점 | 총 2, 각 1 | 총 3, 각 1.5 | 총 3, 각 1 | 총 6, 각 1 | 총 4.5, 각 1.5 | 총 7.5, 각 1.5 | 총 4, 각 1 |

소문항 배점이 서로 다르면 풀어 쓴다 — 25-1-중간 실물
`(총 7점, (a),(b)는 각 2점, (c)는 3점)`. 26-1-기말에는 이 형태가 안 나왔다.

## 현행과 달라 고쳐야 할 것

대조할 현행 산출물이 없으므로, 아래는 **첫 산출물에서 반드시 맞춰야 할 정본 기준**이다
(사용자가 지적하기 전에 우리가 지킬 목록).

1. 배점 괄호는 **대괄호 `[2.0점]`** — 둥근 괄호 `(2.0점)` 아님. 정수도 `[2점]` 이 아니라 **`[2.0점]`**
2. 묶음 머리는 **`[1~3]`** — 대괄호·물결·안쪽 공백 없음. `【 1 – 3 】`(배재식)·`※`·`*` 접두 금지
3. 혼합 묶음은 **문서 순서 그대로** — `[서답형4, 35]`. 선택형을 앞으로 정렬하지 말 것
4. 서답형 라벨은 **`[서답형 N]`**(볼드, 인라인) — `[서술형N]`·`〔서답형N〕` 아님
5. 마무리는 **`※ 확인 사항` 두 줄 + 얇은 상자** — `- 끝 -`·`- 수고하셨습니다 -` 넣지 말 것
6. 요약 화살표는 **`⇩`(U+21E9)** — `↓`(U+2193)·`⇓`(U+21D3) 아님
7. (A)(B) 짝 선지 구분자는 **`…` 한 개(점 3개)** — `……`·`-----`·탭 정렬 아님
8. `<보기>` 는 **상자 안 왼쪽 첫 줄** — 상자 위 가운데 아님
9. 요약문·주어진 문장·`<보기>`·첫머리 안내문·마무리는 **전부 테두리 상자** — 맨줄로 흘리지 말 것
10. 실물 자료형 지문(편지·기사·대화·인터뷰·소설·매뉴얼)은 **굵은 상자**로 감쌀 것
11. 쪽번호는 **러닝 헤더 오른쪽 끝 `{p} / {n}`**(슬래시 좌우 공백) — 하단 가운데 쪽번호 아님
12. 머리표에 **결재란을 넣지 말 것**(26-1-기말에서 빠졌다)
13. **문항 번호를 본문보다 크게 키우지 말 것**(배재는 키우지만 광문은 같은 크기)

  그 문항 한정인지 회차가 더 필요하다. 이미지 원본도 없다.
- **편지 지문의 고딕 서체명 미확정.** 촬영본이라 서체명을 못 읽는다(HCRDotum 계열로 추정).
- **순서 배열 규칙이 직전 회차 것이 아니다.** 26-1-기말에 순서 문항이 없어 25-1-중간에서
  가져왔다. 선지 구분자 ` - `·grid2 배치가 26-1-기말에도 유효한지 확인 못 했다.
- **소문항 차등 배점 표기가 직전 회차 것이 아니다.** 26-1-기말 서답형 7개는 전부
  `[총 N점, 각 M점]` 균등형이었다. 차등형 문구는 25-1-중간의 둥근 괄호 실물을 대괄호로
  바꿔 추정한 것이다.
- **`[서답형 N]` 공백·`(기호표기 필수)` 공백이 학교 자체에서 흔들린다.** 정본 안에서 두 형태가
  섞여 있다. 통일 방침은 정해 두었으나 학교 확인은 못 했다.
- **단 폭 판정에 0.9mm 여유가 있다.** 25-1-중간 양끝맞춤 오른쪽 끝은 101.9 / 195.8mm(단 폭 86.9)
  인데 상자 폭 실측은 85.1~86.0mm 다. 상자 안여백 처리 차이일 수 있다.
