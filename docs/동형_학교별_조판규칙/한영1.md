## 5. 문제 유형별 차이

**들여쓰기·행간은 유형 무관 균일하다.** 유형이 갈리는 곳은 두 군데뿐이다 —
*무엇을 상자에 넣느냐*, *선지를 몇 열로 놓느냐*.

| 유형 | 상자 | 선지 |
|---|---|---|
| 어휘(낱말 쓰임) | 없음 (지문 안 밑줄 + 원문자 `①exceeds`) | 1행 1선지 |
| 어휘(문장 나열형) | 문장 상자 + `<Word Box>` 상자 | 1행 1선지 / 조합형은 **3열** |
| 빈칸 | 없음 | 1행 1선지 |
| 순서 | **주어진 글 상자**(첫 줄 들여쓰기 **있음**) | **3열** `(A)-(B)-(C)` |
| 삽입 | **주어진 문장 상자**(첫 줄 들여쓰기 **없음**) | 선지 없음 — 지문 안 `( ① )` 이 선지 |
| 요약 | **`<요약문>` 상자** (앞에 ⬇) | (A)(B) 2열 탭 표 |
| 장문 | 없음 | 1행 1선지, 선지에 `[Ⅰ]` 을 붙이기도 |
| 대화/인터뷰 | 없음 | 지문 아래 `Q. …` 볼드 발문 → 1행 1선지 |
| 서술형 | `[조건]` 상자 / `[보기]` 상자 / 낱말 상자 | 답란 |

빈칸은 **밑줄 문자열**(약 40mm)로 인쇄하고 문장 끝이면 밑줄 뒤에 마침표를 찍는다.
요약 상자 안 빈칸만 예외적으로 `( A )` 형태다.

## 6. 보기 / 조건 / 요약 / 주어진문장

**학교마다 제일 크게 갈리는 자리이고, 한영1은 회차마다도 갈린다.**

### `[보기]` — 상자, 캡션은 첫 줄 왼쪽 (26-1-기말)

```
┌───────────────────────────────────────────────┐
│ [보기]                                         │
│ 1.Renewable energy is often promoted as a way │
│   to balance electricity needs and …          │
│ 2.Renewable energy sources are completely …   │
└───────────────────────────────────────────────┘
```

- 테두리 **0.24pt**, 상자 폭 = **단 폭 전체**
- `[보기]` 는 상자 안 **첫 줄 왼쪽에 볼드**. 캡션이 상자 윗변 선에 걸치지 **않는다.**
- 항목은 `1.` `2.` … (번호와 내용 사이 공백 없음), 되풀이 줄은 내용 첫 글자에 맞춰 내어쓰기

`<Word Box>` 는 같은 상자인데 캡션이 **첫 줄 가운데**이고 내용이 4열 탭 정렬이다.

```
┌───────────────────────────────────────────────┐
│                  <Word Box>                   │
│ overtook    transcribe   outperform   impulse │
│ trivial     magnitude    deficiency   basin   │
└───────────────────────────────────────────────┘
```

> 회차 변동: 26-1-중간은 `< 보기 >`(꺾쇠 안쪽 한 칸)를 **첫 줄 가운데**에 둔다.
> **25-1-기말에서만** `< 보 기 >` 가 **상자 윗변 선에 걸쳐** 가운데 놓이고(선이 캡션
> 좌우로 끊긴다) 안쪽에 내용 상자가 한 겹 더 있는 **이중 상자**다.
> 26-1-기말·26-1-중간에는 이 형태가 없다.

### `[조건]` — 상자, 라벨 열 + 항목 열

```
┌───────────────────────────────────────────────────────────┐
│ [조건]    1. 주어진 단어(구)를 모두 사용하되, 새로운 단어는 추가하지 말 것.│
│           2. 단어의 형태는 문맥에 맞게 변형할 수 있음.              │
│           3. 묶음으로 제시된 단어(구)는 분리하지 말고 사용할 것.       │
│           4. 문장을 완성하는데 필요한 경우, 문장부호를 적절히 사용할 것.  │
│              (예시 , / . / ! / ; / :  등등)                     │
│ [단어(구)] cause / move / the digestive system / the muscles / │
│ / slow digestion and / stomach problems / blood / to / from   │
└───────────────────────────────────────────────────────────┘
```

- 라벨은 상자 첫 줄 왼쪽, 항목은 탭으로 벌린 둘째 열에 쌓인다
- 같은 상자 안에 `[단어(구)]` 같은 **다른 라벨 블록이 이어 붙기도** 한다
- 회차 변동: 26-1-중간은 `[ 조건 ]`(안쪽 한 칸) + 항목 `1)` `2)` `3)` `4)`

### `<요약문>` — 상자, 라벨은 첫 줄 맨 앞 인라인

```
                        ⬇
┌────────────────────────────────────────────────────┐
│ <요약문> People once believed that the brain could not │
│ change. However, research shows that … a skill that │
│ can be ( A ) through repetition. This suggests that │
│ people are not completely ( B ) by their current …  │
└────────────────────────────────────────────────────┘
```

- 지문 → (각주) → **⬇ 단독 줄 가운데** → 상자
- `<요약문>` 볼드가 상자 첫 줄 맨 앞에 붙고 **바로 요약문이 이어진다**(별행 아님)
- 상자 안 빈칸은 `( A )` `( B )` — 괄호 안쪽 좌우 각 한 칸
- 회차 변동: 26-1-중간은 라벨 없이 상자만 (화살표는 같음)

### 주어진 글 / 주어진 문장 — 둘 다 상자, 라벨 없음

- **순서**의 주어진 글: 상자 + 첫 줄 들여쓰기 **있음**
- **삽입**의 주어진 문장: 상자 + 첫 줄 들여쓰기 **없음** (상자 왼쪽에 붙는다)
- 지문 안 삽입 자리 표시 `( ① )` — 괄호 안쪽 좌우 각 한 칸, 앞뒤 문장과 한 칸 띄움
- (A)(B)(C) 문단은 `(A) ` 뒤에 맞춰 내어쓰기

## 7. 문항 묶음 표기

```
[3~4] 다음 글의 주제로 가장 적절한 것을 고르시오. [각 3점씩]
3.
   One way that music could express emotion is simply through …
```

- 대괄호 `[ ]`, **안쪽 공백 없음**. 닫는 `]` 뒤에 반각 공백 하나
- 범위 구분자 **물결표 `~` (U+007E)**
  ⚠ 26-1-중간은 하이픈(`[2-3]`)이었다. **직전 회차 기준 `~`.**
- 지시문은 **같은 줄**, 끝에 마침표, 그 뒤 `[각 N점씩]`
- 두 줄이 되면 둘째 줄은 **지시문 첫 글자에 맞춰 내어쓰기**(12.2mm B4)

### 구성원이 무엇을 갖는가 — 두 갈래

| 묶음 지시문 | 구성원 | 배점 |
|---|---|---|
| 지시문이 곧 발문 (`…고르시오.`) | **번호만** — `3.` `7.` `10.` `14.` `18.` | 묶음 머리에 `[각 N점씩]` |
| `…읽고, 물음에 답하시오.` | 각자 발문 — `24. 윗글 [Ⅰ]과 [Ⅱ]의 …? [3점]` | 구성원마다 |

**이 규칙이 현행과 정반대다**(§13).

### 선택형 + 서술형 혼합

```
[24, 서술형 1] 다음 글 [Ⅰ]~[Ⅱ]를 읽고, 물음에 답하시오.
```

- `[{선택형번호}, 서술형 {서술형번호}]` — 쉼표 뒤 한 칸, `서술형` 과 번호 사이 한 칸,
  여기서는 **마침표 없음**(본문 라벨 `서술형 1.` 과 다르다)
- 배점은 묶음 머리에 안 붙고 구성원이 각자 갖는다

### 장문 지문 구분

`[Ⅰ]`(U+2160) `[Ⅱ]`(U+2161) — **한중일 로마숫자**. 지문 머리에 붙고 발문 안에서도 쓴다.

```
[Ⅰ] Lateral thinking is quite distinct from vertical thinking, which is the …
21. 다음 글 [Ⅰ]~[Ⅱ]에서 답을 찾을 수 없는 질문은? [2.9점]
22. 다음 글 [Ⅰ]-[Ⅱ]를 읽고 이해한 내용으로 적절하지 않은 2개는? [2.9점]   ← 22번만 하이픈
```

22번만 `-`, 나머지는 `~`. 학교 표기가 흔들린다 → **`~` 로 통일**한다.

## 8. 서술형 라벨

```
서술형 1. 글[Ⅰ]의 빈칸 (A)~(C)에 들어갈 말을 글[Ⅱ]에서 그대로 찾아 쓰시
오.(각각 한 단어씩, 대소문자 구분하지 않음.) [6점]
    (A) ______________, (B) ______________ (C) ______________
```

- **대괄호가 없다.** `서술형` + 한 칸 + 번호 + `.` + 한 칸 + 발문
- 라벨과 발문이 **한 덩어리로 볼드**
- 선택형과 **별도 번호**(1부터). 선택형 24 → 서술형 1
- 넘치는 줄은 **단 왼쪽에 그대로 붙는다(내어쓰기 0)** — 묶음 머리와 반대
- 강조어(`두 문장을 찾아, 번호와 함께 바르게 고치시오`, `모두`, `숫자로만`)에는
  볼드 위에 **밑줄**을 겹친다

| 회차 | 라벨 |
|---|---|
| 26-1-기말 (정본) | `서술형 1.` |
| 26-1-중간 | `[서답형4]` (대괄호, 공백 없음) |
| 25-1-기말 | `[서술형4]` (대괄호, 공백 없음) |
| 한영3 2024 | `[서술형 1]` |

> 머리표 문제유형 표는 같은 것을 `서답형` 이라 부른다. 실물 불일치이므로 둘 다 그대로.

### 답란 형태 (26-1-기말 6문항 전부)

| 유형 | 형식 |
|---|---|
| 낱말 여러 개 | `(A) ______________, (B) ______________ (C) ______________` |
| 어법 고치기 | `(    )번 : ____________ ➔ ____________` × 2 (한 줄에 나란히) |
| 영작(문장) | `답 ➔ People should avoid exercising right after eating because` → 다음 줄에 단 오른쪽까지 밑줄 + 마침표 |
| 첫 글자 단어 | `답: b ______` / `d ________` (지문 빈칸이 `b______` 라 답란도 같은 글자로) |
| 숫자 배열 / 번호 나열 | `답: ______________________________________` |

`답` `답:` 라벨만 볼드, 밑줄은 단 오른쪽 끝까지.

## 9. 배점 표기

- 괄호 **`[ ]` (ASCII 대괄호)**, 발문 끝에 **반각 공백 하나** 뒤 붙인다
- 소수 한 자리. 정수는 `[3점]` (`[3.0점]` 아님)
- 묶음은 `[각 3점씩]` `[각 2.8점씩]`
- 서술형 꼬리말(`부분점수 없음` 류)은 **안 쓴다.** 대신 채점 기준을 배점 **뒤**에 괄호로:
  `[6점] (채점기준: 틀린 개수당 1점씩 감점, 최하점 0점)`

### 26-1-기말 실물 배점표 — 합계가 정확히 떨어진다

| 문항 | 배점 | | 문항 | 배점 |
|---|---|---|---|---|
| 1, 2 | 3.0 | | 16, 17 | 2.9 |
| 3~4 | 각 3.0 | | 18~19 | 각 2.9 |
| 5, 6 | 3.0 | | 20, 21, 22, 23 | 2.9 |
| 7~8 | 각 3.0 | | 24 | 3.0 |
| 9 | 3.0 | | **선택형 24문항 합계** | **70.0** |
| 10~13 | 각 2.8 | | 서술형 1, 4, 6 | 6 |
| 14~15 | 각 2.8 | | 서술형 2, 3, 5 | 4 |
| | | | **서술형 6문항 합계** | **30** |

배점 계단: **3.0(앞쪽 기본형) → 2.8(묶음 어휘·빈칸) → 2.9(중후반) → 3.0(마지막 장문)**.
총합 70.0에 정확히 떨어지도록 계단을 맞춘다. 서술형은 **4점/6점 두 값만** 쓴다.

⚠ 발문 끝 공백은 붙은 줄(`모두 고르시오.[3점]`)과 띈 줄이 섞여 있다. 짧아서 양끝정렬이
안 걸린 줄이 붙어 있으므로 원저작은 '공백 없음'으로 보이지만, 조판은 한 칸으로 통일한다.

## 11. 기타 글리프

| 항목 | 값 |
|---|---|
| 요약 화살표 | **`⬇` (U+2B07)** — 자루가 좁고 머리 날개가 뒤로 휜, 꽉 찬 굵은 화살표. 배재의 `⇓`(U+21D3, 이중선)와 다르다. 현행 산출물도 U+2B07 이고 모양이 맞는다. |
| 답란 화살표 | **`➔`** — 굵은 오른쪽 화살표 (U+2794 계열) |
| 순서 선지 구분자 | **하이픈 `-`, 앞뒤 공백 없음** — `(A)-(B)-(C)` |
| (A)(B) 짝 선지 | **구분자 문자 없음.** 테두리도 없다. 머리행 `(A)` `(B)` 각 열 가운데 + 탭 정렬. 단 폭 대비 (A)열 중심 27.8%, (B)열 중심 66.4% |
| 삽입 자리 표시 | `( ① )` |
| 장문 지문 라벨 | `[Ⅰ]`(U+2160) `[Ⅱ]`(U+2161) |
| 원문자 | `①`~`⑤` (U+2460~), `ⓐ`~`ⓔ` (U+24D0~) |
| 밑줄 관행 | 발문 강조어 = 볼드 + 밑줄 겹침 / 지문 어휘·어법 = 원문자 + 밑줄(`①exceeds`) / 지문 지시 대상 = 밑줄 + 볼드(`(A) the latter`) |
| 각주 | `* 표제: 뜻 ** 표제: 뜻` 오른쪽 정렬 (26-1-중간에는 `•` 를 쓴 줄도 있다) |

```
객관식 26, 서술형 6      ← 1회

```

| 항목 | 원고가 주는가 |
|---|---|
| 선택형 번호 | **안 준다** — 발문 문장으로 바로 시작. 조판이 1부터 붙인다 |
| 서술형 표시 | **준다** — `서술형1.` `서술형2.` … (**공백 없음**). 기출은 `서술형 1.` 이므로 공백을 넣는다 |
| 묶음 표시 | **준다** — `[9~10] 다음 글의 밑줄 친 부분 중 어법상 어색한 것은?`. 물결표도 원고가 `~` 로 준다 |
| 혼합 묶음 | **안 준다** — 서술형을 전부 뒤에 몰아 놓는다. `[24, 서술형 1]` 은 지문 공유를 판정해 조판이 만들어야 한다 |
| 배점 | **안 준다** — §9 계단표대로 조판이 배정한다 |
| 선지 마커 | `①~⑤`, `ⓐ~ⓔ`, `(A)(B)(C)`, 보기 항목 `1.~11.` |
| 상자 표기 | `<보기>` `< 보기 >` `<조건>` `<조 건>` (한 원고 안에서 흔들린다) |
| 출처 태그 | **준다 — 지워야 한다** |

### 출처 태그 — 세 계열이 다 나온다

```
다음 글의 괄호 (A), (B), (C) 안에서 … 가장 적절한 것은? [21년 11월 22번]
 [1과]
 [24년 3월 21번]
서술형2. 다음 글을 읽고, … 완성하시오. … [H1-1809 20번]
```

발문 끝에 붙거나 묶음 구성원 지문 앞에 **단독 줄**로 온다. 기출에는 인쇄되지 않으므로
전부 제거한다. **날짜형(`[YY년 M월 N번]`)만 잡는 정규식으로는 `[1과]` 와
`[H1-1809 20번]` 을 놓친다.**

### 정규화가 필요한 것

- `↓`(U+2193) → **`⬇`(U+2B07)**
- `<보기>` `< 보기 >` → `[보기]` / `<조건>` `<조 건>` → `[조건]`
- 출처 태그 제거 (세 계열 전부)
- 순서 선지 `① (A) - (C) - (B)` → `① (A)-(C)-(B)` (하이픈 앞뒤 공백 삭제)
- `서술형1.` → `서술형 1.`
- 지문 첫머리 반각 공백(원고 지문은 ` Do you ever …` 로 시작) 제거 → 들여쓰기는 스타일로
- 탭 다열 선지(`① priceless\t inaccessible\t discourages`)를 (A)(B)(C) 탭 표로
- `➀~➄` 섞이면 `①~⑤` 로

### 그 밖에 알아 둘 것

- 지문은 모두 **선행 공백 한 칸**으로 시작한다 — 문단 판정 신호로 쓸 수 있다
- 어법·무관문장 유형은 지문 뒤에 `①       ②       ③       ④       ⑤ ` 처럼
  **마커만 늘어놓은 줄**이 온다(선지 내용 없음)
- 대화 지문 뒤에 `*S: Student` 같은 각주 줄이 붙기도 한다(2회)
- 답란 형태가 기출과 1:1로 대응하지 않는다. 원고 형태를 그대로 찍지 말고 §8 답란표로 옮긴다

## 자료가 없어 못 정한 것

1. **본문 글자 크기가 추정치다.** 정본이 스캔이라 두 방법이 갈렸다 —
   (a) 자연폭 mm/글자를 한영3(8.51pt 실측)과 비교 → 7.7pt,
   (b) 행간 대비 비율 → 8.2~8.6pt.
   **8.1pt(A4) / 9.9pt(B4), 오차 ±0.6pt** 로 적었다. 행간은 자기상관으로 재서 신뢰도가
   높다(9.7pt A4). 한영1의 **텍스트층 있는 기출이 한 회차라도 확보되면 바로 확정**된다.

2. **행간을 어느 쪽으로 갈지 결정이 필요하다.**
   - 26-1-기말(정본): 행간 9.7pt(A4) = **11.9pt(B4)**, 30문항 **6쪽**
   - 26-1-중간 · 한영3 2024: 행간 12.0pt(A4) = **14.7pt(B4)**, 같은 30문항 **8쪽**
   - 현행 산출물: **15.0pt(B4)**

   26-1-기말은 학교가 6쪽에 밀어 넣으려고 **눌러 짠 회차**로 보인다. 직전 회차 원칙대로면
   11.9pt 지만, 이건 '세부'가 아니라 지면 밀도 전체를 바꾸는 값이라 **사용자 확인이
   필요하다.** (현행 15.0pt 는 한영고 표준에 가깝다.)

3. **머리표·쪽번호의 서체**를 정본에서 확정하지 못했다(스캔 판독). 현행은 머리표
   HCRBatang, 푸터 NanumMyeongjo. **본문이 고딕(돋움)인 것은 확정**이다.

4. **선지 마커 뒤 공백**이 정본 안에서 섞여 있다(`① From` vs `①If`). 어느 쪽이 원저작인지
   못 갈랐다 — 공백 한 칸으로 통일하기로 정했다.
   묶음 지시문 뒤 `[각 N점씩]` 앞 공백도 같은 이유로 한 칸으로 통일.

5. **`⬇` 의 코드포인트**를 스캔에서 확정할 수 없다. U+2B07 로 잡은 근거는 현행 산출물이
   U+2B07 이고 글리프 모양이 정본과 맞는다는 것뿐이다.

6. **상자 테두리 굵기(0.24pt)·안여백**은 한영3 벡터에서 가져왔다. 한영1 스캔에서는
   비슷해 보일 뿐 실측이 아니다.

7. 정본이 **손글씨 답이 적힌 응시본**이라 일부 줄이 필기에 가려져 있다(4쪽 (A)(B) 표,
   5쪽 서술형 1 답란). 해당 줄 원문 확정은 미완.

8. **원고 선택형 수(1회 26 / 2회 25)와 현행 산출물 24가 안 맞는다.** 원고가 실제로
   줄어든 것인지 조판이 잘라 맞춘 것인지 확인이 필요하다.
