# 디자인 단위 스키마 v1

> 스키마: `core/schema/units.schema.json` · 작성 2026-09-21
> 원칙: 작은 단위로 큰 단위를 만든다. 콘텐츠는 필드(bind)로만 들어온다. 색·서체는 토큰 이름으로만 적고 값은 옷이 준다.

## 단위

| 단위 | 역할 | 안에 드는 것 |
|---|---|---|
| 원자 `atom` | 인디자인 오브젝트 하나. `text` `line` `rect` `ellipse` `image` `path` — 모두 `rotate`·`opacity` | 치수(mm)·토큰·bind |
| 부품 `part` | 원자 묶음. 콘텐츠 자리는 원자의 `bind` | 원자 |
| 블록 `block` | 유형 1개. 필드 스키마 + 모양(부품) 1개 이상. **콘텐츠 연동 단위** | 필드·모양→부품 |
| 지면 `page` | 칸(zone) 배치 + 고정 부품(러닝헤드·쪽번호). **PDF 한 면 = 지면 하나** | 칸·chrome→부품 |
| 구간 `section` | 지면 반복 규칙 + 앞 간지. STEP·PART·DAY·회차 | 지면 |
| 틀 `plan` | 구간 순서 + 앞뒤 면 + 규격. 라인업 이름 | 구간·spec |
| 규격 `spec` | 판형·도련·제본·도수 | 값 |
| 옷 `skin` | 토큰 값 + 블록별 모양 선택 + 이미지 교체 | 값 |
| 세트 `set` | 콘텐츠가 오는 단위(지문 1개 + 딸린 블록). contents 는 이것만 보낸다 | 블록 id + 필드 값 |

- 부품 안에 부품 없음, 블록 안에 블록 없음. 반복은 **세트**(블록 여러 개)와 **구간**(지면 여러 번) 두 곳에서만.
- **묶기·풀기(인디자인의 그룹)**: 원자 여럿 → 묶기(Ctrl+G) → 부품 → 풀기(Ctrl+Shift+G) → 원자. 부품 → 올리기(콘텐츠 자리 이름표 = 글상자의 bind 가 필드) → 블록 → 풀기 → 부품(지금 옷의 모양). 캔버스의 떠 있는 도구와 오른쪽 사슬에 버튼.
- `bind` 이름 = 블록 필드 이름. `sys.page_no` `sys.section` `sys.title` 은 책이 채운다.
- 토큰은 `$이름`. 옷의 `tokens.color` / `tokens.font` 에서 값을 찾는다. 없으면 조판 중단(조용히 넘기지 않는다).

### 원자 = 인디자인 오브젝트 전부 (2026-09-22)

인디자인 PDF 를 분해했을 때 잃는 게 없도록 원자를 인디자인 PageItem 에 맞췄다. 실제 납품 PDF(워크북 12면)에서 잰 것: 회전한 글 27, 반투명 14, 자유 도형 45(측면 탭·로고·화살표), 둥근 네모 38, 글 안 서식 조각 100+.

| 인디자인 | 원자 | 속성 |
|---|---|---|
| TextFrame | `text` | `text` 는 글(str) 또는 **조각 목록(rich)** `["The ", {"t":"boy","b":true,"color":"$sel"}, {"t":"2","sup":true}]` — 굵게 `b`·기울임 `i`·밑줄 `u`·취소선 `s`·위첨자 `sup`·아래첨자 `sub`·조각별 `color`·`font`·`size` (문자 스타일). 줄바꿈 `\n` = 단락. **단락 스타일** `tracking`(자간 ‰)·`indent`·`indent_first`(음수 = 내어쓰기)·`indent_right`·`space_before`·`space_after`. **텍스트 프레임 옵션** `inset`(하나 또는 [위,오른쪽,아래,왼쪽])·`valign`·`columns`·`gutter` |
| GraphicLine | `line` | `stroke.cap` = `butt`·`round`·`square` (선 끝) |
| Rectangle | `rect` | `radius` 하나 또는 [왼위, 오위, 오아래, 왼아래](분해기가 모서리마다 잰다) · `gradient` `{type: linear|radial, angle, stops:[{c:"$tok", at}]}` (fill 대신) |
| Oval | `ellipse` | `gradient` |
| Rectangle + 놓인 그림 | `image` | `fit` = `contain`(다 보이게)·`cover`(틀 채우고 자르기) · `img` `{x,y,w,h}` = 틀 안에서 그림 전체가 놓인 자리(틀 왼쪽 위 기준, 틀 밖은 잘린다 — 인디자인 프레임 안 그래픽. 분해기가 클립으로 잰다) |
| Polygon · 펜 패스 | `path` | `d` = SVG path(M L C Q Z), 좌표는 `x y w h` 상자 안 **0~1 비율** — 폭·높이를 바꾸면 따라 늘어난다. `evenodd` 구멍 · `gradient` |
| Table | 부품 | 새 원자가 아니다 — 캔버스 ②부품 탭 「표 만들기」가 머리 행 면 + 괘선(선) + 칸마다 글상자(`bind: c{행}_{열}`, 가운데 정렬·안쪽 여백)로 부품을 만든다. 칸을 원자로 고친다 |
| Group | 부품 | Ctrl+G |
| 모든 오브젝트 | 공통 | `rotate`(°, 시계 방향, 가운데 축) · `opacity`(0~1) |

분해기(`decompose.from_pdf`)의 판정: 선 1개 → `line` · `re` 또는 축에 나란한 4변 → `rect` · 곡선 4개 → `ellipse` · 4변+곡선 4개 → `rect`+`radius` · 그 밖 → `path`. 글은 `dir` 로 회전을, span 마다 서체·크기·색·굵기가 단락과 다르면 조각으로. 그림은 변환 행렬로 회전·원래 크기.
글(2026-09-22 둘째): **밑줄** = 글자 바로 밑(기준선 ~ 아래 1.5pt)의 얇은 선(≤1.6pt, 줄보다 두 글자 넘게 길지 않은 것)을 그 글자들의 `u` 조각으로 삼고 선 원자로는 안 낸다 → 콘텐츠가 바뀌어도 밑줄이 따라간다. **단락** = 오른쪽 끝이 1.5글자 넘게 이른 줄 다음은 `\n`. **내어쓰기** = 둘째 줄부터 들여 있으면 `indent` + 음수 `indent_first`. 실측(모의고사 명일1 7면): 밑줄 60개가 조각으로, 선 원자 75 → 15.
**합치기(2026-09-22 셋째)** — `decompose.group`: 원자에서 부품으로 올라가는 첫 걸음. (1) 상자(면·도형·그림, 40mm² 이상) 안에 든 것은 그 상자와 한 묶음(가장 작은 상자에) → (2) 같은 줄(세로 겹침이 작은 쪽의 절반·큰 쪽의 3할 넘음, 한쪽은 15mm 이하 — 문장 + O/X) → (3) 가로로 겹치고 세로로 1.5mm 안에 쌓인 것(발문 + 선지). 면 가장자리에 닿은 것(러닝헤드 띠·측면 탭)과 세로 괘선은 장식이라 줄·쌓임으로 안 묶고, 세로 괘선을 사이에 둔 것은 다른 단. 실측: 워크북 9면 46원자 → 후보 15(문장+O/X 줄 5개가 각각), 모의고사 3면 두 단이 갈라진다.
아직 없는 것: 탭 위치(HTML 에 없다 — 칸을 나눠 글상자 여럿으로) · 그림자·혼합 모드. 자간·여백·다단·그라디언트는 PDF 에서 못 잰다(PyMuPDF 가 shading 을 안 낸다) — 만들 때만.

## 화면의 말 (2026-09-22 결정 — 캔바 식)

사용자에게 보이는 건 다섯 말뿐. 데이터 이름은 그대로(괄호).

| 화면 | 데이터 | 캔바 | 인디자인 |
|---|---|---|---|
| 문서 | 틀 plan | 디자인 | 문서 |
| 페이지 | 지면 page | 페이지 | 페이지 |
| 요소 | 블록 block (모양 = 부품 part) | 요소·업로드 | 라이브러리·스니펫 |
| 브랜드 | 옷 skin | 브랜드 키트 | 색상 견본·스타일 |
| 원고 | 세트 set | 대량 제작(Bulk Create) 데이터 | 데이터 병합 |

원자(글상자·선·면·원·그림·도형·표)는 요소 패널의 「기본 — 직접 그리기」. 저장 단위가 아니라 재료. 그려서 글상자에 **자리 이름**을 붙이고 「★ 요소로 저장」하면 요소(블록)가 된다 — 이게 캔바의 "데이터 필드 연결"이자 우리 원고 규칙의 전부. 그룹(Ctrl+G)은 이름 없는 부품. 요소는 「그룹 해제해서 고치기」로 낱개로 풀어 고친 뒤 다시 저장.
요소 안 편집 = 더블클릭(파워포인트 그룹 안 편집): 그 페이지에서 낱개로 풀려 고치고 새로 그릴 수 있고, 「저장하고 나가기」로 같은 요소(부품·자리 목록)를 갱신해 쓴 곳 전부에 반영, 「취소」는 원래대로. 헤드리스 시험 scratchpad `edit_steps.json`. `?plan=<id>&page=<id>` 도 깊은 링크.
역할 구분: 요소·문서(틀)·브랜드 만들기는 우리(작업실), 바깥 사용자는 문서 고르기 → 브랜드 → 원고 → PDF 3단계(예정).

## 화면 · 코드

- 캔버스 `/units` (`templates/units_canvas.html`) — Canva 식이되 **왼쪽 세로 탭이 인디자인 순서의 단위**: ①원자(오브젝트) · ②부품(그룹) · ③블록(콘텐츠 자리, 「설명으로 만들기」) · ④지면(페이지 목록·흐름 설명) · ⑤틀(책 구성) | 👕옷(색·서체·모양) · 📝세트(콘텐츠, 「이 지면의 블록 자리로 세트 만들기」). 가운데 ④지면(위에 뜬 도구: 이름·옷·복제·지우기), 아래 지면 띠(번호·끌어 순서·끝의 +). 오른쪽은 고른 것의 **단위 사슬**(블록→모양→부품→원자 / 부품→「블록으로 만들기」 / 원자 속성 편집). 원자를 Shift+클릭으로 여럿 고르고 「부품으로 묶기」 → 부품 → 「블록으로」 = 단위가 올라가는 길. 자유 배치 요소 `page.items` = `[{block|part|atom, x, y, w?}]`. 깊은 링크 `/units?tab=atoms#pair`.
- 캔버스의 문서 = **틀(plan)**. `/units` 는 틀 목록(시작 화면: 「＋ 새 틀」, 틀 카드) → `/units?plan=<id>#<page>` 로 한 틀을 편다. 아래 지면 띠·＋·←/→·지우기·순서는 그 틀의 지면 순서(`planIds`: front → sections(divider, pages) → back) 위에서 움직이고, 바꾸면 틀을 한 구간으로 다시 써 저장한다. 지면은 라이브러리(공유)에 있어 다른 틀이 쓰는 지면은 라이브러리에 남긴다. 위 도구: ← 틀 · 틀 이름 · 지면 이름 · 옷 · 📖 책 미리보기(세트를 끼운 전체) · ⬇ PDF(`/api/units/pdf?plan=`, `core/units/pdf.py` 크로미움 인쇄, `--user-data-dir` 는 이 맥에서 멎으니 금지) · ⧉ · 🗑. 빈 틀엔 3단계 안내.
- 편집기 표준 기능(2026-09-22 일괄): 손잡이 8방향(Shift 비율, 요소는 폭만) · 회전 손잡이(원자, Shift 15°) · 치수 라벨 · 자(Ctrl+R)·자에서 끌어 안내선(붙음, 밖으로 끌면 삭제, `page.guides`) · 격자 5mm(Ctrl+') · 여백선 · Space+끌기/가운데 버튼 손 도구 · Ctrl +/-/0/1·프리셋·Ctrl+휠 확대 · 잠금(Ctrl+L, `item.lock`, 못 고름)·숨김(`item.hide`, 안 그림) · 레이어 패널(눈·자물쇠·▲▼) · 간격 같게·폭 같게 · 오려두기 · 한 단계 앞뒤(Ctrl+]/[)와 맨 앞뒤(Ctrl+Shift+]/[) · Tab 다음 요소 · Enter 편집 · 글상자 더블클릭 = 바로 고치기(textarea) · 오른쪽 클릭 메뉴 · 팔레트 포인터 끌기(고스트) · 폭 맞춤 기본. 시험 scratchpad `pro_steps.json`(16) · `real_input.py`(진짜 마우스).
- 화면 둘(2026-09-22): **문서 목록**(`/units`, 사이트 레일은 그대로·편집 도구는 감춘다 — `.cv.browsing`)과 **편집**(문서를 열면 `body.editing-doc` 로 사이트 레일까지 감추고 창을 독차지 — 피그마가 파일을 여는 것처럼). 목록으로 돌아가기는 위 ←.
- **대지(pasteboard)** — 캔버스 지면 둘레 20mm(`BOARD`, 미리보기 요청의 `board`, `render.Ctx.board`). 지면 밖에 놓은 요소가 잘리지 않고 회색 자리에 보인다(인디자인 대지). SVG 만 커지고 좌표계는 지면 기준 그대로 — `#paper` 는 지면 크기, `.svgwrap` 만 음수 자리로 민다(`placeBoard()`), 그래서 모든 mm 계산이 그대로다. 인쇄·책 미리보기에는 안 들어간다(`_canvas` 일 때만).
- 위 도구 줄은 문서 일만 — 「← 내 문서」 · 「⌂ 스튜디오」 · 문서 이름 · 「…」(문서 창) · 미리보기 · 검수 · PDF · 인쇄용 · 저장 상태. 페이지 복제·지우기는 아래 썸네일, 도구 설명은 도구 상자 옆(`#thint`).
- **인디자인 꼴로 압축**(2026-09-22): 위 컨트롤 바(도킹 40px — ← 내 문서 · ⌂ 스튜디오 · 문서 이름 · … · 미리보기/검수/PDF/인쇄용 · **고른 것의 X·Y·폭·배율·정렬** · 저장 상태) · 왼쪽 도구 막대 아이콘만 38px(이름은 툴팁) · 요소 패널 232px(머리의 ◧ 로 접고, 접히면 캔버스 왼쪽 손잡이 ▶ 로 편다) · 오른쪽 속성 240px · 아래 쪽 띠는 **기본 접힘**(얇은 상태 줄만, ▤ 로 편다). 1680×1050 에서 캔버스가 창의 72%(오른쪽까지 접으면 86%) · 높이 93%.
- **세로로 이어 보기**(2026-09-23, 인디자인처럼 굴리면 다음 쪽): `#pages` 안에 쪽 수만큼 칸(`.pslot`)을 세로로 놓는다. 지금 쪽 칸(`.cur`)에는 **진짜 지면(`#paper`)** 이 들어가고 나머지 칸은 그림(`pageSvg` 캐시)만 — 그래서 좌표·선택·손잡이 코드는 하나도 안 바뀐다. 굴려서 화면 가운데에 온 칸이 열린다(`#area` 의 scroll + 140ms, `flowLock` 으로 되넘어감 방지), 이웃 칸을 누르면 그 쪽이 열리고 화면에 들어온다. 상태 줄 「연속」 으로 끄면 지금 쪽만(`.cv.noflow`). 같은 지면을 문서에 두 번 넣을 수 있으므로 **id 가 아니라 칸 번호(`curIdx`·`data-i`)** 로 지금 쪽을 가린다.
- **페이지 마주보기 = 문서 설정**(2026-09-23): 오른쪽 「문서」 칸의 체크(`plan.facing`, 스키마에 있음, 안 적으면 켠 것)로 **문서마다** 켜고 끈다 — 인디자인의 파일 > 문서 설정과 같은 자리. 끄면 한 쪽씩 보이고 상태 줄 「펼침」 단추도 꺼진다(대지는 그대로 20mm).
- **펼침면 보기**(2026-09-23): 한 줄(`.prow`)에 두 쪽이 맞붙고 1쪽은 오른쪽에 선다(왼쪽은 빈 자리 `.pblank`) — 2·3 / 4·5 …. 상태 줄 「펼침」 으로 끄고 켠다(`view.spread`, 기본 켬). 맞춤 계산은 한 줄에 두 쪽이 들어가게(`cols()`), 굴릴 때도 「줄」 단위로 골라 같은 펼침면 안에서는 안 넘어간다. 맞은편 쪽을 누르면 그 쪽이 열려 바로 고칠 수 있다. 펼침 보기에선 대지를 안 그린다(`board: 0` — 옆 쪽을 덮으니까), 끄면 20mm 대지가 돌아온다. 책 조판의 짝·홀 뒤집기는 따로 — 지면 속성 「좌우 반전」(`mirror`, 짝수 면에서 좌우 반전).
- **도형 모양**(2026-09-23): 도형 도구(P)를 고르면 도구 설명 상자에 모양 7종(화살표·삼각형·체크·별·말풍선·마름모·육각형, `SHAPES`)이 나오고 고른 모양으로 그려진다(`shapeD` → `addAtom`). 그린 뒤에도 오른쪽 속성의 「모양」 에서 바꾸거나 경로 `d` 를 직접 쓸 수 있다.
