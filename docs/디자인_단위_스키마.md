# 디자인 단위 스키마 v1

> 스키마: `core/schema/units.schema.json` · 작성 2026-09-21
> 원칙: 작은 단위로 큰 단위를 만든다. 콘텐츠는 필드(bind)로만 들어온다. 색·서체는 토큰 이름으로만 적고 값은 옷이 준다.

## 단위

| 단위 | 역할 | 안에 드는 것 |
|---|---|---|
| 원자 `atom` | 인디자인 오브젝트 하나. `text` `line` `rect` `ellipse` `image` | 치수(mm)·토큰·bind |
| 부품 `part` | 원자 묶음. 콘텐츠 자리는 원자의 `bind` | 원자 |
| 블록 `block` | 유형 1개. 필드 스키마 + 모양(부품) 1개 이상. **콘텐츠 연동 단위** | 필드·모양→부품 |
| 지면 `page` | 칸(zone) 배치 + 고정 부품(러닝헤드·쪽번호). **PDF 한 면 = 지면 하나** | 칸·chrome→부품 |
| 구간 `section` | 지면 반복 규칙 + 앞 간지. STEP·PART·DAY·회차 | 지면 |
| 틀 `plan` | 구간 순서 + 앞뒤 면 + 규격. 라인업 이름 | 구간·spec |
| 규격 `spec` | 판형·도련·제본·도수 | 값 |
| 옷 `skin` | 토큰 값 + 블록별 모양 선택 + 이미지 교체 | 값 |
| 세트 `set` | 콘텐츠가 오는 단위(지문 1개 + 딸린 블록). contents 는 이것만 보낸다 | 블록 id + 필드 값 |

- 부품 안에 부품 없음, 블록 안에 블록 없음. 반복은 **세트**(블록 여러 개)와 **구간**(지면 여러 번) 두 곳에서만.
- `bind` 이름 = 블록 필드 이름. `sys.page_no` `sys.section` `sys.title` 은 책이 채운다.
- 토큰은 `$이름`. 옷의 `tokens.color` / `tokens.font` 에서 값을 찾는다. 없으면 조판 중단(조용히 넘기지 않는다).

## 화면 · 코드

- 캔버스 `/units` (`templates/units_canvas.html`) — 파워포인트·Canva 식: 왼쪽 지면 띠(번호·썸네일, 지금 지면 강조) + 「＋ 지면」(본문·빈 면·간지·표지·복제, 지금 지면 **뒤에** 끼워진다 — `POST /api/units/pages?after=<id>`, pages.json 순서 = 문서 순서). 「요소」를 누르면 지금 지면에 들어가고(아래로 쌓임), 끌어다 놓으면 그 자리. 요소는 끌어 옮기고 오른쪽 손잡이로 폭, 화살표 키 0.5mm, ⧉ 복제, ✕. 오른쪽: 판형·좌우반전·요소 목록·색(옷 토큰)·지면 순서, 요소 골랐을 땐 x/y/폭·모양. 자동 저장. 자유 배치 요소는 `page.items` = `[{block|part, x, y, w?}]` — 콘텐츠 블록 자리는 캔버스에서만 견본으로 그리고, 책 흐름(세트)에선 system 블록(머리말·쪽번호)만 그린다. 칸(zones)은 책 흐름용으로 남아 있다(라이브러리에서 고침). 깊은 링크 `/units#pair`.
- 라이브러리 `/units/library` (`templates/units.html`): 왼쪽 라이브러리·분해(PDF·그림·프롬프트), 가운데 미리보기(SVG), 오른쪽 JSON 편집. 깊은 링크 `/units/library#plans/workbook_mini`.
- 라이브러리 `catalog/_units/<kind>.json` (`core/units/store.py`) — 배포에선 볼륨이 정본, 리포는 시드(`deploy/catalog_sync.py` 가 없는 폴더만 보탠다).
- 그리기 `core/units/render.py` — 부품·블록·지면·틀을 같은 코드로. 글은 `<foreignObject>` 로 브라우저가 감고, 높이는 글자 수로 어림해 아래 원자를 민다. 부품 폭은 칸 폭에 맞춘다(가로 비례). 없는 토큰은 자홍색 + 경고.
- 분해 `core/units/decompose.py` — PDF 는 PyMuPDF(도형 → 그림 → 글 순서, 줄을 단락으로 합침, 재단선 안으로 자름), 이미지·프롬프트는 클로드(`YONE_ASSIST_MODEL`, JSON 글로 받는다).
- 시험 `tests/test_units.py`.

## 입력 → 분해 → 목록

| 입력 | 분해기 | 출력 |
|---|---|---|
| PDF 한 면 | PyMuPDF: 벡터(선·면)·글(span)·이미지가 이미 오브젝트 | `decomposed` — 원자 목록 + 잰 토큰(색·서체) + 부품 후보 |
| 이미지 | 클로드가 보고 원자로 그린다 | 같은 형식 |
| 프롬프트 | 클로드가 원자로 그린다 | 같은 형식 |

분해 결과는 라이브러리에 **후보**로 들어간다. 사람이 고르고 이름 붙이면 부품이 되고, 필드를 붙이면 블록이 된다.

## 새 것이 오면

| 들어오는 것 | 늘어나는 것 | 코드 |
|---|---|---|
| 새 문항 유형 | 블록 1 (+부품 1) | 0 |
| 같은 유형 다른 생김새 | 부품 1 + 모양 1줄 | 0 |
| 새 면 배치 | 지면 1 | 0 |
| 새 라인업 | 틀 1 | 0 |
| 새 브랜드·학교 | 옷 1 | 0 |
| 새 원자 종류(예: 표) | 원자 타입 1 | 렌더러 1곳 |
