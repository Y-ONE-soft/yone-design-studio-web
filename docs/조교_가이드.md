# 조교용 작업 가이드

> Y.ONE DESIGN 통합웹으로 조판 작업하는 방법

---

## 1. 시스템 개요

- 웹 주소: **https://yonestudio.com**
- 로그인: 아이디 `assistant` / 비밀번호 (별도 전달)
- 사용 가능 메뉴: **조판, 표지** (목업, 채팅은 비공개)
- 작업 트리거는 조교 PC에서, 실제 InDesign 작업은 Y.ONE 아이맥에서 진행

---

## 2. 사전 준비 (1회만)

### 2-1. Google Drive 데스크탑 앱 설치

1. https://www.google.com/drive/download/ 접속 → Google Drive for desktop 다운로드
2. 설치 후 본인 구글 계정으로 로그인
3. 메뉴바의 구글드라이브 아이콘에서 동기화 상태 확인

### 2-2. 공유 폴더 접근 확인

Y.ONE 관리자가 다음 폴더를 본인 이메일로 공유했는지 확인:
```
Y.ONE WEB/조판결과/
```

Finder에서 다음 경로에 보여야 합니다:
```
~/Library/CloudStorage/GoogleDrive-(본인계정)/공유 드라이브/
또는
~/Library/CloudStorage/GoogleDrive-(본인계정)/내 드라이브/.../Y.ONE WEB/조판결과/
```

### 2-3. InDesign 설치

본인 Adobe 계정으로 Creative Cloud → InDesign 2026 (또는 호환 버전) 설치.

---

## 3. 작업 흐름

### 3-1. 조판 트리거 (웹)

1. 브라우저로 https://yonestudio.com 접속
2. 로그인 (assistant 계정)
3. 조판 메뉴 → 교재 선택 → 학교/학년 선택
4. 원고 업로드 → "조판 시작" 클릭
5. 진행 상황을 페이지에서 확인 (자동 로그 표시)
6. 완료되면 PDF 다운로드 버튼 활성화

### 3-2. .indd 파일 검수/수정

작업 완료 후 약 1~2분 안에 본인 Google Drive 동기화 폴더에 결과가 도착:

```
.../Y.ONE WEB/조판결과/[학교명]_[작업ID]/
   ├── *.indd     ← 검수/수정할 파일
   ├── *.pdf      ← 최종 PDF
   └── 기타 메타데이터
```

⚠️ **중요 — InDesign 작업 규칙**

```
[금지] 구글드라이브 폴더의 .indd를 InDesign에서 직접 열기
       → 네트워크 지연/잠금으로 오류 발생 가능

[권장]
1) 작업 폴더를 본인 컴퓨터의 ~/Desktop/조판검수/[학교명]_[작업ID]/로 복사
2) 복사본의 .indd를 InDesign으로 열어서 수정
3) 저장 후 → 구글드라이브 폴더에 다시 복사 (덮어쓰기)
```

### 3-3. 작업 완료 후

수정한 .indd 파일을 구글드라이브 공유 폴더에 다시 올리면:
- 자동으로 Y.ONE 아이맥에도 동기화됨
- Y.ONE 측에서 최종본 확인 가능

## 4. FAQ

**Q. yonestudio.com에서 목업 메뉴가 안 보여요.**
A. 정상입니다. 조교 권한에서는 목업/채팅 접근이 제한되어 있습니다.

**Q. 작업 결과가 구글드라이브 폴더에 안 보여요.**
A. Google Drive 데스크탑 앱이 켜져 있는지, 동기화가 진행 중인지 확인. 5분 이상 안 보이면 Y.ONE에 문의.

**Q. .indd 파일을 직접 열어도 되나요?**
A. **안 됩니다.** 반드시 로컬로 복사 후 작업하세요. 구글드라이브 동기화 중인 파일을 InDesign으로 열면 충돌이 발생합니다.

**Q. 작업이 끝났는데 yonestudio.com에서 다운로드가 안 돼요.**
A. 페이지를 새로고침 후 다시 시도. 그래도 안 되면 Y.ONE에 작업ID 알려주기.

**Q. 동시에 두 작업을 트리거하면?**
A. 한 번에 한 작업씩만 처리됩니다 (InDesign이 동시에 두 작업 못 함). 작업이 끝날 때까지 기다린 후 다음 작업 시작.

---

## 5. 비상 연락

- yonestudio.com 접속 불가 / 작업이 멈춤 / 결과가 안 옴 → Y.ONE 관리자에게 연락
- 작업ID(URL의 일부) + 학교명 + 시간 알려주면 추적 가능
