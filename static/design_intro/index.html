Approach

교재 디자인의 목적은 장식이 아니라
학생이 더 잘 읽고, 더 잘 푸는 것.

  • 01

    읽히는 위계

    발문 · 지문 · 보기 · 해설이 눈으로 구분되도록 타이포그래피 위계를 먼저 설계합니다. 예쁘기 전에, 읽혀야 합니다.

  • 02

    학습 흐름을 따르는 조판

    필기 여백, 문항 간격, 페이지 리듬까지 실제 수업에서 쓰이는 흐름에 맞춰 지면을 배치합니다.

  • 03

    인쇄까지 책임지는 데이터

    화면용 시안이 아니라 CMYK 4도 인쇄용 PDF 기준으로 작업합니다. 재단선 · 도련까지 인쇄소에 바로 넘길 수 있는 데이터로 납품합니다.

Service 02

무엇을 만들 수 있나요.

  • 01 표지 디자인 앞면만 · 앞+뒤 · 책등 포함 전체 표지까지. 시리즈 아이덴티티를 만들고, 후속권은 리스킨으로 이어갑니다.
  • 02 내지 편집 · 조판 단어장 · 문제집 · 참고서의 본문 조판. 원고(한글 · 워드)를 받아 학습 구조에 맞는 지면으로 완성합니다.
  • 03 교재 한 권 통합 제작 표지 + 내지 + 인쇄용 PDF까지 한 권 단위 완성. 신규 시리즈는 템플릿 세팅부터 시작해 후속권 단가를 낮춥니다.
  • 04 마케팅 인쇄물 학원 리플렛 · 브로셔 · 안내물. 교재와 같은 톤으로 학원 브랜드를 정리합니다.
Process 05

의뢰에서 납품까지,
여덟 단계.

착수금 → 작업 → 최종 확인 → 잔금 → 최종 PDF 전달 순서로 진행됩니다.

최종 파일은 잔금 결제 확인 후 전달됩니다.
잔금 결제 후 인쇄용 PDF 및 디지털 PDF를 최종 전달합니다.
  1. 01
    문의 접수
    교재 종류 · 분량 · 희망 일정 · 원고 상태를 이메일로 공유합니다. (구글폼은 현재 준비 중)
  2. 02
    견적 확정
    견적서 PDF 발송 → 의뢰자 확정.
  3. 03
    착수금 결제 결제 1단계
    견적의 50% 착수금 입금 확인 후 작업 시작. 세금계산서 발행 가능.
  4. 04
    원고 전달 · 작업 착수
    정리된 원고 전달 시점부터 마감 일정 카운트 시작. 원고 지연 시 일정도 함께 밀림.
  5. 05
    시안 전달 · 수정 (2회 무료)
    초안 시안 → 1차 수정 → 2차 수정. 이후 유상 수정으로 진행됩니다(범위·비용은 별도 안내). 이 단계까지 워터마크 미리보기만 제공.
  6. 06
    최종 확인
    의뢰자가 최종 시안을 확정 → 인쇄 직전 검수 완료.
  7. 07
    잔금 결제 결제 2단계
    잔금 50% 입금 확인 후 최종 파일 전달. 잔금 결제 전에는 워터마크 PDF만 제공.
  8. 08
    최종 인쇄용 PDF 전달
    잔금 결제 후 인쇄용 PDF(CMYK 4도) + 디지털 배포용 PDF를 최종 전달합니다. InDesign 원본(.indd)은 별도 협의.
  • 최종 파일은 잔금 결제 확인 후 전달됩니다. 잔금 결제 전에는 워터마크 미리보기 PDF만 제공.
  • 소액 의뢰: 소액 작업은 작업 완료 후 일시 결제로 진행 가능.
  • 결제 방법: 계좌이체 또는 세금계산서 발행 후 입금. 카드결제 미지원.
  • VAT 별도: 견적서 · 계산서 모두 부가세 별도로 청구됩니다.
FAQ · Terms 06

계약과 권리,
미리 명확하게.

의뢰 전 반드시 확인해 주세요. 항목을 누르면 상세 내용이 펼쳐집니다.

01 계약 및 착수금 ＋

견적서 합의 + 착수금 50% 입금 시점부터 계약이 성립합니다.

  • 별도 계약서가 필요한 경우 양식을 제공합니다 (전자서명 가능).
  • 일반 의뢰는 착수금 입금 확인 후 작업 시작.
  • 소액 의뢰는 작업 완료 후 일시 결제로 진행 가능.
02 환불 기준 ＋
  • 작업 착수 전: 착수금 100% 환불
  • 작업 시작 ~ 초안 시안 전달 전: 착수금 70% 환불
  • 초안 시안 전달 후: 환불 불가 (이미 수행된 디자인 시간 비용)
  • 의뢰자 귀책 지연(원고 미전달 · 연락 두절 30일↑): 자동 종결 + 환불 불가
03 저작권 및 사용 범위 ＋
  • 최종 PDF의 사용 권리는 의뢰자에게 양도 — 인쇄, 배포, 교재 판매 등 자유롭게 활용 가능.
  • 디자인 저작권(레이아웃 · 일러스트 · 인포그래픽)은 Y.ONE DESIGN에 귀속됩니다. 의뢰자는 사용권만 갖습니다.
  • 제3자 양도 · 재판매(다른 출판사 · 학원에 디자인 자체를 넘기는 행위)는 별도 협의 후 가능.
  • 유료 폰트 · 이미지 · 스톡 소스는 의뢰자 라이선스 또는 별도 구매가 필요합니다.
04 원본파일 제공 여부 ＋

기본 납품은 인쇄용 PDF(CMYK 4도) + 디지털 배포용 PDF입니다.

  • InDesign 원본(.indd) 파일은 기본 제공이 아닙니다. 별도 협의로 진행.
  • 원본 파일 전달은 별도 협의로 진행됩니다.
  • 전달 후 디자인 사용 범위는 해당 교재 시리즈에 한정됩니다.
05 포트폴리오 사용 가능 여부 ＋

제작물은 Y.ONE DESIGN의 포트폴리오 · 홍보 자료로 사용될 수 있습니다 (웹사이트 / 영업 자료). 이때 학교명 · 강사명 · 브랜드 로고는 마스킹 처리합니다.

  • 비공개 요청 가능 — 계약 시 알려주시면 포트폴리오 사용을 제외합니다 (추가 비용 10%).
  • 특정 페이지만 노출하거나 일부만 마스킹 처리 등 세부 조정 가능.
  • 비밀유지(NDA): 의뢰자가 제공한 원고 · 내부 자료는 작업 외 목적으로 사용하지 않습니다.
06 수정 범위 및 추가 비용 ＋

시안 확정 후 2회까지 무료 수정, 이후 유상 수정으로 진행됩니다(범위·비용은 별도 안내).

  • 무료 수정 범위: 단어 교체, 텍스트 오타, 페이지 순서, 일부 색상 미세 조정 등 부수적 변경.
  • 별도 견적 범위: 시안 확정 후 레이아웃 · 폰트 시스템 · 컬러 시스템 · 디자인 컨셉 변경, 본문 전면 교체 등 골격에 영향을 주는 수정.
  • 긴급 작업 · 반복 수정이 잦은 경우 별도 견적으로 사전 합의.

분쟁 해결: 본 계약과 관련된 분쟁은 우선 협의로 해결하며, 협의 불가 시 의뢰자 주소지 관할 법원을 1심 관할 법원으로 합니다.
