## 학교별 특이사항

### 강동고
- **학년 1**: 일반 패턴
- **학년 2 특수 카테고리** (parser 미분류):
  - `번호_영어` (19회): 단어 시험 — `1. The two cases...` 같은 번호+영문
  - `테두리_대화` (16회): 대화문 박스 — `Q: ... / A: ...`
  - `해석` (5회): `[한글 해석]` 패턴
- 페이스트보드에 미리 배치된 개체 (모든 spread 공통):
  - `⇓` 화살표
  - `<보 기>` 헤더
  - `<조 건>` 헤더
  → 사용자가 필요시 수동으로 끌어들이는 방식

### 명일여고
- 박스류 매우 세분화 (학년 무관 일관됨):
  - `테두리_순서삽입`, `테두리_보기`, `테두리_조건`, `테두리_다중선택`
- 다른 학교 대비 가장 정교한 분류 → parser와 매칭 양호

### 배재고
- `보기 테두리` / `보기 테두리_` → 거의 모든 박스에 사용 (학교 표준)
- `영어지문-순서` → 다른 학교의 `지문_순서`
- `표` 단락 → 표 안 텍스트 별도 스타일

### 상일여고
- 박스류 모두 `테두리`로 통일 (단순)
- 학년 2: `서답형 시작`, `서술형답지 사본`, `테두리_요약`, `테두리_일반` 추가

### 성덕고
- `테두리`로 통일 + `!선지` (특이 분류 — 다중선지/짝지어진 선지 추정)
- `순서` 별도 (지문_순서 외)

### 한영고
- 박스류 다양: `테두리`, `테두리_순서`, `테두리_조건`, `지문_순서 사본`
- 학년 1: 박스 종류 다양
- 학년 2: 단순화

## 결정 필요사항

### A. 매핑 전략

**옵션 A**: 학교별 STYLE_ALIAS만 추가 (현재 parser 그대로)
- 장점: 단순, 빠른 구현
- 단점: 강동 학년2 특수 카테고리, 명일 박스 세분화 손실 (정확도 70-80%)

**옵션 B**: parser 분류 강화 + 학교별 STYLE_ALIAS
- 추가: 단어시험(번호+영문) 패턴, 대화문(`Q:/A:`) 패턴, 해석(`[한글]`) 패턴, 박스 카테고리 세분화
- 정확도 90%+ 예상, 코드 복잡도 증가

**옵션 C**: 학년별 분기까지 (강동/상일)
- 정확도 95%+, 유지보수 부담

### B. 페이스트보드 별도 개체 처리

**옵션 1**: 그대로 두고 사용자가 수동으로 사용
**옵션 2**: 자동으로 페이지 안에 끌어들임 (예: `<보 기>` 박스 직전 단락 위에 배치)

### C. 학년별 분기 vs 학교 단위만

- 강동: 학년1 vs 학년2 매우 다름 → 학년별 분기 권장
- 다른 학교: 학년 1/2 비슷 → 학교 단위로 충분

## 자동화 정확도 목표

사용자 코멘트 ("사람의 손이 거의 안 닿고 검수만 하는 정도")를 만족하려면:
- 옵션 B + (강동 한정) 옵션 C
- 페이스트보드: 옵션 2 (자동 배치) 또는 사용자가 한번에 끌어들이는 매크로 제공
