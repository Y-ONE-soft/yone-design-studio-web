## 2. 사이클 규격

```
사이클(지문 1개) = A2 B2 C2 D2 E2 (10p 고정) + O n페이지(가변) + M 패딩(0~1p)
사이클 총 길이는 짝수 (좌우 파리티 보존) — O가 홀수면 M 1p 추가
```

정본 검증: 사이클 1·4·12 = `O3 + M1` → 14p / 나머지 = `O4 + M0` → 14p.
정본이 전부 14p였던 것은 그 회차 실전이 3~4p로 균일했기 때문이며 **14p는 규격이
아니다**. 실전 원고는 회차마다 달라 정본이 존재하지 않는다(사용자 확인).
M-마스터 페이지의 존재 이유는 **파리티 패딩**이다.

## 6. 알려진 함정 (이번 구현에서 실측)

- `PDF`, `prompt` 는 ExtendScript 내장 읽기전용 전역 — 변수명으로 쓰면 대입 실패로
  스크립트가 로그도 없이 죽는다.
- `pages.add()` 직후 기존 프레임 지정자(`itemByID` 포함)가 무효화된다.
  프레임 생성/페이지 삽입을 **먼저** 하고 대상을 나중에 resolve 할 것.
- 스레딩(`previousTextFrame` 대입) 직후 `parentStory` / `textContainers` 접근이
  "Object is invalid"로 실패한다. 저장 → 재오픈으로 참조를 새로 잡을 것.
- `Document.textFrames.itemByID()` 는 해석되지 않는다. `page.textFrames` 로 접근.
- 비워진 스레드 프레임은 `texts[0]` 접근이 무효 — `frame.characters.length` + 가드.
- iCloud(`Mobile Documents`) 경로에서 PDF export 중 InDesign이 크래시하며
  **기존 PDF를 0바이트로 덮어쓴다**. 빌드·export는 로컬에서.
- 업로드 슬롯 키가 결과 파일명에 남는다 (`indd_고2_26년_6월_세로.indd`).
