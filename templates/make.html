🪜 조립

작은 것부터 쌓아 책이 된다 — 부품 → 틀 → 스텝 → 책. 칸을 누르고 파란 단추를 누르면 오른쪽에 지면이 뜬다.

  • 1부품역할마다 지면 조각 하나 — 원고가 들어가는 자리
  • 2틀빈 칸 + 껍데기(머리말·탭·쪽번호) + 간지
  • 3스텝틀 + 부품 + 지문 n개 = 구간 하나
  • 4책스텝 넣고 빼고 · 순서 · 세로 → 견본 조판

역할 32종마다 원고 단락 하나를 그 역할의 부품으로 그린다.

터미널: book <책> make --what=parts

원고 없이 간지 3벌 + 틀 5종(a1·sheet·pair·flow·s3).

터미널: book <책> make --what=frames

스텝 하나를 고르고 지문 몇 개만 앉혀 본다(간지 포함).

터미널: book <책> make --what=step --key=<키> --n=2

체크로 넣고 빼고, ▲▼ 로 순서, 숫자로 지문 수 제한. 저장하면 견본(스텝마다 지문 2개)을 앉힌다.

    전권 PDF: book <책> all (몇 분). 구성만: book <책> select --exclude=… --order=… --limits=키=2 --cycle=on
