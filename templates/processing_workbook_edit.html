워크북 가공

워크북 .indd를 업로드하면 서버 작업 폴더에 격리해서 처리합니다. 다른 InDesign 작업과 섞이지 않습니다.

1. 워크북 파일 업로드

.indd 파일 하나를 업로드하세요. 업로드된 파일은 워크북가공/uploads/<타임스탬프>_<파일명>/ 폴더에 저장되며, 작업 후 백업·추출 결과도 같은 폴더에 모입니다.

2. 작업 모드

대상 스토리 (복수 선택 가능)
업로드하면 후보 스토리가 표시됩니다.

3. 서술형 제거 실행

선택 스토리에서 서술형 발문 묶음(발문+지문+답란)을 모두 삭제합니다.

3. 회차 식별

4. 삭제할 회차 선택

3. 원본 파일 경로

방금 업로드한 파일을 가공본으로 보고, 위 경로의 원본과 회차/발문 단위로 비교합니다.

3. 지문번호 탐지

문서의 지문번호와 섹션 구성을 읽어옵니다. (모의고사 [N]/{N}/{2606NN}/숫자프레임 자동 인식. 교과서·수능특강은 아래 라벨 형식 추가.)
