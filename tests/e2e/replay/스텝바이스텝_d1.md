## 막힘 기록

한 줄씩 — `문제 → 기능 추가 / 기능 수정(버그)` · 커밋.

- 01 · 재단 여백까지 칠한 면이 「넘침」으로 잡힘 → 기능 수정 (`db355ed7`)
- 01 · 재단선 없는 인쇄 PDF 받기 오류 → 기능 수정 (`db355ed7`)
- 01 · 글 굵기를 굵게/보통만 고를 수 있음 → 기능 추가: 「굵기」 칸 100~900 (`db355ed7`)
- 02 · 문단 안 일부 글자만 굵은 파랑 불가 → 기능 추가: GREP 스타일 (글상자 속성 「＋ GREP 규칙」)
- 02 · 공백 두 칸이 한 칸으로 줄어듦 → 기능 수정: 연속 공백 유지
- 02 · 지문 줄 끝을 인디자인처럼 못 고름(편집기는 한 줄씩 채움) → 기능 추가: 줄 나눔 Shift+Enter(양끝맞춤 유지, 인디자인 강제 줄바꿈)
- 02 · 양끝맞춤에서 꽉 찬 줄의 공백을 못 줄임(브라우저는 늘리기만) → 기능 추가: 「양끝 줄 낱말 최소 ‰」(인디자인 낱말 간격 최소)
- 02 · 그 칸이 한 줄 5칸 자리에 끼어 눌리지 않음 → 기능 수정: 칸을 다음 줄로
- 02 · 글줄 위치가 1mm 단위로 반올림(행간 7.76mm 가 8·8·7·8mm) → 기능 수정: 글 배치 해상도 10배(zoom)
- 02 · 자간을 주면 문맥 대체 글자·합자가 꺼짐(영도체 숫자·fi) → 기능 수정: 자간 있어도 liga·calt 켬
