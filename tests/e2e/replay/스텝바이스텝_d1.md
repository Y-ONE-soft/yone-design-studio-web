## 막힘 기록

한 줄씩 — `문제 → 기능 추가 / 기능 수정(버그)` · 커밋.

- 01 · 재단 여백까지 칠한 면이 「넘침」으로 잡힘 → 기능 수정 (`db355ed7`)

- 01 · 글 굵기를 굵게/보통만 고를 수 있음 → 기능 추가: 「굵기」 칸 100~900 (`db355ed7`)

- 02 · 공백 두 칸이 한 칸으로 줄어듦 → 기능 수정: 연속 공백 유지
- 02 · 지문 줄 끝을 인디자인처럼 못 고름(편집기는 한 줄씩 채움) → 기능 추가: 줄 나눔 Shift+Enter(양끝맞춤 유지, 인디자인 강제 줄바꿈)
